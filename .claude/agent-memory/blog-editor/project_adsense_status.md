AI_GOAP 개발 블로그는 아직 애드센스 계정이 없거나 Phase 5 이전 단계다 (2026-07-09 기준).

**Why:** 승인되지 않은 광고 코드를 미리 심으면 애드센스 심사에 불리하거나 정책 위반 소지가 있다. 승인 이후에는 Blogger 자체 "자동 광고" 기능이 템플릿 레벨에서 처리하는 경우가 많아, 수동 광고 코드 삽입은 필요성이 확인된 뒤에만 검토하기로 함.

**How to apply:** html_content를 생성할 때마다 광고 관련 태그/스크립트를 절대 삽입하지 않는다. 마스터 에이전트가 "애드센스 승인 완료" 또는 "Phase 5 진입"을 명시적으로 알려주기 전까지 이 정책 유지. 상태가 바뀌면 이 메모리를 업데이트할 것.
