# 클립 샷 직접 재검 = 산수 두 줄 (스틸 여덟 장을 대신한다)

**Why:** lf01(8분 롱폼)에서 검수 두 라운드가 **자막이 의심스러운 샷의 스틸만** 떴다.
의심스럽지 않은 샷의 **첫 프레임**은 아무도 안 봤고, 거기에 결함이 있었다 —
영상의 첫 3.0초가 사건 이전(텅 빈 벌판)인데 자막은 「지금 늑대 무리가 들어와 있습니다」였다.
롱폼은 클립이 8~10개라 스틸 전수가 비싸다. 산수는 공짜다.

**How to apply:** 카탈로그 `D:\AI_GOAP-videos\clips\library\library.json` 을 읽어
(영상 파일을 훑지 말 것 — 문법 §4) 샷마다 두 줄을 검산한다.

```
① 사건이 언제 오나   사건 시각(샷 기준) = preS − clip.in      → 목표 ≈ 0~1.0초
② 창이 충분한가      clip.out − clip.in ≥ 샷 길이(자막 dur 합 + 0.35)
```

- ① 이 **1.0초를 넘으면** 그만큼 죽은 화면이 앞에 붙는다.
  🔴 **콜드 오픈 샷이면 사유가 있어도 반려.** 첫 화면은 되돌릴 수 없다.
  뒤 샷이면 `source` 에 사유가 적혀 있는지 본다(예: `camDist` 가 커 카메라가 늦게 도착 →
  lf01 S23 은 `camDist 16` 이라 `in:6` 으로 앞을 잘라내 ① 을 음수로 만들었다 = 옳은 처리).
- ① 이 **음수**면 사건이 이미 지나간 뒤부터 보여 준다 — 상태(무덤·경보줄)를 보여 주는
  샷이면 정상, 「지금 벌어진다」고 말하는 샷이면 틀렸다.
- ② 를 어기면 엔진이 `want = min(tOut − 1/120, …)` 로 클램프해 **마지막 프레임이 얼고**
  그 정지가 `check.mjs` 정적 검사에 잡힌다.
  ⚠️ TTS 전에는 임시 타이밍(`PROVISIONAL_CPS 5.6`)이 실측(6.7)보다 20% 길어
  ② 가 만족돼도 정적 경고가 뜬다 — **TTS 전 클립 정적 경고는 결함이 아니다.**
  다만 TTS 뒤에도 남으면 그때는 진짜다.

스틸은 이 산수가 이상할 때 + **화면 문자열·개수·방향을 말하는 자막**에만 뜬다
(`node tools/scene-video/render.mjs <ep> --still <t>` — 엔진 스틸이 정본이고,
클립 스틸 `-a/-b/-c` 는 샷이 실제로 쓰는 창과 다를 수 있다).
