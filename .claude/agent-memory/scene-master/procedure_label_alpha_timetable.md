# 화면 글자 ③-b 재검 = **알파 시간표를 식에서 푼다** (스틸이 아니라 산수)

`ADR-V25-15` ②(`ep14s-2` 실패로 2026-08-10 신설) 재검 절차.
**Why:** 좌표 감사·겹침·잘림·팔레트 게이트가 전부 통과하는데 글자가 **최대 알파 0.145 ·
0.2초**만 뜨고 발화 개시 전에 사라진 사고가 났다. 스틸 한 장은 「그 순간」만 보여 주므로
**노출 길이를 못 잡는다.** 시간표는 식에서만 나온다.

**How to apply:**

1. **타임라인을 `timed.json` 에서 직접 재구성한다.**
   줄 길이 = `dur + pauseAfter`(밀리초) · 샷 길이 = 줄 길이 합 + `SHOT_TAIL 0.35`.
   `rel[i] = {t: 줄 시작(샷 기준), dur: 위 합}`.
2. **`cue`/`since` 원점을 안다** (`engine/engine.js:396-403`):
   - `cue(i, lead, span)` → `a = rel.t − lead` / `b = rel.t + rel.dur·span`, 0~1 clamp.
     🔴 **`lead` 는 초 단위 절대값이지 비율이 아니다** — 비율로 읽으면 창이 통째로 어긋난다.
   - `since(i) = ts − rel[i].t`. 시작 전이면 음수.
3. **`ease = smoothstep`** 이므로 `ease(u)=0.6 → u ≈ 0.566`, `ease(u)=0.4 → u ≈ 0.434`.
   이 두 수만 있으면 `ease(clamp((x−A)/B))` 꼴을 전부 뒤집을 수 있다.
4. 각 `ctext(...)` 의 **알파 인자**를 그대로 가져와 α=0.6 이 되는 시각 둘(뜨는 자리·지는 자리)을
   풀고 **길이**를 낸다. 곱해진 항이 있으면(`st·cardIn·cardA`, `grow²·cardA`) 다 곱해서 푼다.

**판정선 셋** — 하나라도 어기면 반려:
- **최대 알파**가 낮다(≲0.5). `ep14s-2` 실패치 0.145.
- **α ≥ 0.6 구간**이 짧다. 승인 하한 참고 = `ep14s-3` 최솟값 **2.34초**(13개 전부 최대 알파 1.00).
- 그 구간이 **그 글자를 부르는 나레이션의 발화 개시보다 앞서 끝난다.**

🔑 **알파가 clamp 로 1 에 머무르는 식이면 그 글자는 샷 끝까지 산다** — `ep14s-3` 의 조건 칩이
8.99초 노출된 이유다. 반대로 `1 − ease(...)` 꼴이 붙어 있으면 **꺼지는 시각이 있다**. 그것부터 찾아라.
⚠️ 스틸은 **확인 사살**로만 쓴다. 「그 시각에 보인다」는 「읽을 시간이 있다」가 아니다.
