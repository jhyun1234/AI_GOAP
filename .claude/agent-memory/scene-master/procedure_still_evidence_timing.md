# 임시 타이밍 스틸은 「후보 확인」이지 「채택 근거」가 아니다

**규칙:** 화면 문자열·개수·방향·존재를 말하는 자막은, **`build/timed.json` 이 생긴 뒤에**
그 자막의 실측 시각으로 스틸을 떠서 검증한다. TTS 전 스틸은 클립 후보를 고르는 데만 쓴다.

**Why:** lf01(롱폼 1호)에서 검수 1·2·3차와 **마스터 1차 판정까지** 전부 임시 타이밍
(`engine/engine.js` 의 `PROVISIONAL_CPS 5.6`) 위에서 스틸을 떴다. 실측이 들어오자
같은 자막이 클립 안에서 **3.5초 옮겨 갔고**, 「화면 오른쪽에는 무덤이 서 있고요」가
무덤 0기인 프레임 위에서 3.0초 내내 떠 있게 됐다(R7 · 반려 3회 → 사람 인계).
같은 자리가 세 번 깨졌는데 원인이 매번 달랐다 —
1차 = 스틸을 안 뜸 / 2차 = 뜨고 잘못 셈 / **3차 = 옳게 셌지만 사라질 좌표계에서 셈.**
「세는 방법」이 수렴했다고 원인이 없어진 게 아니었다.

**How to apply:**

- 임시 길이는 실측보다 **약 20% 길다**(`say.length / 5.6` vs 실측 ~7.0자/초).
  자막이 뒤로 갈수록 어긋남이 누적되므로 **회차 뒷부분일수록 위험**하다.
- 검증 시각은 손으로 세지 말고 `timed.json` 에서 뽑는다 — 필드는 `dur`·**`pause`**
  (`pauseAfter` 아님, 단위 ms). 샷 사이에 `SHOT_TAIL 350ms`.
  ```
  shot 시작 = Σ(앞 샷들의 Σ(dur+pause) + 350)
  line 시작 = shot 시작 + Σ(앞 줄들의 dur+pause)
  clip 시각 = clip.in + (line 시각 − shot 시작)
  ```
- **카메라가 움직이는 클립은 「사건이 프레임에 있는 구간」이 좁다.** `camDist` 가 크면
  그 구간을 먼저 찾고(스틸 2~3장) `clip.in` 을 거기에 맞춘다.
  창(`out − in`)이 샷 길이보다 짧아지면 **원본에서 더 길게 재슬라이스**한다 —
  lf01 이 `season-…-135` 를 18→23초로 그렇게 고쳤다(`recSec`·`preS` 불변이면 같은 녹화의
  같은 순간이므로 ADR-LF-5 연출 금지 위반이 아니다).
- 자막 문구를 안 고치고 클립 `in/out` 만 바꾸면 **TTS 재실행이 필요 없다**(재렌더만).
