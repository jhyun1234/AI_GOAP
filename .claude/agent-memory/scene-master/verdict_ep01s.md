**ep01s 재제작본 = APPROVED (2026-07-29). 누적 반려 1회** (1차 반려=`spoke`↔`ep00s/channels` 장치 중복 → `pins` 신설 → 2차 통과 → 마스터 승인).
판정서 = `tools/scene-video/episodes/ep01s/notes/verdict.md`. 109.7초(shot tail 포함) · 12샷 · 자막 33줄 · 그림 10종 전면 재제작.

**Why (이 회차의 본안은 "돌려막기가 실제로 끊겼는가"였다):**
옛 11종은 주석에 *"가이드 패턴 16(카드 그리드)"* 처럼 **라이브러리에서 고른 흔적**이 남아 있었고,
새 10종은 전부 *"이 글은 닿지 못하는 이야기다"* 라는 그 글 고유의 축에서 출발한다. 끊겼다고 판정했다.

**How to apply:**
- **돌려막기 판정은 파일 전문 대조 + 기계 대조를 같이 한다.** 주석 제거 후 토큰 Jaccard 를 재면
  이 리포에서 **0.4~0.5 는 `lib.js` 붓의 바닥값**이고 복사-붙여넣기는 0.8 을 넘는다. 유사도 상위가
  짧은 파일에 몰리므로(토큰 집합이 작아 값이 뜬다) 순위만 믿지 말고 상위 쌍은 눈으로 읽을 것.
- **원류를 확인하기 전에 "저 회차와 닮았다"로 반려하지 말 것.** ep01s `rebound` 와 ep00s `wire` 는
  "같은 그림 두 번(막힘→열림)" 장치가 문장까지 닮았는데, `git show HEAD:…/ep01s/kinds/stage2d.js` 와
  옛 scene.json(`"callback":"S1"`)을 보니 **원류가 ep01s 였다.** 0편이 1편의 장치를 이어받은 것.
- **이 회차가 정한 상한 3건 — 다음 회차가 선례로 인용하면 반려한다:**
  ① `rebound`/`pins` 공유 기하는 **3샷이 상한**(S1·S1B·S9). 4번째 샷·타 회차 반입 금지.
  ② "막힌 그림을 후반에 열어 되받기"는 ep00s·ep01s 가 다 썼다. 3번째 회차는 사유를 kind 주석에 적어 제출.
  ③ `latch` 의 좌우 from→to 박스 쌍도 이제 ep01s 어휘다. ep02s 가 "막힌 길"을 같은 배치로 그리면 반려.
- **검수팀 목록은 셈이 빈다.** 이번엔 "문서 지연 2곳"이라 했는데 `grep` 하니 3곳(`writer.md` 40·43·66)이었다.
  숫자가 붙은 보고는 항상 직접 세어 볼 것.
- **화면 밖 문서 지연은 렌더가 아니라 커밋을 막는다.** 반려 슬롯(상한 3회)을 화면과 무관한 사유로
  소모하지 않되, 판정서에 필수 조치로 못박아 다음 회차가 선례로 못 쓰게 한다.
