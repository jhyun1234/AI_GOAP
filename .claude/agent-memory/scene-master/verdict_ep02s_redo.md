# ep02s 재작업 = APPROVED (2026-07-30)

검수팀이 **리포에 없는 기준**(쇼츠 60초 상한)으로 반려해 83.6→47.9초로 잘렸던 회차를
사람이 되돌려 다시 만든 트랙. 반려 카운트는 사람이 0에서 다시 세도록 확정했다.
산출은 `-redo` 접미사(`review-redo.md` / `writer-redo.md` / `verdict-redo.md`).
샷 8→12 · 자막 15→28 · 렌더 47.9→87.3초. **마스터 반려 0회.**

## 🔴 화면 문자열 전수 대조는 손이 아니라 스크립트로

**Why:** 검수팀이 행 번호 표를 붙여 오지만 그건 검수팀이 스스로를 검사한 결과다.
손으로 표를 대조하면 표에 있는 것만 보게 된다.

**How to apply:** `scene.json` 의 모든 `spec` 값을 재귀로 뽑아(문자열+숫자, `*Cue` 제외)
공백·따옴표·가운뎃점을 지운 뒤 원문 본문에 `includes` 로 넣어 본다. ep02s 는 96개 중
36개가 미검출로 나왔고, **그 36개를 하나씩 열어 세 부류로 갈라야 판정이 된다**:

1. **화면에 렌더 안 됨** — 도형 파라미터(`fill` 은 막대 높이, `at` 은 가로 위치).
   `fillText` 인자인지 코드에서 확인해야 알 수 있다.
2. **렌더 전 익명화됨** — `wardline.js` 의 `KNOWN` 집합처럼 kind 가 필터링한다.
   JSON 에 지어낸 값이 남아 있어도 화면엔 안 나간다.
3. **원문 서술의 재기술(라벨)** — 이건 통과. 원문에 없는 **사실 주장**만 반려다.

🔑 **가장 값진 신호**: ep02s 재작업에서 **새로 들어온 4샷만 미검출 0건**이었다.
미검출이 옛 샷에만 몰려 있으면 "이번 작업에서 지어낸 것은 없다"가 기계적으로 증명된다.

## 🔴 "리포에 규정이 없다"는 통과 근거가 못 된다

검수 2차가 화살촉 가려짐을 통과시키며 *"리포 어느 문서에도 주인공이 가려지면 안 된다는
규정이 없으므로, 안 적었던 기준을 꺼내 반려하는 건 이 트랙이 존재하는 이유와 같은 잘못"*
이라고 썼다. **결론은 맞았지만 논거는 채택하지 않았다.**

**Why:** `reads` 훼손은 규정 목록 문제가 아니라 **마스터 승인 4조건에 직접 걸리는 항목**이다.
규정이 없어도 반려할 수 있고 해야 한다. "규정 없음 = 통과"를 선례로 남기면 다음에 진짜로
`reads` 가 깨진 컷이 같은 문장으로 통과한다.

**How to apply:** 가림·겹침·가독성 건은 **`reads` 의 비트별로 시각을 찍어** 판정한다.
가려지는 구간이 reads 가 아무것도 요구하지 않는 자리면 통과, reads 의 비트와 겹치면 반려.
ep02s 는 붙잡히는 순간(66.5s)·표식이 붙는 순간(70.5s) 둘 다 화살촉이 또렷해서 통과시켰다.
**"몇 초 가려졌나"가 아니라 "언제 가려졌나"가 기준이다.**

## 🔑 cue × 상태 = 동시 성립 조건은 창(window)을 계산해 봐야 안다

검수 2차가 놓친 것을 여기서 잡았다. `tripwire.js` 의 `trapLabel` 은
`tk > 0.02 && trapped` 동시 성립일 때만 그려지는데, `trapCue=2` 가 오르는 시각(샷내 5.50s)과
`trapped` 창(2.97~4.43 · 8.17~)이 **거의 안 겹쳐** 라벨이 샷 마지막 0.61초에만 떴다.
reads 는 이행됐으니 통과지만, 자막 길이가 조금만 달라지면 **한 프레임도 안 뜬다.**

**How to apply:** `reads` 가 "~하면 ~가 붙는다" 꼴이고 구현이 `cue(...) && 애니메이션 상태`
이면, `timed.json` 으로 자막 경계와 애니메이션 주기(`CYCLE` 등)의 창을 **직접 계산**한다.
스틸 한 장으로는 안 보인다 — 그 시각에 우연히 겹쳤을 수 있다.

## 🟡 원문이 안 준 수를 자막이 소리 내어 말한 자리 (다음 회차 금지)

`spec.count = 3` 과 자막 `이 셋`(S1) · `씬에 직접 놓은 셋은`(S2). 원문은
`직접 배치한 주민들`(복수)일 뿐 셋이라 한 적이 없다. 화면에 숫자 `3` 은 안 찍힌다.

**이번에 반려 안 한 이유**: S1 의 `이 셋` 은 같은 날 오전 1차 컷에서 내가 승인한 줄이고
S2 가 그걸 이어받았다. 오전에 통과시킨 단어를 오후에 반려하면 골대를 옮기는 것이 된다.

**How to apply (다음 회차):** 그림의 **자리 수**는 근거만 있으면 된다(ep02s 의 6칸=`Random.Range(1,7)`,
4칸=`테스트 4종`). 하지만 **자막이 수를 소리 내어 말하려면 원문에 그 수가 있어야 한다.**
🔴 `scene.json` `notes.수치_정직성` 이 "3(씬 배치 주민 수) … 전부 원문에 있다"고 적어 놨다.
**다음 회차가 이 문장을 선례로 인용하면 반려한다.**
