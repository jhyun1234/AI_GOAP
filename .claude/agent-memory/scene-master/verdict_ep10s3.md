# ep10s-3 「편한 기능을 일부러 지웠다」 = APPROVED (2026-08-08)

누적 반려 **0회**. 26.2초 / 본문 21.0 / 예고 2.7. `check.mjs` 24항목 전부 OK.
판정서 = `tools/scene-video/episodes/ep10s-3/notes/verdict.md`.

**Why:** 3편 분할의 마지막이자 **3막의 마지막 편**이라 예고가 막 전환을 여는 문이었다.
ep02s 가 정확히 이 자리에서 「원문 마지막 문단」을 예고 근거로 삼는 사고를 냈고 검수도
통과시켰기 때문에, 예고 사실성을 최우선 재검증 항목으로 잡았다.

**How to apply:** 아래 셋은 다음 회차에서 그대로 재사용한다.

## 1. 막 전환 예고는 URL 로 대조한다 (문장 대조 아님)
`Docs/영상_시리즈_구성안.md` 의 **행 URL** 과 `state/schedule.json` 의 `sources.<ep>.url` 이
문자 단위로 같은지를 본다. 제목·주제 칸은 표현이 흔들리지만 URL 은 안 흔들린다.
- ep10s-3: 구성안 26행(11 · 4막) URL = `sources.ep11s.url` ✅ / 27행(12 · M9) URL = `sources.ep12s.url` ✅
- 막 이름은 구성안 55·60행(`### 3막 · 다시 짓기 (영상 4~10)` / `### 4막 (영상 11~13)`)이 정본.
  훅 문구의 출처도 62행에 실재했다(「만드는 이야기 → 잃는 이야기」).
- 누수 검사는 `shots`+`spec`+`lines`+`hook`+`outro`+`hud`+`youtube` 를 한 문자열로 만들어
  다음 글의 고유 낱말을 기계로 센다(ep10s-3 = 밭·재해·터전·넷 전부 0).

## 2. 🔴 「스스로 다시 세었다」는 명단은 네 번째로 틀렸다
`sfx[].why` 가 전 회차 latch seed 를 「7(기본) = ep02s·ep03s·**ep04s-2·ep05s-2·ep05s-3**」로
적었는데 실제는 **41 · 67 · 37** 이었다. 하필 그 문장이 「옛 문서에서 베끼지 않고 다시 셌다」고
못박고 있었다. 결론(101·103 미사용)만은 참이라 반려하지 않았다.
🔑 **판정법: `why` 의 명단은 근거가 아니라 검증 대상이다.** 결론만 기계로 다시 세고,
명단이 틀렸으면 렌더 영향 유무로 반려/박제를 가른다.
전수 명령 = `episodes/*/scene.json` 의 `shots[].sfx[]` 를 node 로 훑어 kind별 dur·seed 출력.

## 2-B. 🔴 그 전수 표조차 근거가 아니다 — 파형을 쟀다
판정 도중 형제 편 **ep10s-1 이 바로 이 항목으로 반려**된 것을 알았다([[procedure_sfx_waveform_correlation]]).
그래서 `synth()` 로 상관을 직접 쟀고 ep10s-3 은 통과했다:
**sweep(dur 0.60 · seed 101) 최대 0.0217** / **latch(dur 0.145 · seed 103) 최대 0.7729**
(척도: 0.99대 = 같은 소리 반려 / seed 갈면 0.68~0.79 가 하한).
🔑 **교훈: 「seed 가 고유하다」까지 확인해도 아직 파라미터 표다.** 소리는 소리로 판정한다.

## 3. 넘긴 채 통과시킨 3건 — **선례로 인용 불가**
① `sfx why` 의 전 회차 seed 명단 오류 → 명단을 손으로 옮겨 적지 말 것(기계 출력만 붙인다).
② `trace.js` 머리주석이 `span 0.10`, 실제 코드는 `0.06` → **값을 고치면 그 값을 말하는 주석을
   같은 커밋에서 전부 grep 해 고친다.** 인라인에만 적으면 모순 문서가 하나 더 생긴다.
③ `rollback.js:173` 목수 고리 α0.45 흰색이 강조색 위 → `rgb(115,255,189)` 98px(0.012%).
   팔레트 게이트가 hue 152 로 읽어 **구조적으로 통과시킨다.** 다음 회차는 α1.0 + 밝기만 흔들기로
   원천 해소할 것. **「게이트가 통과시켰다」는 통과 근거가 아니다.**
