## 🔧 freq 전수는 반드시 스크립트로 낸다 (손으로 세면 두 번 다 틀렸다)

작성팀·검수 양쪽이 같은 표를 손으로 세다 연속으로 틀렸다. 마스터는 이 한 줄을 돌린다:

```
node -e "…episodes/*/scene.json + episodes/_archive/*/scene.json 를 순회하며
         shots[].sfx[] 를 kind 별로 freq 정렬 출력…"
```
빠지는 세 자리가 매번 같다: **`_archive/`** · **`freq` 미지정 줄(기본값 칸을 점유한다)** · **형제 편**.
