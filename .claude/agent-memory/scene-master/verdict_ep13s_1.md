## 🔑 kind 를 고친 회차의 재검증 = **격리 스틸 비교**

검수는 「1차 스틸 ↔ 2차 스틸」을 비교했는데 그러면 **kind 수정과 의도한 편집(라벨·인트로)이
한 프레임에 섞여** Δ>8 이 1,752 픽셀 나오고 「의도한 것이다」라는 *주장*으로만 갈린다.

```
scene.json 은 지금 것으로 고정 → kinds/ 만 옛 커밋으로 되돌린다
  git checkout <옛커밋> -- tools/scene-video/episodes/<ep>/kinds
  node tools/scene-video/render.mjs <ep> --still 7.6,15.123,18,24,30.2
  git checkout HEAD -- tools/scene-video/episodes/<ep>/kinds
비교 = ffmpeg 로 rgb24 원시 디코드 후 채널 바이트 절대차 (PNG 디코더 필요 없음)
```

이러면 남는 차이가 **오직 kind 수정의 효과**다. ep13s-1 에서는 Δ>8 이 **0픽셀**로 떨어졌다
(검수 설계에서는 1,752). `build/stills/` 는 gitignore 라 리포를 안 더럽히지만 **끝나면 지운다** —
마지막 렌더가 옛 kind 판이면 남은 PNG 가 거짓 증거가 된다.

🔴 **대조표에 「그 파일이 실제로 바뀌었나」 열을 넣어라.** 검수가 「SH·SO 비트 동일 = fillRect 판이
setLineDash 판과 일치」라고 썼는데 **`nextpeek.js`(SO)는 애초에 안 바뀐 파일**이었다.
안 바뀐 파일이 같은 픽셀을 내는 것은 아무것도 증명하지 않는다. `git diff --stat <옛> HEAD -- kinds` 먼저.

## 🔴 「봄」이 노트에 살아남았다 — 반려를 낳은 낱말은 `notes` 까지 훑어라

검수 2차가 「`episodes/ep13s-1/` 안의 「봄」 **0건**」이라고 단언했는데 실제로는 4건이었고,
그중 **2건은 지금 그림을 틀리게 서술**했다(`notes.그림 설계`, `notes.겹침 감사`).
같은 문단 안에서 한 문장은 「겨울 끝으로 바뀌었다」고 적고 다른 문장은 「봄」이라고 적는다.

- **화면은 옳다**(스틸로 확인) → 렌더 무관 → 승인 유지.
- 🔴 **통과 사유는 「노트라서」가 아니라 「화면이 옳다는 것을 픽셀로 확인했기 때문」이다.**
  확인 없이 같은 일이 올라오면 반려. **이 판정을 「노트 오류는 통과」 선례로 인용 금지.**
- `notes` 는 다음 작성팀의 **설계 정본**이다 — 낡은 서술이 남으면 반려된 결정이 되돌아온다.

## 잣대 확정 — 이 편에서 내가 확인한 것

- **`cue` 창 = `lead + rel[i].dur × span`** 이고 `engine.js:199` 에서 **`rel.dur = timed.dur + pauseAfter`**.
  `render.mjs:114` 은 `at = line.t + delayMs`(줄 시작 기준). 세 줄을 열어 검산하면 `delayMs` 는 손으로 풀린다.
- **아웃트로 카드 = `TOTAL − 3000`**(ADR-V25-10). 옛 메모의 `TOTAL − 2600` 은 폐기됐다.
- **한국어 라벨 판정은 kind 의 `fillText` 리터럴부터** — 하드코딩 문자열이 0개면 화면 글자 집합 = `spec` 전체다.
  그다음 `spec` 문자열에 로마자 정규식을 돌리면 전수가 기계로 끝난다.
- **HUD 의 `Claude Code`·`GOAP` 는 개정 ADR-V-10 예외 ③에 이름이 적혀 있고 `ep12s-3` 과 문자열이 동일** =
  시리즈 고정값이지 그 편의 선택이 아니다. 인트로 자막의 `AI` 도 §2-C 가 못박은 사용자 예시문이다.
- **버린 것을 되살릴 수 있나는 산수로 판정한다** — 본문 한 줄 ≈ 자수/6.58초 + pause.
  ep13s-1 은 되살리면 총 38.56초 > 상한 38 = fail 이라 **`excluded[0]` 이 길이 게이트로 강제**됐다.
- **길이 35.4초(warn)는 반려 아님** — 상한 38 아래 · 사용자 확정 35±3 · 선례 ep10s-2 37.93 · ep12s-1 36.1.
  🔴 warn 을 이유로 인트로·훅·예고·소개를 깎으라고 요구하면 §2-C(ADR-V25-9) 위반이다.
- **`cue(i)` 인덱스 접힘**: 줄을 빼면 `cue(1)` 이 **에러 없이** `cue(0)` 으로 접혀 그림이 조용히 고장 난다.
  `check.mjs` 가 못 본다. 길이를 줄이라고 요구할 때 `~Cue: 1` 을 쓰는 샷은 건드리지 말 것.
