# ep13s-3 = APPROVED (2026-08-10, 마스터 반려 0 · 검수 반려 0)

3편 분할의 마지막, 4막 피날레. 형제 둘은 각 1회 반려인데 **이 편만 검수 1차 통과**였고,
그게 사실인지 검수가 덜 판 것인지 가르는 게 판정의 특수 조건이었다.

**Why:** 검수도 같은 대본을 오래 본 상태라 작성팀 판단에 물든다. 「반려 0」은 무결의 증거가
아니라 **검증해야 할 주장**이다.

**How to apply:** 반려 0 보고를 받으면 검수의 **결론**이 아니라 **수치**를 재현해라.
ep13s-3 에서 8개 항목(게이트·총 길이·카드 시각·delayMs 둘·상관 둘·라벨 수)을 다시 쟀고
**전부 재현됐다** — 그래서 「덜 팠다」가 아니라 「작성팀 결함이 notes 산문에만 있었다」가 답이었다.
🔑 **검수 표에서 어긋난 것 2건을 찾았는데 결론은 안 흔들렸다**(상위 6쌍→7쌍 · thud 중앙값
0.074→실측 −0.045, 절댓값을 쓴 듯). **sfx 대조표가 틀리고 결론이 살아남는 건 이번이 세 번째다.**

## 🔴 시제 판정선 — 「완료형이 아니면 통과」는 형태가 아니라 **조건을 지는 방식**으로 본다

원문이 조건절(「그렇게 만들면」) 안에서만 말한 설계를, 자막이 완료형으로 옮기면 안 난 사고를
난 것으로 만든다. ep13s-3 은 15자리 전수에서 완료형 0건.

문제가 된 자리 = S2[1] 「0.1초만 스쳐도 **되감겨요**」(현재형).
검수는 *"원문이 조건절 안에서 쓴 현재형과 **같은 형태**"* 라고 통과시켰는데 **사유가 부정확하다** —
- 원문의 현재형은 「-니까요」가 **앞 문장의 조건절을 물려받아** 선다.
- 자막의 현재형은 **①앞 줄의 의도형(「되돌리려 했어요」) ②그 문장 안의 양보절(「-스쳐**도**」)** 이 진다.

**판정 규칙 3줄** (다음 회차에 그대로 쓸 것):
1. **완료형인가**(되감겼어요 / rewound) → 맞으면 즉시 반려. 현재형은 그 자체로 반려 아님.
2. **조건을 지는 것이 그 줄 안이나 바로 앞 줄에 있는가** → 없으면 반려.
3. **뒤집힘이 한 줄 뒤에 오는가**(「그래서 안 그랬다」) → 오면 「출시된 빌드가 그랬다」 독해가 성립할 자리가 없다.
🟡 남는 위험은 적어만 둔다: 그 줄만 잘라 보면 현재 사실로 읽힌다. 제목·훅이 미수형이면 반려 아님.

## 🔴 어미 연속을 「정정 요구」에서 「렌더 전 이행 조건」으로 올린 근거

`voice.json rules.1` = **「같은 어미 2연속까지, 3연속 금지」**(명문). ep13s-3 은 SH~S4 **7연속**
(뻔했어요·나아요·했어요·되감겨요·했어요·죽어요·생겼어요) = 규칙의 2.3배, 승인 최댓값(ep10s-3 의 5)+2.

**Why:** 게이트가 없어 한 번도 집행된 적이 없으므로 **단독 반려 사유로는 못 쓴다**(그 판단은 유지).
그런데 나는 ep12s-3 에서 이걸 **파이프라인 문제로 승격**시켰다 — 그 직후 편에서 시리즈 최고
기록을 그냥 통과시키면 승격이 무의미해진다. 게다가 비용이 **피날레의 착지 줄**에 얹혔다
(「마을의 마지막 날이 생겼어요」가 일곱 번째 같은 낙차).

**How to apply:** 반려하지 말고 **굽되, 재검증을 기계로 묶어라.**
- 고칠 자리는 **`sfx` 가 안 붙은 샷**에서만 고른다 → `delayMs` 가 안 움직인다
  (`sweep` 은 `since(i)`, `thud` 는 그 줄 자신의 `rel` 에만 매달린다).
- 🔴 **문안은 마스터가 정하지 않는다** — 정하면 검수 없이 나간 대본이 된다. 요구만 적고 작성팀에 돌린다.
- 재검증 = `check.mjs` 실패 0 + **S2·S4 자막 불변 확인** + **총 길이 외 게이트 값이 움직이면 재판정**.

## 🔴 thud 돌려막기 — 「8위」로 통과시켰고, 그건 이 편이 깨끗해서가 아니다

`synth()` 실호출 · 절대 표본 정렬 상관으로 리포 전수 190쌍을 다시 쟀다.
ep13s-3 `thud(0.36/108)` 최근접 = `ep05s-2(0.21/112)` **r = 0.8730 → 190쌍 중 8위**.
**이미 발행된 회차끼리 7쌍이 더 높다**(최댓값 `lf01(0.16/150)–lf02(0.17/150)` **0.9904**).
→ 승인돼 나간 일곱 쌍에 안 댄 잣대를 이 편에만 댈 수 없어 통과.

🔴 **진짜 원인은 회차가 아니라 관행이다** — `thud` 의 `freq` 미지정이 **기본 150 으로 몰려서**
lf01·lf02·ep03s 가 사실상 같은 소리를 낸다. 트랙 층위 숙제로 남았다(게이트 0건).
🔑 `KIT.thud` 는 `rng` 를 안 부르므로 `(dur, freq)` 가 파형을 완전히 결정한다 — **seed 로는 못 가른다.**

## 🔑 「굽기」 조건을 걸 때의 트리거 설계 — 실제로 작동했다

같은 날 작성팀이 두 줄(S1 `낫거든요` +1자 · S3 `하게 했죠` +3자)을 고쳐 최장 연속 2 로 내렸고,
**본문 19.2 → 19.6초**가 움직여 내 트리거에 걸려 돌아왔다(총 길이는 예외로 뒀는데 본문이 걸렸다).

**Why:** 「총 길이 외 게이트 값이 움직이면 다시 와라」로 걸었더니 코디네이터가 **자의로 통과시키지
않고** 가져왔다. 트리거를 **예외 목록으로 좁게** 적은 것이 주효했다 — 「이상하면 와라」였으면 안 왔다.

**How to apply:** 굽기 조건에는 항상 ①**안 움직여야 하는 것**(그 줄들의 `rel` = `delayMs` 유효성)
②**움직여도 되는 것**(총 길이) ③**나머지는 전부 재판정** 세 칸을 적어라. 재판정 때 재검할 것:
- `timed.json` 의 **손대지 않은 줄의 `rel` 이 한 자리도 안 변했는지** → `delayMs` 유효성이 여기 달렸다.
- 카드 오프셋은 **마지막 샷이 안 바뀌면 그대로다**(ep13s-3: 앞이 0.42초 밀렸는데 SO 안 오프셋 3,789ms 불변).
- 🔑 **어미 교체는 증량/감량 방향을 고를 수 있다.** 형제가 본문 하한에 붙어 있으면(ep13s-2 = 18.1,
  하한 18.0) 증량 쪽으로 고르는 게 맞다 — 실제로 `check.mjs ep13s-2` 로 확인했더니 참이었다.
- 🔑 어미를 바꾸면 **원문에 더 가까워질 수도 있다** — S3 「멈추기만 했어요」→「멈추기만 **하게** 했죠」가
  원문 *"멈추기만 **하도록** 했습니다"* 의 사역 구조를 되살렸다. 시제 재검에서 이걸 보고 가점 처리했다.

## 🔴 「일부 이행」 — 이번엔 반려 안 했고, 다음엔 반려한다

`publish` 전 조건으로 건 문구 정정 9건 중 **4건만** 반영된 채로 승인 요청이 왔다.
코디네이터가 「다 했다」고 주장한 적은 없어서(다른 트리거로 돌아온 것) **반려하지 않고 publish 를 막았다.**

**How to apply:** 문구 조건은 **`grep` 한 번으로 확인되는 칸 목록**으로 다시 적어 돌려보내라.
그리고 「다음에 부분 이행으로 오면 반려」를 명시해라 — 목록이 기계 검증 가능하면 그 예고는 집행 가능하다.
🔴 특히 위험한 잔존 유형 = **파일이 자기 값을 부정하는 문장**
(`notes` 가 「S4 는 1,400ms 어림값」이라 적었는데 필드는 실측 확정 `1375`).
🟡 재TTS 는 **옛 테이크 wav 를 유물로 남긴다** — 지우라고 시켜라(같은 편에서 두 번 생겼다).

## 다음 회차가 선례로 인용하면 안 되는 것

1. **최종 총 길이 35.6초(35,552ms) 통과** — 권장대역 초과 0.55초는 **내가 어미를 굽게 한 대가**이고
   값을 알고 시켰다. 사용자 35±3 허용 전례(ep10s-2 37.93)로 통과한 것이다. **목표로 삼지 마라.**
2. **thud r = 0.873 통과** — 「0.87 까지 괜찮다」가 아니라 「더 높은 발행 전례 7쌍이 있어 잣대를
   댈 수 없었다」이다. 관행이 고쳐지면 이 방패는 사라진다.
3. **어미 7연속** — 통과가 아니라 **구운 것**이다.
4. **`spec.hookCue` 는 금지 대상이 아니다** — 폐기된 것은 **캔버스에 훅 문구를 그리는 블록**이고,
   훅 샷의 cue 인덱스 필드명은 발행된 회차 다수가 쓴다(ep04s-1~). 이름만 보고 반려하지 말 것.
