# `ep14s-1` = **APPROVED** (2026-08-10) · 4편 분할 중 1편 · `ADR-V25-13`~`15` 첫 적용 회차

누적 반려 **0**(검수 0 · 마스터 0). 승인하되 **`publish` 전 `notes` 문구 정정 4건**을 조건으로 걸었다.
판정서 = `tools/scene-video/episodes/ep14s-1/notes/verdict.md`.

## 🔴 이 회차가 가르친 것 1 — **「화면」은 세 층이고 두 층은 회차 소관이 아니다**

**Why:** `notes` 의 단언 셋이 전부 거짓이었다. 전부 **캔버스(`kinds`)만 보고 쓴 문장**인데
프레임 전체를 주장했다 — ①「화면에 올린 수는 0개」인데 카드에 「곡식 6개」 2회 ②「「개인화」는
자막에도 화면에도 없다」인데 카드 `ocSrc` 에 「M11 개인화 경제」 ③「`GOAP` 를 버렸다」인데
HUD 둘째 줄이 **전 구간** 「…만드는 GOAP AI 마을 게임 개발일지」.
**값은 셋 다 옳다** — `ADR-V25-8` 고정 문안 · 구성안 문구 · 14-2 의 실제 제목에서 기계 파생.

**How to apply:** 낱말·수 전수를 받으면 **`spec` 만 보지 말고 세 층을 따로 세어라**
— ①캔버스 `spec`/`ctext` ②`scene.hud`(`hudTitle`·`hudOutro`) ③아웃트로 카드
(`outro.source`·`part`·`siblings`·`next`·`hook`·`hud.aiHook`). 카드는 `build/stills/` 의
마지막 장을 **눈으로 열면 한 번에 보인다**. 🔴 뒤의 두 층은 시리즈 고정이라 **회차를 반려하지 마라 —
노트 문장의 범위를 한정시켜라.** 명세 빈칸(§2-D 가 「화면」의 층을 안 정함)은 사용자 판단으로 이월.

## 🔴 가르친 것 2 — **피크 천장 초과는 「출력 피크」로 절대 못 잡는다**

**Why:** `synth()` 는 천장(0.46)에 걸리면 **스스로 gain 을 깎아** 내보낸다. 출력 피크는 정의상
0.46 을 못 넘으므로 「전수 재서 초과 0건」이 **항상 참인 거짓 검사**가 된다. 처음에 그렇게 재고
「코디네이터 발견(lf01 S20/S28)이 재현 안 된다」고 결론 낼 뻔했다.
**How to apply:** `console.warn` 을 가로채서 세라. 그렇게 재니 리포 전체 경고 **2건 = lf01 S20(0.062)·
S28(0.060)** 으로 코디네이터 값과 일치. `ep14s-1` 은 tick 0.3674 · drop 0.1235 로 여유.

## 🔴 가르친 것 3 — 브리프 `§6` 수치 원장이 **같은 수를 두 편에 동시 배정**한다

**Why:** `ep14s` 브리프가 「상한 8 ↔ 곡식 6개」를 **1편 재료**로 적고(§3 은 "1편 곁가지로 강력 추천"),
같은 §6 이 「곡식 6개 + 상한 8 + 곡식 4개」를 **2편의 가장 센 조합**으로 적었다. 그대로 따랐으면
형제 둘이 같은 수를 같은 뜻으로 썼을 것 — 브리프 자신의 유형④ 금지에 걸린다. 작성팀이 `excluded`
2번에서 되받아쳐 뺐다.
**How to apply:** 원장에 **「이 수의 소유 편」 열**을 요구하라. **재료 목록은 소유 목록이 아니다.**

## `ADR-V25-15②` 첫 실측 재검법 (검수는 개정 전 잣대로 본다 — 마스터가 다시 재라)

`timed.json` 으로 샷 `rel`(누적 `dur`+`pause`)을 세우고, kind 의 알파식 × **엔진 진입 페이드**
(`ENTER 0.26` · `0.12 + 0.88·smoothstep`)를 곱해 **α≥0.6 구간**을 수치로 훑는다.
- 잣대 셋: **최대 α** · **α≥0.6 총 길이** · **그 구간이 부르는 자막 개시보다 앞서 끝나나**.
- `ep14s-1` = 9자리 전부 max α **1.000**(ep14s-2 실패값 0.145와 자릿수가 다르다), 앞서 끝나는 것 0.

  소멸)는 **자기를 부르는 자막이 도는 동안 살아 있다가 다음 줄에서 지워진다** = `reads` 이행.
- 🟡 **S2 라벨이 자막 개시 +1.70s 에 켜진 것을 통과시켰다** — 근거는 「늦게 켜도 된다」가 아니라
  **「켠 뒤 자막이 1.6초 더 돌아 1.63초를 확보했다」**. 가이드의 ±20프레임으로 재면 51프레임 늦다.
