## 🔴 `ADR-V25-15` ③-b — 이 편의 실패가 만든 조항이고 이 편이 첫 통과다

1차 반려 사유 = **화면에 올린 글자가 읽을 시간이 없었다**(최대 알파 0.145 · 창 0.2초 ·
나레이션 발화 개시 0.310초보다 먼저 소멸). 그림은 라벨 없이 읽히는데 **정보를 지는 글자가
안 뜬** 반대 방향 실패. 정본 = `Docs/영상_25초_전환_실행명세서.md` `ADR-V25-15` ②.

**③-b 직접 검산식** (이것만 있으면 어느 회차든 푼다):
```
W = lead + dur×span            (cue 창 · dur 은 timed.json 실측 · rel[0].t = 0)
k = (ts + lead) / W
최종 알파 = (0.12 + 0.88·smoothstep(ts/0.26)) × (kind 안의 알파식)
                ↑ 엔진 ENTER 페이드를 반드시 곱한다 (engine.js:388)
```
재라는 값 셋: **최대 알파 · 알파 0.6 이상 구간 · 그 구간이 발화 개시보다 앞서 끝나는가.**
발화 개시는 wav 를 직접 읽어 **10ms 창 RMS>0.02** 로 잰다(ep14s-2 세 줄 0.310/0.460/0.480 —
검수와 소수 셋째 자리까지 일치했다).

🔑 **글자와 그 글자를 담은 상자는 한 몸이다.** 검수 1차 처방(`(k−0.34)/0.21`, 글자만 늦춤)은
**3.8px 상자 위에 13.5px 글자**를 만들었다 — 작성팀이 상자·띠까지 함께 밀어 넘어섰다.
**검수 처방을 작성팀이 넘어선 첫 사례.**

## 🔴 `latch` 파형 상관 — 정본 대역 (세 층이 전부 좁게 적었다)

리포 latch 전 인스턴스 **25개 · 300쌍** 전수 실측:

```
전체 대역           0.629 ~ 0.998
기본 seed(7) 쌍 제외  0.628 ~ 0.845   중앙 0.765
최댓값 0.9976 = (0.14,기본7) ↔ (0.16,기본7)  ← seed 미지정 두 편, 둘 다 발행됨
```
> **판정선: 0.85 이하 = 정상 대역, 그 수만으로 반려 못 한다. 0.99 대 = seed 미지정 신호.**

몸통이 340/680Hz 고정이라 seed 를 아무리 갈아도 이 아래로 안 내려간다.
🔴 옛 서술 **「0.68~0.79 이 하한」(작성팀)·「0.76~0.83」·「0.713~0.815」(검수)** 은 전부 실측이
아니다 — 인용 금지. ep14s-2↔14-3 = 0.7939 는 발행분 231쌍 중 **26쌍(11%)이 더 높다.**

2. 진행 식 `m` 에 **감소 항이 없는가**(단조 비감소면 루프 안에서 왼쪽으로 못 간다)
