# ep14s-3 = APPROVED (2026-08-10 · 마스터 반려 0 · 검수 반려 0 · `publish` 전 이행 1건)

4편 분할의 셋째. 형제 14-2·14-4 가 각 1회 반려인데 이 편만 검수 1차 통과 —
`ep13s-3` 과 같은 조건이었고 **이번에도 검수가 옳았다.** 검수 수치 **14개를 재현했고 전부 맞았다**
(`ep12s-1` 이후 처음으로 상관값이 한 자리도 안 틀린 회차).

## 🔴 「전수」의 정의를 넓혔다 — 검수의 전수에 **여섯 칸이 빠져 있었다** (일곱 번째 사례)

검수는 ⓐ`lines` ⓑ`spec` ⓒ`kinds/*.js` 의 `fillText` 셋만 셌다. **화면에 그려지는 문자열이 더 있다** —
`hud.title` · `hud.aiHook` · `hud.outro`(HUD 는 전 구간 상시) · `hook` · `outro.next` · `outro.siblings[]`(마지막 3초 카드).

**Why:** 「어려운 낱말 전수」의 사정권은 「대본」이 아니라 **「화면에 뜨는 글자 전부」**다.
빠진 칸에 실제로 **GOAP·AI** 가 있었다(면제 대상이긴 하다 — `ADR-V25-13` 고유명사 + `ADR-V25-8/10`
브랜딩 정본이라 회차가 손댈 수 있는 칸이 아니다).
**How to apply:** 전수 = `lines[].text/say/en` + `shots[].spec` 문자열 + `fillText` 리터럴
**+ `hud.*` + `hook` + `outro.next` + `outro.siblings[]`**. 앞 셋만 센 보고는 전수로 인정하지 않는다.

## 🔴 원문 **압축**은 어디까지 허용되나 (다음 회차 선례)

이 편은 화면 칩을 「자기 자신**을 대상에서** 제외」 → 「자기 자신 제외」,
「상대가 목수 **직업이기를 요구합니다**」 → 「상대가 목수**여야**」로 줄이고 `notes` 에
**「원문 어절 그대로」**라고 적었다. 문자열 대조로는 **0회 vs 1회**로 어긋난다.

**허용** — ①낱말이 하나도 추가되지 않는다(조사·어미·서술어만 줄인다) ②주어·대상·부정·조건이
안 바뀐다 ③라벨 폭 제약이 실재한다. → `ADR-V25-13` ①의 *"재료가 원문 안에 있어야 한다"* 를 충족.
**금지** — ①낱말 하나라도 원문 밖에서 오면 「지어낸 문자열」(`ep13s-1` 「봄」 형태)
②수식어를 떼서 범위가 넓어지면(「**밭의** 전제」→「전제」) 다른 주장이 된다
③부정·조건·수량 연산자(「~만」·「~뿐」·「없다」·「~면」)가 사라지면 반려.
🔴 ④ **`notes`·`source` 에 「원문 어절 그대로」라고 쓰지 마라** — 쓰는 순간 다음 검수가 문자열
대조로 재고 헛돈다. **「원문 어절을 조사만 줄여 옮겼다」**로 적는다.

## 🔴 `notes` 부분 이행 = **다음 회차부터 반려**로 승격했다

코디네이터 정정 2건 중 **하나만 제대로 됐다.** 둘을 가른 것은 **라벨 문장 한 줄**이다:
- ✅ `outro.siblings` — 「🔴 아래 옛 서술은 작성 시점의 기록이다」를 달아 옛 글이 **기록**으로 읽힌다.
- 🔴 `notes.길이` — `---` 아래에 산정식이 그대로 살아 있고 라벨이 없어서
  **「🔴 아직 인용할 실측이 없다」가 살아 있는 주장**으로 읽힌다(맨 위엔 실측 36.1초가 있다).

**Why:** `ep13s-3` 이 「특히 위험한 잔존 유형 = **파일이 자기 값을 부정하는 문장**」으로 지목한 그 형태다.
코디네이터가 스스로 자수한 뒤에 **절반만** 고쳤고, 마스터에겐 「갈아 끼웠다」로 보고됐다.
**How to apply:** 반려 대신 **`publish` 를 막고**, 조건을 **grep 한 줄로 검증되는 형태**로 적어 돌려보낸다
(`includes()` 셋이 전부 false). 조건에는 ①**안 움직여야 하는 것**(`shots`·`lines`·`spec`·`sfx`·
`youtube`·`outro`) ②움직여도 되는 것 ③나머지는 재판정을 반드시 적는다.
🔴 그리고 **`ep14s-4` 부터는 「고쳤다」 보고의 부분 이행 자체가 반려**임을 판정서에 박았다.

2. **`notes` 정정의 부분 이행** — `publish` 차단으로 끝낸 것은 이번이 마지막.
3. **형제 예고 빈칸 위치 어긋남**(`ep14s-2` 예고는 3번째 · 이 편 훅은 4번째) — 「어긋나도 통과」로 읽지 마라.
   시청자가 안 세서 넘겼다. 분할 회차는 예고 그림의 위치·개수를 본편과 맞춰 쓴다.
4. **thud 0.2164 / latch 0.794** — 이 편이 유난히 깨끗한 것이지 「이 정도면 된다」가 아니다.

   = **최소 34.4초**라 권장대역 30~34 는 도달 불가능. **대역 재조정은 사용자 판단 대기.**
