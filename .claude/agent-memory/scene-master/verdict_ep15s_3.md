`ep15s-3`(M12 성격 축 · **5편 분할 3편**) = **APPROVED 조건부**. 마스터 반려 0 · 누적 반려 1(검수 1차).
판정서 = `tools/scene-video/episodes/ep15s-3/notes/verdict.md`.

**Why:** 검수 2차가 통과시켰지만 **세 층 누구도 아웃트로 카드 프레임을 안 봤다.** 그 3초가
페이오프 카드다. 그리고 「전수」가 또 전수가 아니었는데, 이번엔 **내 기억의 전수 목록에도
없던 층**이 하나 나왔다.

**How to apply:** 아래 다섯을 다음 회차 판정에 그대로 쓴다.

## 🔴 ① 아웃트로 카드 × HUD 겹침 — 게이트가 0건인 자리 (신규 적발 유형)

**원인은 두 요소이고 하나만으로는 안 터진다** (전부 직접 렌더해 확인):

- **`hud.title` 2줄** → 진행 바가 **아래로 60px** 내려온다.

## 🔴 ② 화면 글자 「전수」 목록에 `shots[].chapter` 를 더한다 (9번째 사례)

화면 우상단 **칩**이다(`engine/engine.js:413` `chip.textContent = act.chapter`).
이 편 값 = `인트로 / 훅 / 어긋난 상태 / 피해 / 기각한 안 / 뒤집힘과 착지 / 아웃트로`.
**모든 프레임에 찍힌다.** 그런데 내 옛 전수 목록조차 이 슬롯을 이름으로 안 불렀다.

**현행 정본 목록** = `lines` + `spec` + `fillText` 리터럴 + **`shots[].chapter`** + `hud.*` +
`hook` + `outro.source/part/next/siblings` + `act`.
ep15s-3 실측 = **49칸**(작성팀·검수는 캔버스 `spec` 15종만 세고 「전수」라 적었다).

🟢 결론은 안 바뀌었다 — 영문은 `hud.aiHook`·`hud.outro` 의 `Claude Code`·`GOAP`·`AI` 뿐이고
`ADR-V-10` ③고유 기술명 예외다. **하지만 「영어 0개」라는 notes 문장은 HUD 층에서 거짓**이다
(`ep14s-1` 의 「세 층」 병).

## 🔴 ③ 검수가 **맞는 수를 틀린 수로 「정정」**했다 (새 유형)

`reachgap.js` swap 시점 표식 x. 참값 = `ease(0.90909) = 0.976627` → `150 + 156×0.976627 = 302.35`.
- 작성팀 **302.4** = ✅ 맞다 · 검수 **302.2** = ❌ 틀렸다(`mv 0.9755` 를 씀) · 최종 `≈302` = ✅

작성팀이 「네 번째 수를 안 만들려고」 반올림해 **검수의 오류를 우연히 흡수**했다.
🔑 **반올림으로 층 간 불일치를 덮는 것은, 참값을 먼저 구해 두 후보가 같은 값으로 떨어지는지
확인했을 때만 안전하다.** 302.2·302.35·302.4 가 셋 다 302 로 가서 살았다 — 참값이 302.45 였으면
틀린 값이 박제됐다. **참값을 계산한 층은 마스터뿐일 수 있다.**

## 🔴 ④ 「낱말보다 N초」 인용 금지 — 줄 기준을 먼저 적어라

S1 집 세우기가 낱말 「집」(0.85) 기준 **0.65초**로 한도 0.67 에 붙었다. **통과다.**
- **정본 기준점은 「그 줄」**(`scene-reviewer.md` §5) — 줄 기준이면 초과가 아예 없다.
- 낱말 기준은 **강화판**이고, 그것으로도 통과다.
- 「더 당기면 두 물체 상태」라는 검수 주장을 **기하로 검산해 성립**시켰다:
  `mv = ease((since(1)−1.00)/0.55)` · `cpx = lerp(150,306,mv)` →
  **swap 1.50 = x 302.35(집 306 과 3.65px)** vs **swap 1.20 = x 196.9(109px)**.
  0.3초만 당겨도 「날아가는 표식」과 「자라는 집」이 동시에 보인다.

## 🔴 ⑤ wav 어절 시각 측정법 = **정본 승격 판정함**

절차(작성팀이 `notes.wav 어절 시각 재는 법`·`writer.md` §9 에 박은 것):
**①말 끝을 먼저 잡는다 ②간극으로 절을 나눈다 ③간극이 없으면 자음 랜드마크**
(5ms hop · 저역 RMS 골 = 폐쇄음 · 고역 차분 RMS 버스트 = 마찰·파열음).

🟢 **내가 10개 wav 를 다시 떠서 검증했다 — 검수 값이 전부 재현**(Δ≤0.02초).
랜드마크 이름표까지 맞았다(wav01 「밖」의 ㅂ·ㄲ = 3.122·3.232 **정확히 일치**).
독립 증거도 나왔다 — 「**삼**」의 ㅅ 버스트가 **1.113~1.143** 에 있어 「삼십팔 개시 1.11」을 못 박는다
(초고의 「≈1.36」이 오염값인 것이 확정).

🔴 **정본 위치 = `.claude/agents/scene-reviewer.md` §5**(±20프레임 판정선을 못 박은 절)
**+ `scene-writer.md` 교차 참조.** 이유: **판정선이 있는 자리에 측정법이 없는 것이 사고의 구조다.**
§5 는 「그 낱말과 0.67초」라 말하는데 「그 낱말이 언제인가」를 정하는 법이 없어 세 층이 각자
`dur` 자수 배분을 썼다. 회차 `notes` 는 유일한 집이 될 수 없다(형제 다섯이 공유할 값).
`check.mjs` 는 아니다 — **게이트가 아니라 측정법**이고 wav 디코더가 필요하다.
⚠️ **지시서 개정은 마스터가 직접 하지 않는다** — 코디네이터가 사용자에게 올린다. 렌더 조건 아님.

🔑 **후행 무음 실측 대역 갱신 = 0.36~0.57초**(ep15s-1 5개 0.36~0.53 + ep15s-3 10개 0.46~0.57).
