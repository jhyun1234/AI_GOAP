# `ep15s-5` = **APPROVED (조건부)** — 2026-08-10 · M12 성격 축 5편 중 **5편**(밀스톤 착지)

이행 조건은 `notes` 문장 셋을 좁히는 것뿐(렌더·게이트 영향 0). 판정서 = `episodes/ep15s-5/notes/verdict.md`.

## 🔴 새로 정한 축 — **한 편 안에서 색의 뜻을 뒤집는 조건 넷**

이 편은 **강조색 = 로그(안쪽)에 다 있는 것 / 흰색 = 화면에 보이는 것**으로 시리즈 관행을 뒤집었다.
논지가 「**가득 찬 쪽이 바로 안 보이는 쪽**」이라서다. **승인했다. 조건은 넷이고 전부 필요하다:**
1. **회차 안 예외 0** — 그 회차 `kinds` 를 **전수로 읽어** 확인한다(층의 주장 말고).
2. **그 뜻을 회차가 스스로 가르치는 자리가 본문 첫 그림에** 있다(이 편 SH = 왼쪽 가득 / 오른쪽 빔).
3. **아웃트로(카드 + 미리보기)에서 축을 되돌려** 다음 회차로 안 물려준다.
4. 🔴 **읽힘이 색에 안 매달린다 — 라벨과 색을 둘 다 지워도 사건이 읽힌다.** **이게 통과의 몸통이다.**

🔑 검수는 1·3만으로 정당하다고 봤는데 **그 둘로는 부족하다.** 「규정에 없다」도 「스스로 일관된다」도
통과 근거가 못 된다(`ep02s` 재작업). 이 편이 통과한 진짜 이유는 `reads` 다섯 줄이 전부
**「채움 대 빔」**이라 **색의 뜻을 반대로 읽는 시청자도 결론에 도달**한다는 것이다.
🔴 **다음 회차가 「ep15s-5 가 뒤집었으니 나도」로 인용하면 반려한다.**

## 🔴 브리프 안에서도 **근거의 층이 갈린다**

`ep15s/notes/planner.md` **§4** 는 M13 을 *「로그에만 있던 이야기를 화면으로」* 라고 부른다 —
**M12 글 끝의 그 금지된 예고 문단의 표현 그대로**다(런북 함정 8 · ep02s·ep11s·ep12s 가 세 번 사고).
같은 브리프 **§8** 은 M13 파일을 직접 열어 소제목 「**문제: 무덤은 있는데 이름이 없었다**」를 뽑아 뒀고,
**작성팀이 §4 가 아니라 §8 을 골라** 사고를 피했다.
🔑 **「브리프에 있었다」는 근거가 아니다 — 그 칸이 무엇을 열어 봤는지가 근거다.**
🔑 이번 건은 **그 금지 문단이 우연히 같은 방향(로그를 화면으로)을 가리켜** 특히 위험했다.
밀스톤 전환 예고 문형은 선례와 동일: ep12s-3 「13편·」 · ep13s-3 「14편·」 · ep14s-4 「15편·」 · 이 편 「16편·」.
