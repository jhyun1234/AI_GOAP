  그것은 정본이 아니다. lf01 은 M19 화폐 구간에서 DRAFT 를 버리고
  `Docs/M19_…실행명세서.md`(사다리 2단)를 썼다. **DRAFT 를 인용한 회차는 반려.**
- 🔴 **§6 유도 궤도 확인은 `BLOG_COVERAGE.md` 를 연다** — lf01 의 「재설계·늑대·화폐」 셋 중

  memory 로 판단하지 말 것.
