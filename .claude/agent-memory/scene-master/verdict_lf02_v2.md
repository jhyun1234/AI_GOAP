# lf02 v2 (`format:"wide"` · 590.7초 · 27샷 · 자막 122줄) = ✅ **APPROVED — 조건부** (2026-08-10)

판정서 = `tools/scene-video/episodes/lf02/notes/verdict-v2.md`.
검수 1차 REJECTED(R1) → 2차 PASS → **마스터 APPROVED + 렌더 전 이행 4건**. 마스터 반려 0.
사용자가 `ADR-V25-13`~`15`(비개발자 규격) 신설 후 지시한 재제작. 정본 = `notes/remake-input.md`.

**Why:** 검수가 「전수」라고 쓴 어미 검사가 **2/4** 였고, 그 위에 세워진 세 갈래 선택지가
전부 무효였다. 그리고 v1 판정서를 열어 보니 **그 축을 아예 안 봤다**.

**How to apply:** 아래 다섯을 다음 판정에서 바로 쓴다.

## ① 🔴 「앞 버전이 통과시켰다」 = **선례인가 누락인가** — 판정서를 열어 가른다

검수가 *"v1 이 더 무거운 4연속을 안고 승인된 선례가 있다"* 를 근거로 판단을 넘겼다.
`git show HEAD:…/scene.json` 으로 **4연속이 v1 에 실재함은 확인**됐다. 그런데
v1 판정서(`verdict.md` 493줄)에서 `어미|연속|voice.json|말투` 를 grep 하니 **그 축을 판정한
절이 0개**였다 — v1 의 축은 사실 표본·행 번호·「로만」·유도·check·스틸·클립·구조·excluded 였다.

> 🔴 **못 본 것은 선례가 아니다.** 통과는 *판단의 결과*일 수도 *검사의 부재*일 수도 있고
> **둘은 정반대의 판정 근거다.** 「선례 존중」과 「새로 생긴 것만」이 동시에 무효가 되고
> **네 번째 갈래(전부 닫는다)** 가 남는다.
> 🔑 **검수가 준 선택지가 N개라고 답이 그 안에 있는 게 아니다** — 전제를 먼저 재라.

## ② 🔴 어미 연속 정본 축 = **문장 단위 + 「니다체」 통합**

`ep12s-3` 이 정한 축(*"`say` 를 `[.?!]` 로 쪼갠 문장 단위. 자막 **줄** 단위로 세면 통과로 보인다"*)에
**부류 묶음**을 더한다:

```
니다체 = 습니다 · 합니다 · 겁니다 · 입니다 · 봅니다 …  (/[가-힣]니다$/)   ← 전부 끝 억양 -니다
한다체(밟혔다·잡았다)는 니다체와 다른 부류다 — 섞으면 오탐이 난다
그 외: 거든요 / 더라고요 / 고요 / 네요 / 죠 / 예요 / 어요·아요 (voice.json 이 스스로 나눈 granularity)
```
lf02: 자막 122줄 → **149문장**. 줄 단위 = 5건(오탐 1 포함) · **문장 단위 = 4건 · 최장 4**.
v1 커밋본도 **4건 · 최장 4**. 🔑 **검수가 놓친 2건이 하필 「v1 에도 있던 것」** — 「전수」가
**자기가 찾은 것의 검증**으로 좁아진 형태다(여덟 번째 사례).

🔴 `check.mjs` 에 어미 검사는 **아직도 0건**이고 이번엔 **롱폼에서도 났다** — 게이트 신설
근거가 한 편 더 두꺼워졌다.
