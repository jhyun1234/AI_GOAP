**`d01s` = 커밋 직송 트랙(dNNs) 파일럿 1호** — 소재는 블로그 글이 아니라 세션 로그
(`devlog/sessions/2026-08-11.md`, M26-2차 W5R 「상주는 예약이다」). 2026-08-11 브리프 완료 →
`tools/scene-video/episodes/d01s/notes/planner.md` + `.staging/01_planner_brief.md`.
**후보 6 → 독립 사건 2. 2편 분할 권고**(①Day 0 유령 습격 배너 + F 명령에 주민 홀로 죽음 → 예약제
②그 예약제가 낳은 「눈앞의 증발」 → RTS 시야 규칙).

**Why / 이 회차에서 새로 판 것:**

🆕 **dNNs 에서 분할의 대가는 연속극과 다르다 — 「신선도」와 「공급」이 새로 붙는다.**
① 트랙의 존재 이유가 명세 §6 *"이번 주에 실제로 벌어진 개발 사건"* 이라 **편이 늘수록 뒤 편이
나갈 때 사건이 낡는다**(연속극은 두 달 전 이야기라 이 손해가 없다). ② 공급이 주 1~2편
사람 트리거(ADR-D-4)라 3편이면 다음 창에 재료가 쌓이기도 전에 3주를 당겨 쓴다.
③ 파일럿은 완주 직후 사용자 재판정이 걸려 있어(명세 §1) **재판정 전에 굳는 편 수가 적을수록 좋다.**
🔑 그래서 dNNs 의 분할 기본값은 **연속극보다 한 칸 보수적**이다.

🆕 **인용 전수 대조를 스크립트로 돌렸다** (표본 아님 — 부모가 요구). 패키지에서 인용문을
기계로 추출(`> ` 블록 + 표 셀의 `"…"`)해 7일치 로그와 정규화 후 부분문자열 대조 →
**76건 / 실체 불일치 0 · 표기 편차 2**(문장 중간 절단 1 · `...` 생략 1). 커밋 해시 8건 전수 실재.
🔑 **정규화가 대조의 전부다** — 줄바꿈(로그는 커밋 본문이 하드랩)·따옴표 중첩(패키지가 로그의
`"…"` 를 `'…'` 로 바꿔 인용)·굵게·이모지를 안 지우면 **전부 가짜 MISS 로 뜬다.** 실측으로
정규화 미비 때문에 21건이 헛불이었다.

🆕 **패키지에 없는 수치를 로그에서 역방향으로 찾는 것이 기획의 실질 부가가치다.**
scene-source 의 ② 수치표(15행)는 정확했지만 **로그에 있는데 안 담긴 수치가 11건** 있었고
그중 하나가 이 회차 최강 수치였다 — *"Play 10분이 게이트가 못 보는 결함 셋을 잡았다"*
(검사 477개 vs 사람 10분). 🔑 **역인덱스 방향(로그 → 패키지)으로 한 번 더 훑어라.**
게이트 총계도 패키지는 증분만 적어 **현재값 479 가 어디에도 없었다**(사람 메모리엔 478 이 남아 있다).

🆕 **낱말 벽의 새 유형 — 「게임 안 사물처럼 들리는 내부 상태 이름」.**
부화·무장·재무장·회수는 늑대·무덤처럼 들리지만 **게임에 그런 물건이 없다.** 「고유명사·게임 안
사물은 어려운 낱말이 아니다」는 잣대가 여기서 오작동하므로 **전부 목록에 넣었다.**
🟢 이 회차는 훅이 안전하고(결함 셋이 전부 화면 사건) **본문 가운데가 위험**하다 —
해결부(예약·부화·회수·히스테리시스·반경 부등식)가 통째로 도구 내부 규칙이라 `ep13s` 붕괴형이다.

🆕 **dNNs 분할 시 예고의 근거를 ADR-D-3 안에서 찾는 법.** ADR-D-3 은 예고 재료를
「같은 원문의 이월·다음 문장」으로만 정해 형제 편 예고의 근거가 없어 보인다. → **A2 처럼 같은
로그 파일의 「뒤쪽 사건」이면 문언 안에 든다.** 앞 편은 뒤쪽 사건을, 마지막 편이 패키지 ④(W6)를 쓴다.
🔴 **W6(위험 기억)이 무엇인지 로그가 풀지 않았다** — `nextpeek` 그림은 「당한 자리를 기억한다」
층위까지만. 기능 상세 창작 금지.

🔴 **파이프라인 실사 1건** — `publish.mjs:690` 의 형제 편 안내는 `sources[base].split` 을 읽는데
**dNNs 는 `sources` 에 키가 없다**(ADR-D-2). 즉 **분할해도 설명문에 형제 안내가 안 붙는다**
(라벨 정규식 `^ep0*(\d+)s-(\d+)$` 도 `d01s-1` 을 안 잡는다). 게이트는 안 죽는다 —
check.mjs 에 id 형식 검사가 없다. 형제 잇기는 아웃트로 자막 또는 사람 손.

🔴 **브랜드 §7 금기가 이 회차에서 특히 위험하다** — 결함 발견·해결 설계·1회 부화 폐기·밀도 지적·
표현 결함 발견이 **전부 사용자(사람)**다. AI 몫은 구현·게이트·13:44 확인뿐. 「AI가 스스로 잡았다」는
원문 위반 + 금기 위반 동시. 🟢 반대로 이 구도가 브랜드 §5 기둥 4(「사람이 한 일」)의 교과서다.
