ep09s(M7 상호대화와 가시성, **3막**)를 **2편으로 분할**해 브리프를 작성 (2026-08-07).
산출은 `.staging/01_planner_brief.md` **와 `episodes/ep09s/notes/planner.md` 두 곳** —
`.staging/` 가 회차마다 덮어써져 ep08s-2·-3 검수 기록이 유실된 뒤 마스터가 요구한 규약이다.

- 9-1편 = 성격·직업을 다 갈라 놨는데 화면에선 다 똑같은 점이었고, 이름표·정보줄로 점이 사람이 된 이야기
- 9-2편 = 말은 거는데 대화로 안 보였고, 반경 **4타일→2타일**·멈춰 마주보기·말풍선 우선순위로 말을 「장면」으로 만든 이야기
- 다음은 ep10s(**3막 그대로 · 막 전환 없음** · M8 관계·소유·부탁). 4막 전환은 11편이다.

**Why:** 이 글은 원문이 **3,777자로 시리즈 최단급**이고 **수치가 극히 얇다** — 9-1편의 사건에 붙은
숫자가 `M4·M5`·`5단계`뿐이라 제목 후킹(warn)을 억지로 채우면 지어낸 수치가 나온다. 그래서 브리프에
「없는 수치를 만들지 말고 첫 줄로 승부하라」를 못 박았다. 반대로 9-2편은 `4→2타일` 전후 대비 쌍이
원문에 아라비아 숫자로 실재해 제목감이 확실하다.
또 이 회차가 **ADR-V25-6(상한 28초) 적용 1호**다 — 25.0 을 칼같이 맞추다 예고가 6~7자로 쪼그라든
ep08s-2 사고 뒤 3초를 연 것이라, 길이를 예고에서 깎으면 개정 취지를 정면으로 어긴다.

**How to apply:** ep10s 기획 때 직전 회차는 `ep09s-2`. **ep09s 두 편의 실제 길이와 게이트 결과를
먼저 보라** — 28초 대역에서 본문 20초가 어떻게 잡히는지의 첫 실측이다. 그리고 ep10s 는 M7 이
미뤄 둔 숙제(표현 전용 대화 → 관계 축적)를 갚는 편이라 **9-2편이 깔아 둔 다리를 그대로 받는다**.
