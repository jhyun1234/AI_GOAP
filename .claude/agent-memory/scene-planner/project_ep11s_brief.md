ep11s(블로그 11편 · M8 후속 + M9 예고)를 **분할하지 않고 1편**으로 브리프 작성 (2026-08-08).
산출 = `.staging/01_planner_brief.md` + `episodes/ep11s/notes/planner.md`. `schedule.json` 무수정.

**여기서 막이 바뀐다 — 3막 · 다시 짓기 → 4막 · 잃을 수 있는 마을**(구성안 표 11행, URL 대조로 확인).
⚠️ 대조 함정: ep11s URL `…/claude-code-ai-unity-goap-ai.html` 과 번외편 URL
`…/claude-code-ai-unity-goap-ai-ai.html` 이 **끝의 `-ai` 한 조각 차이**다. 끝까지 대조할 것.

**Why(분할 안 한 근거):** 제목이 「빚 정산 + 경로탐색 경계」라 사건이 둘로 보이지만,
**경로탐색 경계(IPathfinder/ADR)는 1번 조각이 없다.** 원문이 *"잘 돌아가고 있고, 저는 이걸
건드릴 생각이 없습니다"* · *"알고리즘을 바꾸지는 않되"* 라고 직접 쓰고, 절 제목도
*"같은 작업 도중 던진 **질문**"* 이다 = 유형 ①(어긋난 상태 없음) + ②(없던 창구를 만듦 = 구현)
+ ③(고민은 뒤집힘 아님)에 동시에 걸린다. 관측된 실패가 0이라 25초 편의 0~3초 훅이
"언젠가 맵이 커지면 큰일 난다"가 되는데, **4막 개막편에 그 훅을 세울 수 없다.**
말풍선 3초 여운은 세 조각이 형식상 있으나 원문이 한 문단뿐(유형 ⑤) → 곁가지.
→ 사건 1개 = 「동속 추격은 수렴하지 않는다, 쫓아가기 전제를 버리고 빚+정산으로」.
직전 편 `outro.next` = 「11편 · 집을 다 짓고도 품삯을 놓쳐요」와도 정확히 맞물린다.

**수치 사정:** 원문 5,590자, `<table>`/`<svg>`/`<pre>` **전부 0개**(정규식이 지운 것 없음, 오염 0).
아라비아 숫자는 **`60초`(타임아웃 → 품삯 증발)가 두 번**, `1·2·3단계`, `3초` 여운뿐.
전후 대비 쌍 = 「60초 지나면 보상이 사라졌다 → 끝내 못 만나도 빚은 사라지지 않는다」가 유일한 제목감.
「수백 배·열 배」는 곁가지 절의 수치라 제목에 쓰면 제목 이행 게이트에 걸린다.
🔴 머리말에 `selected_commits_range` 주석이 없어 **커밋 수를 쓸 수 없다** — 브리프에 명시했다.

**How to apply:** ep12s 기획 때 직전 회차는 `ep11s`(분할 없음). ep12s = **4막 그대로**(막 전환 없음),
블로그 **13편** · M9 공간과 재해. 🔑 영상 12편 = 블로그 13편인 이유는 구성안이 블로그 12편(번외 ·
개발 방법론)을 본편 밖으로 뺐기 때문이다 — **원문의 "다음 개발일지" 문장으로 예고를 쓰면 안 되는
전형적 자리**이고, ep11s 는 우연히만 일치했다.
