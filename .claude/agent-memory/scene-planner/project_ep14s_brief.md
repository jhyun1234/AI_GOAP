**2026-08-10 완료.** `ep14s` = **4편 분할**(채널 첫 4분할). 후보 **21개 중 17개 탈락.**
브리프 = `tools/scene-video/episodes/ep14s/notes/planner.md`.

- `ep14s-1` 공용 창고를 지웠다(게으른 주민의 하루 끝이 농사꾼과 같았다 → 각자 주머니·곳간)
- `ep14s-2` 곡식 6개를 지닌 의뢰인이 거절당했다 → 원인은 **목수 자신의 주머니 여유 공간**
- `ep14s-3` 목수가 남의 집만 짓고 평생 노숙(부탁 스캔이 자기 자신을 제외)
- `ep14s-4` 성격별 거리를 줬는데 안 흩어짐 → 식사가 모닥불 앞에서만 = 모닥불이 중력

**Why (다음 회차에 그대로 쓰이는 판단 셋):**

1. 🆕 **「비개발자에게 30초 안에 성립하나」가 두 번째 축이 됐다**(`ADR-V25-13`~`15`,
   `ep14s` 부터). 세 조각이 다 있어도 이 축에서 떨어질 수 있다 — **Burst 크래시 역추적**이
   실례다(어긋남·뒤집힘·남는 한 줄 다 있고 드라마도 셌다). 사건의 실체가 **도구가 도구
   안에서 실패한 것**이면 대응하는 일상 개념이 없어 비유 없이는 성립하지 않고, 비유를
   그만큼 쌓으면 개발일지가 아니라 비유 모음이 된다. 실측 근거 = `ep13s-2`(같은 유형,
   본문 3줄 중 3줄 붕괴).
2. 🆕 **「이미 나간 앞 회차와 결론이 겹치면 세우지 않는다」** — 기존 유형④는 형제 편끼리의
   규칙이었는데 여기서는 **앞 회차와** 겹쳤다. M11 의 「간호 2단계로 몰림을 풀었다」는
   기제가 다른데도 시청자가 받는 문장이 `ep13s-3`(「간호 때문에 아무도 안 죽는다」)과
   같다. 🔑 확인법: **직전 회차의 훅 문장과 나란히 놓고 읽어 본다**(`outro.next` 만이
   아니라 `outro.siblings` 의 형제 문구까지).
3. **형제 편의 주인공이 겹치면 훅에서 갈라 세운다** — 14-2·14-3 이 둘 다 목수 무대인데,
   2편은 **거절당한 의뢰인**, 3편은 **집 없는 목수 자신**으로 주인공을 갈랐다.

**「어려운 낱말 목록」(§7) 쓰는 법** — 낱말을 **편별로** 나눠 적었더니 작성팀이 자기 몫만
보면 된다. 각 낱말에 ✅원문 풀이 그대로 / 🔺부분 / ❌풀이 없음 셋만 찍는다.
🔑 가장 값이 나간 발견은 **원문이 이미 쉬운 대체어를 준 자리**다 — 「앵커」→원문의
「기준점」, 「수령 공간」→「주머니 여유 공간」, 「인벤토리 선반」→「몸에 지닌 것·집 곳간」.
①풀어쓰기의 재료는 대개 **그 낱말 바로 앞뒤 문장**에 있다.
🔴 비유는 **절대 지어 주지 않았다**(기획팀 문구가 화면에 그대로 올라간 사고 2회).

**How to apply:** 도구 내부 사건이 많은 원문(M11 은 선반·컴파일러·클램프·Burst·게이트가
잔뜩)에서는 **편 배정 자체를 ②′로 걸러라** — 채택 4편은 전부 「사람에게 일어난 일」이다.
버린 사건도 곁가지로는 살려 두되 **0초 금지 + 원인 설명 금지**를 명시한다(Burst 건은
「목수가 집을 지어준 순간 게임이 멈췄다」까지만 허용, 분모 0 설명은 금지).
