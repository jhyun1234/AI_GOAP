**2026-08-10 완료.** `ep15s` = **5편 분할**(채널 최다, 직전 최다 `ep14s` 4편). 후보 **29개 중 24개 탈락.**
브리프 = `tools/scene-video/episodes/ep15s/notes/planner.md` (동일본 `.staging/01_planner_brief.md`).

- `ep15s-1` 성격 여섯이 말투만 달랐다(목표 30개 중 성격이 닿는 건 3개 → 24개 · 180칸 → 36줄)
- `ep15s-2` 굶주린 주민이 늑대 앞에 굳어 선 채 물렸다(배고픔 100 vs 도망 92 → 105)
- `ep15s-3` 떠돌이 목수가 38타일 밖으로 이사해 마을이 집을 못 얻었다(부탁은 6타일)
- `ep15s-4` 부탁 중에 지은 모닥불이 주인을 잃어 무한 건축
- `ep15s-5` 성공 기준은 통과인데 회상 테스트는 실패 → 「로그에만 있었다」(M13 으로 가는 다리)

**Why (다음 회차에 그대로 쓰이는 판단 넷):**

1. 🆕 **「수치 목록」에 슬롯표를 만든다.** `ep15s-2` 는 **100·92·105·110·95** 다섯 수가 전부
   같은 단위(우선순위)라 나열만 하면 작성팀이 조합을 지어낸다 — `ep13s-2` 의 「최소 비용 1→8」
   반려가 정확히 그것이었고, 브리프에 수가 다 있어서 **수치 게이트를 통과**해 버렸다.
   그래서 **값 → 붙는 슬롯 → 시점**의 3열 표를 넣고 「이 표를 벗어난 조합 금지」를 명시했다.
   🔑 발동 조건 = **같은 단위의 수가 셋 이상 한 편에 몰릴 때.** 타일(38/6/8)도 같은 처리를 했다.
2. 🆕 **수치가 정말 없는 편은 「찾아본 범위」를 적고 대체재를 준다.** `ep15s-4`(모닥불 무한 건축)는
   절 전체에 셀 수 있는 값이 0개였다. 「수치 없음」만 적으면 작성팀이 「모닥불 N개」를 지어낸다 →
   원문이 준 **양(量)의 인상**(「격자로 빼곡히」·「반경이 만원」)을 대신 재료로 지정했다.
3. 🆕 **②′(비개발자 30초)로 떨어진 후보는 표를 따로 만들어 롱폼(wide) 후보로 이관한다.**
   이번엔 넷이었고(ADR 전수 감사 · 겨울 조리 탐색 폭발 · 계측기 자체의 구멍 · **자동 검사가 내가
   방금 정한 값을 반려한 건**), 마지막 것은 **이 회차에서 드라마가 가장 셌는데** `ep14s` 의
   Burst 건과 같은 자리에서 떨어졌다. 각 후보에 **「롱폼에서 살 자리」**를 한 줄씩 붙여 뒀다.
4. 🆕 **앞 회차와 무대가 같으면 「훅 계약」을 브리프에 명문화한다.** `ep15s-3`(목수가 멀리 이사)은
   `ep14s-3`(목수가 자기 집이 없다)과 **결론이 겹칠 위험**이 있었다. 탈락(유형⑦) 대신 채택하되
   **금지 문구를 지정**했다 — 「부탁을 걸 상대가 없다」 계열 금지, 「성격이 목수를 마을 밖으로
   내보냈다」에서 시작. 🔑 판정 기준은 **피해자가 다른가**였다(14-3 = 목수 자신 / 15-3 = 마을).

**「어려운 낱말 목록」에서 새로 한 것** — 낱말 표 앞에 **편별 위험도 순위**를 붙였다.
이 원문은 훅이 쉬운데 **뒤집힘이 도구 내부**인 편(1편: 「배율표 → 여섯 축 벡터」)이 가장 위험했다.
🔑 그런 편은 **원문이 결과를 사람 말로 옮긴 문장**을 찾아 「①의 재료는 이 둘뿐이다」로 못 박는다
(여기서는 「서른여섯 줄」 문장과 **「숫자를 사람 말로 옮기면 이렇습니다」** 문단).
🔑 `ep15s-4` 는 반대 사례 — 화면은 최상급으로 쉽고 **원인 문장의 따옴표 셋**
(「무엇을 짓는지」·「누가 바쁜지」·「부탁으로 지은 집은 의뢰인 것」)이 전부 풀이라 ①만으로 완주한다.
