**`ep16s` = M13 「사건과 흔적」** (원문 `2026-08-04-unity-goap-m13-events-and-traces.html`).
2026-08-11 브리프 완료 → `tools/scene-video/episodes/ep16s/notes/planner.md` + `.staging/01_planner_brief.md`.
**후보 22개 → 사건 5개.** 5편 분할 **권고**(확정은 작성팀 — 부모 지시가 그랬다). 4편안(16-4를 16-3에 흡수)과 그 대가도 §0-C 에 적었다.

편별: ①무덤에 이름이 없었다 ②위험을 화면에 띄웠는데도 누구인지 몰라 못 구했다 ③명부를 만들었더니 한 사람이 명부를 덮었다 ④죽으면 관계까지 지워지고 있었다 ⑤같은 판을 다시 방치했더니 회상이 달라졌다.

**Why / 이 회차에서 새로 판 것:**

🆕 **커밋 로그가 사건 경계의 독립 검증 도구다.** `git log --grep` 으로 M13 구현 커밋을 뽑았더니
`feat(m13): A…` `B…` `C1…` `C2…` `C3…` 묶음이 **내가 센 다섯 사건의 경계와 그대로 맞았다.**
원문 서술 순서만 보고 세면 「같은 항목의 후속 보정」을 별개 사건으로 오인하기 쉬운데,
커밋 묶음은 그걸 한 덩어리로 묶어 준다(예: B 계열 커밋 5개가 전부 `ep16s-2` 하나).
🔴 다만 **커밋이 사건을 정하지는 않는다** — 탈락한 D 항목(`4d2c265b`)도 커밋 하나다.
커밋은 「내가 나눈 경계가 임의적인가」를 되묻는 용도다.

🆕 **낱말 벽의 새 유형 — 「같은 회차 안에서 화면 요소 이름이 여럿 겹친다」.**
M13 은 UI 이름이 셋이다(상태줄 · 정보줄 · 회고 명부). 낱말 하나하나는 안 어려운데
**편마다 다른 것을 다루면서 비슷하게 부르면 시청자가 같은 것인지 다른 것인지 모른다.**
처방은 비유가 아니라 **분리** — 각 편이 자기 편에 실제로 나오는 것 하나만 다루고 나머지는 언급조차 안 한다.
(`ADR-V25-13` 의 ①②③ 배정으로는 안 잡히는 자리라 브리프 §7 머리에 경고로 따로 적었다.)

🟢 **표현층 회차는 `ADR-V25-13` 조건이 유리하다.** 밀스톤 자체가 「콘솔에 있던 것을 화면으로 옮기기」라
채택 5편 **전부 사건의 실체가 화면에서 보이는 것**이다. `ep13s` 실측(도구 내부 동작 편이 본문 3줄 중 3줄 붕괴)의
정반대 조건 — 브리프에 그 사실을 적어 두면 작성팀이 불필요한 비유를 안 만든다.

🆕 **예고 대조가 처음으로 「완전 일치」로 끝났다.** `ep15s-5` 의 `outro.next` =
「16편 · 무덤에 이름이 없던 마을 이야기」이고 `ep16s-1` 이 그 사건이라 **이어받기 처리가 필요 없었다**
(`ep12s-1` 이 했던 첫 줄 이어받기 불필요). 대신 새로 걸린 것 하나 — **직전 편 `nextpeek` 의 수와 원문의 수가
다르다**(미리보기 동그라미 **셋** vs 원문 무덤 **일곱**). 미리보기는 그림이라 수를 안 세지만 본편은 수치 게이트를
받으므로, **원문이 정본**임을 브리프에 못 박았다.

🆕 **`order` 마지막 회차라도 「시즌 마지막」이 아니다.** `ep16s` 가 `order` 끝이지만 다음 글은 이미 발행돼 있어
(`2026-08-06` M14 가을과 겨울) `backlog.mjs --extend` 가 편입하면 `ep17s` 가 된다. 이 경우 예고 재료는
**`published/` 의 다음 발행 글을 직접 열어 밀스톤 층위로** 뽑는다(id 는 미정으로 두고 막은 말하지 않는다).
🔑 이번 건은 **두 정본이 같은 말을 한 좋은 사례** — M13 이 남긴 질문(「집과 밭이 있었는데 왜 죽었지?」)을
M14 가 자기 글 첫 문제(「준비된 자의 아사」)로 그대로 받는다. 분할에 흔들리지 않는 예고 축이다.

⚠️ **유형⑦(앞 회차와 겹침)이 이번엔 「수치와 인용」 층위에서 왔다.** `ep15s-5` 가 이미 자막으로 내보낸
「그냥 죽었어, 별 이야기가 없었다」 인용 · 「로그에만 있었다」 · 「노동 2%」 · 「전달이 0」이
**M13 원문에 그대로 다시 들어 있다.** 가만 두면 반드시 겹치므로 `ep16s-5` 에 재사용 금지 계약을 걸고,
그 편이 가진 고유물(「그 뒤에 내가 뭐라고 말했는가」)을 지정했다.

**How to apply:** 다음 회차 분할 판정 때 ①커밋 로그로 경계를 되묻고 ②UI·화면 요소 이름이 여럿이면
편 간 분리 계약을 브리프에 적고 ③직전 편 `scene.json` 의 `outro.next` **와 `nextpeek.spec` 의 수**까지 대조한다.
