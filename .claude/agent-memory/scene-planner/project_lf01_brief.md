# lf01 (첫 `format:"wide"` 롱폼) 기획 브리프 완료 — 2026-08-09

브리프 = `tools/scene-video/episodes/lf01/notes/brief.md`.
8마디 골격 정본 = `Docs/롱폼_영상_트랙_실행명세서.md` W8 / 문법 정본 = `Docs/롱폼_대본_문법.md`.

**Why:** 채널 정문 영상이라 특정 글의 각색이 아니라 창작 구성이다. 소재가 발행 글 10편 +
`Docs/` 명세서 + devlog 에 흩어져 있어, 마디마다 정본 경로를 못 박아 두지 않으면
검수(출처 명시 대조)가 성립하지 않는다.

**How to apply:** 다음 롱폼 회차에서도 아래 세 가지를 브리프 맨 위에 먼저 확인해 적는다.

## 1. 🔴 무인 촬영은 「플레이어 입력이 필요한 기능」을 구조적으로 못 찍는다

클립 226개 전수 확인 결과 `built` detail 은 **House·Campfire·FarmPlot 셋뿐**이었다.
M22 울타리·문, M23 계획 고스트, 수리·철거가 찍힌 클립은 **0개**.
이유 = 울타리는 B 모드 드래그로 **사람이 그어야** 생기는데 촬영은 무인 방치(ADR-LF-4)다.

→ 롱폼이 "최신 기능"을 다루려 하면 거의 항상 이 벽에 부딪힌다. 브리프 단계에서
**클립 카탈로그의 `kind`·`detail` 분포를 먼저 세고**, 없는 것은 ①촬영 세션 추가 요청
(사람이 조작한 판) ②캔버스로 대체 중 하나로 못 박아 작성팀에 넘긴다.
🔴 디버그 강제 스폰은 ADR-LF-5 반려 사유 — 대안으로 제시하지 말 것.

예외적으로 M23 행동 모션은 찍혔다(`built-260809-0424-39` = 망치 든 목수).

## 2. 게임 HUD 좌상단은 항상 있고, 그게 곧 M13 의 결과물이다

스틸 6장 전부 좌상단에 `Day N · n년째 계절` + 상태 알림줄(최대 4줄)이 있다.
엔진 wide HUD 제목 띠와 겹칠 수 있어 문법 §4 반려 사유 후보.
🔑 그런데 그 알림줄이 M13 표현층 산출물이라 **숨기면 ⑥마디의 증거가 사라진다.**
기획 의견 = 숨기지 말고 엔진 HUD 제목을 짧게. (사용자/마스터 판정 대기)

## 3. "전말은 시리즈에서" 유도의 궤도 확인처

ADR-LF-7 은 유도 대상이 발행 궤도에 있는지 검수하라고 한다. 확인처 둘:
- 쇼츠 진도 = `tools/scene-video/state/schedule.json` 의 `order` 마지막 (2026-08-09 = `ep13s` = M10)
- 블로그 대기열 = `tools/blog-automation/BLOG_COVERAGE.md` 154~164행 (M14→M15→M16→M17→M18)
화폐(M16~M18)는 이 대기열에 있으므로 유도가 성립한다. M19 글 자체는 DRAFT 라 사다리 1단 불가
→ 화폐 발췌는 `Docs/M19_화폐전면철거와_실물마을_실행명세서.md` 에서.
