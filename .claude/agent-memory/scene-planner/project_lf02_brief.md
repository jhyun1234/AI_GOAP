  「자잘한 구현은 맡기고, 게임의 방향을 바꾸는 결정은 제가 쥔다」(M11 글 138행).

## 골격 (콜드오픈 + 챕터5 + 마무리)

간호 비용 「1」 사고(콜드오픈) → 무엇이 만들어졌나 → 명세가 코드에 선행 → 사람 몫과
AI 몫의 경계 → AI 는 실수한다 그래서 게이트 → 기억 잃는 동료에게 사고법을 남기다 → 마무리.
검색 의도 5개(S1~S5)를 챕터 하나씩에 매핑했다 — 챕터가 어느 의도도 안 갚으면 잘라라.

🔑 **차별점은 S4(실패담)**다. 검색 결과의 "AI로 게임 만들기"는 대부분 성공담인데,
이 리포에는 AI 가 저지른 실수가 커밋·명세서에 그대로 남아 있다
(실패 불가능한 테스트 3회 · 감쇠율 산수 착오로 전원 아사 · 셸 일괄수정 YAML 파괴를
게이트가 잡음 · `git add -A` 사고).
