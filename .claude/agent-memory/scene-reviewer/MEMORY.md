- 🔴 [효과음·라벨의 **말 축**은 wav 를 열어야 나온다](review_method_sfx_timing.md) — cue 역산식 + **`dur` 을 글자 수로 배분 금지**(선행 0.29~0.51 · **후행 0.46~0.57** 이 늘 붙는다 · 오차 0.72초) · 간극이 없으면 **자음 랜드마크**(고역 버스트 ㅅㅈㅍㅌ · 저역 골 ㄱㅂㄷ)로 짚어라 · **줄마다** 재라(내가 ep15s-3 에서 한 줄만 재고 두 번 틀렸다) · 🔴 **후행 무음도 0.50~0.56초 붙는다 — 어절 시각을 `dur` 로 배분하면 0.7초까지 틀린다**(20ms RMS 포락선 + 내부 무음 **길이 순위**로 절 경계를 떠라 · 짧은 dip 은 파열음)
- 🔴 [효과음 겹침 = synth 파형 상관 + 통제군](review_method_sfx_waveform_correlation.md) — 절대 표본 정렬(리샘플 금지) · **tick·drop·thud·riser·pad 는 seed 를 안 읽는다** · latch 바닥 0.74~0.83(**승인 253쌍 분포 중앙 0.809 를 같이 내라**) · **길이 다른 kind 간 r≈0.3 은 패딩 인공물** · 진짜 피크는 `peakCeil:99` · 🔴 **사인 글라이드는 낮은 r 이 무죄가 아니다 — `dur`+`from` 이 같으면 같은 소리**(위상 반주기 T½ + 포락선으로 판정 · ep15s-2 반려) · 🔴 **반음 거리로 반려하기 전에 승인·발행분 전체 쌍 분포부터 내라**(drop 120쌍 = min 0.00 · 중앙 2.32 — ep15s-3 을 1.16반음으로 반려할 뻔했다) · 🔴 **한 쌍이 아니라 kind 전수 census 를 한 번에 내라** — 판정이 「통제군 어디인가」로 끝나고, ep02s↔lf02 drop **r=1.000**(발행분 둘) 같은 자리는 그때만 보인다
- [동색 가림 · clip 이음매 글자 복제](review_method_same_color_and_clip_seam.md) — 빗금 위 같은 색 라벨과 clip+translate 이음매는 혼합 픽셀이 0개라 게이트가 구조적으로 못 본다. 확대 스틸 + 테두리 한 행 샘플
