그 신호를 놓치면 무한 왕복이 된다.

  끝난 시점부터"** 다. 자막 한 줄만 세면 절반쯤 작게 나온다.
- **`git status` 를 반드시 본다.** 씬 파일만 고쳤다는 보고와 달리 `engine/kinds/bars.js` 와
  `scenes/ep01s.json` 이 함께 바뀌어 있었다. 엔진 변경은 다른 회차로 파급되므로

  기준을 사후에 흔들지 않기 위해서다.
