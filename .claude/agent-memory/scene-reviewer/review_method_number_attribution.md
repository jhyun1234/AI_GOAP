화면·자막의 수치를 대조할 때 **`grep` 으로 그 수가 리포에 있는지 확인하고 끝내지 마라.**
그 수가 **원문에서 어느 사건에 붙어 있었는지**까지 맞춰라. 사건이 다르면 반려다.

**Why:** 이 파이프라인에서 「사실 대조를 통과한 사실 오류」는 거의 전부 이 모양이었다.

| 회차 | 자막·화면 | 원문에 실재하는가 | 무엇이 틀렸나 |
|---|---|---|---|
| `ep11s` | 「목수가 집 짓고 **품삯 주러** 쫓아가요」 | 낱말 전부 실재 | **방향**이 반대(목수는 알리러 가고, 품삯은 의뢰인이 준다). 검수·마스터 두 층 통과 후 **사용자가 잡았다** |
| `lf02` v1 | `identity` 판의 행 번호 `03`·`06` | 03·06 이라는 수는 흔하다 | 그 인용문의 **실제 행은 4·5**. 검수 3라운드가 「정본 근거」라며 통과시켰고 마스터가 잡았다 |
| `lf02` v2 | 「위협 넷을 통째로 갈아 끼울 때도 **게임 코드는 0줄**」 | 「게임 코드 diff 0줄」이 커밋 본문에 **글자 그대로 실재** | 그 문자열은 **W6(그림 배선 `83fea176`)** 의 DoD 다. 자막이 말하는 사건은 **W1 교체(`665f79cc`)** 이고, 정본이 그것을 「코드 **14파일**」로 센다 |

세 번 다 **낱말 대조·`grep`·숫자 존재 검사는 전부 통과**했다. 갈린 것은 귀속이다.

**How to apply — 행위·수치 문장마다 네 가지를 따로 묻는다:**

1. **그 수가 원문에 있는가** (기존 검사)
2. 🔴 **원문에서 그 수는 어느 사건·어느 커밋·어느 절에 붙어 있었나** — `source` 가
   사건 이름까지 적고 있지 않으면 그 자체가 정정 요구다. 「§W1 … / §W6 …」처럼
   **두 근거를 한 문장으로 이어 붙인 `source` 는 특히 의심하라** — 대개 뒤엣것의 수를
   앞엣것의 사건에 붙인 것이다.
3. 🔴 **주어가 같은가 · 방향이 같은가** (누가 누구에게 · 주러/받으러)
4. 🔴 **그 사건을 정본이 스스로 몇으로 세는가** — 명세서의 「대상 파일」·「DoD」·`git show
   --numstat` 이 다른 수를 대고 있으면 그것이 반증이다.

**검산 명령 (커밋을 근거로 든 수치)**

```
git log -1 --format='%H %ad %s' <sha> --date=iso     # 그 커밋이 정말 그 사건인가
git show --numstat --format="" <sha>                 # 「N줄」 주장의 반증
git show <sha> -- '<경로>' | grep -E '^[+-]' \
  | grep -vE '^[+-]\s*(///|//|\*)'                   # 주석·툴팁을 걷어낸 실질 변경
```

🔑 **실질이 참인데 문장이 거짓인 경우가 있다.** lf02 v2 의 W1 은 `Assets/Scripts` 42줄이
전부 주석·`[Tooltip]` 문자열이라 **실행되는 문장은 0줄**이었다. 그러니 반려하면서
「거짓말이다」가 아니라 **「이 축으로는 참이니 그 축을 자막과 `source` 에 적어라」**를
처방으로 줘라 — 재료를 죽이지 않는 것이 이 트랙의 규율이다.
✅ **그 처방이 실제로 통했다**(lf02 v2 2차): 「게임 코드는 0줄」 → 「**게임이 돌아가는 코드는
한 줄도 안 고쳤고요**」. 수를 바꿔 맞추지 않고 **참인 축을 이름으로 부르는** 형태다.

🔴 **「주석뿐인가」는 눈으로 훑지 말고 분류기로 세라.** 비대칭 diff(`11+/8−`)에서 눈이 흔들린다.

```
git show --format="" <sha> -- <경로> | grep -E '^[+-]' | grep -vE '^(\+\+\+|---)'
  → 각 줄을  ///  ·  //  ·  [Tooltip]/문자열 인자  ·  **그 외**  로 분류해 센다
  → 「그 외 = 0」이어야 「실행 문장 0줄」이 증명된다
```
lf02 v2 실측: **81줄 = 37(`///`) + 22(`//`) + 22(Tooltip) + 그 외 0.**

🔑 **같은 수 문자열이 한 샷에 둘 있어도 판정이 갈릴 수 있다.** lf02 S23 의 「0줄」 둘 중
`/2` 는 `Docs/CLAUDE.md` **비용표(일반 규칙) 직접 인용**이라 참이고, `/4` 는 **특정 커밋의
실측치**로 말하면서 다른 커밋의 수를 빌려 와 거짓이었다.
**「규칙 인용」과 「사건 실측」은 별건으로 판정한다.**

⚠️ **반대로 이걸 근거 없는 의심으로 쓰지 마라.** 사건이 같고 수도 같으면 통과다.
lf02 v2 의 나머지 여덟 값(47·1,061·839·125·22,478·121·34·433)은 전부 같은 커밋
트리에서 다시 세어 소수점까지 맞았고, 그런 자리는 지적하지 않는다.
