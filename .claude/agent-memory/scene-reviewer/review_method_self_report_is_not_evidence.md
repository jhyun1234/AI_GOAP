**「고쳤다」는 보고는 근거가 아니다. 항목마다 파일과 실측으로 다시 확인한다.**

**Why:** 2026-08-04 2차 검수 여섯 편에서 실제로 나온 것 —
- `ep05s-1`: 넷 중 **둘만** 고쳐졌고, 1차 정정 요구 6건은 **한 건도** 안 고쳐졌다.
  `git diff` 로 확인하니 `scene.json` 실질 변경이 sfx 한 덩어리뿐이었다(나머지는 재포맷).
- `ep05s-2`: 1차 반려가 *"세 자리를 갈아라"* 였는데 **한 자리만** 고치고 나머지 둘은
  원문 그대로였다. 커밋 메시지에는 *"뿌리를 뽑는다"* 라고 적혀 있었다.
- `ep04s-3`: *"0.19/seed41 로 옮겨 **해소했다**"* — 재 보니 상관이 오히려
  **0.7460 → 0.7761 로 올랐다**(더 닮았다).
- 세 회차가 *"현역 12회차 sfx 56건"* 을 적었는데 실측 **46건**이었다
  (56 = 46 + **같은 커밋이 지운** 고아 넷의 10건).

**How to apply:**
- `git diff <이전커밋> HEAD -- <그 파일>` 로 **무엇이 실제로 바뀌었는지 먼저** 본다.
  자기보고와 대조하기 전에. → [[review-method-what-changed]]
- 숫자 주장은 **재현 명령을 직접 돌린다.** 전수는 그 시점에 다시 세고, 파형 유사도는
  `synth()` 를 실호출해 상관을 재고, 프레임 계측은 헤드리스에서 뜬다.
- 1차 리포트에 적힌 정정 요구를 **표로 만들어 열림/닫힘을 하나씩 표시**한다.
  "대체로 반영됨" 같은 판정을 내리지 않는다.

## 🔴 내 처방이 틀렸을 가능성을 같이 검산하라

`ep04s-3` R-1 은 **검수가 반려를 철회**했다. `latch` 는 몸통이 340/680Hz 고정이라
`dur` 을 바꿔도 음색이 안 변하고, seed 가 다른 쌍은 **0.72~0.78 을 못 벗어난다** —
그게 이 합성기의 하한이다. *"더 갈라라"* 는 **달성 불가능한 요구**였다.
게다가 같은 편의 `thud×3` 은 통과시키면서 `latch×2` 만 반려해 **잣대가 달랐다.**

- 반려하기 전에 **그 처방이 물리적으로 가능한지** 먼저 확인한다.
- 같은 종류의 중복을 회차 안에서 **다른 기준으로 재고 있지 않은지** 본다.
- 철회할 일이면 철회하고 사유를 적는다. 3회차까지 끌지 않는다.
