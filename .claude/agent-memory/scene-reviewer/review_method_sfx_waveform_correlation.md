# 효과음 겹침은 **절대 표본 정렬 상관**으로 재고, 통제군을 같이 낸다

**Why:** 같은 쌍이 검수 0.851 / 마스터 0.595 로 갈린 전례가 있다. 갈린 원인은 정렬 방식이다 —
**정규화 위치로 리샘플하면** 길이가 다른 같은-seed 쌍이 상쇄돼 −0.02 까지 떨어진다.
그리고 `seed` 가 같아도 kind 가 다르면 상관이 0 인데, 파라미터 표만 보면 「seed 191 이 겹친다」로
잘못 반려하게 된다(ep13s-2 latch 191 ↔ ep13s-3 sweep 191 실측 **r = 0.0007**).

**How to apply:**

```js
// synth(kind, {...opt, gain:1}, 44100) 로 뽑고, 짧은 쪽을 0으로 채워 길이를 맞춘다.
// 🔴 리샘플 금지.
const corr = (a,b) => { const n=Math.max(a.length,b.length); let sa=0,sb=0,sab=0;
  for(let i=0;i<n;i++){const x=i<a.length?a[i]:0,y=i<b.length?b[i]:0; sa+=x*x;sb+=y*y;sab+=x*y;}
  return sab/Math.sqrt(sa*sb); };
```
모집단 = `episodes/**/scene.json` 전수(`_archive`·`lf01`·`lf02` 포함).
**건수는 인용하지 말고 그때 다시 세라** — 2026-08-10 하루 안에 113 → **121건**(34개 회차)이 됐다.

🔴 **`tick`·`drop`·`thud`·`riser`·`pad` 는 `o.seed` 를 읽지도 않는다.** 「seed 미지정이니
기본값 충돌을 보라」는 요구가 오면 **질문 자체가 성립 안 한다고 답하라.** `rng()` 를 부르는
kind 는 `latch`(기본 seed 7)와 `sweep`(기본 11) 둘뿐이다(`sfx.mjs` `KIT`).

🔴 **길이가 크게 다른 두 kind 사이의 r ≈ 0.3 은 겹침이 아니라 제로패딩 인공물이다.**
긴 소리(drop 0.52s)와 짧은 소리(latch 0.14~0.21s)를 절대 표본으로 맞추면 「앞에 에너지,
뒤는 0」이라는 껍데기를 공유한다. **지문 = 값이 그 kind 전체에 걸쳐 균일하다**
(실측: drop ↔ latch 23건이 0.286~0.301). 진짜 유사라면 파라미터에 따라 흩어진다.
판정은 **같은 kind 안에서만** 하고, 다른 kind 와의 r 은 무시한다.

🔴 **통제군을 반드시 같이 낸다.** r≈0 이 「안 겹친다」인지 「측정이 안 됐다」인지는 통제로만 갈린다.
2026-08-10 실측(44.1kHz):

| 통제 | r | 읽는 법 |
|---|---|---|
| `latch` 같은 seed, dur 만 다름 | **0.993** | latch 는 dur 로 안 갈린다 = seed 필수 |
| `latch` seed 만 다름 | 0.778 | seed 를 갈면 0.99 → 0.78 |
| `sweep` seed 만 다름 | 0.011 | sweep 은 seed 가 파형을 통째로 바꾼다 |
| 다른 kind, 같은 seed | ~0.000 | **seed 공유는 그 자체로 근거가 못 된다** |

🔑 **kind 마다 「상관 바닥」이 다르다.** `latch` 는 몸통이 340/680Hz 고정이라
**어떤 두 latch 도 r 0.74~0.83 아래로 안 내려간다** — 그 값을 겹침 증거로 쓰면 latch 를
아무도 못 쓴다. 판정은 「그 kind 의 바닥 대비 어디인가」로 한다.

🔴 **「바닥 대비」를 말로 하지 말고 분포를 같이 내라.** 기존 승인 seed 전수를 **같은 dur 로
고정해 모든 쌍**을 재면 한 번에 나온다(ep14s-3 검수, latch seed 23개 → **253쌍**, dur 0.21):
`min 0.7671 · p25 0.8004 · **중앙 0.8094** · p75 0.8209 · max 0.8525`.
이 표가 있으면 「형제 쌍 0.794」가 **중앙값 아래**임을 한 줄로 보일 수 있다 — 절대값만
인용하면 매번 같은 논쟁을 다시 한다. 스크립트는 20줄이고 1초 안에 끝난다.
`drop`·`thud`·`tick`·`riser`·`pad` 는 `rng` 를 안 부르므로 **(dur, from, to, freq) 가 파형을
완전히 결정** — 그 경우 파라미터 전수 대조가 곧 파형 대조다(작성팀이 그렇게 주장하면 참이다).

🔴 **사인 글라이드(`riser`·`drop`)에서는 상관이 「다르다」를 증명하지 못한다 — 위상으로 풀어라.**
`from` 이 조금만 달라도 r 이 0 근처로 떨어지므로(승인 회차끼리 통제군 전부 |0.013| 이하)
**낮은 r 은 무죄가 아니다.** 판정식 = **누적 위상차가 반 주기에 닿는 시각 T½** 을 구하고,
그 시각의 포락선 값을 같이 낸다. `drop` 은 `√k` 글라이드라
`T½ = ( 0.5·√dur / ((2/3)·Δf) )^(2/3)` · 포락선은 `exp(-5t)`.
실측(ep15s-2 1차 반려): `drop(0.46·560→104)` ↔ 발행된 `ep08s-1 drop(0.46·560→96)` 는
**dur·from 이 같고** r = **0.389**(통제군 최대 0.013 의 30배), `T½ = 0.159초`인데 그 시각
포락선이 아직 **0.45** — 즉 **들리는 구간 전체가 같은 파형**이다. `to` 8Hz 차이는 진폭 10%
구간에만 있다. 🔑 **`dur` 과 `from` 이 같으면 그것만으로 같은 소리**라고 보고, 고칠 때도
그 둘을 함께 벌리게 요구하라(`to` 만 바꾸는 처방은 무효).

🔴 **반음 궤적으로 반려하기 전에 「승인·발행분 전체 쌍」 분포부터 내라 — 안 그러면 소급 반려용
임계값을 네가 새로 만든다.** 2026-08-10 `ep15s-3` 검수에서 실제로 반려 직전까지 갔다:
형제 `ep15s-2 drop(0.46·560→104)` 과 **평균 1.16반음 · dur 차 2%** 라 「같은 소리」로 보였다.
그런데 승인·발행 `drop` 15건의 **모든 쌍 120개**를 재니
`min 0.00 · p25 0.78 · **중앙 2.32** · p75 4.43 · max 15.47`(반음)이고
**`ep02s ↔ lf02` 는 0.00반음 · dur 차 0.000**(둘 다 기본 480→120)이었다. 즉 1~2반음은
**발행분이 서로 앉아 있는 자리**다. 위상도 같이 봐야 갈린다 — 그 쌍은 `T½ = 0.0107초`
(포락선 0.948)로 15-2 반려 건(0.159초·포락선 0.45)의 **15배 빨리 이탈**한다.
🔑 판정선은 **`dur`·`from` 이 같아 T½ 가 들리는 구간까지 끌리는 경우**이고,
반음 거리는 그 위에 얹는 보조 축이다(`thud` 처럼 `dur` 이 같고 기음만 다른 정지 음색은 예외).

🔴 **`latch` 는 `dur` 이 길수록 상관이 올라간다 — 「전수 범위 바깥 = 다른 소리」가 성립 안 한다.**
몸통이 340/680Hz **고정**이고 개성은 `click = rng(seed)` 앞 15ms 뿐이라, **길수록 공유 파형의
비중이 커진다.** `ep15s-2` 2차가 「dur 0.255 는 전수 최댓값 0.225 바깥」이라며 길이를 늘렸다가
**최대 |r| 0.8587 로 판정선을 넘었다**(seed 241 고정 실측: 0.105→0.7736 · **0.120→0.7958** ·
0.135→0.8115 · 0.160→0.8277 · 0.190→0.8434 · 0.225→0.8545 · 0.255→0.8587).
🔑 **대역의 성립 조건을 같이 확인해라.** 마스터 정본 `0.628~0.845(중앙 0.765)` 는
**`seed` 를 명시한 23건 · 253쌍**으로만 재현된다(내가 재현 확인). `ep02s`·`ep03s`·
`_archive/eptest-m11` 은 **기본 seed 7** 이라 넣으면 max 가 **0.998~1.000** 으로 뛴다
(ep02s ↔ eptest 는 인자 전 미지정 = 완전 동일). 오염된 상단으로 「안전」을 주장하게 된다.
🔴 **`gain` 상한은 `dur` 과 반대로 움직인다** — 짧을수록 피크/RMS 가 커져 천장이 내려온다
(seed 241: dur 0.105→gain 상한 0.0691 · 0.12→**0.0728** · 0.21→0.0870 · 0.255→0.0935).
「dur 을 줄여도 피크는 안 올라간다」는 **거짓**이다. 짧게 가르는 처방을 낼 때 `gain` 을 같이 봐라.

🔴 **작성팀의 「리포 전수를 훑었고 안 겹친다」를 그대로 받지 마라 — 열거를 다시 뽑아라.**
같은 사고에서 `riser` 열거는 전수 정확했는데 `drop` 열거만 **충돌하는 한 줄(`ep08s-1`)이 빠져
있었다.** 20줄 스크립트로 `episodes/**/scene.json` 의 `(kind, dur, from, to, gain)` 을 한 번에
찍어 대조하는 것이 유일하게 믿을 수 있는 절차다.

🔴 **타격음(`thud`)은 「같은 `dur` + 기음 몇 Hz 차이」가 상관에 안 잡힌다.** 0.29초·214Hz 와
0.29초·230Hz 는 위상이 4.6주기 어긋나 r 이 바닥으로 떨어지지만 **귀에는 1.25반음 차이의 같은 툭**
이다(ep15s-4 ↔ ep10s-2 실측). `thud` 는 **`dur` 이 같으면 `freq` 거리(반음)로 판정**하고,
2반음 안쪽이면 성격(막힘·실패)까지 같은지 확인해 정정을 요구하라. 고치는 비용이 0 이다 —
`thud` 의 `delayMs` 는 어택(2ms)이 정하므로 **기음을 바꿔도 배치 계산이 안 흔들린다.**
🔑 반대로 `riser` 는 **`dur` 이 같아도 통과할 수 있다** — 길이가 같으면 상관이 인공물 없이
유효하고(ep15s-4 0.78·140→760 ↔ ep15s-5 0.78·260→900 = **r −0.000**), 순간 주파수
`f(k) = f0 + (f1−f0)k²` 를 25/50/75/100% 에서 찍어 **전 구간 5반음 이상 갈리는지**를 같이 보이면 된다.

**파형이 갈려도 「성격」은 따로 본다.** 같은 kind 가 형제 편에서 **같은 샷 번호·같은 cue·같은
뜻**에 붙으면 수렴이다. 병렬 작성이라 사고가 아니므로 **의견 등급**으로 올리고, 옮길 쪽은
지시서 kind 표의 정의에서 **더 먼 쪽**(은유로 확장한 쪽)이라고 짚어 준다.

**같이 재는 것 — 피크 천장.** 실제 `gain` 으로 `synth` 를 돌려 피크가 0.46 을 넘는지 본다.
넘으면 그 소리만 조용해진다. 상한은 **설정마다 다르다**(`latch` dur 0.17/seed 191 은 0.081 까지).
고정 표의 숫자를 상한으로 인용하지 말 것.
🔴 **진짜 피크는 `synth(kind, {...opt, peakCeil: 99})` 로 뽑아야 보인다** — 기본 호출은
천장에서 잘라 내보내므로 「0.46 미만」이 항상 참이 된다. 리포 전체를 이 방법으로 훑으면
초과 건을 직접 찾을 수 있다(2026-08-10 스캔: `lf01 S20` 0.4656 · `lf01 S28` 0.4674 두 건).

## 🔴 kind 전수 census 를 한 번에 내라 — 「이 편의 소리 하나」만 재면 통제군이 없다

**Why:** `ep15s-5` 2차(2026-08-10). 코디네이터가 *"`riser`·`drop` 자체를 발행분 전체와 대조한
사람은 아직 없다"*고 지적했다. 실제로 그때까지의 대조는 전부 **의심 가는 한 쌍**만 재고 있었다.
kind 하나를 통째로 합성해 **모든 쌍**을 내니 판정이 한 번에 끝났고, 덤으로 **아무도 모르던
동일 소리**가 나왔다 — **`ep02s` S5 ↔ `lf02` S2 의 `drop` 이 r = 1.000**(둘 다 기본값
0.28·480→120, 둘 다 이미 발행). 한 쌍씩 재는 방식으로는 영원히 안 보였을 자리다.

**How to apply:**
- `episodes/*/scene.json` 을 훑어 그 kind 의 `(dur, from, to, seed)` 를 전부 모으고,
  **N(N−1)/2 쌍을 한 번에** 낸 뒤 `min / 중앙 / 95% / max` 를 보고서에 싣는다.
  판정은 「이 편의 최댓값이 **통제군 어디에 있나**」로 한다 — 절대선(0.85)만 보면 근거가 약하다.
  (ep15s-5 drop: 최댓값 **0.025** < 통제군 **중앙 0.026** → 「발행된 임의의 두 drop 보다 안 닮았다」)
- **반음 거리를 같이 낸다.** 순수 사인(`riser`·`drop`)은 낮은 r 이 무죄의 증거가 아니다.
  실측 대역: drop 171쌍 min 0.000 / 중앙 0.026 / 95% 0.504 / **max 1.000** ·
  riser 136쌍 min 0.000 / 중앙 0.000 / 95% 0.182 / **max 0.309**(= riser 는 r 이 애초에 안 올라간다).
- 🔑 **`dur` 이 같은 것 자체는 죄가 아니다** — 같은 길이는 상관이 유효해지는 조건일 뿐이다.
  `ep15s-4`(0.78·140→760) ↔ `ep15s-5`(0.78·260→900)는 **r = 0.000 · from 10.72반음**으로 통과.
