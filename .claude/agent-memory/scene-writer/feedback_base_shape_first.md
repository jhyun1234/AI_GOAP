새 회차의 `kinds/` 를 짤 때, **샷을 하나씩 보며 "여기엔 어떤 그림이 어울리지"를 묻지 않는다.**
원문을 통째로 읽고 사건을 표로 뽑은 뒤 **"이 글의 기본 도형은 무엇인가"를 한 문장으로 먼저
답하고**, 열 개 그림을 그 한 도형의 변주로 파생시킨다.

**Why:** 샷 단위로 고르면 매번 "숫자니까 카운터, 비교니까 막대"가 되고, 그건 결정 트리가
누구에게나 주는 답이라 회차마다 같은 그림이 나온다. 사용자 판정 = *"비슷한 애니메이션을
돌려막기하는 건 내가 원하는 방향이 아니야."* 실제로 도형을 먼저 정하니 같은 데이터가 다른
그릇으로 갔다 — ep01s 의 `ByReason` 로그는 "수치 4개"라서 카드 그리드였는데, 축을 정하고 보니
그 로그가 하는 말은 비교가 아니라 "한 방향으로만 몰렸다"여서 값이 길이가 되는 갈래 그림이 됐다.

실제 축 두 개:
- `ep00s` = **어긋남** → 한 줄의 선과 그 위를 오가는 신호
- `ep01s` = **닿지 못함** → 뻗었다가 되돌아오는 획 (열 개 그림이 전부 이 획의 변주)

**How to apply:**
- 착수 순서: 원문 정독 → 사건을 "무슨 일이 벌어지나" 열로 표에 나열 → 공통 모양 한 문장 →
  그때부터 kind 이름·spec 설계. 이 문장은 `scene.json.notes` 와 `notes/writer.md` 에 그대로 적는다.
- **회차 안에서 같은 kind 를 두 샷에 쓰는 것은 돌려막기가 아니라 되받기다.** 단 조건이 있다 —
  두 번째가 첫 번째를 뒤집어야 한다(ep00s `wire` 변조→게이트 / ep01s `rebound` 벽→열림,
  `shelf` 못 닿음→닿음). 같은 말을 두 번 하면 그건 그냥 재탕이다.
- 옛 회차의 kind 는 **형식만** 본다(파일 구조·import 경로·spec 읽는 법·정적 구간 대책).
  다 짠 뒤에 옛 이름 목록과 대조해서 하나라도 겹치면 그 샷은 다시 본다.

## 🔴 "안 겹친다"는 대조표를 만든 뒤에만 적는다

이름 겹침(0건)을 확인해 놓고 **형태 겹침까지 안 겹친다고 단언하면 안 된다.** ep01s 2차가
이것 하나로 반려됐다 — `spoke`(방사 네 갈래)가 `ep00s/channels`(평행 관 넷)와
"한 출발점 → 네 갈래 → 하나만 채워짐 + 값 3을 움직이는 표식 3개 + 하단 가운데 mono 캡션"까지
같았고, 다른 건 배치뿐이었다. writer.md 에는 "읽었다"고 적혀 있었지만 **항목 대조는 안 했다.**

- 같은 소재(같은 로그·같은 수치)를 두 회차가 다룰 때만 위험하다. 그럴 땐 앞 회차의 해당
  kind 를 **끝까지 읽고 표로 항목 대조**한 뒤에 쓴다: 출발점 라벨 문자열 / 구조 / 값의 실물화
  방식 / 캡션 렌더 위치·정렬 / 논지 / 배치.
- **기각 논증이 앞 회차 주석과 같은 문장이 되면 신호다.** 같은 논증을 다시 세우면 같은 계열의
  답에 도착한다. ep01s 는 `metrics` 기각 사유를 `channels.js` 주석과 똑같이 써 놓고
  같은 답에 도착했다.
- 앞 회차 주석에 *"뒤 회차가 X 를 쓰고 있으니 나는 Y 로 간다"* 가 있으면 **그건 사 둔 간격**이다.
  뒤 회차가 X 를 버릴 때 Y 로 들어가면 안 된다.

## 🔴 "아직 없어서 못 했다"고 미뤄 둔 대조는 **사유가 사라지는 순간** 다시 한다

`ep08s-3` 은 형제 편 `ep08s-2` 가 아직 없어서 그림 대조를 못 한다고 writer.md 에 적었다.
그 뒤 8-2 가 나와 `outro.siblings` 는 8-2 제목으로 갱신됐는데 **그림 대조만 안 다시 했고**,
페이오프 컷이 8-2 와 구도가 통째로 겹쳐 반려됐다(가로 시간축 + 한 눈금 위의 세로 기둥 +
`TICK` 라벨 + 훑는 표식 — 하필 두 편 다 가장 오래 머무는 컷이었다).

- **씬 파일이 형제 편을 보고 갱신됐다는 것은 그 편이 존재한다는 뜻이다.** 갱신 커밋에서
  「형제가 없어서」로 미뤄 둔 항목을 전부 다시 훑어라.
- 뒤에 나가는 편이 고친다 — 앞 편은 이미 검수를 마쳤고 `order` 상 먼저 나가므로
  **뒤엣것이 「본 그림」으로 읽힌다.**
- 갈라내는 가장 확실한 축은 **그 회차가 값을 무엇으로 지는가**다. ep08s-2 는 네 그림이
  전부 「1차원 축 위의 자리」였고, ep08s-3 은 「길이(막대+문턱선)와 각도」로 갈랐다 —
  **눈금 있는 측정 축을 회차에서 통째로 없애는 것**이 한 항목씩 다투는 것보다 낫다.
