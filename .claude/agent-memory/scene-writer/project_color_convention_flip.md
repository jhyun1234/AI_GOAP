기본 색 규약은 **강조색 = 해결/정답 · 흰색 = 대조 대상**이다(`lib.js` 팔레트 주석).
`ep15s-5` 가 이걸 **뒤집어**(강조색 = 로그·안쪽에 다 있는 것 / 흰색 = 화면에 보이는 것)
승인받았고, 그 판정이 조항으로 굳었다(마스터, 2026-08-10).

## 🔴 허용 4조건 — 넷을 다 만족해야 하고, **논지가 요구할 때만**

1. **회차 안 예외 0** — 그 회차 `kinds` 를 **전수로 읽어** 확인한다(층의 주장 말고 코드).
2. **그 뜻을 회차가 스스로 가르치는 자리가 본문 첫 그림에 있다**
   (ep15s-5 는 훅의 「왼쪽 가득 / 오른쪽 빔」).
3. **아웃트로(카드 + 미리보기)에서 축을 되돌려 다음 회차로 안 물려준다.**
4. 🔴 **읽힘이 색에 안 매달린다 — 라벨과 색을 둘 다 지워도 사건이 읽혀야 한다.**

## 🔴🔴 통과의 몸통은 **4번**이다 — 1~3번으로는 부족하다

검수는 ①(회차 안 일관)과 ③(축 되돌림)으로 정당하다고 봤는데 **마스터가 기각했다**:
> 「규정에 없다」도, 「스스로 일관된다」도 그 자체로는 통과 근거가 못 된다(`ep02s` 재작업 판정).

ep15s-5 가 실제로 통과한 근거는 **`reads` 다섯 줄이 전부 「채움 대 빔」으로 서 있고
색 이름이 한 번도 필요 없다**는 것이었다. 마스터가 스틸에서 **색의 뜻을 반대로 읽는
시청자도 결론에 똑같이 도달함**을 확인했다 — 즉 뒤집기는 **얹은 층**이지 **지고 있는 층**이 아니다.

## 🔴 `ep15s-5` 를 선례로 인용하면 반려다

「ep15s-5 가 뒤집었으니 나도」는 **명시적으로 금지**된 인용이다(마스터의 「인용하면 안 되는 것」 1번).
쓰려면 **자기 편에서 4번을 스스로 증명**해야 한다 — `reads` 를 쓴 뒤 **색 이름을 지우고
다시 읽어** 사건이 남는지 보는 패스가 그 증명이다.

🔑 그리고 **논지가 요구할 때만**이다. ep15s-5 는 명제 자체가 「가득 찬 쪽이 바로 안 보이는
쪽」이라 뒤집기가 곧 결론이었다. 「그림이 예뻐서」는 사유가 못 된다.
