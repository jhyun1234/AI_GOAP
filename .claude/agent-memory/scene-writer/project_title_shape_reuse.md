**같은 소재를 다시 다룰 때 반복해도 되는 것은 「숫자 훅」이고, 반복하면 안 되는 것은
「제목의 문장 모양」이다.**

**Why:** 지시서는 *"먹히는 훅의 형태는 반복해도 된다 / 같은 수치가 같은 뜻으로 두 번
나오는 것만 피하면 된다"* 고 못박는다(ep06s 가 훅을 통째로 버려 숫자 0개 회차를 낸 사고의
반작용). 그런데 이 규칙을 곧이곧대로 읽으면 **제목이 세 번 같아진다.** 실제로 채널에
이미 둘이 있었다:

| 회차 | 제목 |
|---|---|
| ep06s | 주민 **다섯 명**이 **한 사람처럼 움직였어요** |
| ep07s-1 | 성격을 줬는데도 **여덟 명**이 **똑같은 일만 했어요** |

ep08s-3 도 사건이 「겨울 예고가 뜨자 주민 전원이 동시에 비축에 뛰어들었다」라 그대로 쓰면
세 번째 「N명이 똑같이 …했어요」가 된다. 세 회차의 사건은 실제로 **전부 다르다**
(ep06s = 시간표가 같다 / ep07s-1 = 일감이 같다 / ep08s-3 = 위기 신호 하나가 개인차를
덮어썼다). 제목만 같으면 시청자는 같은 편으로 보고 넘긴다.

**How to apply:**
- 숫자는 그대로 쓴다(ep08s-3 도 `10명`을 썼다). 바꾸는 것은 **문장의 뼈대**다.
- 갈라낼 재료는 **그 편만 가진 것 둘** — ①**방아쇠**(무엇이 그렇게 만들었나)
  ②**잃은 것/버린 것**(무엇이 사라졌나). ep08s-3 = 「**겨울 온다니까** 주민 10명이
  **하던 일을 다 놨어요**」.
- 🔑 동사를 페이오프와 맞물리게 하면 덤이 하나 생긴다 — 제목의 '놨다'와 마지막 자막의
  「고집쟁이는 밭일을 **안 놔요**」가 같은 동사로 맞물린다.
- 🔴 착수할 때 `episodes/*/scene.json` 의 `youtube.title` 을 **전부 훑어라.** 소재가
  가까운 회차만 보면 안 된다 — ep06s·ep07s-1 은 서로 다른 글이고 형제 편도 아니다.
- 이건 [[feedback-base-shape-first]] 의 제목판이다. 그림에서 남의 회차 어휘가 섞이는 것을
  막는 것과 같은 일을 제목에서 한다.

## 🟡 수치가 정말 없으면 warn 을 받는다 — 지어내지 않는다 (ep09s-1, 2026-08-07)

`제목 후킹 (수치)` 는 **warn 이고 반려 사유가 아니다.** 편의 사건에 붙은 수치가 원문에
없으면 **첫 줄로 승부하고 warn 을 감수한다.**

**Why:** ep09s-1(이름표)의 사건에는 원문 수치가 없었다. 후보 넷이 다 막혔다 —
`M4`·`M5`(밀스톤 번호라 환산 불가 + 화면 라벨로 이미 씀) / `5단계`(이 편은 그중 A 하나만
다뤄 제목이 약속하면 **제목 이행 게이트가 편의 사건을 바꿔 버린다**) /
`0`·`1↔0`(다른 절 소재 + `코드 0` 은 ep05s-3 이 **같은 뜻으로** 이미 씀) /
`4타일→2타일`(같은 글의 **다른 편** 것).
🔑 체류를 만드는 것은 제목이 아니라 첫 줄이다(18.30% → 55.16%, 3.01배).

**How to apply:** 제목에 숫자를 넣으면 **제목 이행 게이트가 그 숫자를 첫 두 줄로 끌어올린다.**
그러니 「숫자가 이 편의 사건 안에 있는가」를 먼저 보라 — 없으면 넣는 순간 편이 바뀐다.
최종 응답에 `제목 수치 없음: <원문에서 찾은 것 전부>` 를 적어 사람이 판단하게 한다.

## 🟢 이미 두 번 쓴 수치는 **버리지 말고 화면 라벨로 강등한다** (ep12s-3, 2026-08-08)

ep12s-3 의 사건에는 센 수치 쌍이 둘 있었다 — **코드 0줄**(에셋 하나로 재해 추가)과
**작물 0개 소실**(그 재해가 아무것도 못 때림). 그런데 `코드 0줄` 은 ep05s-3·ep10s-2 가
**이미 두 번** 쓴 수치다(착수 때 `youtube.title` 전수 확인).

**How to apply:** 셋 중 하나를 고르는 문제가 아니다.
- **제목에는 그 편 고유의 수치**를 쓴다 → 「작물은 **0개** 사라졌어요」.
- **겹치는 수치는 화면 라벨로 내린다** → S1 물띠 옆 `NEW ASSET / .CS DIFF 0`.
  🔑 그러면 ①제목의 수치 중복이 0 이고 ②사실은 하나도 안 버려지며 ③**자막 한 줄(≈3.7초)을
  안 쓰고** 아이러니가 완성된다(한 화면에 0 이 둘 — 위는 자랑, 아래는 사고).
- 🔴 **강조색은 나레이션이 부르는 쪽에만** 준다. 화면이 조용히 쥔 수치까지 강조하면
  둘 다 안 읽힌다.
- ⚠️ 화면에 내린 수치는 **제목 이행 게이트가 못 본다**(게이트는 `text`/`say` 만 읽는다).
  그러니 내리는 것은 **제목에 안 쓴 쪽**이어야 한다. 반대로 하면 red 다.
