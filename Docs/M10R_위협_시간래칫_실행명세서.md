# M10R — 위협 시간 래칫 + 출몰별 타깃 롤 실행명세서

작성 2026-07-24. M10 야생위협 시스템의 **에스컬레이션 축 개정**. 기존 명세는
`Docs/M10_야생위협과방랑자_실행명세서.md`, 이 문서는 그 위협 스케줄만 갈아끼운다.

## 0. 배경 — 왜 고치나 (Day 43 관측)

현재 활성 티어는 **현재 마을 규모(주민+밭+집)** 로 잠금 해제된다
([`ThreatService.PickTier`](../Assets/Scripts/M0/World/ThreatService.cs:70) ←
[`CurrentScale()`](../Assets/Scripts/M0/World/ThreatService.cs:150), 매 틱 실시간 재측정).

| 티어 | 현재 잠금 | 대상 |
|---|---|---|
| 외로운 늑대 | 규모 0 | 밭 |
| 늑대 무리 | 규모 8 | 주민(부상) |
| 큰 곰 | 규모 16 | 주민(부상) |

**결함(음성 피드백 루프):** 규모 ≥ 8 → 늑대 무리 → 주민 사망 → 규모가 8 아래로 →
`PickTier`가 외로운 늑대(밭)로 **강등** → 이후 밭만 갉음 → 주민 안전 → 규모 7에서 **영구 안정**.
즉 **사망이 위협을 무장해제**시켜, "끝내 못 이기면 전멸"이라는 로그라이크 경주(ADR-M10-8 정신)가
**구조적으로 불가능**하다. Day 43 방치 관측에서 실측됨.

**해결:** 에스컬레이션 축을 *되돌아가는 현재 규모* → *단조 증가하는 게임일(`GameTime`)* 로 교체하고,
타깃 종류(밭/주민)를 티어 고정 속성이 아니라 **출몰별 시드 롤**로 바꾼다. 게임일은 사망해도
줄지 않으므로 위협이 약해지지 않고, 작은/줄어든 마을도 주민 공격 롤을 계속 맞아 **소용돌이 → 전멸**이 성립한다.

## 1. 성공 기준 (측정 가능)

- **[래칫]** 주민 1명 사망 전후로 하루 경계 로그의 `활성위협`이 **동일**하다 (규모 하락에 의한 강등 0건).
- **[초반 완만]** Day 0~12 구간의 모든 위협 발동 로그가 `밭 N/M 소실` (주민 부상 0건).
- **[중반 착탄]** Day 12 이후 발동 로그에 `부상 N명`이 섞여 등장 (VillagerTargetChance 0.5).
- **[결정성]** 같은 출몰 서수 = 같은 타깃 종류 (EditMode 게이트 green, ADR-M10-1 유지).
- **[전멸 경로]** 개입 없는 장기 방치에서 사망이 누적되어 전멸화면(M10-F)에 도달 (관측 목표 — DoD 아님).
- EditMode 전체 green, 2종 빌드(Editor/Player) 0 오류.

## 2. ADR (구현 중 갈릴 판단 선결 — 바꾸려면 사유를 커밋 메시지에)

- **ADR-M10R-1 (M10-6 개정):** 등록제 플래토의 잠금 축을 `MinVillageScale`(현재 규모) →
  `UnlockDay`(게임일)로 교체한다. 활성 = `UnlockDay ≤ GameTime` 중 최신(최대 UnlockDay) 1개.
  게임일은 단조 증가 → 티어는 **되돌아가지 않는다(래칫)**. 사유: §0 음성 피드백 루프.
- **ADR-M10R-2 (M10-1 재확인):** "확률 금지"는 유지된다. 타깃 롤은 진짜 난수가 아니라
  **출몰 서수 시드**(`StableHash.Fnv1a(ordinal, DisplayName+"|tgt")`)로 뽑는 결정적 값 — 세이브/로드
  재현성이 안 깨진다. 진입점 시드와 **다른 솔트**("|tgt")를 써 타깃과 진입변이 상관되지 않게 한다.
- **ADR-M10R-3:** 타깃 종류(밭/주민)는 **티어 고정 속성이 아니라 출몰별**로 정한다. 밴드는
  `VillagerTargetChance`(0~1)만 제공하고 매 출몰이 롤한다. **곰(0.75)도 25%는 밭을 친다**
  (사용자 확정 2026-07-24 — 100% 고정 안 함).
- **ADR-M10R-4:** 타깃 종류는 **출몰(Spawn) 시점에 1회 확정**하고 개체 인스턴스에 박아둔다
  (`ThreatAgent.TargetsVillagers`). 이동 모드(추격/고정)·타격·HUD 분기가 전부 이 인스턴스 값을 읽는다.
  예고(Forecast) 시점엔 타깃 미확정 — 예고는 "무엇이 오는지"만 알리고 "어디를 치는지"는 착탄 때 드러난다.
- **ADR-M10R-5:** `VillageScale` 순수 함수와 그 게이트 테스트는 **존치**한다 (하루 경계 로그가 마을 크기를
  정보로 계속 노출 — 위협 게이팅에서만 손을 뗀다).

#### W1-b. `Assets/Scripts/M0/World/ThreatService.cs`

1. **`PickTier` 축 교체** — 규모(int) → 게임일(float):
```csharp
/// <summary>활성 밴드 (순수, ADR-M10R-1): UnlockDay ≤ day 중 최신(최대 UnlockDay). 동률은 배열 앞.
/// 충족 밴드가 없으면 null. 게임일은 단조 증가 → 한 번 열린 밴드는 닫히지 않는다(래칫).</summary>
public static ThreatSO PickTier(ThreatSO[] threats, float day)
{
    ThreatSO best = null;
    if (threats != null)
        foreach (ThreatSO t in threats)
        {
            if (t == null || t.UnlockDay > day) continue;
            if (best == null || t.UnlockDay > best.UnlockDay) best = t;
        }
    return best;
}
```

2. **출몰별 타깃 롤 헬퍼 신규** (public static — 게이트 대상):
```csharp
/// <summary>이번 출몰이 주민을 노리는가 (순수·결정적, ADR-M10R-2·3): 출몰 서수 시드로 [0,1) 분수를
/// 만들어 chance와 비교. 진입점 시드와 다른 솔트("|tgt")로 상관 차단. 0=항상 밭, 1=항상 주민.</summary>
public static bool RollTargetsVillagers(ThreatSO so, int ordinal)
{
    if (so.VillagerTargetChance <= 0f) return false;
    if (so.VillagerTargetChance >= 1f) return true;
    uint h = StableHash.Fnv1a(ordinal.ToString(), so.DisplayName + "|tgt");
    float r = (h & 0xFFFFFFu) / (float)0x1000000; // [0,1)
    return r < so.VillagerTargetChance;
}
```

## 4. ⚠️ 오해 위험 (선차단)

- **오해 A — 진짜 `Random`을 쓴다:** ✗. `UnityEngine.Random`/`System.Random` 금지. 오직
  `StableHash.Fnv1a` 시드(ADR-M10R-2). 세이브/로드 재현성이 깨지면 안 된다.
- **오해 B — 타깃을 매 프레임/매 재타겟마다 다시 롤한다:** ✗. **출몰 1회**만 롤해 개체에 박는다
  (ADR-M10R-4). 재타겟(추격)은 대상 *위치*만 갱신하지 타깃 *종류*를 바꾸지 않는다.
- **오해 C — `VillageScale`을 통째로 삭제한다:** ✗. 게이팅에서만 손을 떼고 정보 로그용으로 존치(ADR-M10R-5).
- **오해 D — 밴드가 여러 개 동시 활성:** ✗. 여전히 최신 1개(PickTier). 곰이 열리면 늑대 무리·외로운 늑대는
  선택되지 않는다 — 대신 곰이 `VillagerTargetChance 0.75`로 밭/주민을 섞어 친다.

## 7. 재미 검증 — 플레이어가 새로 보게 되는 것

지금까지는 늑대에게 주민 하나를 잃으면 오히려 마을이 "안전해져" 밭만 갉아먹히는 정체 상태에 갇혔다.
이 작업 뒤에는, **초반 12일은 밭만 뜯기며 완만하다가, 12일째부터 늑대 무리가 절반의 확률로 주민을 물고,
한 명이 죽어도 위협이 물러서지 않아 남은 사람들이 차례로 쓰러지는 하강 곡선**을 보게 된다. 개입하지 않고
버티면 30일째 큰 곰까지 겹쳐 마을이 무너지고 전멸화면에 도달한다 — "방치하면 몰살당해 더는 진행할 수 없다"는,
사용자가 요청한 바로 그 장면이 처음으로 실제로 연출된다.
