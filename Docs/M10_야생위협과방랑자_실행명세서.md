## 0. 목적

M9까지의 마을은 자가 교정(P0 식사 100 + 상시 채집)이 굶주림 계단을 구조적으로 항상 이겨
상실이 착탄하지 않았다. M10은 **먹는 걸로 해결되지 않는 위협**(야생 위협 → 부상 → 사망)과
**상실의 회복 경로**(방랑자 → 플레이어 수락)를 한 쌍으로 넣어 상실의 순환을 만든다.

게임 구조 = **로그라이크식 경주**: 마을 규모가 임계를 넘을 때마다 위협 티어가 오른다
("성장이 위협을 부른다"). M10은 격퇴 수단이 없으므로(전투 = M11) 등록 티어를 1~3으로
플래토시킨다 — 목표 상태는 **"방치하면 전멸 가능, 돌보면 손실 있는 생존"**. 전멸 필연 금지
(M6 절벽 교훈), 전멸 불가능도 금지 (재미 건강 기준).

## 0.5 넓히기 분류 (①선반 위 물건 / ②새 선반 — 사용자 가치관, 필수 항목)

**②새 선반 3개** (각각 "완성 후 무엇이 에셋 1개짜리가 되는가"):

| 선반 | 내용 | 완성 후 에셋 1개짜리가 되는 것 |
|---|---|---|
| 위협 선반 (M10-C) | ThreatSO 스키마 + ThreatService(예고·스폰·타격) + ThreatAgent(개체) | **새 몬스터/티어 = ThreatSO 에셋 1개 + WorldConfig.Threats 등록, 코드 0줄** (M10-G 리허설이 증명). 소실 곡선은 DisasterService.LossCount 재사용 |
| 부상·사망 선반 (M10-A/B) | 부상 상태·감속·goal 필터·간호·사망 계단·무덤 | **새 부상 원인 = Injure() 문 호출 1줄** (M11 전투가 이 선반 위에 얹힘). 치료 가속 직업 = JobSO.TendRecoveryMult 에셋 값. 중상 확장 = InjurySeverity enum 뒤 append + 에셋 필드 (코드 최소) |
| 런타임 인구 문 (M10-E) | SpawnVillager 단일 스폰 문 + WandererService + 수락 UI | **방랑자 유형·빈도·대사 조정 = 에셋 값**. 시작 드래프트 UI(백로그)·M11 재건이 같은 문을 재사용 |

**①선반 위 물건** (기존 축 데이터만): Job_Medic (JobSO 에셋 — 직업 추가 비용표 그대로),
성격별 FleeRadiusMult 값 (기존 성격 에셋 필드), Goal_TendInjured·Goal_Flee (Goal 추가 = 에셋
+ 씬 등록), Chatter_WandererArrive (M9-E FireScene 이벤트 전용 대화 패턴), Threat_Tier1~3 에셋.

## 1. 성공 기준 (측정 가능)

- **M10-S1**: 위협 사이클 관측 — HUD 예고("늑대가 다가온다") → 개체 스폰·접근 → 타격 →
  퇴장이 Play 1사이클(12일) 내 1회 이상. Console `[Threat]` 예고·발동·퇴장 로그 3종.
- **M10-S2**: 부상 착탄 — 주민 부상 ≥ 1회, 정보줄에 "부상" 표기 + 이동 감속 체감.
  간호로 회복 시 `[Injury] 회복` 로그.
- **M10-S3**: 사망 착탄 가능 — 간호 없이 방치된 부상자가 사망 (무덤 오브젝트 + HUD 알림).
  **이탈은 굶주림에서만, 사망은 부상에서만** (로그 사유 검증 — ADR-M10-3).
- **M10-S4**: 방랑자 순환 — 도착 알림 + 주민 술렁임 + Y/N 프롬프트. Y = 합류(정보줄·HUD
  식량일수 분모 즉시 반영), N 또는 방치 = 퇴장. 판정은 플레이어 입력만 (ADR-M10-7).
- **M10-S5**: 사다리 작동 — 마을 규모 임계 도달 시 다음 티어 출몰 (Console에 티어 전환 로그).
  규모 미달이면 티어 1 반복 (플래토).
- **M10-S6**: 전멸 종료 — 주민 0명 시 "마을의 마지막 날" 요약 화면 (생존 일수·사망·이탈·정착
  카운트). 재건 버튼 없음 (M11).
- **M10-S7**: 리허설 — 티어 3 위협 추가 커밋의 diff에 .cs 0개 (에셋 + WorldConfig 등록뿐).
- **M10-S8**: 중립 불변식 — WorldConfig.Threats 비우고 방랑자 미배선이면 M9 동작과 diff 0
  (EditMode 게이트 + Play 10분 로그 비교).
- **M10-S9**: 재미 관측 (회상 테스트 전 단계) — 2사이클(24일) 방치에서 부상·사망·방랑자 고민
  중 **최소 1개 사건이 실제 착탄**. 0건이면 밸런스 실패로 간주하고 §8 관찰 항목으로 조정.

## 2. 재미 검증 — 플레이어가 화면에서 새로 보게 되는 것

좌상단에 "늑대가 다가온다 — 이틀 뒤"가 뜨고 주민들이 술렁인다. 맵 가장자리에서 붉은
개체가 마을로 걸어 들어오면 주민들이 하던 일을 놓고 모닥불 쪽으로 흩어지는데, 고집쟁이
농부만 밭에 늦게까지 남아 있다가 물린다. 정보줄에 "부상"이 붙고 걸음이 절뚝여지며, 치료사가
달려가 곁을 지키면 회복하고 — 손이 모자라면 무덤이 하나 생긴다. 며칠 뒤 "방랑자가 마을
어귀에 왔습니다 — 요리사 · 새침 [Y]수락 [N]거절"이 뜨고, 플레이어는 좌상단 식량 일수를
곁눈질하며 처음으로 마을의 미래를 저울질한다. 잃는 것과 채우는 것이 전부 화면에서 벌어진다.

## 3. ADR-M10 (구현 중 갈릴 판단, 바꾸려면 사유를 커밋에)

1. **확정 발동·확정 착탄 (ADR-M9-4 계승)**: 위협 스케줄·타격·희생 선정에 확률 금지.
   위력은 곡선(LossCount 재사용)과 결정적 선정(거리순, 동률은 AgentId 사전순)뿐.
   UnityEngine.Random은 표현(대사 선택)에만 허용.
2. **부상 상태 쓰기 단일 지점**: 부상 진입은 `VillagerAgent.Injure()`, 회복 진행은 SimTick
   내부, 완치는 `HealInjury()` — 이 세 지점 외 쓰기 금지. 사망 정리는 Depart와 동일하게
   State=Dead + OnDestroy 단일 경로 (두 번째 정리 경로 금지, ADR-M6-3 계승).
3. **결말 이원화 금지**: 이탈 = 굶주림 계단 전용, 사망 = 부상 계단 전용. 부상이 이탈을
   부르거나 굶주림이 사망을 부르는 crossover 금지 — 각 계단은 자기 원인만 갚는다.
4. **위협 개체는 주민이 아니다**: VillagerAgent 재사용 금지 — ThreatAgent 별도 클래스.
   서비스 결합은 좌표·ID뿐 (후반 확장 인지 규칙 1). 이동은 IPathfinder 창구 경유
   (`Docs/ADR_경로탐색_확장경계.md`), **타일 예약 비참여** (일과성 통과자 — 주민과 겹쳐도
   무해. M11 전투에서 재검토).
5. **창고 성역 유지 (ADR-M9-5 계승)**: ThreatSO 타깃에 스톡 차감 없음. 위협이 때리는 건
   주민(부상)과 시설(기존 파괴 문)뿐.
6. **사다리 = 등록제**: WorldConfig.Threats에 등록된 티어만 존재한다. 활성 티어 = 마을 규모
   ≥ MinVillageScale 중 **최대 MinVillageScale 에셋 1개** (동률이면 배열 앞). 규모가 더 커져도
   등록 밖 티어는 없다 = 플래토. M10 등록은 1~3, 상위 티어는 M11에서 등록 1줄.
7. **방랑자 수락은 플레이어 전권**: 판정 입력은 Y/N 키뿐. 주민 술렁임은 표현 전용(FireScene)
   — 결정에 불개입 (ADR-M7-1 정신). 수락 UI는 키 입력 + HUD 프롬프트 줄 (버튼 UI는 백로그).
8. **격퇴 없음**: M10 위협 개체는 무적 통과자다. HP·전투·플레이어 개입(공격 명령) 전부 M11.
   "위협을 줄이는 수단"을 임시로 넣고 싶어지면 멈추고 질문 (버려질 코드 금지 — 사용자 결정).
9. **방랑자 후보는 시뮬 외부**: 수락 전 후보는 표현 전용 오브젝트 — RegisterAgent 미호출,
   포만·식사·FoodDaysLeft 분모 불포함. 합류 순간에만 SpawnVillager 문을 지난다.
10. **세이브 주석 규약 (ADR-M0-10)**: 부상 상태(심각도·회복·방치 누적)·위협 스케줄
    (_lastStrikeDay)·기록 카운터(사망/이탈/정착) = 세이브 대상. 진행 중 ThreatAgent 개체·
    방랑자 후보 = 저장하지 않음 (로드 후 다음 스케줄에서 재출몰).

### 4.3 ThreatSO (신규 스키마 — 위협 1종 = 에셋 1개)

```csharp
/// 야생 위협 정의 (M10-C, ADR-M10-6) — 티어 1개당 에셋 1개. 활성 티어(마을 규모 기준)가
/// PeriodDays마다 확정 출몰한다 (확률 없음 — ADR-M10-1). 격퇴 불가 (ADR-M10-8, M11에서 개정).
/// 새 위협 추가 = 이 에셋 1개 + WorldConfig.Threats 등록, 코드 0줄 (M10-G 리허설이 증명).
[CreateAssetMenu(menuName = "AIVillage/M0/Threat", fileName = "Threat")]
public sealed class ThreatSO : ScriptableObject
{
    public string DisplayName;                  // 예: 외로운 늑대
    [Tooltip("이 티어가 활성화되는 최소 마을 규모 (주민+밭+집). 활성 = 충족 중 최대 티어 1개.")]
    public int MinVillageScale;
    [Tooltip("출몰 주기 (게임일). 이전 발동일 + 이 값 = 다음 발동일.")]
    public float PeriodDays = 6f;
    [Tooltip("발동 전 예고 (게임일) — HUD 경보 + 주민 술렁임 시작 시점.")]
    public float WarnDays = 1f;
    [Tooltip("true = 주민 타격(부상), false = 밭 시설 타격(RemoveCountableAt — M9-B 문 재사용).")]
    public bool TargetVillagers;
    [Tooltip("타격 반경 (타일, 맨해튼) — 도착 지점 기준 이 안의 후보만 희생 대상.")]
    public int StrikeRadiusTiles = 3;
    [Tooltip("주민 감지 반경 (타일) — 이 안의 주민에게 ThreatNear=1 (도망 트리거). 개인 배율 곱.")]
    public int DangerRadiusTiles = 6;
    [Header("위력 곡선 (DisasterService.LossCount 재사용 — 산식 이원화 금지)")]
    public float BaseLossPct = 0.25f;
    public float PerTargetPct = 0.03f;
    public float MaxLossPct = 0.25f;            // 결정 9: 부상자 ≤ 인구 25% 상한이 여기
    [Header("표현")]
    public float MoveSpeed = 2.5f;              // 개체 이동 속도 (타일/초)
    public Color BodyColor = new Color(0.8f, 0.2f, 0.2f); // 스프라이트 없을 때 마커 색
    public string[] ForecastLines;              // 예고 술렁임 ("늑대 울음이 들려…")
    public string[] StrikeLines;                // 타격 순간 반응 대사 (재해 StrikeLines 패턴)
}
```

### 4.4 에셋 신설·수정 (전부 제안치 — 기존 값 우선, 관측 후 튜닝)

**AgentConfig 추가 (부상 축)**: `InjuredMoveSpeedMult 0.4` / `InjuryRecoverDays 1.0` (간호
만 1일이면 완치 — 자연 회복 없음, 결정 11) / `InjuryDeathAfterDays 1.5` (방치 누적 사망 —
굶주림 0.5일보다 길게: 위협 발견→간호 판단의 유예) / `InjuredLines` ("다리가…", 부상 순간) /
`DieLines` ("먼저 갈게…", 사망 직전) / `TendLines` ("금방 나을 거야", 간호 시작).

**WorldConfig 추가 (방랑자)**: `WandererIntervalDays 5` (도착 주기 — 위협 주기 6과 어긋나게:
회복이 상실 직후 오지 않도록 위상차) / `WandererWaitDays 0.7` (응답 대기 — 초과 시 퇴장) /
`WandererGoal` 미사용 — 방랑자는 goal이 아니라 인구 문 / `Threats` 배열.

### 4.5 검산 — 착지 상태(주민 4·밭 4·집 ~2) 기준 (본 명세의 필수 숙제)

- **마을 규모** = 4 + 4 + 2 = **10** → Tier1만 활성 (임계 12 미달). 방랑자 1~2명 수락 + 밭·집
  증가로 12를 넘겨야 Tier2(주민 부상)를 만난다 — "성장이 위협을 부른다"가 수치로 성립.
- **Tier2 부상 수**: 도망 성공 시 StrikeRadius 3 내 잔류 0~2명 → LossCount(2) =
  ceil(2 × min(0.25+0.06, 0.25)) = **1명**. 인구 25% 상한과 일치 (4명 기준 1명).
- **간호 수지**: 회복 1일(일반) vs 사망 1.5일 — 여유 0.5일. Medic이면 0.33일 완치.
  간호가 하루 종일 걸리므로 노동 1인 이탈 = "손이 모자람"이 경제 압박으로 전이 (결정 11).
- **속도**: 위협 2.5타일/초 vs 주민 기본 2.0 — 도망은 감지 선반(6타일)의 선행 덕에 성립,
  부상자(0.8)는 다음 타격의 최우선 후보 (부상 방치가 위험을 복리로 만든다).

private float _injuryRecovery;    // 간호 누적 (게임일 환산) — InjuryRecoverDays 도달 시 완치
private float _injuryNeglectDays; // 미간호 누적 — InjuryDeathAfterDays 도달 시 사망
private float _tendedUntil;       // 간호 유효 시각 (Time.time) — TendRunner가 틱마다 갱신
private float _tendMult = 1f;     // 현재 간호자의 회복 배율 (Job.TendRecoveryMult)

/// 부상 진입의 유일한 문 (ADR-M10-2) — 호출처는 ThreatService.ExecuteStrike뿐.
public void Injure(InjurySeverity severity)
{
    if (State == AgentState.Dead || Injury != InjurySeverity.None) return; // 중복 부상 무시 (M10은 단일 심각도)
    Injury = severity;
    _injuryRecovery = 0f; _injuryNeglectDays = 0f;
    if (State == AgentState.Moving || State == AgentState.Acting)
        AbortPlan("부상 — 하던 일 중단", warn: false, cooldown: false);
    ShowTransient(Pick(_cfg.InjuredLines));
    _sim.Hud?.Notify($"{ShortName}이(가) 다쳤습니다");
}

/// 간호 표시 (TendRunner 전용) — 유효 시간 안엔 사망 계단 정지 + 회복 진행 (결정 11).
public void MarkTended(float untilSec, float recoveryMult)

// SimTick — 굶주림 계단 블록 바로 아래 (같은 패턴, 원인은 분리 — ADR-M10-3):
if (Injury != InjurySeverity.None)

    else _injuryNeglectDays += deltaGameDays; // 간호 중엔 정지(홀드) — 리셋 아님 (⚠️②)

}

private void Die()

/// 간호 러너 — 최근접 미간호 부상자에게 이동 후 곁에서 채널링. 간호 표시는 대상의
/// MarkTended만 (부상 상태 쓰기는 대상 본인의 SimTick — ADR-M10-2 단일 지점 유지).
public sealed class TendRunner : ActionRunnerBase
{
    private VillagerAgent _target;
    private const float TEND_RANGE_TILES = 1.5f;  // 곁 판정 (알고리즘 상수)
    private const float TEND_MARGIN_SEC = 0.3f;   // 표시 유효 여유 (틱 간격 커버)

    public override bool Prepare(VillagerAgent agent)
    {
        _target = agent.Sim.FindNearestInjured(agent); // 자신 제외·미간호 우선·거리순 (결정적)
        if (_target == null) { FailReason = "간호 대상 없음"; return false; }
        MoveTarget = new Vector2Int(_target.TileX, _target.TileY);
        return true;
    }

    public override RunnerResult Tick(VillagerAgent agent, float dt)
    {
        if (_target == null || _target.State == AgentState.Dead) { FailReason = "대상 소멸"; return RunnerResult.Failed; }
        if (_target.Injury == InjurySeverity.None) return RunnerResult.Succeeded; // 완치 — 플랜 완료
        int d = Mathf.Abs(agent.TileX - _target.TileX) + Mathf.Abs(agent.TileY - _target.TileY);
        if (d > 2) { FailReason = "대상 이동 — 재계획"; return RunnerResult.Failed; } // 절뚝이라 드묾
        float mult = agent.Job != null ? agent.Job.TendRecoveryMult : 1f;
        _target.MarkTended(Time.time + TEND_MARGIN_SEC, mult); // 틱마다 갱신 = 연속 간호
        return RunnerResult.Running; // 완치까지 채널링 (P0 인터럽트가 자연스러운 손 떼기)
    }
}
// Goal_TendInjured: Trigger [InjuredCount >= 1] / Goal [InjuredCount <= 0] — OnValidate 정합 OK
// (목표 0은 트리거 ≥1 불만족). 부상자 2명이면 플랜에 Tend×2 (RipeCrop 연속 수확 패턴).
// Job_Medic: TendRecoveryMult 3 + Goal_TendInjured Boost +30 → 치료사가 먼저 달려간다.

/// 문(Construction.RemoveCountableAt / VillagerAgent.Injure)을 호출한다 (ADR-M9-3 사상).
/// Threats가 비면 SimulationLoop이 서비스 자체를 null로 (중립 불변식 — DisasterService 패턴).
/// 세이브 대상 = _lastStrikeDay (ADR-M10-10). 진행 중 개체는 저장 안 함.
public sealed class ThreatService
{

    public event Action<ThreatSO, int> OnStruck; // (위협, 피해 수) — HUD·대사 구독

        => aliveCount + farmPlots + houses;

    // Tick(gameTime): nextStrikeDay = _lastStrikeDay + tier.PeriodDays.
    //   gameTime ≥ nextStrikeDay - WarnDays → Forecasting = tier + OnForecast 1회
    //   gameTime ≥ nextStrikeDay → Spawn(tier) + _lastStrikeDay 갱신 + Forecasting 해제
    // Spawn: 가장자리 진입점(순수 EntryPoint — StableHash(발동 서수) 시드로 4변 중 택1,
    //   변 중앙) → ThreatAgent 생성. 목표 타일 = TargetVillagers ? 최근접 주민 타일
    //   : 밭 구역 앵커 (Zones.TryGetZone — 미확정이면 기지).
    // ExecuteStrike(so, tile): ThreatAgent 도착 통지가 유일한 호출처.
    //   TargetVillagers: 후보 = StrikeRadius 내 생존·비부상 주민 → 수 = DisasterService.LossCount
    //     (곡선 재사용 — 산식 이원화 금지) → 희생 = 거리순 앞 N (동률 AgentId 사전순, 순수)
    //     → 각자 Injure(Light). 재해와 달리 시드 셔플이 아닌 거리순: "가까이 있던 사람이
    //     다친다"가 도망 행동과 인과로 묶여야 한다 (⚠️①).
    //   !TargetVillagers: 후보 = 전체 밭 → LossCount + PickVictims(StableHash 시드 — 재해와
    //     동일) → RemoveCountableAt(FarmPlotCount, ...) (M9-B 문).

  축과 함께 설계돼야 함 — M11).
- **F-D 숙련도·호칭**, **시작 드래프트 UI** (SpawnVillager 문만 공유 준비), **버튼식 수락 UI**
  (Y/N 키가 이번 스코프), **위협 상주·서식지·세력권**, **몬스터 스프라이트 아트** (마커 폴백,
  에셋 교체는 자유), **세이브 구현** (주석 선언만 — ADR-M0-10).
- **창고·스톡 타격** (ADR-M10-5), **관개수로 부활** (파킹 유지 — 태크트리 백로그).

## 8. 관찰 항목 (🟡 — 발현 조건 명시, 즉시 수정 아님)

- 🟡 **Tend vs P0 우선순위 (45)**: 간호자가 굶으면서 간호를 놓지 않는 문제는 P0(100)가
  구조적으로 방지하나, 역으로 "간호가 노동(비축)에 항상 밀려 사망 과다"가 관측되면 Priority
  상향이 아니라 Job_Medic Boost 상향부터 (성격·직업 축이 지렛대 — ADR-M5-1).
- 🟡 **Flee 90 < P0 100**: 극한 기아 주민이 위협 곁에서 식사하는 장면이 관측되면 — 피신처와
  식사 앵커가 같은 모닥불이라 실害는 없을 것으로 예상. 어색하면 Flee 대사만 추가 (수치 불변).
- 🟡 **방랑자 주기 5일 고정**: 사망·이탈이 잦은 판에서 회복이 못 따라가면 "인구 결손 연동
  주기"(결손 시 단축)를 검토 — 단 먼저 위협 곡선부터 (변인 분리, 밸런스 4커밋 방식).
- 🟡 **Goal_ExpandFarm 절대값 트리거 (M9 잔여)**: 마을 규모에 밭이 포함되므로 확장 정체가
  티어 상승을 막을 수 있다 — M10 Play 관측에서 밭 수 정체가 보이면 FoodDaysLeft 전환을 함께.
- 🟡 **위협 개체의 타일 예약 비참여**: 주민과 겹침이 시각적으로 거슬리면 표현(스프라이트
  정렬)만 조정 — 예약 참여는 M11 전투에서 (ADR-M10-4).
