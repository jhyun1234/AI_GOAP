## 0. 성공 기준 (측정 가능)

- **S1** 늑대 1마리 출몰 시 주민(사냥꾼 우선)이 반격하고, Console에 `[Combat] 타격 — <주민> → <위협> (HP n→m)` 로그가 찍힌다.
- **S2** 위협 HP가 도주선 이하로 내려가면 도주하고 `[Combat] 격퇴 — <위협>` 로그 + 연대기 사건(Repelled)이 남는다. HP 0이면 `[Combat] 사냥` 로그 + 고기 드랍(전역 RawFoodStock 증가 로그).
- **S3** 적습(2마리 이상)에서 무리 잔존율이 도주선 아래로 내려가면 잔여 전원이 도주한다 (개체별 반죽음 없이 — 무리 단위 로그 1줄).
- **S4** 주민 선택 정보줄에 `체력 n/100`이 보이고, 포만 0 지속 시 HP가 매 게임일 감소하는 로그가 찍힌다. HP 0 = 사망 (기존 사망 문 Die/StarveToDeath 경유).
- **S5** 무기 보유 주민의 타격 간격이 맨손 대비 배율만큼 짧다 (로그의 타격 소요 시간으로 확인 가능).
- **S6** 명령("싸워라")을 내리면 기존 명령·거부 시스템을 경유하고, 겁 많은 주민은 거부할 수 있다 (RefusedXXX 로그).
- **S7** 중립 불변식: `WorldConfig.Threats`가 비면 M20 동작과 완전 동일 (전투·HP 감소 이벤트 0). 신규 필드 전부 기본값이면 기존 판과 동일 진행.
- **S8** 게이트: 기존 전체 green 유지 + 신규 `M21_CombatGates` green. 특히 부상·간호 게이트(M10_Injury·M11_Care)가 HP 재표현 후에도 green.

## 3. ADR — 구현 중 갈릴 판단을 미리 결정 (바꾸려면 사유를 커밋에)

### ADR-M21-1 · 북극성 개정 — "격퇴하며 버티는 기록 경주" (ADR-M10-8 폐기)
겨울 = 계절 시험(대비로 버팀), 위협 = 능동 시험(반격 가능). 연대기·기록 경주(M13~M15)는 북극성의 몸 그대로. 격퇴·사냥은 연대기에 사건으로 남아야 한다 — 검증 문장: *"3년차 봄, 늑대 다섯 적습을 사냥꾼이 앞장서 물리쳤다."* 舊 ADR-M10-8("격퇴 불가")은 폐기 — 당시 이유(위협 = 페이스메이커)는 래칫이 계승하고, 격퇴가 래칫을 되돌리지 못하게 하는 것으로 원 의도를 지킨다(ADR-M21-4).

### ADR-M21-2 · 주민 HP = 단일 생존 척도, 쓰기는 문 하나
- `Hp`는 VillagerAgent의 상태. **쓰기 문은 `TakeDamage(amount, DamageCause)` 하나** + SimTick의 자연 변화(아사 감쇠·출혈·간호 회복). 밖에서 Hp를 직접 만지지 않는다 (ADR-M0-3 정신).
- 기존 축의 재표현 (삭제 아님): 부상 상태·간호 2단계·치료사 완치·`MyWasAttacked`/`MyWasStarved`·사망 문(Die/StarveToDeath) 전부 유지. 바뀌는 것은 "죽음까지의 시계"가 일수 카운터에서 HP로 옮겨지는 것뿐.
- 아사는 즉사가 아니라 진행: 포만 < `StarvingBelowSatiety` 지속 시 HP가 깎인다. **HP 회복은 포만 충족 + (부상 시) 간호**로만 — 자연 회복으로 전투 피해가 공짜로 지워지면 위협이 다시 날씨가 된다.
- 플래닝 슬롯 아님: goal·액션은 HP를 조건으로 걸지 않는다 (이번 범위). HUD·판정만 읽는다. 슬롯 승격은 필요가 관측된 뒤 별도 결정.

### ADR-M21-3 · 판정은 CombatService 한 곳 — 에이전트=주민 전제 금지
피해 계산·위협 HP 차감·도주선·무리 도주선·사냥 판정·드랍은 전부 CombatService. ThreatService는 출몰 스케줄·수명, ThreatAgent는 표현+이동, VillagerAgent는 표현+자기 상태의 문(TakeDamage) 유지 — "위협은 표현+이동, 판정은 서비스"(M10-C) 확장. 타격자 식별은 인터페이스·ID 기반 — 몬스터·타 종족이 같은 문으로 들어온다 (CLAUDE.md 후반 확장 규칙 1).

### ADR-M21-4 · 래칫 티어 단조 유지 + 완충은 규모·간격만 (양방향, 클램프)
`UnlockDay` 시간 단조는 불가침 — 격퇴 실적이 티어를 되돌리지 못한다 (영구 안정 루프 구조적 차단, M10R 원 진단 유지). 완충은 **다음 출몰의 마릿수·간격**에만:
- 격퇴 성공(무리 격퇴/사냥) → 다음 출몰 마릿수 완화 (이김의 보상).
- 주민 사망 → 다음 출몰 마릿수 완화 + 간격 지연 (자비 — 손실이 마모가 아니라 리듬이 되게. 림월드 adaptation의 이중 축 그대로).
- 완충은 **1회 소모·클램프(최소 1마리)** — 누적 스택이 무한히 쌓여 위협 0이 되는 길 금지.

### ADR-M21-5 · 무기 = 배율, 게이트 금지 (맨손 가능)
무기 없어도 싸울 수 있다. 무기는 타격 간격 배율 (M20 헌장 문법 — 부재가 느껴지는 장치: 무기 없는 판은 전투가 느려 부상이 는다). `ItemType.PrimitiveWeapon` 재활용, 재료 = 나무 3 + 돌 2 (enum 주석의 기존 값 — 발명 아님). 소유는 개인 논리 슬롯 `MyHasWeapon` (분실·내구도 없음 — 이번 범위).

### ADR-M21-6 · 마릿수·HP는 에셋이 정의한다 (콘텐츠 비용표 유지)
위협 신필드는 전부 ThreatSO append (에셋 YAML은 **Edit만** — M19 교훈: 셸 재작성 금지). 완성 후 몬스터 종 추가 = 에셋 1개 + Threats 등록, 코드 0줄이 유지되어야 한다 (M10-G 리허설 대상).

### ADR-M21-7 · 참전은 하이브리드 — 자율(성향·직업) 기본 + 명령은 거부 가능
Goal_Fight와 Goal_Flee는 **같은 트리거(ThreatNear==1)·반대 성향 가중치** — 겁 많으면 피신이 이기고, 용감하거나 사냥꾼이면 반격이 이긴다. 플레이어 명령("싸워라")은 기존 명령·거부 시스템(JudgeOrder) 경유 — 완전 징집 금지 (정체성 C: 협상. 림월드 분석 결론). 명령을 쓸 시점은 화면이 알려준다 (적습 중 상시 표시 — W8).

### ADR-M21-8 · 위협의 죽음도 문 하나
위협 HP 차감·도주 전환·사망은 CombatService가 ThreatAgent의 문(`ApplyHit`→내부 상태) 경유로만. 도주 = 격퇴 사건, HP 0 = 사냥 사건 + 드랍. **드랍은 전역 RawFoodStock** (개인 아님 — 격퇴는 공용 무대, ADR-M20-9 전이 통로: 사냥꾼의 효율이 마을 비축으로 흐른다).

## 4. 수치 관계식 (전부 제안치 — 기존 값 우선 원칙, 조용히 넣지 않는다)

기존 값 위치: 아사 시계 = `AgentConfigSO.DepartAfterStarvingDays`, 부상 시계 = `InjuryDeathAfterDays(1.5)`·`InjuryRecoverDays(1)`. HP 환산은 이 시계들을 **보존**하도록 역산한다:

- `MaxHp = 100` (제안). 표기 정수.
- 아사 감쇠: 포만<10 지속 시 `StarveHpLossPerDay = 100 / DepartAfterStarvingDays` → 기존과 같은 날수에 죽는다 (아사 소요 시간 불변 — 검증된 밸런스 보존). W1 구현: 필드 0 = 자동 환산 (OnValidate 아닌 접근자 `StarveHpPerDay`).
- 출혈: 부상 상태·미간호 시 `BleedHpLossPerDay = InjuredBelowHp / InjuryDeathAfterDays` (W1 구현 확정 — 0 = 자동 환산. 부상 진입 시 HP ≤ InjuredBelowHp이므로 잔여분 기준. 검산: 67/1.5 ≈ 44.7/일 → 방치 1.5일 사망, 기존 시계 보존). 간호 중 출혈 정지(홀드 — 기존 규약 계승), 회복 = `TendRecoveryMult` 계승.
- HP 자연 회복: `SatedHpRegen`/일 (W1 구현 확정) — **굶주리지 않고 부상도 아닐 때만**. 부상 중 회복은 간호의 몫 (전투 피해가 시간만으로 지워지면 위협이 다시 날씨가 된다 — ADR-M21-2 "포만 충족" 경로의 실체).
- 위협 타격 피해: `ThreatSO.StrikeDamage = 34` (제안 — 3대 = 사망. 기존 "부상 1회 = 사망 아님" 보존: 1대는 부상+감속).
- 부상 상태 파생: 피격으로 `Hp < 67`이면 `Injury = Light` (기존 InjuredMoveSpeedMult 0.4·노동 goal 차단 그대로).
- 위협 HP: Tier1 늑대 60 / Tier2 무리 개체 60 / Tier3 곰 150 (제안). 주민 맨손 타격 피해 `VillagerHitDamage = 10`, 타격 간격 `CombatHitSec = 4초` → 맨손 1:1 늑대 = 6대·24초 (그동안 늑대도 1~2회 반격 — 맨손 솔로는 아프다).
- 무기 배율 `WeaponHitSecMult = 0.5` (2배 빠름), 사냥꾼 `CombatDurationMult = 0.5` — 곱 결합 (무장 사냥꾼 = 4배. M20 배율 문법).
- 개체 도주선 `FleeBelowHpPct = 0.4`, 무리 도주선 `RoutBelowPct = 0.5` (잔존 비율 < 50% → 전원 도주).
- 마릿수: `SpawnCount = clamp(SpawnCountBase + ⌊(day − UnlockDay) / CountGrowthEveryDays⌋ − 완충, 1, SpawnCountMax)`. 에셋 제안: Wolf 1/성장 없음/최대 1 · Pack 2/10일마다 +1/최대 5 · Bear 1/20일마다 +1/최대 2.
- 완충: 무리 격퇴 1회 → 다음 출몰 −1마리 (1회 소모). 주민 사망 1명 → 다음 출몰 −1마리 + 발동 +2일 지연 (1회 소모, 스택 상한 3).
- 정찰 예고 연장: `JobSO.WarnBonusDays = 1` (Job_Scout만) — 생존 정찰꾼 1명 이상이면 WarnDays에 가산 (인원 비례 아님 — 1명이면 족하다).

⚠️ 위 숫자들은 전부 **제안치**다. 구현 시 에셋에 넣고, Play 관측으로 조정한다. 기존 시계 값(아사·부상 일수)은 **바꾸지 않는다** — M17 값의 짝 규율.

- **B1 명령 원정 특례** — 명령된 Goal_Fight는 **트리거(ThreatNear==1)·즉시 달성 검사를 우회**하고 러너가 최근접 위협 위치로 원정한다 (완료 = 위협 소멸·도주). 특례 없으면 밭 타깃 체류 위협에 원거리 주민은 ①트리거 미발동=자율 불가 ②명령해도 goal 조건(ThreatNear==0)이 이미 만족돼 빈 플랜 즉시 완료 = 명령 무의미 — W8 "⚔ 습격 중" 상시 프롬프트가 개입을 권하는데 수단이 없는 공수표가 된다. 부상 거절·JudgeOrder·보상 문법은 기존 그대로. **자율 참전은 근접(ThreatNear) 유지** — 특례는 명령에만.

**DoD**:

## 재미 검증 — 플레이어가 화면에서 새로 보게 되는 것

지금까지 위협은 지나가는 날씨였다 — 예고가 뜨고, 누가 물리고, 늑대는 떠났다. 이번 작업이 끝나면 늑대 무리가 **마을에 머무르며** 프롬프트에 "⚔ 습격 중"이 상시로 떠 있고, 겁 없는 주민과 사냥꾼이 **마주 서서 싸우는 장면**이 벌어진다. 플레이어는 주민을 골라 "싸워라/피해라"를 명령할 수 있고(겁쟁이는 거부한다), 정보줄의 **체력이 깎이는 것**을 보며 개입 시점을 잰다. 이기면 무리가 꼬리를 말고 도주하는 **격퇴 장면**과 고기 보상, 전멸 화면과 연대기에는 "늑대에게 죽었다"와 "적습을 물리쳤다"가 남는다. 굶주림도 즉사가 아니라 체력이 줄어드는 과정이 되어, "제때 개입"의 창이 모든 죽음 앞에 열린다.
