## §1. ADR (구현 중 갈릴 판단 — 바꾸려면 사유를 커밋 메시지에)

- **`ADR-M24-1` 압력은 단조다.** 게임일·역대최고인구·조우횟수 세 항 전부 감소 불가.
  난이도를 낮추는 어떤 경로도 만들지 않는다. 회복은 **자비 장치(방랑자)** 가 맡는다.
  *(근거: `ADR-M10R-1`이 고친 음성 피드백 루프의 재발 방지 + 그 거울상인 회복 불가 방지)*
- **`ADR-M24-2` 마릿수는 예산이 정한다.** `ThreatSO.SpawnCountBase/Max/GrowthEveryDays`는
  **휴면**시킨다(값 무시). 두 산식이 공존하면 언젠가 갈린다.
- **`ADR-M24-3` 편성은 예고 시점에 확정된다.** 발동 시점에 다시 계산하지 않는다.
- **`ADR-M24-4` 전략은 데이터다.** 종족별 행동 차이를 `if (종족 == 오크)` 로 쓰는 순간 반려.
  `{특성, 해금압력}[]` 배열 + 미등록 = 중립 폴백만 허용한다. *(`ADR-M0-1` 정신 계승)*
- **`ADR-M24-5` 조우는 출몰이다.** 격퇴 여부와 무관 (N6).
- **`ADR-M0-9` 개정** — 슬롯 번호 재사용 금지의 예외: **에셋 참조 0이 게이트로 증명된
  휴면 슬롯**에 한해 재사용을 허용한다.
  *개정 사유: 번호 재사용을 금지한 이유는 기존 에셋의 참조가 밀리는 것인데, 휴면 3칸은
  `M19-T1`이 에셋 참조 0을 지속 감시해 왔으므로 그 위험이 존재하지 않는다.*

```csharp
/// <summary>전역압력 (순수 — 게이트 M24-T2). 두 항 모두 단조 증가라 절대 줄지 않는다.
/// 🔑 인구는 **현재값이 아니라 역대 최고값**이다 — 현재값을 쓰면 사망이 난이도를 낮춰
/// ADR-M10R-1이 고친 음성 피드백 루프가 그대로 돌아온다.</summary>
public static int GlobalPressure(float gameDay, int peakPopulation, float daysPerPoint, int popPerPoint)
    => Mathf.FloorToInt(gameDay / Mathf.Max(1e-4f, daysPerPoint))
     + Mathf.FloorToInt(peakPopulation / Mathf.Max(1, popPerPoint));

/// <summary>종족 유효압력 (순수). 조우가 많을수록 그 종족만 먼저 진화한다.</summary>
public static int EffectivePressure(int globalPressure, int encounters, float k)
    => globalPressure + Mathf.FloorToInt(encounters * k);
```

## §4. 수치 관계식 (전부 **제안치** — 기존 값 우선 원칙, `ADR-M0-2`)

### 4.1 압력과 등급

```
전역압력 = ⌊게임일 / D⌋ + ⌊역대최고인구 / S⌋          D = 3(제안) · S = 4(제안)
유효압력(R) = 전역압력 + ⌊조우횟수(R) × k(R)⌋          k: 고블린 0.5 · 오크 0.25 · 기사단 0.3 · 악마 0.2
예산 = 전역압력
악마 마릿수 = clamp(1 + ⌊(게임일 − 25) / 30⌋, 1, 4)     W = 25일 · G = 30일 (제안)
```

| 등급 | 고블린 | 오크 | 기사단 | 악마 |
|---|---|---|---|---|
| 1 | 1 | 3 | 4 | — |
| 2 | 2 | 5 | 6 | — |
| 3 | 4 | 8 | 9 | — |
| 4 | 7 | 12 | 14 | — |

> 🔴 **기존 값 우선**: 체력·타격 피해·재타격 주기·감지 반경은 **현행 늑대/곰 에셋 값을 계승**한다
> (`MaxHp 60/150` · `StrikeDamage 34` · `RepeatStrikePeriodDays 0.25` · `StrikeRadius 3` ·
> `DangerRadius 6` · `MoveSpeed 2.5`). 새로 발명하지 않는다.

### 4.2 전략 테이블 (공정성 검사 대상 — 게이트 M24-T4)

> **게이트 M24-T4의 판정 단위**: *"이 특성의 답이 **지금 이 차수에 존재하는가**"*이다.
> M22에서 이미 완료된 수단(울타리·문 잠금·망루·함정)은 압력 0부터 가능하므로 항상 통과한다.
> 아직 없는 수단(창고 잠금 = 2차 · 천사 = 3차)을 답으로 갖는 특성은 **이번 차수 에셋에
> 넣는 순간 게이트가 red** 가 된다. 순서를 문서가 아니라 기계가 강제한다.

| 종족 | 해금압력 | 특성 | 답 | 답 가능 시점 |
|---|---|---|---|---|
| 고블린 | 0 | `ExitOnGoal` (한 번 치고 즉시 이탈) | 추격·망루 요격 | M22 3차 완료 |
| | 8 | `ShortWarning` | 상시 방어선 | M22 완료 |
| | 14 | `ApproachFlank` | 문 잠금 L | M22 2차 완료 |
| | 22 | `TrapLearning` | 함정 재배치 | M22 3차 완료 |
| 오크 | 0 | (없음 — 정면) | 울타리 | M22 완료 |
| | 10 | `NoFlee` | 함정·다수 무장 | M22 3차 완료 |
| 기사단 | 6 | `TargetDefense` | 망루 분산 | M22 3차 완료 |
| | 12 | `ApproachMultiPoint` | 전 방향 방어 | M22 완료 |
| | 20 | `ApproachFlank` | 망루 재배치 | M22 3차 완료 |
| 악마 | 0 | `NoFlee` | 총력전 | M22 완료 |

> 🔴 **1차에 넣지 않는 특성 2건** (답이 없어 `M24-T4`에 걸린다):
> 고블린 `TargetStorage`(답 = 창고 잠금) → **2차** · 악마 압력15 "천사를 노린다"(답 = 천사 호위) → **3차**.
> 고블린의 1차 정체성은 `ExitOnGoal`이 맡는다 — **한 번 치고 바로 달아나므로 잡으려면
> 쫓아가거나 망루로 요격해야 한다.** 창고를 털기 시작하는 것은 2차부터다.

### 4.3 개입 창 (게이트 M24-T3)

```
개입 창(초) = ⌈주민HP(100) / (StrikeDamage × 스탯배율)⌉ × RepeatStrikePeriodDays × 하루초
             ≥ 8초 (제안 하한)
```
스탯배율이 이 하한을 깨면 **배율 상한이 그 지점에서 잘린다.** 압력이 올라도 개입 창은 안 줄어든다.

Day 20쯤, 화면 위에 예고가 뜬다 — **"3일 뒤: 고블린"**. 지난번에 고블린이 문을 두드리고 갔던 게 떠올라 문을 잠그고 함정을 문 앞에 깐다. 그런데 이번엔 고블린이 문 쪽으로 오지 않고 **망루가 없는 남쪽으로 돌아 들어온다** — 다섯 번 막히는 동안 배운 것이다. 다음 예고는 **"기사단"** 이고, 이번엔 세 방향에서 동시에 들어와 망루부터 부순다. 같은 날짜, 같은 마을인데 **대비해야 할 것이 매번 다르다.** 그리고 크게 당해 사람이 절반으로 줄어든 다음 날, 낯선 사람이 마을 어귀에 나타난다 — 평소보다 훨씬 빨리.

지금까지는 늑대가 와서 물고 갔고, 플레이어가 할 수 있는 일은 울타리를 더 두껍게 치는 것뿐이었다. **이 차수가 끝나면 "무엇이 오는가"를 알고 "그에 맞게 다르게 준비하는" 일이 생긴다.**
