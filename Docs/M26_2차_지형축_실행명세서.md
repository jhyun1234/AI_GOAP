### 🔴 전제 1의 전말 — 1차가 남긴 구멍

1차 W3은 지형을 **통행 배열 두 장**에 먹였고([`SimulationLoop.cs:1217`](../Assets/Scripts/M0/SimulationLoop.cs:1217)),
W6은 **리스폰**에 통행 판정을 넘겼다(`ConfigureRespawn(..., (x,y) => Terrain.IsWalkable(x,y) && ...)`).
그런데 **초기 스폰은 아무것도 안 받았다** — `SpawnAll(baseX, baseY, radius, sink)` 에 판정이 없다.

증상: 판 시작 시 나무·돌이 **호수 위·절벽 위에 설 수 있다.** 그 노드가 발견되면
`FindNearestDiscovered` 가 고르고 → 주민이 가려다 `Unreachable` 로 접힌다 →
**최근접이 계속 그 노드면 goal이 반복해서 접힌다.**

⚠️ 이것은 §14 관찰항목 3(*"물이 길을 너무 막는가"*)의 **진짜 원인 후보**다. 비율을 낮추기 전에
이것부터 고쳐야 한다 — 안 고치고 물을 줄이면 **증상만 옅어지고 원인은 남는다**(안티패턴: 증상 패치).

## §1. 성공 기준 (숫자로 — 회귀가 어디에 보이는가)

1. **통행 불가 타일 위의 자원 노드 = 0개.** 시드 20개를 전수로 돌려 `Terrain.IsWalkable(n.TileX, n.TileY) == false` 인 노드를 세어 0 (게이트 `M26B_T1`).
   🔑 **실패 가능성 증명 병기**: 판정을 끄면 **0이 아니어야** 한다 — 아니면 빈 검사다.
2. **지형 전용 자원이 그 지형에서만 난다.** 늪 전용 자원 노드 전수의 지형이 늪, 물가 자원 전수가 물에 인접 (게이트 `M26B_T2`).
3. **먼 쪽을 고르는 일이 실제로 일어난다.** Play 1판에서 *"가까운 후보를 두고 먼 후보를 골랐다"* 로그 **≥ 1건** (W4의 존재 증명 — 최근접만 보던 시절에는 **구조적으로 0건**).
4. **중립 불변식**: 위험·지형 가중치를 0으로 두면 W4의 선택 결과가 **`FindNearestDiscovered`와 타일 단위로 동일** (게이트 `M26B_T4`). 기존 게이트 `M0_WorldGates` 2건이 무수정 통과.
5. **위험 기억이 선택을 바꾼다.** 들판 위협에 당한 뒤, 같은 자리의 노드가 **여전히 최근접인데도** 다른 노드가 선택되는 로그 ≥ 1건 (게이트 `M26B_T6` + Play).
6. **구조가 구조적으로 가능하다.** 부상 방치 사망 소요(`InjuryDeathAfterDays`)가 **맵 끝에서 마을까지 걷는 시간보다 길다**를 순수 함수로 검산 (게이트 `M26B_T7`). 🔴 **짧으면 W7은 장식이다** — 이 검산이 먼저다.
7. **게이트 총계 464 → 486** (N = 22, W8에서 확정 — 2026-08-11 `failed="0"`). 기존 게이트 전원 무수정 통과.
8. **재미 판정 (사용자 Play)**: *"저 자원은 탐나는데 저기는 가지 말자"* 라는 판단이 한 번이라도 서면 성립.

## §2. ADR (구현 중 갈릴 판단을 미리 결정 — 바꾸려면 사유를 커밋에)

### ADR-T2-1 — 노드가 설 수 있는 땅의 판정은 **하나**다

초기 스폰과 리스폰이 **같은 판정 함수**를 쓴다. 🔴 **개정 (2026-08-11 자가 재검토)**: 그 판정은
**자원 타입까지 받는다** — W2가 지형 조건을 자원별로 걸었는데 판정이 좌표만 받으면 리스폰이
조건을 못 읽어 **은이 고갈 후 늪을 걸어 나온다.** W1에서 통행에 대해 고친 이원화를 W2가
지형 조건으로 **다시 만들어 냈다.** 판정 하나 = `(자원, x, y)`.

리스폰이 이미 쓰는
`(x, y) => Terrain.IsWalkable(x, y) && !Construction.HasBuildingAt(x, y)` 를 **그대로** 스폰에 넘긴다.

🔑 **왜 못 박는가**: 판정이 둘이면 "리스폰은 피하는데 스폰은 서는" 지금 상태가 **다른 모양으로
재발한다.** 舊 아키텍처를 죽인 3대 병 중 하나가 다중 경로다 (`ADR-M0-3`의 정신).

### ADR-T2-2 — 지형이 무엇을 낳는지는 **에셋이 정한다**

`ResourceTypeSpawnData` 에 지형 조건 필드를 append 한다. **코드에 "늪은 X를 낳는다" 표를 두지
않는다** (`ADR-M0-2` · 1차 `ADR-T-5`의 재사용). 지형을 늘려도, 자원을 늘려도 **코드 0줄**.

### ADR-T2-3 — 채집 선택은 **거리 하나 → 점수 하나**로 바꾸고, 최근접은 그 특수 경우다

`FindNearestDiscovered` 를 지우지 않는다. 점수 함수를 새로 만들고 **모든 가중치가 0이면
결과가 최근접과 같아지도록** 만든다 (중립 불변식, 성공 기준 4).

🔑 **왜 이 형태인가**: 舊 함수를 갈아엎으면 회귀가 어디서 났는지 알 수 없다. 중립 불변식이
있으면 **가중치를 켜고 끄는 것만으로 원인을 가른다** (1차 `TerrainService.IsEmpty` 와 같은 규약).

⚠️ **비용은 거리가 아니라 경로 비용이다.** 늪 너머 10칸과 평지 10칸은 맨해튼으로 같지만 실제로는
다르다 — 그러나 후보마다 A\*를 돌리면 예산을 넘는다. **1차 타협**: 맨해튼 거리 × 목적지 타일의
`EnterCost` 를 근사로 쓴다. 정확한 경로 비용은 **3차 이후** (스코프 가드).

### ADR-T2-4 — 위험 기억은 **마을이 아니라 개인**이 갖는다

당한 사람만 안다. 마을 전체가 즉시 아는 것은 (ㄱ)정보가 공짜가 되고 (ㄴ)한 명의 불운이
전원의 행동을 잠근다. 성격이 이미 있는 축(`M12` 성향 벡터)이므로 **겁쟁이는 오래 기억하고
용맹은 빨리 잊는** 자리를 남긴다 — 값은 3차.

⚠️ 전달 통로(대화로 퍼짐)는 **이번에 안 한다** — `ChatterSO` 가 있어 나중에 에셋 1칸이다.

### ADR-T2-5 — 새 `ResourceType` 을 만들지 않는다 (슬롯 잔여 1)

`SlotId.Count = 51`, 예산 **52** → 잔여 **1칸**. 새 자원 타입 하나가 슬롯 하나를 먹는다.
늪 희귀자원은 **기존 타입 재배치**로 표현한다 (예: `Silver` 를 늪·원거리 전용으로).

🔴 이 결정을 뒤집으려면 **슬롯 예산 증액을 먼저 결정**해야 한다 — 명세 안에서 조용히 넘지 않는다.

### ADR-T2-6 — 들판 위협은 **새 상태를 만들지 않는다**

배회(`PickWanderTile` · `WanderAnchor` · `WanderRadiusTiles`)가 이미 있다. 상주 = **퇴장 조건이

```csharp
// 후보 판정에 두 조건 + 밀도를 얹는다. 밀도는 **채택 확률**이지 개수가 아니다
// (개수를 건드리면 nodeCount 의 뜻이 흐려진다).
private bool TerrainAccepts(ResourceTypeSpawnData d, int tx, int ty)
{
    TerrainTypeSO here = _terrainAt?.Invoke(tx, ty);
    if (d.allowedTerrain is { Length: > 0 } && !System.Array.Exists(d.allowedTerrain, t => t == here))
        return false;
    if (d.adjacentTerrain is { Length: > 0 } && !HasNeighbor(tx, ty, d.adjacentTerrain))
        return false;
    return here == null || _rng.NextDouble() < here.NodeDensityMult;   // 1 = 오늘과 동일
}
```

## §13. 재미 검증 — 플레이어가 화면에서 무엇을 새로 보게 되는가

지금 지도는 **예쁘지만 균질하다.** 호수를 돌아가는 것은 보이지만, 돌아가서 얻는 것은
바로 옆 나무와 똑같다. 땅이 달라도 **결과가 같으니 판단할 것이 없다.**

이 차수가 끝나면 땅마다 나는 것이 달라진다. 은은 늪 안쪽에만 있고, 물고기는 물가에만 선다.
그리고 들판에는 **돌아다니는 것들이 산다.** 채집하러 나선 주민이 처음으로 갈림길에 선다 —
가까운 덤불은 늪 건너에 있고, 안전한 덤불은 두 배 멀다. 주민은 늪을 피해 먼 쪽으로 돌아가고,
화면에는 *"가까운 후보를 두고 먼 후보를 골랐다"* 가 뜬다.

그리고 한 번 당하고 나면 **그 자리를 피한다.** 플레이어가 아무것도 안 가르쳐 줬는데, 영희는
어제 오크에게 당한 남쪽 숲을 오늘 지나치고 북쪽으로 간다.

판이 끝났을 때 남는 말이 달라진다 — *"이번 판은 은이 늪 건너에만 있어서, 결국 아무도
못 갔던 판이었어."*
