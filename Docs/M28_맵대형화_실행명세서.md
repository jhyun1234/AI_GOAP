## §0. 성공 기준 (숫자)

1. **100² 회귀 0**: W2(밀도 스키마) 적용 후 100² 스폰 결과 = 기존과 동일
   (나무 40 · 돌 25 · 철 15 · 은 4 · 식량 12 · 물가 8 — 게이트로 검산).
2. **200² 부팅**: 노드 = 밀도 ×4 (나무 160 · 돌 100 · …) · 상주 고블린 **16무리**
   (`BandCount` — T8c 산식) · 게이트 전체 green.
3. **쿼리 예산**: 위협 리패스(추격·배회) ≤ **4건/프레임** — 5번째 `TryConsume()` = false
   (순수 함수 게이트).
4. **여유율 자동 green**: `M26B_T7` 200² = 1.5일 ÷ (100초÷600초/일) = **9.0×** (하루 600초 덕).
5. Play(사용자): 200² 10분 방치 — NoSolutionFound 0 · 프레임 히치 체감 0 · 지형 렌더 확인
   (🔴 화면 판단은 렌더해서 볼 것 — 호수·능선 덩어리감 §7-1).

## §0.5 재미 검증 — 플레이어가 화면에서 새로 보는 것

맵이 4배가 되면서 시작 화면 밖에 **진짜 미지**가 생긴다: 은광은 마을 반경의 80%(80타일 =
편도 도보 40초) 밖이라 원정이 "준비하고 떠나는 일"이 되고, 들판에는 상주 고블린 무리가
4개가 아니라 **16개** 깔려 어느 길로 채집을 가느냐가 매판 달라진다. 위협·방랑자는 맵 변에서
마을까지 100타일을 걸어오므로 예고와 도착 사이가 길어져 **대비할 시간**이 체감된다.
카메라를 끝까지 빼면 아직 못 밝힌 어둠이 화면 대부분을 덮는다 — 탐험가가 처음으로 직업값을
하는 판이다.

## §2. 분류 원칙 — 개수·거리의 이중 장부 (이 명세의 심장, M27 §2의 자매)

맵 크기를 k²배(면적) 키울 때, 공간 수치는 넷 중 하나로만 움직인다:

| 분류 | 뜻 | 환산 | 예 |
|---|---|---|---|
| **개수 = 면적당** | 밀도가 경험이다 | **per-10k-타일로 적고 코드가 곱한다** | 노드·클러스터·상주 무리(선례 T8c) |
| **거리·절대** | 도보 시간의 의미 (생존 루프 비용) | **유지** | 사다리 하위(식량 5·나무 10·돌 15·물가 20·철 25) · 국소 반경(시야·기억·배회·안전 12) |
| **거리·비례** | 맵 대비 위치의 의미 (희귀 = 끝자락) | **반경 대비 비율로 재산정** | 은광 40(=반경의 80%) → 200²에서 **80** |
| **덩어리·절대** | 우회 비용의 의미 | **유지** — 개수가 면적 비례로 늘어 밀도 보존 | `PLAIN_CELL 18`·`RELIEF_CELL 26` (호수가 커지는 게 아니라 **많아진다**) |

- **왜 은광만 비례인가**: M26 2차의 문장 "거리 = 희귀도 = 위험"에서, 하위 단은 *생존 루프의
  도보 비용*(600초 하루에 5타일 = 2.5초 — 시간 축과 짝)이고 최상단은 *맵의 끝자락*이라는
  위치 서사다. 전부 절대로 두면 큰 맵의 바깥 75%가 빈 껍데기가 되고, 전부 비례로 늘리면
  생존 루프가 늘어진다. **바깥 고리는 300+ 신규 컨텐츠(사용자 방향)의 자리로 비워 둔다.**
- **덩어리 유지의 근거**: 노이즈 격자가 절대면 호수 크기는 같고 개수가 면적 비례 — 면적당
  원칙과 정합. "대륙급 대형 호수"는 컨텐츠 욕심이지 확장 산수가 아니다 → 백로그.
  단 ⚠️ 화면 판단은 렌더해야 안다 — §0-5 Play 확인 항목.

## §4. ADR-M28 (구현 중 갈릴 판단 — 바꾸려면 사유를 커밋에)

- **ADR-M28-1 (개수는 면적당으로만)**: 공간에 뿌려지는 것의 수는 절대 개수 필드 신설 금지 —
  `~Per10kTiles` + 코드 환산(`Round(density × tiles/10000)`, 최소 1은 명시 결정)만 허용.
  선례 = `ResidentBandsPer10kTiles`(T8c). *"지금 맵 기준으로 적은 수는 전부 미래의 버그다."*
- **ADR-M28-2 (거리 이중 분류)**: 새 거리·반경 값은 §2의 절대/비례 분류를 툴팁 첫 단어로
  선언한다(`[절대]`/`[비례]`). 비례 값은 "반경의 몇 %"를 주석에 남긴다.
- **ADR-M28-3 (맵 정의 짝)**: `mapSize`·`mapOffset(=mapSize/2)`·씬 MapQuad 스케일 셋은 한
  몸이다 — W4 게이트가 감시. 맵 크기 변경 커밋은 셋을 함께 만진다.
- **ADR-M28-4 (주민 경로는 무예산)**: 쿼리 예산은 **위협의 연속 소스**(추격 리패스·배회
  재선정)에만 건다. 주민 경로(액션 시작)는 게임 코어라 조이지 않는다. 웨이브 스폰 버스트는
  드문 이벤트(주기 1일 = 10분)라 1차에서 제외 — §8 승격 조건에서 재평가.
- **ADR-M28-5 (교체 금지 승계)**: HPA*·렌더러 더티 스캔 최적화·JPS/A* 개조는 **프로파일링
  실측 후** (`ADR_경로탐색_확장경계` 판단 규칙). 이 명세는 예산 상한 하나만 신설한다.

  /// 상한 초과 = 실패가 아니라 연기다: 추격은 지난 경로로 한 프레임 더 걷고 다음 프레임 재시도.

  public sealed class PathQueryBudget

      public bool TryConsume(int frameCount)
      {
          if (frameCount != _frame) { _frame = frameCount; _used = 0; }
          return ++_used <= PER_FRAME;
      }
  }

  [Min(0f)] public float nodeCountPer10kTiles;
  [Min(0f)] public float clusterCountPer10kTiles;

## §7. Play 관측 항목 (사용자)

1. **지형 덩어리감** (200²) — 호수·능선이 "물방울"로 보이면 §2-3 유지 판정을 뒤집는다 (렌더가 정본).
2. **원정 체감** — 은광 80타일(편도 40초)이 "준비하고 떠나는 일"로 느껴지는가, 그냥 지루한가.
3. **탐험 페이스** — 시야 7·보폭 15로 4만 타일: 밝히는 재미인가 노동인가 (이론 하한 ~24분).
4. **위협 도착 시간** — 진입→마을 100타일(50초): 예고~도착의 대비 시간이 재밌는 길이인가.
5. **프레임** — 10분 방치 중 히치 체감 (특히 웨이브 스폰 순간 — ADR-M28-4 재평가 재료).

## §8. 300² 승격 조건 (2차 차수의 관문 — 전부 통과해야 값 회전)

3. 웨이브 규모 × A* 최악 비용(300² = 노드 9배) 재검토 — 스폰 버스트 히치가 실측되면 분산 스폰.
