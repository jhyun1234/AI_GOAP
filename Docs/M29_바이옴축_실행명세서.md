1. **온대 보장**: 기지 거리비 0.35 미만(200² 기준 ~35타일)은 **전 타일 온대 팔레트** — 게이트 전수.
2. **지리 성립**: 시드 20개 × 200²에서 정글·산악이 **각각 1지역 이상** 등장 (빈 검사 방지 포함).
3. **중립 불변식**: `_biomes` 미배선이면 지형 결과가 현재와 **비트 동일** (게이트가 시드 3개 대조).
4. **광산 티어** (2026-08-12 사용자 사다리 개정 — 구리→철·은→다이아→??): 배포 에셋에서
   `minDistanceFromBase`가 **구리 < 철 < 은 < 다이아로 단조 증가**하고 전부 산악 지형에서만
   선다 — 게이트 검사. 제안 사다리(200² 기준): 구리 50 · 철 65 · 은 80 · 다이아 92.
   4티어(??)는 미정 — 지하 층 후보와 짝 (ADR-M29-4 · M30 §2 예약 구획 56).
5. 게이트 485 → **+5 내외 green**. 부팅 시간·프레임 회귀 없음 (바이옴 층 = 노이즈 1장 추가).

## §0.5 재미 검증 — 플레이어가 화면에서 새로 보는 것

맵을 밝히다 보면 **색과 밀도가 바뀌는 경계**를 만난다 — "여기부터 정글이다". 정글은 나무가
빽빽하고 어둡고 느려서 벌목 원정지의 얼굴을 하고 있고, 산악은 절벽 능선 사이 암반에 광석이
박혀 있어 **깊이 들어갈수록 은이 나온다**. 은광 원정은 이제 "80타일 밖의 점"이 아니라
"산악 지대 깊숙한 곳"이라는 **장소**가 된다. 시작 마을 주변은 언제나 온화한 평지·숲 — 첫
10분의 문법은 바뀌지 않는다.

## §2. 설계 — 바이옴 배정층 (이 명세의 심장)

**원리**: 기존 `Noise()`를 큰 격자(`BIOME_CELL 64` — 알고리즘 상수, PLAIN_CELL 판례)로 1장 더
떠서 **어느 팔레트를 쓸지**만 고른다. 습도·고도 밴드는 그대로 산다 — 바이옴은 "지형을
바꾸는" 층이 아니라 **"팔레트를 갈아끼우는"** 층이다.

```
Biome(x, y):
  distFrac = Chebyshev(x−기지, y−기지) / mapHalf          // 0(마을)~1(맵 끝)
  v        = Noise(x, y, BIOME_CELL, saltBiome)            // 기존 함수 재사용 — 0~1 유기적 등고선
  idx      = floor(v × biomes.Length)                      // 후보 선택
  return biomes[idx].MinBaseDistFrac <= distFrac ? biomes[idx] : 온대(biomes[0])
  // 🔑 혼합 배치(사용자 결정)가 이 한 줄이다: 가까이는 비적격 후보가 전부 온대로 접히고
  //    (보장), 바깥은 노이즈가 고른 대로 선다(무작위 — 온대도 바깥에 낄 수 있다).
  //    적격 목록을 다시 뽑지 않으므로 문턱 반지름에서 지역이 재배열되는 링 아티팩트가 없다.
```

- `BiomeSO` (새 에셋 스키마): `DisplayName` · `TerrainTypeSO[] Palette` ·
  `[0,1] MinBaseDistFrac` (이 바이옴이 설 수 있는 최소 기지 거리비 — **[비례] 분류**, ADR-M28-2).
- **온대 = `_biomes[0]`** (MinBaseDistFrac 0 강제 — OnValidate): 폴백이자 안전지대 팔레트.
- 안전반경(`_terrainSafeRadius`)·캐시·`IsEmpty` 중립 계약은 그대로.
- 제안 문턱 (제안치 — Play로 조정): 온대 0 · 정글 **0.35** · 산악 **0.45**
  (200²: 정글 35타일+ · 산악 45타일+ → 은 사다리 80과 정합 — 은은 산악 깊은 곳에만).

## §3. ADR-M29 (바꾸려면 사유를 커밋에)

- **ADR-M29-1 (바이옴 = 팔레트 선택층)**: 바이옴은 지형 종류·밴드·통행 판정에 손대지 않는다 —
  `Compute`의 팔레트 출처만 바꾼다. 지형 문법(M26)과 바이옴 문법이 섞이면 지형 추가 비용이
  "에셋 1개"에서 벗어난다. 완성 후 **바이옴 추가 = BiomeSO 1개 + 씬 배열 등록, 코드 0줄**.
- **ADR-M29-2 (심도 1차 = 기지 거리 근사)**: "광산 안으로 = 희귀"는 1차에서 **기지 거리
  사다리 × 산악 소속**의 곱으로 근사한다 (산악이 바깥 고리에 서므로 방사 방향 심도와 일치).
  지역 가장자리 기준의 진짜 심도 축은 Play에서 근사가 깨지는 것을 관측한 뒤에만 신설한다.
- **ADR-M29-3 (중립 불변식)**: `_biomes` 미배선 = 舊 단일 팔레트 경로 그대로 (비트 동일).
  기존 세이브·게이트·판이 전부 이 문 뒤에서 안전하다.
- **ADR-M29-4 (지하 층 봉인)**: "안으로"의 지하 구현(별도 맵 층·입구·조명)은 이 축에서 설계
  하지 않는다 — 사용자 결정(표면 먼저). 표면 티어가 지하의 자리(더 깊은 희귀)를 침범하지
  않도록 은 위로는 티어를 늘리지 않는다 (지하가 그 위 티어를 가진다).
