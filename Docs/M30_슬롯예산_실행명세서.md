## §3. ADR-M30

- **ADR-M30-1 (재사용은 증명으로만)**: 슬롯 재사용 조건 = ①에셋 참조 0을 **게이트가 지속
  감시**해 왔거나 감사에서 신설 ②코드 참조가 잉여 API임을 판정 ③옛 세이브 값 0이 새 의미로
  무해. 셋 다 커밋에 기록. 재번호 병합은 영구 금지 (ADR-M0-9 승계).
- **ADR-M30-2 (증설 단위 = 필요 + 예약)**: TOTAL_SLOTS는 소비 축의 명세가 예약 구획을
  청구할 때만 늘린다 — 플래닝 비용이 슬롯 수에 선형이라 "미리 크게"는 낭비다.
