## 0. 목적

M2 완료 자가 재검토에서 확인된 후반 리스크 8건 중 **지금 해결하지 않으면 M4+에서 비용이

## 2. 재미 검증 — 플레이어가 화면에서 새로 보게 되는 것

모닥불과 밭뿐이던 마을에 **집**이 올라간다. 집이 생기면 주민들이 쉴 때 모닥불에 모여
불멍하던 풍경이 바뀐다 — **각자 가장 가까운 집 곁으로 흩어져 쉰다.** 마을이 "캠프"에서
"동네"로 보이기 시작하는 순간이다. 집은 통행을 막아서 주민들이 집 사이 골목으로 돌아
다니고, 식량이 궁해지면(생식 10 이하) 주민들이 스스로 밭을 4개까지 늘려 위기에 대응하는
모습이 보인다. 밭이 한꺼번에 익으면 한 주민이 밭 사이를 돌며 연속 수확한다.

## 3. ADR-M3 (구현 중 갈릴 판단, 바꾸려면 사유를 커밋에)

- **ADR-M3-1 (앵커 조회 일반화)**: 앵커 조회는 ConstructionService의 단일 창구
  `TryGetAnchorTile(SlotId[] priority, fromX, fromY, out tile)`로 통합 —
  단일형 슬롯이면 그 위치, 수량형 슬롯이면 **최근접** 완공 위치. 목록 앞이 우선인
  의미(ADR-M2-2)는 무변경. 러너가 위치 인자를 넘긴다. 기존
  TryGetFirstBuiltAnchor는 삭제(git 삭제 — 두 창구 병존 금지).
- **ADR-M3-2 (Ripe/Empty 수치화)**: 슬롯 인덱스 불변(12/13), **의미만 0/1 → 개수**.
  FarmService가 유일한 원천(ADR-M2-4 유지) — CountEmpty()/CountRipe()가 스냅샷 값.
  에셋 조건은 `>=1`(전제)·`Sub 1`(효과)·`==0`(goal)로 개정. 새 슬롯을 파지 않는다.
- **ADR-M3-3 (통행 차단은 건물 속성)**: BuildingSO.BlocksMovement(bool)가 유일한 판정.
  Walkable 갱신은 SimulationLoop의 OnCompleted 구독 한 곳. footprint는 이번에 1×1 고정
  (다중 타일은 실제 큰 건물이 들어올 때). 차단 건물은 **인접 타일에서** 건설한다
  (건설자가 자기가 만든 벽 위에 서는 것 방지).
- **ADR-M3-4 (작업 클레임)**: GoalSO.MaxWorkers(int, 0=무제한). 클레임 카운트의 유일한
  소유자는 GoalSelector — 에이전트는 Claim/Release만 호출. **P0 생존 goal에 설정 금지**
  (생존은 인원 제한 대상이 아니다). 명령(Order)도 제한 없음 — 플레이어 의지가 우선.
- **ADR-M3-5 (세이브 원칙 — 선언, 구현은 M4+)**: 저장 대상 = 서비스 상태만
  (WorldModel 슬롯 · FarmService 밭 · DiscoveryService 노드 · ConstructionService 완공 기록 ·
  에이전트 욕구/위치). **플랜·러너·PendingPlan·쿨다운은 저장하지 않는다 — 로드 후 재계획.**
  시간 기반 상태는 절대 시각(Time.time) 대신 "남은 시간"으로 보관하는 방향으로 전환.
  이후 신규 런타임 상태 추가 시 "세이브 대상인가"를 선언 주석으로 남긴다.
- **ADR-M3-6 (수치 출처)**: 집 비용·개수는 舊 값 우선 — 폐기 전 ActionDatabase의
  BuildHouse(舊 이슈#2에 존재)를 `git show`로 확인해 따르고, 없으면 §4 제안치 + 커밋에 명시.

- **코드 스케치**:
```csharp
/// <summary>앵커 우선순위에서 "지어진 첫 건물"의 타일 (ADR-M3-1).
/// 단일형 슬롯 → 그 위치, 수량형 슬롯 → fromX/Y 최근접. 전부 미완공이면 false (러너가 폴백).</summary>
public bool TryGetAnchorTile(SlotId[] priority, int fromX, int fromY, out Vector2Int tile)
{
    if (priority != null)
        foreach (SlotId slot in priority)
        {
            if (_builtTiles.TryGetValue(slot, out tile)) return true;                  // 단일형
            if (TryGetNearestBuiltTile(slot, fromX, fromY, out tile)) return true;     // 수량형
        }
    tile = default;
    return false;
}
// ConsumeRunner/WanderRunner: TryGetFirstBuiltAnchor(_so.AnchorPriority)
//   → TryGetAnchorTile(_so.AnchorPriority, agent.TileX, agent.TileY)
```

// GoalSO:
[Tooltip("동시 수행 인원 제한 (0=무제한). P0 생존 goal·명령에 설정 금지 (ADR-M3-4).")]
public int MaxWorkers;

// GoalSelector (클레임의 유일한 소유자):
private readonly Dictionary<GoalSO, int> _claims = new Dictionary<GoalSO, int>();
public void Claim(GoalSO g) { _claims.TryGetValue(g, out int n); _claims[g] = n + 1; }
public void Release(GoalSO g) { if (_claims.TryGetValue(g, out int n)) _claims[g] = Mathf.Max(0, n - 1); }
public bool IsFull(GoalSO g) => g.MaxWorkers > 0 && _claims.TryGetValue(g, out int n) && n >= g.MaxWorkers;
