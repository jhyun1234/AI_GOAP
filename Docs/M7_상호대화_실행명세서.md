## 0. 목적

성격×직업 분화(M4~M6)를 **화면에서 확인 가능**하게 만들고(이름표·정보창·대사 확장),
주민이 **서로의 행동에 반응해 말을 거는** 상호대화 선반을 짓는다. 대화는 표현 전용이며
관계 축(원한·단짝, M8)의 토대가 된다. 회상 테스트("남에게 말하고 싶은 순간")의 최단 경로 =
사회적 장면 — "농사꾼이 노는 고집쟁이한테 쏘아붙였는데 걔가 코웃음 쳤다"를 만든다.

## 2. 재미 검증 — 플레이어가 화면에서 새로 보게 되는 것

주민 머리 위에 **"A · 농부"** 이름표가 붙는다. 클릭하면 화면 위에 **"A — 성격 고집쟁이 ·
직업 농부 · 포만 45 · 피로 60 · 지금: 겨울 비축"**이 뜬다 — "쟤 왜 저래?"의 답이 3초 안에
나온다. 그리고 처음으로 주민들이 **서로에게 말을 건다**: 비축하러 뛰어다니던 순둥이 요리사가
모닥불 옆에서 빈둥대는 고집쟁이 곁을 지나다 말풍선을 띄운다 — "일도 안 하면서 밥은 먹고
싶어??" 1초 뒤 고집쟁이가 받아친다 — "흥, 내 방식대로 할 거야." 마을이 개인들의 집합에서
**서로 부대끼는 사회**로 바뀌는 첫 장면이고, 이 장면이 회상 테스트의 첫 득점 후보다.

## 3. ADR-M7 (구현 중 갈릴 판단, 바꾸려면 사유를 커밋에)

- **ADR-M7-1 (대화 = 표현 전용)**: 대화는 말풍선 2개다. 시뮬레이션 상태(욕구·스톡·goal·
  클레임)에 쓰기 0 — ChatterService는 WorldModel 참조 자체를 갖지 않는다. 관계 수치
  축적은 M8 (ChatterSO에 관계 필드를 미리 만들지도 않는다 — 빈 선반 금지).
- **ADR-M7-2 (대화 조건 = 데이터)**: 상황 판정은 ChatterSO 필드(화자 goal 우선순위 하한·
  특정 goal 필터·상대 우선순위 상한·반경)로만. 성격·직업 **이름 문자열 분기 금지** —
  성격별 응수는 {PersonalitySO 참조, Lines[]} 매핑 배열 (ADR-M0-1 계승).
  판정 대역은 goal 에셋의 원본 Priority (개인 bias는 그 주민의 속마음 — 남이 볼 수 없다).
- **ADR-M7-3 (스캔 단일 지점)**: 짝 찾기는 ChatterService 하나가 주기 틱(IntervalSec)으로
  수행한다. 에이전트 개별 스캔 금지(매 틱 O(n²)+스팸 제어 분산). **한 주기 최대 1쌍** —
  대화는 희소해야 장면이 된다.
- **ADR-M7-4 (표시 통로 재사용)**: 발화·응수 모두 기존 ShowTransient 통로. 응수는 지연
  표시(ReplyDelaySec)로 "대화처럼" — 새 말풍선 시스템 금지.
- **ADR-M7-5 (이름표엔 직업만)**: 상시 이름표 = "이름 · 직업". 성격은 선택 정보줄에서만 —
  성격 이름(농사꾼·떠돌이)이 직업처럼 들리는 혼동(2026-07-16 결정)을 표기 위치로 해소.
- **ADR-M7-6 (대화 목록의 집 = WorldConfig)**: ChatterSO 배열은 WorldConfig.Chatters —
  씬 배선 없음. 계절 사이클과 같은 패턴 (에셋 참조 에셋).
