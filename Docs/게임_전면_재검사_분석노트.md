# 게임 전면 재검사 분석노트 (2026-08-05)

> 계기: 화폐 축 폐기 결정(2026-08-04)에 이어 사용자 지시 — *"이전으로 돌아가서 다시 우리
> 게임을 전부 재검사해야 할 것 같다."* 이 문서는 M0~M18의 전 시스템을 사용자가 선언한
> 정체성에 대고 다시 판정한 기록이다. **M19(화폐 철거) 구현은 이 재검사 승인 전까지 보류.**

## 0. 재검사의 잣대

**사용자 선언 (2026-08-04)**: *"마을을 키우면서 야생동물·몬스터 격퇴를 통해서 성장하는
마을 게임"*

잣대 세 축 + 기존 선언 두 개:
- **A. 마을 성장** — 짓고, 늘리고, 사람이 모이는가
- **B. 격퇴** — 위협과 싸워 이기는 것이 성장으로 이어지는가
- **C. 주민 자율** — "자기 생각이 있는 AI와 협상하는 게임" (CLAUDE.md 정체성, 불변으로 간주)
- 기존 북극성 = "성장하며 버티는 기록 경주" (M14 확정) — **B와 긴장 관계, §4에서 재검토**

판정 기호: ✅ 부합 · ➖ 기반(중립, 유지) · ⚠️ 수술 필요 · 🔴 이탈(철거) · ⬜ 공백(없음)

## 1. 요약 — 세 문장

1. **가장 큰 발견: "격퇴"가 게임에 없다.** 위협(늑대·곰)은 적이 아니라 **날씨**다 —
   나타나서 때리고 스스로 떠나며, 주민은 도망칠 수만 있다 (코드 실사 §3).
2. 화폐(🔴)를 빼면 **이탈한 축은 없다** — 나머지는 전부 "마을 게임"의 기반이거나 부합.
   문제는 이탈이 아니라 **공백**이다: 격퇴 루프·성장 사다리·붙잡을 목표.
3. 따라서 처방은 "더 걷어내기"가 아니라 **M19(정리) → M20(직업) → M21+(격퇴 축 신설)**의
   순서다 — §5 권고 로드맵.

## 3. 핵심 갭의 실체 — 위협은 날씨다 (코드 실사)

- 주민→위협 공격 경로: **0건.** `Fight|Combat|반격|격퇴|Slay|Hunt` 전수 grep 결과
  ThreatSO 툴팁 1파일뿐 (2026-08-05).
- 위협의 생애: 예고 → 스폰 → 대상(주민/밭) 타격 → **스스로 퇴장**
  (`ThreatService` 251~266행 — "타격 실행 후 퇴장 경로를 되돌려준다").
- 주민의 선택지: `Goal_Flee`(피신) 하나. 죽이거나 쫓아낼 수 없다.
- 위협의 세기: 마을 규모·게임일 래칫(M10R) — **플레이어·주민의 행동과 무관하게** 자란다.

즉 위협은 페이스메이커(리듬 장치)이지 상대가 아니다. "격퇴를 통해 성장"이 서려면 최소
다섯 조각이 새로 필요하다: ①전투 판정(주민이 위협에 피해를 입힘) ②위협의 체력·도주
③격퇴의 보상(전리품·안전·영역?) ④싸울 수단(협동·무기·시설?) ⑤성장 연결(격퇴가 마을을
어떻게 키우나). **밀스톤 하나가 아니라 축 하나 분량**이며, 별도 브레인스토밍이 필수다.

참고할 기존 분석: `project_rimworld_goap_analysis` — *"적대 AI는 유능할수록 재미있고 관리
대상 AI는 유능할수록 플레이어가 할 일이 없다"*. 격퇴 축은 이 역설의 **좋은 쪽**(적대 AI)에
투자하는 일이라, 관리 축보다 재미 대비 효율이 높을 가능성이 크다.

## 4. 북극성 재검토 (사용자 결정 필요 — 이 문서의 유일한 미결)

| | 기존 북극성 (M14) | 새 선언 (2026-08-04) |
|---|---|---|
| 문장 | "성장하며 **버티는** 기록 경주" | "**격퇴를 통해** 성장" |
| 위협의 자리 | 시험 (버텨내는 대상) | 자원 (이겨서 얻는 대상) |
| 주민의 자세 | 대비 (비축·집·간호) | 대응 + **반격** |

양립은 가능하다 — "격퇴하며 버티는 기록 경주"(겨울 = 계절 시험, 위협 = 능동 시험)로
합칠 수 있다. 그러나 **격퇴가 성장의 엔진이 되는 순간 래칫(M10R)의 "행동 무관 강해짐"은
재설계 대상**이 된다 (격퇴 실적이 위협 수위에 반영돼야 능동이 의미를 가짐).
→ 북극성 문장을 개정할지, 격퇴를 하위 축으로 둘지는 격퇴 브레인스토밍(M21+) 첫 질문으로.

## 5. 권고 로드맵 (재검사의 처방)

1. **M19 화폐 철거** — 승인된 명세 그대로. 재검사와 충돌 없음, 오히려 지반 정리.
   (이 재검사가 M19 명세를 바꾸는 항목: **0건** — §2에서 화폐 외 철거 대상이 안 나왔다.)
2. **M20 직업 전면 재점검** — 격퇴 축을 내다보며 (사냥꾼·경비의 자리를 비워 두는 설계).
3. **M21+ 격퇴 축** — 별도 브레인스토밍 필수 (§3의 다섯 조각 + §4 북극성 질문부터).
   최소 수직 절편(위협 1종을 싸워서 쫓아낼 수 있게)부터.
4. 백로그 유지: 성장 사다리(테크 트리 — 격퇴 보상과 접점 가능), "왜 하는가", 시작 드래프트.

## 6. 이 재검사가 바꾸지 않는 것

- ADR-M0 계열·플래너 동결·콘텐츠 비용표 — 전부 유효 (재검사에서 위반 발견 0).
- 게임 건강 기준(방치가 안락하면 실패)·회상 테스트 — 유지.
- 완료 밀스톤의 코드·기록 — 판정이 ⚠️/⬜라도 **되돌리기(revert) 대상은 화폐뿐**이다.
  재검사의 결론은 "잘못 지었다"가 아니라 "비전의 절반이 아직 착공 전"이다.
