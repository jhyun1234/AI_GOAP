# 겨울 채집 봉쇄 (SeasonSO.ForageFrozen) 실행명세서

작성 2026-07-24. 겨울 위기감 복원의 최종 설계. 앞선 두 시도(①열매 노드 무한 버그 수정
②GatherYieldMult 수확량 배율)는 각각 근본이거나 부족했고, GatherYieldMult는 이 명세로 **되돌림**.

---

## 0. 배경 — 왜 봉쇄인가 (2회 재관측)

- **1차 근본 버그(수정 완료)**: 열매 채집 효과가 M11에서 MyRawFood(개인)로 이전됐는데 GatherRunner가
  전역 스톡만 수확량으로 인식 → 노드 무한. 수정으로 노드 고갈 되살림.
- **노드 고갈만으론 부족(관측)**: 겨울 4일 + 노드가 4일치 수요 초과 + 가을 재충전 → 첫 겨울 못 마름.
- **GatherYieldMult(수확량 배율)도 실패(관측)**: 노드 감소도 함께 줄여 **오히려 더 느리게 고갈** → 2번의
  겨울을 넘김. 사용자 실측: "포만 떨어지면 저장분 다 먹고 또 채집 가서 채워오니 절대 안 죽어."
- **진짜 근본 = 채집이 무한 안전망**: 열매 노드에 재고가 있는 한 forage→eat 루프가 절대 실패 안 함.
  → **겨울엔 야생 채집을 아예 봉쇄**해야 "저장 안 하면 굶는다"가 성립.
- **밭·저장분은 봉쇄 대상 아님(분석)**: HarvestCrop은 MyRipeCrop(29) 게이트라 봉쇄 슬롯(NearDiscoveredFood 5)과
  무관. GrowthMult 0은 성장만 멈추고 이미 익은 작물은 수확 가능. 재성장 안 되니 겨울 밭은 **유한**
  = 가을에 기른 만큼. 즉 밭·조리·저장분은 전부 "가을 대비의 결실" → 겨울 생명줄로 남긴다.

## 0.5 넓히기 분류
**②새 선반의 얕은 확장** — SeasonSO에 boolean 개입 축 1개(ForageFrozen). ADR-M6-1이 "배율 3종"만
허용했으므로 개정. 새 계절의 채집 봉쇄 개성 = ForageFrozen 에셋 값, 코드 0줄. 새 통로 안 만들고 기존
계절→슬롯 경로(BuildSnapshot이 이미 CrisisActive/DaysToCrisis를 계절서 씀)에 얹음(M11 기존통로우선).

---

## 1. 성공 기준 (측정 가능)
- **중립 불변식**: ForageFrozen false 계절의 NearDiscoveredFood = 발견값 그대로(diff 0). 온화·여름·가을 채집 정상.
- **겨울 봉쇄**: 겨울엔 발견 열매 노드가 있어도 NearDiscoveredFood = 0 → 플래너가 HarvestWildBerries를
  후보에서 뺌(전제 `≥1` 불충족). 겨울 채집 플랜 0건.
- **밭 불변**: 겨울에도 익은 작물 수확 가능(MyRipeCrop 경로) — 봉쇄와 무관.
- **굶주림 정상화**: 저장분 없는 주민의 식량 goal NoSolution이 경고 아닌 정보("먹을 것이 없다") 로그.
  이탈은 포만 임계값 구동이라 발동(플래너 무관).
- EditMode: ForageFrozen 게이트 green + 전체 green. 2종 빌드 0오류.
- (관측 목표) 게으름뱅이가 저장분 소진 후 겨울에 이탈, 대비한 주민은 생존.

## 2. ADR
- **ADR-M6-1 개정 (배율 3종 → 배율 3종 + ForageFrozen 플래그):** 계절 개입에 boolean 채집 봉쇄를 추가.
  **이유:** 겨울 위기감이 재생 정지·수확량 배율로 성립 불가 — 채집이 재고 있는 한 무한 안전망이라
  저장 없이도 살아남는다. 봉쇄만이 "가을 대비 or 굶주림"을 성립시킨다. (2회 재관측 근거.
  [[feedback_living_adr_revision]] 적용.)
- **ADR-M6-2 게임건강 예외 (신규):** "NoSolution 0건" 기술건강 기준에 **생존 goal 예외**를 둔다 —
  식량 goal(MayHaveNoSolution=true)의 '먹을 것이 없음'은 버그가 아니라 굶주림(정상). 정보 로그로 강등.
  **이유:** 봉쇄로 처음으로 '진짜 식량 부재'가 발생 — 이걸 버그 경고로 두면 정상 굶주림이 오탐된다.
- **ADR-봉쇄-1 (스코프):** 봉쇄는 **야생 채집(NearDiscoveredFood)만**. 밭 수확·조리·저장분 섭취·
  나무/돌 채집은 안 막힌다 — 겨울 생명줄과 건설 경제 보존.
- **ADR-봉쇄-2 (플래너 레벨):** 런타임(GatherRunner)이 아니라 **플래닝 시점**에 뺀다 —
  런타임 차단은 플래너가 계속 채집을 시도하는 무한 재계획을 부른다.
- **ADR-봉쇄-3 (위조 불가 슬롯, 2026-07-24 실패 후 개정):** 봉쇄 판정은 **어떤 액션도 효과를 갖지 않는
  전용 슬롯 `ForageFrozen`(33)** 으로 한다. 채집 액션에 `ForageFrozen == 0` 전제를 걸어 막는다.
  **이유(실측):** 1차 시도는 `NearDiscoveredFood`(5)를 겨울에 0으로 만들어 막으려 했으나,
  `Explore`가 그 슬롯을 **Set 1** 하는 효과를 가져(전제 없음·상시 가능) 플래너가 **`Explore → 채집`**
  우회 플랜을 세웠고, 런타임 `GatherRunner`는 계절을 모른 채 실제 발견 노드를 찾아 채집에 성공했다.
  → **플래너가 위조할 수 있는 슬롯으로는 봉쇄가 성립하지 않는다.** 게이트로 승격(아래).

## 3. 구현 (완료)
- `SeasonSO.ForageFrozen`(bool, 기본 false) 신설. 클래스 doc·헤더 "배율 3종 + 봉쇄 플래그"로.
- `SeasonService.ForageFrozen` 프록시(Current null=false 중립). 舊 GatherYieldMult·ScaledGatherYield 제거.
- `SlotId.ForageFrozen = 33` 신설(논리형, 예산 34/52). `WorldModel.BuildSnapshot`이 계절에서 주입.
  `HarvestWildBerries.asset`에 전제 `Slot 33 == 0` 추가. **`NearDiscoveredFood`(5)는 원래 의미 그대로
  복원**(계절 무관 = 발견 노드 존재) — 조작하면 Explore가 되돌린다.
- `GoalSO.MayHaveNoSolution`(bool, 기본 false) 신설. `VillagerAgent` NoSolution 지점: 플래그면 정보 로그.
- 되돌림: IActionRunner.ModifyEffects 훅·VillagerAgent.Season 접근자·GatherRunner 계절 로직 제거
  (열매 노드 개인스톡 인식 버그수정은 **유지**).
- 에셋: Season_Winter.ForageFrozen=1, 나머지 3계절=0(명시). Goal_P0_Hunger·Snack·GatherFood.MayHaveNoSolution=1.
- 게이트: `M6_ForageFrozen_NeutralAndFrozen` — 프록시 중립 + **BuildSnapshot 실증**(같은 발견 노드로
  계절만 갈아끼워 1↔0 대조) + **나무 비봉쇄 대조**(스코프 증명). 舊 GatherYield 테스트 제거.
- 관측 신호(M13): 계절 전환 로그·HUD에 `야생채집=봉쇄(열매가 언다)/가능` 노출 — 에셋 미기입이면 즉시 발각.

## 4. ⚠️ 오해 위험
- **A. 밭도 얼린다:** ✗. 봉쇄는 NearDiscoveredFood(야생)만. 밭=MyRipeCrop 별개(ADR-봉쇄-1).
- **B. 런타임에서 채집 막기:** ✗. 플래너 레벨. 런타임 차단은 무한 재계획(ADR-봉쇄-2).
- **B2. 🔴 발견 슬롯(NearDiscoveredFood)을 0으로 만들어 막기:** ✗ — **실제로 실패한 방법**.
  Explore가 그 슬롯을 Set 1 해서 `Explore→채집`으로 우회된다. 봉쇄는 **위조 불가 슬롯**으로만
  성립한다(ADR-봉쇄-3). 게이트 `M6_ForageFrozen_NoActionMayForgeTheSlot`이 재발을 막는다.
- **C. 신규 필드라 기존 계절 자동 false:** Unity는 bool 미기입=false라 이번엔 안전하나, 명시 기입으로 못박음.
- **D. 모든 goal NoSolution 강등:** ✗. MayHaveNoSolution 켠 식량 goal 3종만. 건설 등은 경고 유지(버그 탐지).

## 7. 재미 검증
겨울이 오면 야생 열매가 얼어 아무도 덤불을 뒤질 수 없다. 가을에 밭을 일구고 곳간을 채운 부지런한
주민은 익은 작물과 비축분으로 겨울을 나지만, "천천히 해도 안 죽어"라던 게으름뱅이는 몸에 지닌
몇 알이 떨어지는 순간 먹을 데가 없어, 눈밭을 서성이다 마을을 떠난다 — 처음으로 게으름에 대가가 붙는다.
