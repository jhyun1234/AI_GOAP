## 1. ADR (구현 중 갈릴 판단 — 바꾸려면 사유를 커밋에)

- **ADR-LF-1 가산 원칙**: 세로(쇼츠) 경로의 상수·CSS·검사 기준은 diff 0. 프로필 분기는
  `scene.json`의 `format` 필드("wide"/생략="tall") **한 곳**에서만 갈라진다.
- **ADR-LF-2 회차 id = `lf\d+`**: `epNNs` 계열 정규식(`backlog.mjs` 등)에 절대 안 잡히는
  이름 공간. 분할 id(`ep05s-1`)가 안전했던 전례를 따른다.
- **ADR-LF-3 엔진 = 유일한 합성기**: 게임 클립도 엔진 무대 안 `<video>`로 합성한다.
  ffmpeg 이어붙이기(합성기 2개) 금지 — 자막·HUD·check 가 두 경로로 갈라진다.
  렌더 시간이 문제로 실측되면 그때 사유와 함께 재검토.
- **ADR-LF-4 촬영 = Claude 무개입 독립 공정**: 시작은 스크립트 1회 실행, 산출물은
  `D:\AI_GOAP-videos\clips\`. 파이프라인은 수확물을 소비만 한다.
- **ADR-LF-5 연출 금지**: 대본이 원하는 장면이 수확에 없으면 **세션을 더 돌린다.**
  디버그 명령으로 장면을 만들지 않는다 — 클립은 관측이지 연출이 아니다.
- **ADR-LF-6 소재 정본 사다리**: 발행 글이 있는 구간은 발행 글이 우선. 없는 구간
  (M16~M23)은 리포 안 1차 소스(`devlog/sessions/`·`Docs/` 명세서·git 커밋)가 정본.
  검수는 모든 수치·사건 서술에 출처 파일을 명시해 대조한다.
- **ADR-LF-7 트랙 간 시점 규칙**: 롱폼의 과거 사건은 완결형("허물었습니다"), 쇼츠는
  연대기 시점 유지. 롱폼이 미래 쇼츠 아크 소재를 언급하면 한두 문장 + "전말은 시리즈에서"
  유도로 절제한다. 미래형 서술은 "지금"·"최종 목표" 절에만 허용.
  (검증 사례: 화폐는 M17 구현 → M19 전면 철거가 확정 상태 — "추가 예정" 서술은 오류다)
  🔑 유도 문구("전말은 시리즈에서")는 **실제로 쇼츠가 나올 소재에만** 약속한다 —
  쇼츠는 블로그 발행 궤도를 따르므로, 그 궤도에 없는 소재를 가리키면 지켜지지 않는
  약속이 된다. 검수는 유도 문구마다 대상 소재가 발행 궤도(발행 글 또는
  `BLOG_COVERAGE.md` 대기열)에 있는지 확인한다.
- **ADR-LF-8 게임 리포 변경 봉인**: 허용 목록 = ①`ChronicleService`에 C# 이벤트 1개 +
  invoke 1줄 ②신규 폴더 `Assets/Scripts/M0/Capture/` ③Unity Recorder 패키지
  (`Packages/manifest.json`) ④(부족 시) 서비스에 가산 이벤트 선언. 이 밖의 게임 파일
  diff 는 반려. 구독자 없으면 전부 no-op.
- **ADR-LF-9 실측 전 규칙 금지**: 렌더 시간 허용치·BGM 보강 여부·챕터 길이 조정은
  파일럿 실측 후에만 결정한다.

```js
// lib-node.mjs — 기존 상수는 그대로 두고(쇼츠가 쓴다) 프로필 함수를 추가
export const PROFILES = {
  tall: { STAGE_W: 392, OUT_W: 1080, OUT_H: 1920 },            // 기존 값 그대로
  wide: { STAGE_W: 697, OUT_W: 1920, OUT_H: 1080 },            // 697 = 392×16/9 반올림(제안치
};                                                              //  — 구현 때 폰트 px 정합으로 확정)
export function dimsOf(scene) {
  const p = PROFILES[scene.format === 'wide' ? 'wide' : 'tall'];
  return { ...p, DSF: p.OUT_W / p.STAGE_W, VIEW_H: Math.round(p.OUT_H / (p.OUT_W / p.STAGE_W)) };
}
```
```js
// engine.js boot — scene.json 을 읽은 직후, 그리기 전에
if (scene.format === 'wide')
  document.querySelector('link[href="style.css"]').href = 'wide.css';
```
- `render.mjs`/`check.mjs`: 뷰포트·인코딩 크기를 `OUT_W/OUT_H` 직접 참조 대신

- `wide.css`: `style.css`를 복사해 % 앵커만 가로 레이아웃으로 재계산
  (상단 HUD 얇은 띠 · 중앙 비주얼 · 하단 자막). **style.css 는 한 글자도 안 바꾼다.**
