# M1 · 근본 원인 우선 — 증상에 패치 금지

**언제**: 새 버그·이상 현상을 접수한 모든 순간.

**무엇**: 패치 전에 "왜 일어났나"를 먼저 진단. 진단이 서기 전엔 코드를 안 고친다. 기존 수정이 새 문제를 낳았으면 근본 진단을 **다시** 점검(연쇄 오류 검토).

**왜**: 증상 패치는 판단 규칙을 이원화시켜 다음 버그를 부른다. "대기 가드는 동상·데드락 유발이라 금지"(M4 교훈)처럼 급한 우회가 구조적 결함이 된다.

**실증**: 개체 편차 붕괴 `44b7538`(표면 증상 "동시 허기 웨이브" → 진짜 원인은 해시 함수 구조 결함 → FNV-1a 교체) · JPS 강제 이웃 결함 `c03d461`·`eac0907`(NoSolution의 원인은 MAX_NODES가 아니라 알고리즘 결함 — MAX_NODES 인상 금지).
