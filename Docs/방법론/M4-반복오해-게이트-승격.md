# M4 · 같은 오해 2회 → 규칙/게이트로 승격

**언제**: 동일한 실수·오해가 두 번째로 발생/지적될 때.

**무엇**: 2회 반복된 오해는 ADR 신규 항목을 제안하고, 자동 테스트(게이트)가 못 잡은 위반이면 **게이트 확장이 먼저**다. "게이트가 못 잡는 위반을 발견하면 게이트를 넓히는 게 수정보다 우선."

**왜**: 사람의 주의력에 의존하는 규칙은 세 번째에 또 뚫린다. 규칙을 기계(EditMode 게이트)에 새긴다.

**실증**: M0-T3가 하드코딩·단일경로·좌표스냅을 자동 검사 → 수동 grep 불필요. JPS 결함마다 실측 좌표를 게이트에 박제(`JPS_ObstacleGates`, `JPS_G4`).
