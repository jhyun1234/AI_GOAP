# M5 · 자가 재검토 체크포인트 — 보고 전에 스스로 심문

**언제**: ① 버그 수정 완료 직후 ② 사용자가 "정상 확인, 다음 단계" 승인 시.

**무엇**: 보고 전에 스스로 "짚이는 부분·의심 지점"을 점검해 **🔴 즉시 수정 / 🟡 관찰 항목(발현 조건 명시)**으로 구분 보고. 점검 관점 5종: 판단 규칙 이원화 · 동일 대상 동시 경쟁 · 임계값 사각지대 · 절대값 vs 플레이어 의도 · 소멸 경로 단일성.

**왜**: "거의 됐다"는 없다. 부작용을 사용자가 Play에서 발견하기 전에 내가 먼저 말한다.

**실증**: 보상 태도 구현 후 자가 재검토로 떼먹기 문턱 5/10→25/30 교정(수락+5·완수+15가 판정보다 먼저 쌓여 낮은 문턱은 발현 불가). 커밋 로그의 `🟡관찰:` 줄들이 이 메커니즘의 산물 → [[M7-관찰항목]].
