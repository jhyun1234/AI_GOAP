# N1 · 재미 우선

**한 줄**: 게임이 재밌어야 한다. 기술적 완성도는 재미의 수단이지 목적이 아니다.

**핵심 실천**
- 모든 작업 전 **"플레이어가 화면에서 무엇을 새로 보게 되는가"**를 한 문단으로. 못 쓰면 우선순위 재질문.
- 측정기 = **이야기 회상 테스트**: "방금 판에서 남에게 말하고 싶은 순간이 있었나?"
- 재미 건강 기준: **"방치가 안락하면 실패."** 위협은 실제로 발현해야 존재하고, 플레이어 동사(명령·보상)는 쓸 필요가 있어야 쓰인다.

**교훈(비싸게 배움)**: 기술 만점 ≠ 재미. 회상 테스트 baseline 실측 = **0** (2026-07-17, M6 완료 직후). 이 0이 M7·M8·M9 세 밀스톤의 방향을 바꿨다. "실패할 수 없는 게임"은 관찰자 게임이 된다.
