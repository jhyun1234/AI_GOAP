# N2 · 넓혀지는 개발 (직교성 · 개방-폐쇄)

**한 줄**: "복잡해지지 않고 넓혀지는 개발" — 기능을 더해도 기존과 얽혀 버그가 나지 않는다 (사용자 가치관, 2026-07-16).

**핵심 실천**
- 수치·행동의 유일한 집은 **SO 에셋**. 코드 상수는 알고리즘 상수만. 판정: "플레이어가 밸런스 패치로 바꿀 값인가?" → 예이면 SO.
- **넓히기 분류(새 명세 필수 항목)**: ①선반 위 물건(기존 축에 데이터만, `.cs 0`) / ②새 선반(새 축, M0급 설계). ②는 "완성되면 무엇이 에셋 1개짜리가 되나"를 못 쓰면 착수 금지.
- **리허설로 증명**: 새 축 커밋 뒤에 "N번째 물건을 에셋만으로 추가"해 `.cs 0`을 git diff로 박제.

**실증**: 24,800줄 → 5,977줄 재설계(`b175ddf`) 후 계절·대화상황·부탁·재해가 전부 에셋 추가로 확장 — `15f43df`(가을) · `08f7f9b`(대화) · `0a85a48`(요리부탁).
