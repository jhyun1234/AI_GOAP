# N3 · 명세 선행

**한 줄**: 명세가 코드에 앞선다. 코드는 명세의 번역일 뿐.

**핵심 실천**
- 새 밀스톤·기능은 [[개발_방법론_명세서]]가 가리키는 `spec-write`로 실행명세서를 먼저 쓴다.
- 명세 1항목 = 커밋 1개(부분 커밋 허용, **빌드 깨진 커밋 금지**).
- **명세에 없는 판단은 구현하지 말고 질문**(선택지 + 추천 → [[M8-데이터기반-선택지]]). 명세 밖 아이디어는 코드가 아니라 **백로그**에 한 줄.

**스킬 3종**: spec-write(성공기준·ADR·커밋분할·스코프가드·⚠️오해위험·DoD·재미검증) → spec-implement(ADR·⚠️ 먼저 읽기 → DoD 하나씩) → spec-review(판정표 ✅⚠️❌).
