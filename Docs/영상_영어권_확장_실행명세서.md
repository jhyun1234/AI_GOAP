### 0.3 유튜브 자막 트랙으로는 해결이 안 된다 (기각 근거 박제)

브레인스토밍 중 "영어 SRT 에 배경 박스를 넣어 번인 한국어를 가린다"는 안이 나왔고 **기각했다.**
나중에 같은 안이 다시 올라올 때 재조사하지 않도록 근거를 남긴다.

1. **유튜브가 자막 파일의 스타일을 버린다.** 업로드된 캡션을 자체 내부 표현으로 변환한 뒤
   플레이어 자체 스타일로 렌더한다. SRT·VTT·TTML 모두 배경색·위치·폰트 지정이 무시된다.
   스타일이 먹는 건 문서화되지 않은 SRV3/YTT 뿐이고, 미문서 포맷에 무인 파이프라인을 걸 수 없다.
2. **통제권이 시청자에게 있다.** 자막 배경 유무·크기·색은 시청자 설정이 이긴다.
   배경을 끈 시청자는 겹친 화면을 본다. 그리고 **자막은 끌 수 있다** — 끄면 한국어만 남는다.
3. **위치를 못 맞춘다.** 유튜브 자막은 하단 중앙 고정이고 쇼츠 플레이어는 그 위에
   제목·채널·버튼 UI 를 얹는다.

→ "가려진다"가 **우리가 볼 수도 테스트할 수도 없는 값**에 달린다. 게이트로 잡을 수 없는 실패다.

**파생안(번인을 빼고 clean 렌더 + 자막 트랙 2개)도 기각한다.** 통제는 되찾지만
①자막이 기본 꺼진 시청자에게 글자가 하나도 없는 영상이 되고 ②자막 2줄 상한·하단 안전영역·
잘림 검사가 전부 의미를 잃는다(그 안전영역 검사는 2026-07-29 "자막 둘째 줄이 채널 아이콘에
묻힌" 실제 사고로 생긴 것이다 — `check.mjs:234`) ③이미 잘 되는 한국어 경험을 깨서
아직 존재하지 않는 영어 시청자를 얻으려는 거래다.

## 2. ADR — 구현 중 갈릴 판단을 미리 결정

> 바꾸려면 **무엇을 관측했고 이 결정이 왜 실패하는가**를 커밋 메시지와 이 문서 본문에 남긴다
> (`feedback_living_adr_revision`).

### ADR-V-9 — 영어판은 `scene.en.json` **sidecar**다. 새 회차 폴더를 만들지 않는다.
자동화 전체가 `scene.json` 이라는 정확한 이름으로 게이트하기 때문이다(전제 8).
sidecar 는 기존 파이프라인에 **완전히 투명**하다. `kinds/`·`notes/` 는 공유한다 —
그림을 두 벌 유지하지 않는다.

### ADR-V-10 — 짧은 라벨은 **언어 중립(영어)**, 서술은 한국어.
판정 기준 한 줄: **"이게 코드나 인스펙터에 그대로 있을 법한 말인가?"** → 그렇다면 영어.
서술이면 한국어.

| 영어로 | 한국어로 |
|---|---|
| 상태·축·계기판 이름 (`HUNGER`, `COST`, `PLANNER`, `A*`) | 자막(`lines[].text/say`) **전체** |
| 코드에 실재하는 식별자 | 판정 서술 (`note`, `quote`) |
| 단위·기호 | 인용문 |

이 결정은 **영어판과 독립적으로 그 자체가 이득**이다. 영어권 시청자가 자막을 못 읽어도
그림의 메커니즘을 따라올 수 있고, 한국어 시청자에게는 개발일지답게 읽힌다(코드가 실제로 영어다).
그리고 `spec.*` 가 공유 자산이 되어 영어판 집필 비용이 줄어든다.

### ADR-V-11 — 라벨 규칙은 **게이트로 만들지 않는다.**
"짧은 한글은 경고" 같은 검사를 만들 수 있지만 **몇 자부터 짧은지에 근거가 없다.**
지어낸 임계값으로 게이트를 만드는 것은 ADR-V-7 이 금지한 것이다.
→ 에이전트 지침과 검수로 간다. 표기가 실제로 흔들리는 것이 관측되면 그때 근거를 갖고 만든다.

### ADR-V-12 — 근거 있는 게이트만 옮기고, 근거 없는 것은 **참고 출력**으로 둔다.
`check.mjs:126` 이 못박은 원칙("오탐이 나면 게이트를 무르게 하지 말고 제목이나 첫 줄을 고쳐라")을
영어에서도 지킨다. 그러나 **없는 근거를 지어내지도 않는다.**

| 게이트 | 파일럿에서 | 왜 |
|---|---|---|
| 다음 편 예고 | 🟢 **fail 유지** | 규칙은 그대로고 언어만 교체 = 근거 이전 |
| 형제 라벨 | 🟢 **fail 유지** | 한국어 규약의 기계적 대응 |
| `CPS_REF.en` | 🟢 **15.5 로 확정** | §0.1 실측값. 추정 아님 |
| 말 속도 | 🟡 **참고 출력, 판정 안 함** | 영어 156~161단어/분이 *좋은지* 모른다. 한국어 기준엔 참고 영상 6.93 이라는 대조군이 있었지만 영어엔 없다 |
| 제목 이행 | 🟡 **warn, 사람이 눈으로** | 한국어판은 "과거 5편 중 3편을 잡는다"는 **검증을 통과했기 때문에** 신뢰받는다. 영어는 1편으로 그 검증이 불가능하다 |

🔴 이 둘을 지금 fail 로 만들면 게이트가 "통과했다"고 말하는데 실은 아무것도 검증 안 한 상태가
된다 — M17 에서 실패 불가능한 테스트를 3회 만든 것과 같은 실패다.
**영어 회차가 3편 이상 쌓이면 같은 방식(과거분에 돌려 늦은 것을 잡는가)으로 검증하고 승격한다.**

### ADR-V-13 — 병합은 **Node 한 곳**에서 하고, 병합 결과를 파일로 굽는다.
`scene.en.json` 은 `spec` 을 담지 않고 한국어 파일에서 상속한다(ADR-V-10 의 귀결).
그 병합을 브라우저와 Node **양쪽에 구현하면 반드시 갈라진다.** 그런데 `engine/lib.js` 를
Node 가 못 읽는다(전제 9).
→ Node 가 병합해 `episodes/<ep>/build/en/scene.json` 으로 굽고, 엔진은 그 완성본을 fetch 한다.
**매 실행마다 다시 굽는다** — 기존 파일을 신뢰하지 않는다(낡은 병합으로 렌더하는 사고 차단).

#### 🔄 개정 (2026-08-05, W0 구현 중 발견) — 상속은 **통짜 복사가 아니라 부분 오버라이드**다.

**무엇을 관측했나.** W0 에서 `spec` 42필드를 전수 판정했더니, 한국어로 남긴 12필드
(`note`·`quote`·`topLabel`·`dataSub`·`untouched`·`landing`·`learn`·`meaning`·`nextLabel`
·`archetype`·`rows[].name` ×2)가 **전부 `spec` 안에 있었다.**

**옛 규칙이 왜 실패하는가.** "`spec` 을 통째로 상속한다"를 그대로 구현하면
**영어 영상에 한국어 서술이 박힌다** — 화면에 `다섯이 같은 눈금에 서 있다`,
`다음 편 · 직업과 일과` 가 그대로 뜬다. ADR-V-10 이 "서술은 한국어"라고 정한 순간
**`spec` 은 언어 무관 자산이 아니게 되었는데**, ADR-V-13 이 그 귀결을 안 따라갔다.
두 ADR 이 같은 세션에서 쓰였는데도 어긋난 것이다.

**새 규칙.** `scene.en.json` 이 `spec` 의 **일부 키만** 적으면 그 키가 이기고, 안 적은 키는
한국어 정본에서 상속한다.

```js
spec: { ...k.spec, ...(s.spec ?? {}) }   // 한국어 정본 위에 영어 대본이 덮어쓴다
```

영어 대본은 **서술 12필드만** 적으면 되고, 영어로 공유되는 라벨(`HUNGER`·`ACCEPT`·`GATHER`)은
안 적어도 상속된다. `kind` 는 **여전히 통짜 상속**이다 — 대본이 그림을 재발명하지 못하게 막는
장치이므로 오버라이드를 허용하지 않는다.

🔴 `rows[]` 처럼 **배열 안의 객체는 얕은 병합이 통째 교체**로 동작한다. 영어판이 `rows` 를
적으면 `fatigue`·`accept` 까지 전부 다시 적어야 한다. 이건 의도된 것이다 —
배열 원소를 인덱스로 부분 병합하면 순서가 바뀌는 순간 조용히 어긋난다(W0 커밋의
`tts.mjs` 인덱스 캐시 사고와 같은 종류).

### ADR-V-14 — 채널 분리는 **이 명세에서 정하지 않는다.**
지금 채널의 시청자 풀이 99% 한국이라, 영어 회차의 조회수가 안 나와도 **대본 탓인지 배급 탓인지
구분이 안 된다.** 교란 변수가 재려는 것보다 크다. mp4 는 어느 쪽이든 같으므로 미뤄도 손해가 없다.
→ W5 의 국가 분포 관측 뒤에 별도로 결정한다.

### ADR-V-15 — 옛 회차는 재렌더하지 않는다.
ep00s~ep05s-3 은 한국어 라벨로 이미 나갔다. ADR-V-10 이 시리즈 중간에서 표기를 가르지만,
이 프로젝트엔 이미 선례와 자리가 있다 — `voice.json` 의 `회차_경계` 가 목소리 M3→ME 전환을
그렇게 적어뒀다. **라벨 경계도 같은 자리에 같은 방식으로 남긴다.**

// lib-node.mjs — 기존 epScene/epBuild 는 그대로 둔다(한국어 호출부가 많고 전부 유효하다).
//   새 팩토리만 더한다. 한 프로세스는 한 회차·한 언어만 다루므로 이 모양이면 충분하다.
export const langPaths = (ep, lang = 'ko') => ({
  lang,
  /** 그 언어의 대본 원본. ko 는 정본, 그 외는 sidecar. */
  src:   path.join(epDir(ep), lang === 'ko' ? 'scene.json' : `scene.${lang}.json`),
  /** 병합본이 놓일 자리. ko 는 병합이 없으므로 src 와 같다(ADR-V-13). */
  scene: lang === 'ko' ? epScene(ep) : path.join(epDir(ep), 'build', lang, 'scene.json'),
  build: (...rest) => path.join(epDir(ep), 'build', ...(lang === 'ko' ? [] : [lang]), ...rest),
});

/** 영어 sidecar 는 spec 을 담지 않는다 — 한국어 정본에서 shot id 로 상속한다(ADR-V-10).
    🔴 매 실행마다 다시 굽는다. 있는 파일을 재사용하면 낡은 병합으로 렌더하게 된다. */
export function bakeScene(ep, lang) {
  if (lang === 'ko') return epScene(ep);
  const P = langPaths(ep, lang);
  const ko = JSON.parse(fs.readFileSync(epScene(ep), 'utf8'));
  const en = JSON.parse(fs.readFileSync(P.src, 'utf8'));
  const koById = new Map(ko.shots.map(s => [s.id, s]));
  const merged = {
    ...en,
    shots: en.shots.map(s => {
      const k = koById.get(s.id);
      if (!k) throw new Error(`${lang} 대본의 샷 ${s.id} 가 한국어 정본에 없다 — spec 을 상속할 곳이 없다`);
      /* kind 는 통짜 상속 — 대본이 그림을 재발명하지 못하게 막는 장치다(오버라이드 불가).
         spec 은 **부분 오버라이드**다(ADR-V-13 개정): 라벨은 이미 언어 중립이라 상속되고,
         서술 필드(note·quote·landing·learn·nextLabel…)만 영어 대본이 덮어쓴다.
         🔴 통짜 복사로 되돌리지 마라 — 영어 영상에 한국어 서술이 박힌다. */
      return { ...s, kind: k.kind, spec: { ...k.spec, ...(s.spec ?? {}) } };
    }),
  };
  fs.mkdirSync(path.dirname(P.scene), { recursive: true });
  fs.writeFileSync(P.scene, JSON.stringify(merged, null, 2));
  return P.scene;
}

## 8. 재미 검증 — 시청자가 화면에서 무엇을 새로 보게 되는가

**한국어 시청자**는 W0 이후 그림 안에서 `HUNGER / REST / WORK` 를 본다. 지금까지
`배고픔 / 쉼 / 일` 이던 자리다. 바뀌는 것은 "개발일지를 보고 있다"는 감각의 밀도다 —
화면의 라벨이 실제 코드에 있는 식별자와 같은 모양이 되어, 자막이 설명하는 것과
그림이 보여주는 것이 **코드와 같은 언어로** 이어진다.

**영어권 시청자**는 처음으로 이 채널의 영상을 **끝까지 볼 수 있게** 된다. 지금은
제목이 한국어라 클릭조차 안 하고, 클릭해도 3초 안에 나간다. 파일럿 이후에는
사용자님 목소리가 영어로 말하고, 자막이 영어이고, 그림의 `HUNGER / REST / WORK` 위에서
다섯 고리가 한 세로선에 걸리는 것을 본다 — **한 글자도 안 읽어도 "다섯이 동시에 움직인다"가
전달되는 화면**이다. 그게 이 채널이 영어권에 처음으로 건네는 문장이다.
