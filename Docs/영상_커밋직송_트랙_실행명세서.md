## 2. ADR — 구현 중 갈릴 판단 (바꾸려면 사유를 커밋에)

- **ADR-D-1 · 원문 = 세션 로그 산문.** 검수의 「원문에 없는 문자열」 대조는
  `devlog/sessions/*.md` 본문을 대상으로 한다. **커밋 diff·코드는 교차검증용**이며 자막
  원문이 아니다(비개발자 한국어와 대조 불능). 코드 문자열 그대로 인용은 화면 한국어 규칙의
  기존 예외 ①(코드·로그 그대로 인용)을 따른다.
- **ADR-D-2 · dNNs 는 `schedule.json` 밖에서 산다.** order 에 넣지 않는다(실사: 루틴 선택은
  order 만 본다). 원장은 `state/direct.json` 신설. `sources` 에도 안 넣는다 — publish 의
  `‖ {}` 폴백이 url 없는 설명문을 이미 만든다(ep00s 전례).
- **ADR-D-3 · 예고 = 같은 원문의 이월·다음 문장에서만.** 세션 로그의 "W8 로 이월했다",
  "3차 제안으로 남긴다" 류가 유일한 예고 재료다. 다음 dNNs 회차 번호는 예고하지 않는다
  (다음 소재를 모르는 트랙이다).
  🔄 **시제는 갈래다 (2026-08-11 중간 리뷰 개정 — d01s 두 마스터 판정이 근거)**:
  ⓐ **미래의 이월 작업을 가리키면 예정형**(「~할 차례입니다」) — 아직 안 일어난 일을
  단정하면 함정 8 의 신종이 된다 (d01s-2 실물).
  ⓑ **같은 원문에서 이미 벌어진 형제 편 사건을 가리키면 단정형 허용** — 거기서 예정형은
  오히려 거짓이다 (d01s-1 실물: 「사라진 이야기예요」). 옛 문언("시제는 예정형")은 목적절
  ("아직 안 일어난 일을 단정하면")보다 넓게 적혀 있던 것이라 좁힌다.
  🔗 카드 접두도 같은 갈래를 따른다 — `outro.nextKind: 'episode'(기본 · 「다음 편」) |
  'item'(「다음 항목」)` (`engine/engine.js` 2026-08-11 개정). **마지막 dNNs 편 = 'item'**,
  중간 편 = 기본값. 🔴 track 으로 가르면 중간 편이 되레 틀린다.
- **ADR-D-4 · 주 1~2편 = 사람 트리거.** 크론 없음(25초 명세 S6 「크론 폐기」와 정합).
  트리거 문구 = **「dNN 만들어줘」**. scene-source 는 `direct.json` 의 마지막 커버 커밋
  **이후** 로그만 본다.
- **ADR-D-5 · 사건의 정의.** 커밋 ≠ 사건. 사건 = **①게임의 행동·화면이 바뀌었고 ②원인의
  서사(왜 그랬나)가 로그에 산문으로 있으며 ③브랜드 문서 §3 물음(비개발자가 재미·자신감·
  궁금증 중 하나를 얻는가)을 통과**하는 것. 셋 중 하나라도 없으면 소재 아님.
- **ADR-D-6 · 연속극 중복은 금지가 아니라 명시.** 같은 사건이 나중에 블로그 글이 되면
  연속극이 다시 다룰 수 있다(두 달 뒤 회고는 다른 이야기다 — dNNs 는 「그날 알던 것」의
  속보이고 연속극은 후속까지 소화한 다큐라 원문 층위 자체가 다르다). 단 연속극 기획
  브리프에 「이 사건은 dNN 이 이미 다뤘다」를 **반드시 명시**해 작성팀이 각도를 갈게 한다.
  🔄 **보강 (2026-08-11 중간 리뷰)**: 명시에 그치지 않고 **유형⑦(훅·페이오프 재사용 금지)
  계약을 트랙 간으로 확장**한다 — 연속극이 dNNs 가 다룬 사건에 도달하면 그 dNNs 편의
  훅·제목 문장을 재사용하면 반려다(대조 재료 = `direct.json` 의 event + 해당 회차
  scene.json). ep15s→ep16s 에서 실증된 계약의 트랙 간 판이다.
- **ADR-D-7 · 번호 = `d01s` 부터, 분할 = `d01s-1`.** 기존 분할 규약(ADR-V-1 사건 단위)
  그대로 상속. 제목의 기간 프레임 「Claude Code로 N일차」의 N 은 **lf02 방식**(첫 커밋
  2026-06-24 → 기준 시각을 커밋으로 얼림)을 그대로 쓴다 — 재지 말고 얼린다.

**대상 파일**: `.claude/agents/scene-planner.md` · `scene-writer.md` · `scene-reviewer.md` · `scene-master.md`
