# 종족 침공 축 — 브레인스토밍 기록 (2026-08-09)

> ⚠️ **이 문서는 실행명세서가 아니다.** 브레인스토밍이 **중단된 지점까지의 기록**이다.
> 절차상 남은 단계: 접근안 확정 → 설계 절별 승인 → 실행명세서 작성 → 사용자 리뷰 → 구현계획.
> 새 세션은 아래 「미결」부터 이어가면 된다.

## 0. 왜 이 축이 생겼나 (사슬)

늑대 그림을 못 그려서다. 순서대로:

1. M22 3차 W5c 에서 늑대·곰 그림 자작 → Play 판정 **"정말 너무 너무 너무 최악인 늑대 그림"**
2. 2026-08-09 재작업 1회(총 7라운드) — 참고본의 구조 원칙을 이식해 5회 되돌리며 개선.
   **여전히 반려.** 같은 도구로 망루·함정은 3라운드에 통과했다 → 원인은 도구가 아니라 사람.
3. 조달 조사 → **3방향(Down/Side/Up) 필터에서 대부분 탈락**, 통과한 둘은 **화풍 탈락**:
   - Elthen 2D Pixel Art Wolf $3 — 64×64, 옆모습 한 방향
   - sanctumpixel Wolf Top Down $4.20 — 좌/우만
   - OpenGameArt "Wolf Pack!" 32×32 CC0 — 화풍 불일치
   - vectoraith Wild Animals $10 (늑대 3변종 + 곰) — 화풍 불일치
4. Kenmi 팩 **13종 전수** — 개과 0. Dungeon = 환경 전용. Characters = 인간형만.
   우리 팩은 2026-07-07 다운로드 = 최신판(Update #14)이라 무료 업데이트로 얻을 것도 없음.
5. **결론: "늑대를 유지한다"와 "화풍을 지킨다"는 동시에 성립하지 않는다.**
   → 사용자 결정: **늑대·곰을 없애고 종족 침공으로 간다.**

## 1. 확정된 결정

| # | 결정 | 근거 |
|---|---|---|
| D1 | **늑대·곰 폐기.** 위협은 종족(오크·고블린·기사·천사)이 된다 | 위 사슬 |
| D2 | 위협은 **밭이 아니라 주민을 공격**하는 쪽으로 무게 이동 | 사용자 지시 |
| D3 | **C(종족별 특성)로 간다. 단 B(침입 특성 축)를 먼저 깐다** | C ⊃ B — 고를 목록이 없으면 C는 성립 안 함 |
| D4 | 침입 특성은 **`{축, 값}[]` append-only 배열 + 미등록=중립 폴백** | 리포 관용구 3곳(`PersonalitySO.Traits` · `AgentSpriteSetSO.Actions` · `SlotId`)과 동형. 이래야 새 종족 = 코드 0줄 |
| D5 | **종족 ⊥ 티어.** 게임일 밴드(늑대→무리→곰 3단)를 **폐지** | 종족 특성을 제대로 보고 플레이어가 전략을 짜게 하려면 |
| D6 | 범위는 **최대** — 축 1~4 전부 + 천사 트리거 | 사용자 지시 |
| D7 | **창고 탈취 포함** → `ADR-M10-5`("창고 스톡은 성역") **폐기 필요** | 사용자 지시. 개정 사유문을 명세에 반드시 남길 것 |

### 설계 북극성

> **종족 하나 = 질문 하나. 플레이어의 대비 = 답.**

어떤 종족에 대해 "어떻게 막지?"라는 질문이 안 생기면 그 종족은 **색만 다른 늑대**다.
모든 안은 이 기준으로 잰다.

## 2. 침입 특성 축 메뉴 (B의 내용물)

### 축 1 · 무엇을 노리는가 (Target)

| 값 | 내용 | 플레이어의 답 | 비고 |
|---|---|---|---|
| 주민 | 기존 늑대 | 무장·간호·대피 | 기존 `VillagerTargetChance` |
| 밭 | 기존 늑대 | 밭 재배치 | 기존 |
| **창고 스톡** | 공용 자원 탈취 | 창고 방어 집중 | 🔴 ADR-M10-5 폐기 |
| **개인 식량** | 집에 든 개인 비축 | 집 밀집 배치 | M11 개인경제 활용 |
| **방어 시설** | 망루·함정 우선 파괴 | 분산·이중화 | M22 자산 활용 |
| **집** | 건물 파괴 | 재건 비용 | 목수 부활과 연결 |
| **특정 직업** | 사냥꾼·목수 지목 | 인력 배치 | 새 개념 |

### 축 2 · 어떻게 접근하는가 (Approach)

| 값 | 내용 | 플레이어의 답 |
|---|---|---|
| 정면 | 막힌 건 부순다 (기존) | 두꺼운 울타리 |
| **우회** | 망루 사거리를 피해 돈다 | 망루 배치 설계 |
| **문 지향** | 울타리 말고 문을 노린다 | 문 잠금 + 문 앞 함정 |
| **다지점** | 여러 방향 동시 진입 | 전 방향 방어 |
| **원거리** | 사거리 밖에서 타격 | 붙어야 함 |
| **은밀** | 예고가 짧다(`WarnDays`↓) | 상시 대비 |

### 축 3 · 무엇을 하고 떠나는가 (Exit)

| 값 | 내용 |
|---|---|
| 시간 만료 | 기존 `MaxStayDays` |
| **목표 달성 즉시 이탈** | 훔치면 바로 도주 — 쫓아가 잡으면 되찾는다 |
| **점령** | 안 떠난다. 쫓아내야만 끝 |
| **결사** | 도주선 없음 — 전멸까지 |

### 축 4 · 무엇에 무너지는가 (Break)

| 값 | 내용 |
|---|---|
| 개체 도주선 | 기존 `FleeBelowHpPct` |
| 무리 붕괴 | 기존 `RoutBelowPct` |
| **지휘관 사망** | 하나를 잡으면 전원 붕괴 — 표적 우선순위가 생긴다 |
| **함정 학습** | 한 번 걸리면 다음 출몰엔 피한다 — 함정 재배치 강요 |

## 3. 종족 후보 (축의 조합)

| 종족 | 조합 | 질문 → 답 |
|---|---|---|
| **고블린** | 창고 탈취 · 우회 · 목표 달성 즉시 이탈 · 겁 많음 | *"자원이 새는데 아무도 안 죽는다"* → 창고 방어·추격 |
| **오크** | 주민 · 정면 · 결사 · 무리 붕괴 | *"정면을 어떻게 버티나"* → 울타리·함정·무장 |
| **기사단** | 방어 시설 · 다지점 · 지휘관 붕괴 | *"망루가 먼저 죽는다"* → 분산·이중화, 지휘관 저격 |
| **천사(타락)** | 아래 별도 트리거 | 미정 |

**천사 제안(미확정):** 다른 종족처럼 다루면 "센 오크"가 된다. 대신 **심판자**로 두어
게임일이 아니라 **마을이 한 일**이 부르게 한다 (무덤 N개 초과, 아사 발생 등).
그러면 천사는 난이도가 아니라 **거울**이 되고, M13이 비워 둔 *"왜 하는가"* 칸에
처음으로 무언가 들어간다. 종족 중 유일하게 자기 트리거를 갖는 예외가 된다.

## 4. 밴드 폐지의 대체 축 (미확정)

🔴 **ADR-M10R-1(게임일 래칫)은 실제 버그를 고치며 앉은 자리다** —
*사망 → 마을 규모↓ → 위협 강등 → 밭만 → 영구 안정*이라는 음성 피드백 루프.
밴드를 빼면 **그 자리를 무엇이 대신하는지** 반드시 같이 정해야 한다.

| | 안 | 장점 | 위험 |
|---|---|---|---|
| **E1** | 게임일 = 전역 압력 스칼라 (종족은 "어떻게"만, 마릿수·체력은 게임일 곡선) | 래칫 보존, 종족이 끝까지 산다 | 곡선 하나에 밸런스가 몰림 |
| **E2** | 종족별 독립 스케줄 (각자 해금일·주기, 겹치면 겹친 대로) | 후반 혼성이 자연히 생김 | 겹치는 날 난이도 폭발 |
| **E3** | 계절 축 (가을=고블린, 겨울=오크) | 계절이 처음으로 위협과 연결 | 축이 하나 더 |
| **E4** | 행적 트리거 (창고가 넘치면 고블린, 무덤이 쌓이면 천사) | 플레이어 행동이 세계를 부른다 | 🔴 "쌓지 마라" 퇴행 전략. ADR-M10R-1이 기각한 '마을 규모 축'의 사촌 |

**작성자 추천(미승인): E1 + E2, 천사에만 E4.**

## 7. 이번 세션이 남긴 도구 자산 (버리지 말 것)

늑대는 폐기되지만 **그리는 도구는 남는다** — 앞으로 어떤 그림에도 쓴다.

- `tools/pixel-art/sheet.mjs` — `animalSheet(name, frames, {artW, artH})` 로 **회차별 그림 크기**를
  받게 개정. 바닥선(y=25) 고정 규칙을 식으로 박아 크기가 달라도 발끝이 한 줄에 놓인다.
  넘침 검사 추가(줄 길이·줄 수) — 넘치면 **옆 칸에 조용히 그려지던** 사고를 막는다.
- `tools/pixel-art/recipes/wolf.mjs` — 재작업 5회분의 교훈이 주석에 박제:
  ① 맞닿는 조각은 윤곽줄을 **한 줄만** (둘이면 머리·몸통이 블록 두 개로 분리)
  ② 다리는 **짝끼리 붙이고** 앞뒤 짝은 멀리 (고르게 벌리면 지네)
  ③ 벌린 입 **안은 어둡게**, 흰 것은 송곳니 둘뿐 (흰 덩어리는 부리)
  ④ 뒷모습 밝은 띠는 **가로로** (세로면 가운데 밝은 덩어리 = 얼굴로 오독)
  ⑤ 명암은 부위별이 아니라 **위→아래 한 방향 램프**
