## 고친 것 — 규칙이 아니라 재료
- scene-planner: 브리프 끝에 「다음 편 예고 재료」 절 필수.
  order 의 다음 id → 구성안 표에서 막·원본회차·주제. 막이 바뀌면 크게 적는다.
  표 행은 URL 로 조회한다 — 번호로 세면 0편이 표 밖이라 어긋난다
- scene-writer: 규칙 7 을 구체 요구로. 좋은 예/나쁜 예 + 원문의 "다음 글"
  문장 사용 금지
- scene-reviewer: 새 항목 — 막연한 마무리는 반려 + 예고가 사실인지 정본 대조
- routine-prompt: 무인 실행이 정의서를 안 읽을 수 있으므로 같은 내용
