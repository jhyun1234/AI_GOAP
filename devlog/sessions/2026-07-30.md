**왜 이렇게 했나 (커밋 본문):**
스케줄러가 대본을 안 만들고 있었다. routine.cmd 는 publish.mjs 만 부르고
그 스크립트는 scene.json 이 이미 있어야 돌았다 — 즉 자동이었던 것은
기계 절반(음성·렌더·점검)뿐이고 대본 절반은 사람이 Claude Code 를 열어야 했다.
ep00s·ep01s 는 사람이 손으로 이어 붙인 것이다.

## 무인 파이프라인
- publish.mjs 0단계: 대본이 없으면 로컬 헤드리스 claude -p 로 4개 부서 실행
- 점검 실패 → 에이전트로 되돌리는 루프. routine-prompt.md 가 처음부터
  "검수팀 단계로 되돌아간다"고 적어 뒀는데 코드에는 그냥 exit 1 이었다
- --redo "<지시>": 사람이 주는 재작업 경로
- 서버측 일시 오류(5xx·overloaded)는 3·10·25분 백오프로 스스로 재시도.
  인증·한도는 기다려도 같으므로 즉시 멈춘다
- 인증 선점검: 40분짜리 사슬을 시작하기 전에 만료를 보고 재로그인 안내까지 찍는다
- 고아 kind 자동 정리 — 무인이면 버린 그림을 아무도 안 지운다
- stream-json 진행 로그(부서·파일·명령·거부된 도구·사용 한도)
- 모델 5자리 전부 claude-opus-5 (별칭은 CLI 버전에 따라 다른 세대로 풀린다)
