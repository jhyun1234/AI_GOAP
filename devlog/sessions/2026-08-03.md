**막혔던 문제 / 해결 방법** (이탈률 트랙 전체 — 커밋 본문에 없는 것만):

- **검증용 fixture 를 내가 못 지웠다.** W3(길이 게이트)는 30~45초·47초 회차가 실물로
  없어서 `episodes/_gatecheck/` 를 만들어 실제 `check.mjs` 를 돌렸는데, 정리 단계에서
  `rm -rf` 와 `Remove-Item -Recurse -Force` 가 **둘 다 권한 정책에 막혔다**(의도된 안전장치).
  → 우회하지 않고 사용자에게 넘겼다. 이때 내가 bash 문법(`rm -rf`)을 안내해 PowerShell
  에서 `매개 변수 'rf' 를 찾을 수 없습니다` 로 실패했고, `Remove-Item -Recurse -Force` 로
  정정해 삭제 완료(회차 7개만 남은 것 확인).
- **W4 스크린샷을 못 찍었다.** 브라우저 창이 표시되지 않아 프레임 합성이 안 됐다.
  → DOM 단언(`hidden` 상태를 0초·중간·끝-1.5초에서 실측)과 `check.mjs` 픽셀 게이트
  (안전영역·팔레트·정적 구간·결정성·잘림)로 대체했다. 🔑 **카드가 항상 숨겨져 있어도
  픽셀 게이트는 똑같이 통과**하므로 DOM 단언이 없으면 거짓 통과였다.
- **W5 를 실제 스크립트로 못 돌렸다.** `publish.mjs` 는 `schedule.json`·`uploads.json`
  경로가 고정이라(`backlog.mjs` 의 `SCENE_SCHEDULE` 같은 시험용 문이 없다) 설명문 갈래를
  띄울 방법이 없었다. → 명세 밖 개선은 넣지 않는 규칙대로 env 문을 신설하지 않고,
  작성한 식을 떼어 4가지 상황으로 검증한 뒤 **백로그로 남겼다.**
- **클라우드 프롬프트는 등록 시점 사본이다.** 리포의 `cloud-routine-prompt.md` 만 고치면
  클라우드는 옛 0.5일 게이트로 계속 돈다. → 크론 2회 등록과 **프롬프트 재붙여넣기를 짝으로**
  안내했고 사용자가 둘 다 완료. 🔑 한쪽만 하면 둘 다 하루 한 편 그대로다.
