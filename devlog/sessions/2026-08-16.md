## [02:35] spec(M32): 전쟁 축 1차 실행명세서 — 함락 = 판의 끝

**태그:** #misc

**무엇을 했나:**
- spec(M32): 전쟁 축 1차 실행명세서 — 함락 = 판의 끝

**왜 이렇게 했나 (커밋 본문):**
컨셉 전면 전환(생존 시뮬 → 종족 전쟁)의 첫 명세. 사용자 진단은 "또 다시 많은 기능들이
생겨서 복잡해졌다"였고, 실사 결과 원인은 시스템 수가 아니라 **지는 조건이 없던 것**이다.
서른한 축이 전부 생존 시뮬에 얹혔는데 아무도 못 지니 필수인 시스템이 하나도 없었다.

믿었던 것 → 실제 관측 (실사 5문에서 전제 넷이 뒤집혔다):

- 성격 축이 15개인 줄 알았다 → 6개다(TraitId.cs). 그중 Caution 이 이미 "겁: 담대↔조심"
  이라 "겁/용맹 한 축만 남긴다"의 신설분이 0이다.
- 무기를 새로 붙여야 하는 줄 알았다 → SlotId.MyHasWeapon(40)이 이미 있고
  CombatService.HitInterval 이 weaponMult 를 이미 받는다(ADR-M21-5: 무기는 게이트가
  아니라 배율). 병과 셋이 코드 0줄로 선다.
- 게임오버가 없는 줄 알았다 → ShouldShowGameOver 순수 함수 + 게이트 M10-T6 +
  ComposeGameOver 가 이미 있다. 함락은 새 경로가 아니라 그 함수의 조건 확장이다.
- "서비스가 ID 문자열이라 두 벌이 쉽다"고 했다 → 절반만 맞다. 타격자는 ID 인데
  VillagerHit 의 대상만 ThreatAgent 구체 타입이라 주민↔주민 타격이 시그니처에서
  막혀 있었다. 거울 마을의 진짜 병목이 여기고, W4 의 ICombatant 가 그 답이다.

무기 실사도 함께: Player_Attack_OnlyWeapon 은 4프레임 × 9행(3방향 × 3종류)이고 오버레이
층은 칼날 하나뿐이다. 주민 무기는 검·활·도끼이며 창·방패는 팩에 없다 — ADR-M32-8 로 박았다.

W1 철거(에셋 등록 해제만) · W2 함락 · W3 병과 · W4 진영 분리 · W5 저쪽 마을 · W6 징집·정찰.
중간 리뷰는 W4 커밋 직후(88개 참조 이전율 보고)와 W5 Play 3판 후 둘.

**막혔던 문제 / 해결 방법:**
- 모캡 리타기팅에서 결함이 **여덟 번** 나왔고 전부 화면 또는 수가 잡았다. 추론이 미리
  잡은 것은 **0건**. 목록은 `AI_GOAP-video/tools/scene-video/notes/M32-모캡-리타기팅-인계.md` §7.
- 🔴 **아직 막혀 있는 것**: 새 사람 비율 모델(T포즈)에 모캡을 먹이면 조각이 흩어진다.
  레스트는 정상이고 `@root` 는 최대 0.076m 라 이동으로는 못 흩어진다 → 회전이다.
  T포즈는 팔뼈가 ±Y 라 `to_euler('XYZ')` 가 짐벌 특이점에 걸린다.
  **해법 = 포즈 표를 쿼터니언으로.** 고칠 파일 셋과 코드 조각은 인계 문서에 있다.

**뒤집힌 것 (믿었던 것 → 실제):**
- "성격 축이 15개다" → **6개**다. 그중 `Caution` 이 이미 「겁: 담대↔조심」이라
  "겁/용맹 한 축만 남긴다"의 신설분이 **0**이었다.
- "무기를 새로 붙여야 한다" → `SlotId.MyHasWeapon`(40)과 `CombatService.HitInterval(weaponMult)`
  이 이미 있어 **병과가 코드 0줄로 선다**.
- "게임오버 개념이 없다" → `ShouldShowGameOver` 순수 함수 + 게이트 `M10-T6` 이 **이미 있다**.
- "서비스가 ID 문자열이라 거울 마을이 쉽다" → 절반만. 타격자는 ID 인데 `VillagerHit` 의
  **대상만 `ThreatAgent` 구체 타입**이라 주민↔주민 타격이 시그니처에서 막혀 있었다.
- "모델을 Mixamo 에 맞게 다시 만들면 해결된다" → 처음엔 **아니라고 답했다**(남은 결함이
  `@root` 였으니 맞는 판단이었다). 그런데 `@root` 를 넣고 팔 기준면까지 고친 **뒤에도**
  사용자가 렌더를 보고 「심각하다」고 판정했고, 그 지점부터는 비율이 진짜 원인이었다.
- 🔴 **"무개입 방치에서 아무도 안 죽는다" → 틀렸다.** 촬영 30분에 **4명 죽는다**.
  올바른 한 줄은 **「사람은 죽는데 판은 안 끝난다」** 이고, 그게 「지는 조건이 없다」의
  정확한 그림이다. 롱폼 콜드 오픈 재료가 `death` 컷 4개로 이미 잡혀 있다.
