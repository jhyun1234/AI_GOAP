`ep08s`(원본 = M6 예고된 겨울)는 사건이 셋이라 **3편**으로 나뉘었다.
**`ep08s-1` = 2026-08-06 APPROVED**(누적 반려 0회). 채널의 **첫 25초 편**이고 실측
24.4초 / 본문 21.8초 / 예고는 ADR-V25-2 **②안**(음성 0 + `outro.next`)이다.

**8-2·8-3 착수 전에 처리할 것 2건:**
1. `ep08s-1/scene.json` 의 `notes.길이`·`notes.25초_예산`·`excluded[0]` 이 **개정 前** 게이트 값을
   인용하고 있다(「본문 21초」·「①안 창 0.5초」·「목표 20~25초」). 현행은 **본문 20 · 권장 22.6~25**.
   방치하면 다음 작성자가 「음성 예고는 사실상 불가능」이라고 잘못 배운다.
2. 8-2·8-3 이 생기면 `ep08s-1` 의 `outro.siblings` 를 채운다(두 편의 `youtube.title` 에서
   기계 파생). 지금 그 지시가 8-1 폴더 안에만 있어 8-2 작성자가 읽을 자리가 아니다.

**Why:** `notes/` 는 다음 회차가 읽는 인수인계 경로다. 렌더에는 영향이 없어 반려하지 않았지만,
틀린 채로 두면 옛 게이트로 회차가 돌아간다(리포만 고치고 사본을 안 고친 사고와 같은 형태).

**How to apply:** 8-2 를 기획/작성할 때 위 둘을 먼저 확인한다. 8-2 의 0초는 「다섯이 동시에
배고파졌다」여야 하고 **겨울 이야기로 시작하면 안 된다**(원문이 「계절과 상관없는 데서
튀어나왔다」고 직접 선언한 독립 사건). 관련 = [[verdict-evidence-grades]] · [[factcheck-gotchas]]
