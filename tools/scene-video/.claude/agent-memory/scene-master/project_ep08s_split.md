`ep08s`(원본 = M6 예고된 겨울)는 사건이 셋이라 **3편**으로 나뉘었고, **셋 다 승인됐다**(2026-08-06).

- **`ep08s-1`** APPROVED(반려 0회). 채널 첫 25초 편. 예고 = ADR-V25-2 **②안**. 렌더 완료.
- **`ep08s-2`** APPROVED(반려 1회 — 영어 자막). 예고 **①안**(음성 6자 1.7초)의 첫 사례이고,
  그 실측이 **예고 상한을 1.0 → 1.8 로 교정**한 근거다(짧은 발화 고정 오버헤드 약 550ms).
- **`ep08s-3`** APPROVED(반려 1회 — 4건 한꺼번에). 게이트 24.8초 / 본문 22.2 / 예고 ②안.
  반려 4건(카드에 먹힌 판정 · 문턱 못 넘는 막대 · 라벨 관통 · 8-2 와 구도 중복)이 **전부
  기계 게이트가 통과시킨 자리**에서 났다 — 24항목 green 이던 대본이었다.

**세 편에서 확인돼 다시 안 재도 되는 것**
- 원문 6절 = `전원 · 0 · 반나절 · 5명→10명` / 8절 = `5 · 81.6 · 81.7 · 62.6 · 82.8 · A~E · FNV-1a`.
  **원문에 그 밖의 수는 없다.**
- 「전원 → 10명」 치환은 성립한다(5단계가 10명으로 늘리고 6단계가 「밸런스를 조인 뒤」로 시작).
- 세 편의 `kinds/*.js` 는 `fillText` 가 전부 `spec.*` 에서 온다 — **하드코딩 수치 문자열 0건.**
  형제 페이오프 누출은 렌더 경로 자체가 없다(아웃트로 카드의 형제 라벨은 규약상 정상).

**남은 정정(승인을 막지 않음)**: 8-2 노트 수치 2건 · 8-3 노트의 폐기 kind 흔적 3건과
`notes.길이` 예상값 잔류 · 8-3 `sfx.delayMs` 2건(2,300→2,460 / 2,590→2,810,
[[timing-formulas]]) · `kinds/sametick.js` 비석 삭제.
🔴 **노트 갱신 누락이 세 편 중 두 편에서 났다** — 작성 지시서 항목으로 승격할 후보다.

**파이프라인 문제(회차와 무관)**: `.staging/` 이 회차별로 덮어써진다. 8-3 판정 시점에
`04_verdict.md` 는 8-2 것, **`03_review_report.md` 는 8-1 것**이었다 — 검수 리포트가
남지 않아 사후 대조가 불가능하다.

**How to apply:** 다음 회차가 이 글을 다시 건드리면 위 수치 표를 재사용하고, 새로 주장하는
값만 원문에서 찾는다. 판정 절차는 [[gate-metric-gaps]] + [[timing-formulas]] 를 함께 쓴다.
