**ep10s(M8 관계·소유·부탁) 3편 전부 APPROVED.** 단 **10-2 만 두 번 승인됐다** —
1차(5샷 26.9초, 3단) 승인·렌더 뒤 **4단 고정 구조로 재제작**해 2026-08-08 재승인(8샷 10자막 36.8초).

**ep10s-3 도 4단으로 재제작해 재승인**(2026-08-08, 7샷 9자막 37.0초 · 반려 0).

### 🔴 승인 뒤에 대본이 바뀐 사고 — 알림 없이

`ep10s-2` 를 승인한 뒤 그 편의 `youtube.title` 이 **도치·질문형으로 교체됐는데 보고되지 않았다**
(`…코드 0줄이었어요` → `AI가 알아서 할 수 있을까요? …`). 재검사 결과 게이트는 통과하지만
**제목 후킹 축이 「수치」에서 「정보」로 바뀌어** 내 판정문 기록이 stale 이 됐고 `upload.txt` 도
다시 뽑아야 했다. 🔑 **형제 편을 판정할 때 형제들의 `youtube.title`·`outro` 를 한 번 다시 읽는다** —
카드에 그대로 실려 나가므로 한 편의 제목 변경이 세 편의 화면을 바꾼다.

### 🔴 지금 남아 있는 것

- **시리즈 안에서 구조가 갈렸다.** ep10s-2 만 4단이고 **ep10s-1 · ep10s-3 · ep11s 는 3단 완주본**이다.
  되돌릴지 그대로 낼지는 **사람 결정**이고 회차 판정 밖이다. → [[four-act-structure]]
- **빌드 산출물이 재제작 뒤처짐으로 갈린 적이 있다.** 재승인 시점에 `build/video.mp4`·`en.srt`·
  `upload.txt` 가 옛 5샷본(00:47)이고 `timed.json`·`full.wav` 만 재제작본(16:06)이었다.
  🔑 **재제작 회차는 판정 때 `build/` 파일들의 타임스탬프를 봐라** — 게이트는 `timed.json` 만 읽으므로
  전부 green 인 채로 **옛 mp4 가 그대로 올라갈 수 있다.**
- **문서 정정 이월**: 1차 승인 때 남긴 S5 `why` 의 tick 전수 목록 오류(값은 옳고 표가 틀림).

### 이 회차에서 확인된 사실 대조 형태

- 카드 **형제 줄에 실린 수치도 원문 대조 대상**이다 — 10-1 「3초 만에」·10-3 「3군데나」가
  이 편 화면에 뜬다. 둘 다 원문에 실재했다(`3초 안에 읽기에 충분` · `되돌아가서 세 군데를 다듬었습니다`).
- 🟢 **원문에 `4`라는 글자가 없는 판정 순서(바쁨→배고픔→피로→친밀)를 세어서 숫자로 만들지 않았다.**
  세면 넷이지만 원문이 안 센 것은 화면도 안 센다 — `excluded` 가 그 판단을 인용과 함께 적어 뒀다.
  통과 형태의 본보기다.

**Why:** 재제작 회차는 「같은 회차를 다시 승인하는」 드문 형태라, 무엇이 바뀌었고 무엇이 그대로인지를
매번 diff 로 확인해야 한다(sfx 근거 줄이 안 바뀌었는지가 특히 그렇다).

**How to apply:** ep10s 관련 판정·인용 전에 이 파일을 먼저 본다. 관련 = [[four-act-structure]] ·
