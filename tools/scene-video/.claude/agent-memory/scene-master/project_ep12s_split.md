### 이 세 편이 보여 준 통과 형태

- **원문이 안 센 수는 화면도 안 센다.** 12-2 의 조임은 원문이 「첫째~넷째」로만 쓰므로
  자막이 **「네 군데」 한글 수사**로 받았고 화면 숫자는 40·30 둘뿐이다.
- **화면 항목이 원문 문장과 1:1 로 대응한다.** 12-3 S2 의 `TARGETS · RESIST · AMOUNT` 체크 셋이
  원문의 세 의심(대상 수집 / 저항 판정 / 소실 개수)과 하나씩 맞는다 — `reads` 검증의 좋은 형태.
- **`sfx` 는 지속음이면 완성점이 아니라 시작점에 건다**(12-3 drop `brk 0.108` · 12-2 riser 는
  포락선 마루 `k=0.25` 만큼 앞당김). → [[timing-formulas]]
