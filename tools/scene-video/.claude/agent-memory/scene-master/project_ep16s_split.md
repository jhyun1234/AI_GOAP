**`ep16s` = M13 「사건과 흔적」 5편 분할**(원문 `2026-08-04-unity-goap-m13-events-and-traces.html`).
형제 계약이 잘 지켜지는 회차다 — 화면 요소 이름(무덤/상태줄/명부)을 편마다 하나씩 나눠 가졌다.
⚠️ 아래는 2026-08-11 시점. 판정서 전문은 각 편 `notes/verdict.md` 에 있다(이 파일보다 그쪽이 정본).

### 편별 상태

- **`ep16s-1`(무덤에 이름이 없었다) = ✅ APPROVED** (마스터 반려 0 · 검수 1차 3건 반영).
  🔴 **`ep16s-2` 판정 때 이월 확인 2건** — ⓐ 16-1 이 낸 예고와 16-2 첫 줄이 여전히 맞는가
  ⓑ 형제 seed census(`sweep 277·269·263` / `latch 281·251·271`)가 그 시점에도 안 겹치는가.
- **`ep16s-3`(명부를 한 사람이 덮었다) = ✅ APPROVED** (2026-08-11 · **R1 정정 반영 후 재판정**, 누적 반려 1/3).
  🔑 **정정이 한 줄인지는 `build/audio/` 파일 시각으로 증명된다** — TTS 가 문장 해시로 파일명을 만들어서
  바뀐 줄만 새 파일이 생기고 **옛 파일이 고아로 남는다**. 「바뀐 줄만 봤다」를 보고로 믿지 말고 여기서 볼 것.
  🟡 이월: 정적 게이트 여유가 2.2→**2.8s**(문턱 3.0)로 좁아졌다 — 이 편에 본문을 더 얹으면 길이보다 이쪽이 먼저 터진다.
- (R1 기록) 2026-08-11 반려 사유 = 본문 어미 5연속.
  승인 조건 **넷은 전부 충족**했다: `check.mjs` 실패 0 · 수치 표본 3(「아홉 연발」·「×9」·「사망 몇 명,
  정착 몇 명」) 원문 실재 · `reads`/`source` 실질(13:35 스틸 6장으로 참 확인) · 첫 10초 수수께끼.
  반려는 **본문 「-죠」 5연속 / 「-었죠」 4연속** 하나뿐 → 잣대는 [[ending-repetition-rule]].
  🔑 재제출 시 **사실관계·형제 계약·영어 자막·`excluded` 는 통과로 확정**했다. 어미 정정에는
  **재TTS(`tts.mjs`) + `check.mjs` 재실행**이 반드시 따른다.
- **`ep16s-4`(죽으면 관계까지 지워졌다) = ✅ APPROVED** (마스터 반려 0 · 누적 2회는 길이 1 + 검수 1).
  🔴 **천장 회차다 — fail 38 까지 142ms.** 승인문에 「어떤 후속 수정도 재실측 필수」를 박았다.
  재합성 오차가 0인 근거는 [[timing-formulas]] ④. **`voice.json` 전역 조정 시 제일 먼저 깨진다.**
  🟡 이월 2건: ⓐ`ep16s-1` 의 `en.blurb` 만 `#16-2` 표기(나머지 넷·발행 선례는 `is part N`)
  ⓑ `excluded` #6(RimWorld 진단)은 **롱폼 최우선 후보로 살아 있다** — `lf03` 준비 때 볼 것.
- `ep16s-2`·`ep16s-5` = 검수까지 나왔고 마스터 판정 전(`notes/verdict.md` 없음).

### 이 회차에서 확인한 파이프라인 사실

- 🔴 **형제 병렬 작성에서 `sfx` seed 가 실제로 충돌했다.** 작성 시점 census 는 몇 분 만에 낡는다 —
  형제 편의 `sfx` 유일성은 **판정 시점에 다시 세거나 파형 상관 실측으로** 본다.
- 🔴 **형제 하나의 `scene.json` 이 깨지면 형제 전부의 `check.mjs` 가 죽는다**(`check.mjs:63` 이
  `outro.siblings` 의 각 편을 `JSON.parse`). `ep16s-5` 가 `notes` 안 `*"…"*` 강조 때문에 깨져
  검수가 게이트를 못 돌렸다 — 내 판정 시점엔 고쳐져 있었다. **검수 리포트의 「지금 안 돈다」 절은
  판정 시점에 이미 낡을 수 있다. 게이트는 내가 다시 돌려서 확인한다.**
- ⚠️ **고정폭 문맥 `grep`(`.\{40\}낱말.\{80\}`)은 그 문장이 줄 끝에 붙어 있으면 0건을 낸다.**
  원문 「추억은 … 골라 놓을 때 생깁니다」가 실제로 그랬다 → [[factcheck-gotchas]] ①의 변종.
