**게이트가 green 이라고 해서 사용자가 지시한 값을 지켰다는 뜻은 아니다.** 실제로 한 번 그랬다.

### ✅ 해결됨 — 「총 길이」가 `SHOT_TAIL` 을 안 세던 문제 (2026-08-06)

`check.mjs` 의 실측 경로가 `timed.shots[].lines[].dur + pause` 만 더하고 엔진이 샷마다 넣는
`SHOT_TAIL` 0.35초(`engine.js:16,167`)를 뺐다 → **실제 mp4 = 게이트 값 + 0.35 × 샷수.**
실증: 승인·렌더된 `ep08s-1/build/video.mp4` 의 `mvhd` 가 25.800초인데 게이트는 24.4초라고 했다.
**사용자 판정으로 게이트를 파일 기준으로 고쳤고**(`totalSec = 자막합 + 0.35 × 샷수`),
ep08s-1·-2·-3 이 전부 red 가 되어 각각 0.8·1.4·1.2초를 더 덜었다.
검증 완료: ep08s-2 렌더 실측 **24.833초** ↔ 게이트 24.8. 지금 게이트 출력은
`24.8초 = 자막 23.4 + 꼬리 1.40 … 이 값이 실제 mp4 길이다` 라고 스스로 밝힌다.
→ **이제 길이는 게이트값 그대로 판정해도 된다.**

### 🔴 남아 있는 사각지대 — 24항목이 전부 green 이어도 못 보는 것

- **아웃트로 카드에 먹힌 그림.** 판정·연결선이 카드 뒤에 완성되면 한 프레임도 안 나오는데
  게이트는 조용하다(ep08s-3 R1). → [[timing-formulas]] ①
- **효과음이 그림보다 이른 것.** `delayMs` 는 어떤 항목도 안 잰다. → [[timing-formulas]] ②
- **`reads` 가 거짓인 것.** ep08s-3 1차본은 「넘기도 하고 못 넘기도 한다」인데 한 프레임도
  안 넘었다 — 게이트 24항목 전부 통과했다. → **`reads` 는 문장이 아니라 스윕·스틸로 판정한다.**
- **형제 편과 구도가 겹치는 것.** 이름만 다르면 게이트는 못 본다(ep08s-3 R4).
- **`notes` 안의 거짓 자기검산.** ep09s-1 은 「닿음 다섯 번 이상 · 3.5배 과잉 덮음 · 어느 0.6초
  창을 잘라도」가 실측 **4회 · 2.46배 · 최장 무접촉 1.59초**였다(결론만 맞았다). 렌더는 한
  프레임도 안 바뀌므로 **반려 사유는 아니지만**, 다음 회차가 그 배수를 공식으로 베낀다.
  → 검수가 계산해 준 정정값이 **최종 「렌더 전 반영」 목록에 들어갔는지**까지 본다.
  ep09s-1 은 검수가 본문에서 지적하고 목록에서 빠뜨려 그대로 남았다.
- **검수 리포트의 인용 오류.** 2차가 「첫 자막 3.937초」라고 썼는데 그건 S4 L0 이고 실제
  첫 자막은 3.092초였다. 🔑 **검수가 든 숫자도 `timed.json` 으로 한 번 되짚는다** — 결론이
  맞아도 증거가 틀리면 다음 판정이 그 증거를 승계한다.

### 🔴 스틸은 **증거가 아니라 캐시**다 — 파일 시각을 먼저 본다

`build/stills/*.png` 는 렌더 시점에 얼어붙는다. **ep12s-1 에서 실제로 걸렸다**: 반려 사유였던
라벨 겹침을 `kinds/nextpeek.js`(23:00)에서 고쳤는데 디스크 스틸은 **22:43** 이라, 내가 연 파일에는
**옛 겹침 화면이 그대로 있었다.** 검수·코디네이터의 「스틸로 재확인했다」도 그 낡은 파일이었다.
→ **판정 전에 `ls -l` 로 `kinds/*.js`·`scene.json` 과 스틸의 시각을 비교하고, 스틸이 더 낡았으면
`node render.mjs <ep> --still <초>` 로 직접 다시 뽑는다.** 렌더는 몇 초면 끝난다.

🔑 그리고 **루프가 있는 그림은 한 프레임으로 판정하지 않는다.** ep12s-3 의 `GRAVE` 는 0.5초 루프의
뒷부분에만 있어 32.5초 프레임에는 없었다 — 32.62·32.78·92 를 표본해서야 `reads` 가 참임을 봤다.

**Why:** 「게이트가 재는 것이 출고되는 것과 같은가」를 안 물으면 15편을 그 값으로 판정하고도
모른다. 실제로 그랬다.

**How to apply:** 길이는 이제 게이트값으로 판정한다. 대신 위 네 자리는 **매 회차 직접**
계산·스틸로 본다 — 그게 마스터가 게이트 위에 얹는 몫이다. 관련 = [[verdict-evidence-grades]]
