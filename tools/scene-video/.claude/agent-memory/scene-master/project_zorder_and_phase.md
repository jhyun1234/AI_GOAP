**`check.mjs` 가 구조적으로 못 보는 두 자리다. 마스터가 좌표로 직접 푼다.**

### ① z 겹침 — 잰 대상과 잰 구간이 둘 다 좁으면 「닫혔다」가 거짓이 된다

ep09s-2 `faceoff` 가 세 판을 갔다: C6(말풍선이 흰 표식을 통째로 삼킴) → D1(원은 떨어졌으나
**방향선**이 −3.00px) → 법선 22→30px → **그래도 −1.12px**(30fps 5프레임, 내가 스윕+스틸로 적발).

두 번 다 같은 종류로 틀렸다:
- **잰 대상이 좁았다** — 표식을 `원(r 6.5)` 으로만 재고 같은 함수가 그리는 **획(방향선)** 을 빠뜨렸다.
  상자 **테두리 반폭**(`lineWidth 3 → 1.5px`)도 두 번 빠졌다.
- **잰 구간이 좁았다** — 「두 방향선은 연결선 위에 놓인다」는 **`fk = 1` 에서만 참**이다.
  각이 `lerp(0, toB, fk)` 라 회전 중에는 거의 수평, 즉 말풍선을 밀어낸 **법선 쪽**을 향한다.
  정상상태 최소 +9.3px / 전 구간 최소 **−1.1px**.

🔑 **검산 레시피**: 상자는 라운드렉트 외곽(반폭 + 1.5, 코너 r + 1.5), 선은 butt-cap 직사각형
(길이 8~23, 반폭 1.5)으로 놓고 **샷 전 구간 × 궤적 파라미터 전 범위**를 스윕한다.
음수가 나온 시각을 **30fps 프레임 격자로 환산**하고 그 프레임 스틸을 뜬다 —
프레임 사이의 최악값은 실제로 안 나간다. 팔레트 게이트는 반투명 강조색이 흰 것 위에 얹혀도
hue 152 로 약분돼 **통과한다**(구조적 사각지대).

### ② 손으로 박은 위상 상수 (`PHASE`)

`t` 는 **샷-로컬**(`engine.js:270 ts = (t − s.t)/1000`)이라 앞 샷 길이 변동에는 둔감하다.
그러나 등장 게이트는 `cue → rel.dur` 이므로 **그 샷 자막의 실측 길이에 묶인다.**
ep09s-2 `wideband` = 두 번째 위상 사고(ep08s-3 `weightknob` 은 문턱을 **0번** 넘었고 이건
**등장 게이트 밖에서** 넘었다).

🔑 주석에 「왜 이 값인가」만 있고 **「언제 이 값이 무효가 되는가」**가 없으면 반쪽이다.
재사용·자막 변경 시 다시 풀라는 문장을 요구한다.

**Why:** 둘 다 게이트 24항목이 전부 green 인 채로 나갔고, 검수팀도 두 번 놓쳤다.
**Ratchet: 「닫혔다」는 보고를 받으면 닫은 방법이 아니라 잰 범위를 묻는다.**

**How to apply:** 회차에 움직이는 도형이 겹칠 여지가 있으면 매번 위 레시피로 스윕 → 최악
프레임 스틸. 겹침이 남아도 ①가려지는 글자·숫자가 0 이고 ②검수가 더 나쁜 상태를 근거를 갖춰
비차단으로 판정했고 ③작성팀이 그것을 줄였으면 **반려로 갚지 않는다**([[verdict-evidence-grades]]).
