승인된 대본을 **4단 고정 구조**(ADR-V25-8, `Docs/영상_25초_전환_실행명세서.md` §2-C)로 개정할 때
ep10s-2 에서 실제로 밟은 함정이다. 셋 다 **게이트가 안 잡거나, 엉뚱한 값으로 잡는다.**

**Why:** 개정은 「샷 셋을 앞뒤에 붙인다」로 보이지만 실제로는 ①줄이 샷 사이를 이동하고
②게이트 정의가 바뀐다. 그 둘이 조용한 고장을 만든다.

**How to apply:** 4단 개정·줄 이동·예고 이관 작업을 시작할 때 이 셋을 먼저 확인한다.

### 1. 🔴 줄을 옮기면 그 샷의 cue 인덱스가 **조용히 접힌다**

`engine.js` 의 cue 는 `s.rel[Math.min(i, s.rel.length - 1)]` 이다. 예고 줄을 아웃트로 샷으로
옮겨 본문 마지막 샷이 1줄이 되면 **`cue(1)` 이 그대로 `cue(0)` 이 된다.** 에러도 안 나고
`check.mjs` 도 못 잡는다(정적도 팔레트도 아니다). ep10s-2 의 `shelfCue: 1` 이 그랬고,
그대로 뒀으면 **결론(선반 판)이 자막 시작과 동시에 완성**되는 화면이 나갔다.
→ **줄 이동 = 그 샷의 `*Cue` 전수 재점검.** 고치는 방식은 「같은 자막의 뒷구간」
(`cue(0, lead, span)` + `from` 문턱)이고, 순서 제약(값 먼저 → 장식 나중)을 손 검산으로 지킨다.

### 2. 🔴 아웃트로 **소개 줄에 「다음 편」을 쓰면 예고 길이 게이트가 두 줄을 합쳐 잰다**

`check.mjs` 의 `teaserRe = /다음\s*(편|회차|은|는)|이어서|(\d+)\s*부/` 는 마지막 샷의
**모든 줄**에 돌아간다. 명세서가 예시로 든 소개 문안 「…**다음 편에서** 만나요」가 바로 그
정규식에 걸려, 예고(≤3.0초)에 소개 줄까지 더해진다. → 소개 줄은 「또 만나요」처럼 쓴다.
🔑 `아웃트로 소개 있음` 게이트는 `/개발\s*일지|다음\s*편에서/` 라 **「개발일지」만으로 통과**한다.
그리고 예고 줄의 `pauseAfter` 는 teaserDur 에 더해진다 — 250 을 쓰면 그것만으로 3.0 을 넘긴다.

### 3. 🔴 **본문 초는 자막을 안 건드려도 늘어난다 — 정의가 바뀌었기 때문이다**

옛 정의 `본문 = 총 − 예고 − 아웃트로 카드 3.0` 은 **본문 샷과 겹친 구간을 두 번 뺐다.**
새 정의는 `총 − 인트로 샷 − 훅 줄 − 아웃트로 샷`(warn 대역 18~22).
ep10s-2 의 **같은 다섯 샷이 21.5 → 24.1** 이 됐다. 승인 당시의 「본문 21.5초 green」을 그대로
인용하면 「안 건드렸는데 왜 늘었냐」는 헛질문이 생긴다. → 옛 값은 반드시
**「구조 개정 전 실측」**이라고 이름을 붙여 남기고, 새 값과 나란히 적는다.

### 4. 🔴 개정본은 길이가 넘친다 — 자를 곳은 「다른 줄이 이미 말한 것」이다

인트로 + 훅 + 아웃트로가 **약 15~18초**를 먹는다. 25초 규격으로 승인된 본문(24초대)을 그대로
얹으면 **총 42초대**로 상한 38 을 넘는다(ep10s-2 실측 산정 42.7 → 감량 후 37.1).

🔴 **「인트로·훅·예고·소개를 깎으면 반려」(ADR-V25-9)와 「본문 사건 3요소는 못 뺀다」가 동시에
성립하므로, 실제로 자를 수 있는 것은 「겹친 말」뿐이다.** ep10s-2 에서 -5.6초를 낸 넷이 전부 그것이다:
- **인트로 음성은 압축하고 정체성 전문은 자막이 진다**(-2.0초). 명세 §2-C 가 그렇게 개정됐다 —
  음성 = 「클로드 코드로만 만드는, 에이아이 마을 개발일지입니다」(23자) / 자막 = 전문.
- **훅이 세운 설정을 본문 첫 줄이 다시 풀어 말하는 자리**(-0.9초).
- **화면 라벨이 이미 지고 있는 낱말**(`GOAL LIST`·`PLAN` ↔ 자막의 「목표 목록엔」·「계획을」, -1.5초).
- **인트로가 10초 전에 말한 것을 아웃트로 소개가 반복하는 자리**(-1.1초).

🔴 **`sfx` 가 붙은 줄은 손대지 마라** — `delayMs` 가 그 줄의 실측 `rel` 에서 나온 값이라 자막을
늘리든 줄이든 다시 풀어야 한다. **조일 자리를 소리 없는 샷으로만 고르면 재작업이 0 이다.**
([[project_length_grail_beats_estimate]])

### 5. 자막 길이를 바꾸면 **값을 안 바꿔도** 두 가지가 이동한다

- **cue 가 가리키는 낱말.** `split 0.5` 는 비율이라 자막이 길어지면 다른 어절을 가리킨다.
  ep10s-2 의 stripout 은 같은 0.5 가 세 판본에서 세 낱말을 가리켰다.
- **「화면이 자막을 옮겨 적지 않게」의 겹침 목록.** 늘려도 줄여도 항목이 오간다
  (`GOAL LIST` 가 ① → ② → ① 로 두 번 이사했다). 증감 뒤에는 항상 다시 센다.
- 🔑 **제목 이행은 낱말이 아니라 어절 모양**이다. `titleWords` 는 조사 `[을를이가은는의에서도만로]`
  만 털고 나머지는 포함 판정이라, 어간이 바뀌면(부탁해요 → 청해요) 조용히 죽는다.
