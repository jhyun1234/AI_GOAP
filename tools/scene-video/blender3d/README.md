## 왜 캔버스 안에 넣는가

🔴 **`check.mjs` 는 캔버스 픽셀을 읽는다.** 그림이 캔버스 밖으로 나가면 팔레트·정적·잘림·
결정성 게이트가 전부 장님이 된다. 그래서 `serve.js` 에 `/3d/` 라우트를 두고 **같은 오리진**
으로 준다 — 다른 오리진에서 받은 이미지를 캔버스에 그리면 캔버스가 오염되어
`getImageData` 가 예외를 던진다.

## 실행

```bash
BL="C:/Program Files/Blender Foundation/Blender 5.2/blender.exe"
"$BL" --background --factory-startup --python rig.py        # 주민 뼈대 → villager_rigged.blend
```

경로는 `stage.py` 가 혼자 정한다. 산출물 루트는 환경변수 `SCENE_3D_ROOT`(기본
`D:\AI_GOAP-videos\3d`)이고, **`serve.js` 가 같은 변수를 본다** — 한쪽만 바꾸면 어긋난다.

| | 어디 |
|---|---|
| 스크립트 · 모델 원본(`../blender/Shorts.blend`) | 리포 |
| 리그·마을 `.blend` · 렌더 프레임 · mp4 | `SCENE_3D_ROOT` |

## 조정 손잡이 둘 (`stage.py`)

- `EXPOSURE` — 인물의 밝은 면이 sRGB 0.85 근처에 앉는 값. 1.85 에서 실측 218/255, 클리핑 0px.
- `LANE_LEVEL` — 바닥 알베도. `EXPOSURE` 로 나눠 써서 **노출을 바꿔도 바닥 밝기는 안 변한다.**

🔴 눈으로 고치지 마라. 이 값들은 픽셀을 재서 맞춘 것이고, 눈대중으로 만지다 세 판을 헛돌았다.

## 함정 여섯 — 전부 한 번씩 밟았다

1. **GLB 임포트 객체는 `rotation_mode` 가 `'QUATERNION'`** 이라 `rotation_euler` 가 무시된다.
   안 바꾸면 인물이 전부 옆을 본 채 렌더된다.
2. **Blender 5.2 는 `Material.use_nodes` 를 아직 본다**(6.0 제거 예정 경고만 뜬다).
   안 켜면 노드 트리를 무시하고 **기본 회색 0.8** 로 렌더된다 — 바닥이 사람보다 밝아진다.
3. 바닥을 눕혀서 보면 **스치는 각도의 프레넬 정반사**가 알베도를 압도한다.
   알베도를 0.035 까지 떨어뜨려도 밝다. `Specular IOR Level = 0` 으로 끈다.
4. `view_transform` 이 `'Standard'`(롤오프 없음)라 **광량을 올리면 바로 흰색 클리핑.**
   그 상태에서 어두운 바닥이 중간 회색으로 올라와 「바닥이 밝다」로 오진하게 된다.
5. **뼈 roll 을 자동 계산에 맡기면 축이 뼈마다 갈린다**(팔은 X+ 가 뒤, 다리는 X+ 가 앞).
   `calculate_roll(type='GLOBAL_POS_X')` 로 고정해 **X = 앞뒤 · Z = 좌우 · Y = 비틀림** 을
   전 뼈 공통으로 쓴다. 팔다리는 뼈가 아래를 향하므로 **X 음수가 앞**이다.
6. 유채색 물체를 **스케일 0 이나 발광 0 으로 끄면 밑색이 남는다.** 흰색만 있어야 할
   프레임에 유채색이 남아 규약을 깬다. `stage.gate()` 가 `hide_render` 로 렌더에서 뺀다.

## 로우폴리는 답이 아니다 (실측)

| | 64 샘플 | 16 샘플 |
|---|---|---|
| 원본 (인물 면 40,716) | 0.268 s/frame | **0.151 s/frame** |
| 데시메이트 25% (10,176) | 0.280 s/frame | 0.181 s/frame |

면을 75% 날려도 **더 느리다** — 데시메이트 모디파이어가 매 프레임 평가된다.
손잡이는 **샘플 수**다. 그리고 이 캐릭터는 이미 로우폴리다(6,786 삼각형 · 플랫 셰이딩).
🔴 그래서 **새 소품도 로우폴리 플랫 셰이딩으로 만든다.** 매끈한 소품을 넣으면 그때 깨진다.
