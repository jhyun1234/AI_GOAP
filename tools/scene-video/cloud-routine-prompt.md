# 영상 대본 루틴 — 클라우드용 (사람이 claude.ai 스케줄에 붙여넣는 것)

> 이 파일은 **붙여넣을 프롬프트 원문**이다. 아래 「붙여넣을 것」 절 전체를 복사해
> claude.ai 의 스케줄 루틴에 넣는다. 이 문단과 「왜」 절은 사람이 읽는 설명이라 안 넣어도 된다.

## 왜 클라우드인가

영상 파이프라인은 반씩 나뉜다.

| 절반 | 어디서 | 왜 |
|---|---|---|
| **대본** (기획→작성→검수→마스터) | **클라우드** | Claude 만 있으면 된다. PC 가 꺼져 있어도 쌓인다 |
| **렌더** (음성→mp4→점검) | **로컬 PC** | TTS 모델 645MB · 크로미움 · ffmpeg 가 이 PC 에만 있다 |

블로그가 PC 없이 발행되는 것과 같은 구조다. 대본이 브랜치로 올라오면
`.github/workflows/scene-script-auto-merge.yml` 이 main 에 머지하고,
로컬 스케줄러(로그온 3분 뒤 · 격일 09:00)가 `git pull` 해서 밀린 것을 렌더한다.

⚠️ **켜기 전에 `state/schedule.json` 에 `"scriptBy": "cloud"` 를 넣어야 한다.**
안 넣으면 로컬도 대본을 만들려 들어 **양쪽이 같은 회차를 두 번 쓴다.**

## 클라우드가 못 하는 것 (알고 시작할 것)

크로미움이 없어서 **검수팀이 픽셀을 못 본다.** `check.mjs` 도 `render.mjs --still` 도 못 돌린다.
그래서 이런 것은 클라우드에서 안 잡힌다 — 좌우 잘림 · 정적 구간 · 팔레트 · 하단 안전영역.

**대신 로컬이 렌더할 때 `check.mjs` 14종이 잡고, 실패하면 되돌림 루프가 고친다.**
즉 늦게 발견될 뿐 새어 나가지는 않는다. 원문 대조·사실 확인·다음 편 예고 같은
**글 수준 검수는 클라우드에서 그대로 된다.**

## 붙여넣을 것 (여기서부터 끝까지)

리포 `jhyun1234/AI_GOAP` 에서 **다음 회차의 영상 대본**을 만들어라.

### 0. 할 회차 정하기
- `tools/scene-video/state/schedule.json` 의 `order` 를 순서대로 보며
  **`tools/scene-video/episodes/<id>/scene.json` 이 아직 없는 첫 회차**를 집는다.
- 전부 있으면 **아무것도 하지 말고 "만들 회차 없음"만 보고하고 끝낸다.** 커밋도 하지 마라.
- ⚠️ `state/uploads.json` 은 보지 마라. 그건 로컬이 렌더한 기록이라 클라우드와 박자가 다르다.
  **기준은 오직 `scene.json` 의 존재 여부다.**

### 1. 대본 만들기
`tools/scene-video/routine-prompt.md` 의 절차를 그대로 따른다. 4개 부서를 순서대로:
`scene-planner` → `scene-writer` → `scene-reviewer` → `scene-master`.
각 단계 산출은 반드시 `tools/scene-video/episodes/<id>/notes/` 에 파일로 남긴다
(서브에이전트는 무상태라 대화로 못 물려받는다).

정본 문서를 먼저 읽어라 — `routine-prompt.md` 와 `.claude/agents/scene-*.md` 에
길이 규칙·다음 편 예고·효과음·그림 소유 규약이 전부 들어 있다.

### 2. 이 환경에서 못 하는 것
- 🔴 **렌더하지 마라.** `tts.mjs` · `render.mjs` · `publish.mjs` 를 부르지 마라.
  크로미움도 ffmpeg 도 TTS 모델도 없다. 렌더는 로컬 PC 가 한다.
- 🔴 **`check.mjs` 도 못 돈다**(크로미움 필요). 검수팀은 **글 수준 검수만** 한다 —
  원문 대조 · 화면 문자열 사실 확인 · cue 인덱스 정합 · 다음 편 예고 정본 대조 ·
  돌려막기(앞 회차 `kinds/*.js` 와 장치 비교) · 효과음 배치와 절제.
  픽셀 판정(잘림·정적 구간·팔레트·안전영역)은 **로컬이 렌더할 때 잡는다** — 그걸 전제로 통과시켜라.
  검수 보고서에 **"픽셀 판정 미실시(클라우드)"** 라고 명시해라.
- 🔴 유튜브에 올리지 마라. 업로드는 언제나 사람이 한다.
- 🔴 `Docs/영상_시리즈_구성안.md` 를 수정하지 마라. 읽기 전용이다.

### 3. 커밋과 push
성공했으면 **대본 산출물만** 커밋한다.
```
tools/scene-video/episodes/<id>/scene.json
tools/scene-video/episodes/<id>/kinds/*.js
tools/scene-video/episodes/<id>/notes/*
```
🔴 **다른 경로를 건드리지 마라.** 워크플로우가 이 세 경로만 받고, 벗어나면 머지를 거부한다.
`.claude/agent-memory/` 도 이번엔 커밋하지 마라 — 경로 밖이라 브랜치가 통째로 막힌다.

커밋 메시지: `feat(scene-video): <id> 대본 — 클라우드 루틴`

push 는 **현재 작업 브랜치 그대로** 한다(샌드박스는 세션 브랜치로만 push 를 허용한다).
`.github/workflows/scene-script-auto-merge.yml` 이 받아서 main 에 fast-forward 머지한다.

### 4. 멈춰야 하는 조건
- 기획팀 `SKIP`(원본 글 미발행 등)
- 검수 반려 3회 / 마스터 반려 3회
멈출 때는 `notes/` 에 사유를 남기고 **`scene.json` 을 만들지 마라.**
`scene.json` 이 없으면 로컬이 "대본 대기"로 조용히 넘어가고, 다음 회차에 다시 시도한다.
**애매하면 통과시키지 말고 멈춰라** — 영상은 글과 달리 되돌리는 비용이 크다.
