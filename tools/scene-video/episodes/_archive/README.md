# _archive — 순서표에서 빠진 회차 폴더 보관소

여기 있는 폴더는 **`state/schedule.json` 의 `order` 에 없어서 파이프라인이 다시는
선택하지 않는 것들**이다. 지우지 않고 옮겨 둔 이유: notes/ 의 검수·기획 기록은
당시 판단의 기록이고, 분할 회차의 scene.json 이 출처로 인용한다.

⚠️ 다른 문서·scene.json 이 `episodes/ep04s/...` 처럼 옛 경로로 인용한 것은
전부 이 폴더 아래로 옮겨졌다 (`episodes/_archive/ep04s/...`). 경로만 다르고
내용은 그대로다 — 2026-08-04 정리.

| 폴더 | 무엇이었나 | 왜 빠졌나 |
|---|---|---|
| `ep04s` | 분할 전 M1 회차 (08-03 렌더 149.2초) | 3편 재분할(`ep04s-1~3`)로 대체. 옛 마스터 판정 무효(90cd868). 🔴 **build/video.mp4 를 업로드하지 말 것** |
| `ep04s2` | 2분할 시절 ep04s 후편 (notes 만) | 2분할 → 3분할 재작업으로 대체 |
| `ep05s` | 분할 전 M2·M3 회차 (notes 만) | 3편 재분할(`ep05s-1~3`)로 대체. `notes/planner.md` 의 원문 전문은 분할 편들이 출처로 인용 |
| `ep05s2` | 2분할 시절 ep05s 후편 (notes 만) | 2분할 → 3분할 재작업으로 대체 |
| `eptest-m11` | 블로그 시각표현(표) 검증용 테스트 회차 (118초) | 순서표 밖 실험. 검증 결론은 `Docs/블로그_이미지_자동삽입_명세재료.md` 에 |
