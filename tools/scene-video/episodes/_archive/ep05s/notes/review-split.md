## 🔴 R-1. 반려 사유 — S2 자막이 원문의 단위 **'소비'를 지워 숫자의 방향이 뒤집힌다**

원문(3절, HTML 7행):

'5편 2부'를 가리키는 그림·글자는 화면에 없다. 지금도 반려 사유는 아니지만(예고는 자막이 지고,
훅은 늘 마지막에 남는 줄이다), 다음에 여유가 생기면 예고 cue 에 **다음 편 이름 칩**을 얹는 편이
1차본 `outofstep`("다음 편 이름이 어긋난 표식 아래에서 자라 오른다")의 뜻에 가깝다.

### 5. 다음 편 예고 — 사실 확인 완료 · 3.1초

- 문구: `"다음은 5편 2부, 집을 지었더니예요."` (S9 자막 3, `pauseAfter: 0`)
- 정본 ①: `state/schedule.json` `order` = `… "ep05s", "ep05s2", "ep06s" …` → 다음은 ep05s2 ✅
- 정본 ②: `episodes/ep05s2/scene.json` `hud.title` = `"5편 2부 · 집을 지었더니"` → **문구 일치** ✅
- 내용 사실성: ep05s2 는 원문 5절("집이라는 건물을 추가하면서 여러 문제가 한꺼번에 터졌습니다")
  계열이다 — `BlocksMovement`·`MaxWorkers`·`TryGetAnchorTile`. 예고가 가리키는 것과 같다 ✅
- 구성안 표(`Docs/영상_시리즈_구성안.md:20`)에는 5행이 "3막 / 5편 / M2·M3 생산 체인과 집"으로 한 줄뿐이고
  2부 행이 없다 — 갱신된 지침대로 **반려 사유로 쓰지 않았다.** 없는 막 이름을 지어내지도 않았다
  (`act` = "3막 · 다시 짓기", 표의 3막과 일치).
- ⚠️ 원문 7절의 "다음 편에서는 M4 성격 재편입과 M5 직업 스펙을 다룹니다"를 **근거로 쓰지 않았다**
  — `excluded` 가 그 이유를 정확히 적어 뒀다. ep02s 형 사고 없음 ✅
- 길이 3.1초(산정). 지침의 '3초 안'을 0.1초 넘지만 산정치이고 `check.mjs` 게이트(4초)는 통과다.
  줄일 여지가 있으면 줄이고, 아니면 그대로 둔다 — 반려하지 않는다.
- 🔑 상호 참조 ✅ — ep05s blurb 끝 "(집을 지으며 터진 문제들은 **5편 2부**에서)" ↔
  ep05s2 blurb 끝 "(에셋만 더했는데 기능이 는 이야기는 **5편 1부**에서)". 양방향 다 있다.
  · 작은 흠: 이 편의 유튜브 제목은 "…개발일지 **5편** #shorts"인데 2부가 이 편을 "1부"라고 부른다.
  ep04s/ep04s2 도 같은 상태라 이번 편만의 문제는 아니다. 관찰만 남긴다.

### 6. 정적 구간 경고 — **작성팀 잘못이 아니다. 측정 조건 탓이고, 고칠 것이 없다.**

이게 이번 검수에서 가장 중요한 확인이다.

`check.mjs` 의 픽셀 계측은 엔진이 만든 타임라인 위에서 돈다. `timed.json` 이 없으면 엔진은
**임시 타이밍**을 쓴다 — `engine.js:14-15` `PROVISIONAL_CPS = 5.6` · `LINE_TAIL = 0.5`.
그런데 실제 목소리는 `voice.json` 실측으로 **ME @ speed 1.1 = 6.77자/초(발화)** 이고,
`check.mjs` 의 길이 산정도 `CPS_REF = 6.7` 을 쓴다. **같은 씬을 엔진은 88.2초로, check 는 68.0초로 본다.**
차이 20초는 전부 자막 꼬리 = **이미 화면이 멈춰 있는 구간**에 붙는다.

그래서 실측에 가까운 타임라인을 만들어 다시 쟀다(임시 회차 `eptmp05` 를 복사해
`build/timed.json` 을 6.7자/초로 합성 → 점검 → **폴더 삭제 완료**. `ep05s` 는 건드리지 않았다):

```
가이드 점검 · eptmp05   (= ep05s + 6.7자/초 합성 타임라인)
  OK 편당 길이 90초 이하           68.0초 (실측, 5샷)
  OK 편당 목표 75초              68.0초 (실측, 5샷)
  OK 자막 2초 미만 없음            전부 2초 이상
  ⚠  말 속도 6.0~7.2자/초        5.87자/초 (참고 영상 6.93)
  OK 정적 구간 3초 이하            최대 3.0s          ← 경고 사라짐
  통과 — 경고 1건은 확인 권장
```

정적 구간 상세(같은 타임라인, 10fps 로 다시 훑음):

| 샷 | 임시 타이밍(88.2초 기준) | 실측 근사(68.0초 기준) |
|---|---|---|
| S2 | 5.4초 · 3.0초 | 3.2초 · 2.3초 |
| S3 | 3.6초 · 3.5초 | 2.2초 · 2.7초 |
| S8 | 3.6초 · 3.4초 | 2.8초 · 2.7초 |
| S9 | 4.1초 · 3.0초 · 3.3초 | 3.1초 · 2.3초 · 2.5초 |

**결론: 지금 뜬 S2 4s · S3 3.4s · S9 3.6s 경고는 실제 음성이 붙으면 대부분 3초 아래로 내려간다.
움직임을 더 넣지 마라 — 넣으면 실제 렌더에서 과잉이 된다.** 로컬에서 `tts.mjs` 를 돌린 뒤
`check.mjs` 를 다시 돌려 확인하는 것으로 충분하다.

⚠️ 같은 실험에서 **말 속도가 5.87자/초**로 나왔다(하한 6.0 바로 아래). `check.mjs` 의
`charsPerSec` 은 문장부호를 뺀 글자를 쉼 포함 시간으로 나누므로, 자막이 짧고 `pauseAfter` 가
많은 편일수록 낮게 나온다. 이 편은 16줄에 쉼 합계 4.02초(6%)다. 실측 때 6.0 을 못 넘으면
`pauseAfter` 를 20~30ms 씩 깎는 정도로 대응할 수 있다. **지금 고칠 일은 아니다 — 관찰 항목.**

### 7. 편당 길이 — 68.0초 · 근거 있음

분할 축이 명확하다. `scene.hook`("한 번은 우연이고, 두 번은 구조였다")이 곧 S9 의 결론이고
S1→S2→S3→S8→S9 가 그 한 주장을 세우고 두 번 증명한다. 버린 넷(밭 시각화·쿨다운·앵커 창구·집)은
**버린 게 아니라 ep05s2 로 옮겨졌고** 양쪽 blurb 가 서로를 가리킨다. 목표 75초 아래이므로
C-1/C-2 의 보강 한 줄을 넣을 여유(약 7초)도 있다.

### 8. 효과음 — 통과

| 샷 | kind | gain | dur | freq | delayMs | 판정 |
|---|---|---|---|---|---|---|
| S2 | thud | 0.070 | 0.19 | 176 | 1380 | 상한 0.085 밖 여유 ✅ · 판 착지 = 자막 2가 부르는 사건 ✅ |
| S3 | tick | 0.056 | 0.045 | 1520 | 2100 | **상한 0.065 아래** ✅ · 셋째 카드 착석 ✅ |
| S9 | tick | 0.056 | 0.045 | 1520 | 2640 | 상동 ✅ · 두 번째 자국 겹침 ✅ |

- `delayMs` 를 **독립 재계산**해 확인했다. 예) S3: `born = clamp(sk×3.6 − 2)`, 착석 `born = 0.85`
  → `sk = 0.7917` → smoothstep 역함수 `raw ≈ 0.705` → `W = 0.15 + 4.230×0.72 = 3.196s`
  → `0.705×3.196 − 0.15 = 2.103s` = **2100ms** ✅. S2 는 1.376초(1380 ✅), S9 는 2.642초(2640 ✅).
  ⚠️ 셋 다 **산정 자막 길이** 위의 값이다. `timed.json` 이 나오면 각 `why` 의 식에 실측 길이를
  넣어 다시 내야 한다(작성팀도 `notes.미확인` 에 그렇게 적어 뒀다).
- 앞 회차 돌려막기 대조(전 회차 `sfx` 를 열어 봤다): tick 은 ep00i 0.04/2100 · ep02s 0.05/1760 ·
  ep03s 0.05/1900 · ep04s 0.055/1250 · 0.04/1750 — **0.045/1520 은 겹치지 않는다** ✅.
  thud 는 ep00i 0.15·0.32 / ep03s 0.22 / ep04s 0.26 — **0.19/176Hz 겹치지 않는다** ✅.
- 회차 **안**에서 S3 과 S9 가 완전히 같은 tick 인 것은 **의도로 인정한다.** 이 편의 주장이
  "같은 일이 두 번 일어났다"이므로 두 번째 자국은 첫 번째와 같은 소리여야 한다. `why` 에 근거가 있다.
- 개수는 68초에 3개(90초 환산 4.0개)로 기준(5~8) 아래지만, 사건이 '파일 하나 고치기 / 아무것도
  추가하지 않기'라 조용한 편이 맞다. 다만 그 사유가 적힌 `notes.효과음` 절이 **1차본 기준이라
  지금 씬과 안 맞는다** → C-1 에 포함.

### 9. 말투 — 통과

같은 어미 3연속 없음(최장 2연속: S8 "…였어요 / …옮겼어요", S9 "…거예요 / …지었더니예요").
say 전부 31자 이하(rule 2 의 '25자 안팎' 상한선에 S2.0·S9.0 이 31자로 붙지만 두 문장으로
끊겨 있어 호흡은 살아 있다). 숫자는 전부 `say` 에서 한글로 풀었다("삼"·"이"·"엠투"·"엠쓰리"·
"한 개"·"영 줄"·"씨에스"). 예고의 "5편 2부"만 아라비아 숫자로 남았는데 이는 ep04s·ep04s2·ep05s2
가 모두 같은 형식이라 **시리즈 관행**으로 통과시킨다.
🔎 담화표지는 16줄에 둘("근데" S1.1 · "정작" S8.0)로 rule 3 의 '서너 문장에 하나'보다 성기다.
분할로 표지가 든 줄이 2부로 빠진 결과다 — 고칠 필요까지는 없고, C-2/C-3 을 손볼 때 한 줄
정도에 "그래서"나 "일단"을 얹으면 좋다.

### 10. 그림이 뜻을 나르는가 — 통과

`reads` 5개가 전부 구체적이다. "무언가를 보여준다" 식 빈말 없음. 예: S9 "자국 하나가 눌려 찍혀
있고, 두 번째 자국이 위에서 내려와 그것을 감싸며 정확히 겹친다" — `twice.js` 의 `land` 진행과
정확히 일치한다(확인함).

🔎 관찰 하나 — S9 에서 **자국 안의 이름 "에셋 1개, 코드 0줄" 이 그것을 말하는 자막보다 3.3초 이르다.**
픽셀로 쟀다: 이름이 뜨는 것은 자막 0 시작 +1.5초(`fk > 0.55`, `twice.js:99`), 나레이션이 그 말을
하는 것은 자막 1 시작이다. **반려하지 않는다** — 이건 사건이 아니라 *자국에 찍힌 이름표*이고,
자막 0("M2 요리에서 한 번")이 부르는 '한 번'이 무엇의 한 번인지 화면이 먼저 답하는 구조라
뜻이 어긋나지 않는다. ep00i runmark 사고(사건이 1.64초 먼저 터짐)와는 종류가 다르다.
다만 다음에 이 kind 를 다시 쓸 일이 있으면 기록해 둘 값이다.

## 정리 — 작성팀이 할 일

1. **R-1** S2 자막 0·1 에 '소비'를 되살릴 것. (반려 사유)
2. **C-1** `notes`·`excluded` 를 5샷 68초 기준으로 고치거나 "1차본 기준" 표시를 달 것.

3. **C-2** S1 이 연 '집' 칸을 회수하는 한 줄을 S8 앞에 넣을 것(권장 ⓐ).
