# 작성 노트 — ep00s (2차 · 그림 전면 재설계)

**대본은 한 글자도 안 바꿨다. 그림은 전부 버리고 다시 짰다.**

- 자막 27줄 / 10샷 / `say` · `pauseAfter` 전부 1차와 동일 (검수·마스터 승인본 유지)
- 바뀐 것: `kind` 이름 10개 → **새 kind 9개**, `spec` 전부, `reads` 전부, `notes`, `excluded` 2건 되살림, `checks` 삭제

---

## 1. 왜 그림만 다시 짰나

1차 씬이 부르던 kind 열 개(`stage2d/compare/term/plan/morph/bars/rule/console/metrics/title`)는
**ep01s 의 어휘를 그대로 쓴 것**이었다. 사용자 판정:

> "비슷한 애니메이션을 돌려막기하는 건 내가 원하는 방향이 아니야."

대본은 검수 2차 통과 + 마스터 APPROVED 를 받은 상태였고, 사실관계 위반 0건에
수치도 전부 원문에서 나온 것이었다. **살릴 이유가 충분했다.** 그래서 대본은 고정하고
그림만 이 글의 축에 맞춰 다시 설계했다.

## 2. 이 글의 축 — ep01s 와 무엇이 다른가

| | ep01s | ep00s |
|---|---|---|
| 사건 | 탐색이 4096번 폭발했다 | 코드가 거짓말을 했다 |
| 축 | **양** | **어긋남** |
| 맞는 도형 | 격자 · 카운터 · 막대 · 예산 게이지 | **선 하나와 그 위를 오가는 신호** |

이 편에는 **폭발하는 숫자가 하나도 없다.** 그래서 카운터·예산 막대·격자·2단 막대 계열은
한 번도 쓰지 않았다. 대신 같은 자리에 참과 거짓 두 값이 있고, 거짓이 아래로 번지고,
누군가 그걸 끊는 구조를 그림의 기본형으로 잡았다.

### 하나가 두 샷을 관통한다 — `wire`

S1 의 **변조 지점**과 S7 의 **게이트**가 같은 y 좌표에 선다.
시청자는 40초 뒤 같은 화면으로 돌아와 "그 자리가 달라졌다"를 본다.
회차 **안**의 재사용은 돌려막기가 아니라 되받기다 — 두 모드의 그림이 서로 다른 말을 한다
(lie: '못 감'이 '도착'으로 바뀐다 / gate: '못 감'이 '못 감'인 채로 올라간다).

## 4. 🔑 원문을 다시 읽고 찾은 것

**원문은 결함 C 의 몸통을 코드 한 줄로 지목해 뒀다.**

- 83행 "주민의 논리적 좌표(`Brain.TileX`, `Brain.TileY`)를 목적지 값으로 그냥 덮어써버리는 코드"
- 113행 "`Brain.TileX = targetX` 라는 정확한 코드 패턴"

둘은 같은 물건이다. 1차 씬은 이 한 줄을 S8 에서 **딱 한 번** 썼는데,
그러면 "죽은 버그의 유전자 서열"이 처음 보는 문자열이라 **지문 대조라는 말이 성립하지 않는다.**

지금은 세 번 나온다. 같은 문자열의 상태가 세 번 바뀌는 것이 이 회차의 서사다.

1. **S3** 이름표 아래 — 살아 있음 (`몸통` 딱지)
2. **S5** 금이 그어지고 줄 자체가 접혀 사라짐
3. **S8** 검문소가 들고 있는 **등록된 서열** — 앞으로 나올 커밋을 이걸로 대조한다

## 7. 1차 검수·마스터가 남긴 걸림 — 어떻게 처리했나

| 남은 항목 | 처리 |
|---|---|
| **정적 구간 S7 5.8s / S9 4.4s / S10 3.4s** — "kind 가 줄 수 있는 이벤트가 2개뿐" | ①세 샷 전부 **cue 를 셋으로** 늘렸다(S7 게이트·조항·적용범위 / S9 갈라짐·떨어짐·강조 / S10 취소선·인계) ②모든 샷에 **등속으로 위치가 움직이는 요소**를 하나씩 심었다. 🔴 밝기만 흔드는 '숨쉬는 빛'은 프레임 차이가 거의 0 이라 이 판정에 그대로 걸린다 — ep01s `metrics.js` 가 정확히 그 자리였다. 그래서 전부 위치를 움직인다 |
| **도장 "두 배"가 작은 값 막대 위에 앉는다** | 막대를 버리고 세로 사슬로 갔다. 2:4 가 도장 없이 자리로 보이므로 이 문제가 아예 생기지 않는다 |
| **셸 형식(`$ grep -r … Assets/`)이 원문에 없다** | 검문소로 바꾸면서 지어낸 문자열이 사라졌다. 화면에 글자 그대로 남는 건 `Brain.TileX = targetX` 와 `0건` 둘뿐이고 **둘 다 원문에 있다** |
| **`scene.hook` 이 화면에 안 뜬다** | 그럼에도 안 넣었다. 큰 글자 두 줄을 0초에 띄우는 것은 가이드가 FAIL 로 보는 정적 텍스트 인트로 그 자체다. 필드는 설명·썸네일 문구 후보로 남긴다 |
| **`checks` 키 오용** | 이번엔 `checks` 를 **하나도 안 썼다.** 1차의 유일한 예외였던 `S5.checks.edge`(파편이 화면 밖으로) 가 필요 없어졌다 — 새 `excise` 는 파편을 안 날리고 줄을 접어 없앤다. 코드가 삭제되는 모양에도 그쪽이 가깝다 |
| **작성팀 노트가 옛 수치를 그대로 뒀다** | 이 문서에는 실측이라 주장하는 수치를 넣지 않았다. 못 돌려 봤기 때문이다(아래) |

## 8. 초록의 규칙을 바꿨다

1차는 S2 에서 **거짓말('도착') 자체에 초록**을 칠해 놓고 notes 로 변명해야 했다.
규칙을 바꾸는 편이 변명보다 낫다.

> 이 회차에서 초록은 '옳다'가 아니라 **화면이 지금 가리키는 지점**이다.

그래서 `wire` 의 값(패킷 · 받은 값)은 거짓말이든 진실이든 **전부 흰색**이고,
초록은 변조 지점 · 게이트 · 강조 칸에만 붙는다.

## 9. 🔴 못 돌려 본 것

**작성팀에는 셸이 없어 `node tools/scene-video/check.mjs ep00s` 를 직접 실행하지 못했다.**
아래 셋은 코드로 지키려 했으나 **실측으로 확인되지 않았다.**

1. **결정성 3패스** — 모든 움직임을 `t`·`cue`·`since` 의 함수로만 짰다.
   `Math.random()` · `Date.now()` · 이전 프레임 기억 · CSS transition 을 쓴 곳이 없다.
   난수도 안 쓴다(`rnd` 를 부르는 kind 가 하나도 없다).
2. **아래 가장자리 잘림** — 모든 요소를 캔버스 바닥에서 **20px 이상** 띄웠고,
   바닥 40px 안에는 글로우(`setShadow`)를 걸지 않았다. 가장 아래 요소는
   `wire` lie 모드의 커밋 여섯 점(바닥에서 약 17.5px, 글로우 없음).
3. **정적 구간 3초** — 위 7번 참조.

어긋나면 **대본이 아니라 kind 쪽을 고칠 자리**다. 자막은 승인본이므로 건드리지 않는 것을
기본으로 한다.

## 10. 엔진 변경 없음

이번에는 **`engine/` 아래를 한 줄도 건드리지 않았다.** 새 그림 아홉 개는 전부
`episodes/ep00s/kinds/` 안에 있고 `engine/lib.js` 를 읽기만 한다.

> 참고로 짚어 둔다(이번 작업 범위 밖): `episodes/ep01s/kinds/*.js` 와
