## 7. C. 정적 구간 — 통과 (구조 근거)

🔴 **"ep00s 도 넘겼다"는 근거는 쓰지 않았습니다.** 다음 두 가지로 판단했습니다.

**(1) 구조 — 열 그림 전부 자막과 무관한 `t` 구동 요소를 갖고 있습니다.** 코드에서 전수 확인:

| kind | 계속 도는 것 | 코드 |
|---|---|---|
| rebound | 왕복 표식 3 + 자국 누적 | `frac((t+LEAD)/P + phase)` |
| spoke | 갈래를 흐르는 점 3 | `frac((t+LEAD)/FLOW + j/cnt)` |
| budget | 고리를 도는 탐색 머리 | `frac(t/HEAD_PERIOD)` |
| nosolve | 끊기기를 반복하는 획 4 | `frac((t+0.9)/DROP + i/TRIES)` |
| sprawl | 점 4,096개 각자 위상으로 호흡 | `frac(t/BREATH + ph)` |
| shortfall | 자를 오르내리는 읽기 표식 | `frac(t/CURSOR)` |
| shelf | 목록을 훑는 탐색 머리 | `frac(t/SWEEP)` |
| latch | 미는 획 | `frac(t/PUSH)` |
| teardown | 가림막 뒤 표류 + 되돌아오는 표식 | `frac(t/DRIFT)`, `frac(t/2.0)` |
| erasure | 흘러내리는 잔해 34개 | `frac(t/2.4 + ph)` |

**자막 수와 무관하게 멎을 수 없는 구조**입니다. "자막 3줄인데 이벤트 2개" 같은 조합이
나와도 `t` 구동 요소가 계속 위치를 바꾸므로 정적 구간이 생기지 않습니다.

### E-1. `spoke`(S1B) 가 `ep00s/channels`(S9) 와 같은 장치입니다

두 회차가 **같은 로그 한 줄**을 다룹니다.

| | ep00s S9 `channels` | ep01s S1B `spoke` |
|---|---|---|
| 출발점 라벨 | `inlet: "멈춘 이유"` | `hub: "멈춘 이유"` ← **문자열 동일** |
| 갈래 | 계획 · 자원 · **경로** · 전제 | 계획 · 자원 · **이동** · 전제 |
| 값 | `3 / 0 / 0 / 0` | `3 / 0 / 0 / 0` ← **동일** |
| 캡션 | `ByReason=[Plan=3, Res=0, Path=0, Pre=0]` | 같은 문자열 ← **동일** |
| 캡션 렌더 | `mono(700,11)` 가운데정렬 축소맞춤, 캔버스 하단 | **같은 방식** |
| 값 3의 실물화 | 관에 **떨어지는 블록 3개** | 갈래를 **흐르는 점 3개** |
| 논지 | 한 갈래에만 값이 가고 셋은 빈 채로 남는다 | **같은 논지** |
| 차이 | 평행 세로 관 4개 | 방사형 십자 4방향 |

**다른 것은 배치 하나뿐입니다.** 그림이 픽셀 단위로 같지는 않지만,
"한 출발점 → 네 갈래 → 값은 하나로만 가고 셋은 비어 있다 + 움직이는 표식 3개 +
하단에 같은 로그 캡션" 이라는 **장치가 같습니다.** 그리고 하필 **바로 앞 회차**입니다.

**가중 사유 셋:**

**① `writer.md` 의 주장이 코드와 안 맞습니다.** 80~82행:

> ep00s 의 아홉(...)과도 **이름·형태가 하나도 안 겹친다.** 참고로 읽기는 했다 — 파일 구조,
> import 경로, spec 을 읽는 법, 그리고 "정적 구간은 위치로 푼다"는 대책까지.
> **그림은 하나도 가져오지 않았다.**

읽었다고 적어 두고 이 주장을 했는데, 위 표가 반례입니다. 다른 아홉 종의 기각 사유표는
실제 코드와 전부 맞았습니다(§9 말미) — **이 한 줄만 검증되지 않은 채 단언되어 있습니다.**

**② 기각 근거가 ep00s 의 근거를 그대로 다시 씁니다.** `metrics` 를 버린 이유로 적힌 문장과
`ep00s/channels.js` 주석이 사실상 같은 문장입니다.

```

ep00s/channels.js:11-13 (카드 그리드 기각):

   원인이 어느 관으로 흘렀는지 가려내는 것이다."
```

같은 논증을 다시 세워 **같은 계열의 답**에 도착했습니다.

**③ ep00s 가 사 둔 차별화를 이번에 써 버렸습니다.** 위 주석대로 `channels` 는
**"ep01s 가 카드 그리드를 쓰고 있으니 나는 관으로 간다"** 며 ep01s 를 피해 설계된 그림입니다.
그런데 ep01s 가 카드 그리드를 버리고 네 갈래 쪽으로 옮겨오면서, 0편이 확보해 둔 간격이
사라졌습니다. 두 편을 이어 보는 시청자는 **같은 로그가 두 번, 거의 같은 장치로** 풀리는 것을 봅니다.

**참작 사유(그래서 반려 사유가 이 하나뿐인 이유):** 두 원문이 실제로 **같은 로그 줄을 싣고

자유였고**, 하필 앞 회차가 이미 쓴 그릇 쪽으로 갔습니다.
