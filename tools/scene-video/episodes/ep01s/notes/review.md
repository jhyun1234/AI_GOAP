### 2-1. 1차에 내가 열거한 겹침 8항목 — 항목별 판정

### 2-2. 코드에서 확인한 것 — "네 갈래를 버렸다"가 사실인가

`pins.js` 전문에 **네 개짜리 그릇이 없습니다.** 그리는 것은 둘뿐입니다.

- `spec.lanes` (3개) → `for (let i = 0; i < n; i++)` 레인·핀·이름표
- `spec.unused` (3개) → `un.forEach` 카드 더미

`used`(계획/3)는 **배열 원소가 아니라 별도 필드**이고, 갈래에 담기지 않습니다.
그 값은 ①레인 셋의 이름표가 전부 `used.label` 이라는 사실과 ②좌상단 `계획 3` 칩
두 곳으로만 나타납니다. `channels` 의 `tubes[]` 4원소 균질 구조와 근본적으로 다릅니다.

### 2-3. 코디네이터 질문 — "나머지 셋(Res·Path·Pre 의 0)이 화면에서 어떻게 읽히나"

`channels` 에서 세 0은 **값이 안 떨어진 빈 관**입니다(주석: *"비어 있음은 카드의 0 보다
빈 관 쪽이 훨씬 잘 읽힌다"*) — 즉 **값을 기다리는 그릇**입니다.
`pins` 에서 세 0은 **`unusedLabel:"한 번도 안 쓰인 이유"` 아래 놓인 폐기 더미**입니다 —
값이 흘러들 자리가 아니라 **꺼내 쓰지 않은 물건**입니다. 은유가 다릅니다.

그리고 결정적으로 **강조 대상이 반대**입니다. `channels` 는 세 0 중 `경로`에 `focus:true`
를 걸어 **0 쪽을 주인공으로** 삼습니다(0편의 논지가 "경로가 0이니 내 문제가 아니다"라서).
`pins` 는 세 0 중 어느 것도 강조하지 않고, 시선을 전부 왼쪽 레인·이름표로 보냅니다.
**같은 데이터로 반대쪽을 가리키는 그림입니다.**

`reads` 대조 — 약속과 화면이 맞습니다(17.9s 스틸):
> "S1의 그 획 셋이 벽 앞에 멈춰 서 있고, 각자의 끝에 박힌 이름표가 전부 같은 글자다.
> 오른쪽에는 한 번도 안 쓰인 이름표 세 장이 0인 채로 쌓여 있다"

레인 3 ✓ / 벽 앞 정지 ✓ / `계획` 이름표 3장 동일 글자 ✓ / 우측 `자원 0`·`이동 0`·`전제 0`
어긋나게 쌓임 ✓ / 상단 콘솔 한 줄 ✓.

### 2-4. 자기 진단의 정직성

1차 반려의 근본 원인은 그림이 아니라 **"대조 없는 단언"** 이었습니다. 이번 `writer.md`
3-A 절은 제가 독립 검증한 결과와 **한 줄도 어긋나지 않습니다.** 특히 항목 3·4를
*"강제(원문)라 유지"* 로 **인정하고 넘어간 것**이 중요합니다 — 1차처럼 전부 다르다고

`notes.excluded` 의 콘솔 로그 항목에도 ①카드 그리드 → ②`spoke`(반려) → ③`pins` 3단계

**핵심 차이 = 강조 대상이 카드 체계에서 이탈해 레인 기하로 옮겨갔다는 것.**
`metrics` 도 `channels` 도 "네 값을 같은 그릇 넷에 넣고 하나를 강조"인데, `pins` 는
그 그릇 자체를 3장으로 줄이고 주인공을 밖으로 빼냈습니다.

ep00s 9종 중 형태가 가까울 만한 셋도 직접 열어 확인했습니다.

- **`dossier`**(이름 붙이는 샷): 이름표 = **네 귀의 꺾쇠**(`brackets()`, 선만, 밖에서 수렴).

  없는 낱장 3개. ✅
