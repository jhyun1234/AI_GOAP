그림 전체가 기계에게 정지 화면입니다. 이동 거리를 늘려도(57px 이나 28px 이나 `m` 이
0.00057 로 같습니다 — 이미 두 위치가 겹치지 않아 포화) 해결되지 않습니다.
**바뀌는 잉크의 면적**이 문제입니다.

# 7. 통과했지만 기록해 두는 관찰 3건 (반려 사유 아님)

1. **어미 `~어요` 3연속** — 1행 "안 해요" / 2행 "비어 있어요" / 3행 "틈이었어요"
   (`voice.json` rules.1 "같은 어미 2연속까지, 3연속 금지"). S2 첫 줄이 들어오며 생긴
   이음매입니다. 다만 **승인된 ep01s 에 같은 패턴이 있습니다** — "막아뒀어요"(S6) /
   "갔어요"(S7) / "뺐어요"(S7). 리포에 선례가 있는 것을 새 기준으로 반려하지 않습니다.
   1절을 고치러 파일을 여는 김에 3행을 `~더라고요`·`~거든요` 로 바꾸면 더 좋습니다(선택).
2. **`spec.count = 3` / S1 라벨 3개** — 원문 37행은 "직접 배치한 주민**들**"이라 하고
   숫자 3 을 말하지 않습니다. `notes.수치_정직성` 은 3 을 "원문에 있는 숫자"로 세고
   있는데 축자로는 없습니다. **1·2차 컷에서 이미 통과한 자리**이고 이번 재작업이 만든 것이
   아니므로 반려하지 않습니다. 다만 `수치_정직성` 의 문장은 "화면 구성상 정한 수"로
   표현을 낮추는 편이 정직합니다.
3. **`S3.spec.options` 에 원문에 없는 성격 이름 셋이 남아 있음**
   (`성실`·`겁많음`·`쾌활`, scene.json 83행). 화면에는 안 나갑니다 —
   `wardline.js:26~27` 의 `KNOWN` 집합이 셋을 `···` 로 익명화합니다(확인함).
   기능상 문제는 없지만, **씬 JSON 만 읽는 사람에게는 지어낸 이름이 그대로 보입니다.**
   다음에 이 샷을 열 때 `["게으름","탐구","용감함","···","···","···"]` 로 바꾸는 편이 낫습니다.
