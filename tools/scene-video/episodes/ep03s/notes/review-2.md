## 3. 🟠 → ✅ `purge` 걷힘 순서를 실제로 갈았다 + **타이밍 재환산**

### 3-1. 코드 확인 — 좌상→우하가 아니다

`kinds/purge.js` 77행:

```js
const gone = clamp((wk * (dmax + 0.7) - (dmax - distOf(i))) * 2);
```

`distOf(i)` = 이름 붙은 칸(`markAt` = 58, 7행 5열)까지의 거리, 세로 성분에 칸 간격비
`(18+4)/(32+4)` = 0.6111 을 곱해 화면 거리로 맞춘다(62~67행). **거리가 먼 칸이 먼저 빈다.**
1차의 `clamp(wk×67 − i)`(인덱스 순차 = 좌상→우하)는 사라졌다. ✅

손검산으로 확인한 것:
- `dmax` = **5.4263**(맨 윗줄 양 끝, i=0 · i=8) — 씬·writer.md 의 5.426 과 일치 ✅

  (수치 확인: 59번째로 비는 칸이 `markAt` 이고 시각 +1469ms)
- 거리 (3,4] 고리에 **19칸** — writer.md 의 "19칸이 몰려 있고"와 일치 ✅
- 앞머리라는 '선'이 없어지고 같은 거리의 칸들이 한꺼번에 빈다 → ep02s `sweep` 의
  `headIdx = sk×34` 와 장치가 더 이상 같지 않다 ✅
