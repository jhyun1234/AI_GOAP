## 🔴 R-1. S8 `rung60` — "이탈 → 복귀"가 화면에서 사라졌다 (작성팀이 고쳐라)

**이것이 이번 재구성이 만들어 낸 유일한 실질 결함이다.** 인덱스만 보면 안 보인다.

`leaveCue` 와 `returnCue` 를 같은 자막(2)에 합쳤는데, `rung60.js` 는 두 값을 **서로 상쇄되는
이중 lerp** 로 쓴다.

```js
// kinds/rung60.js:35-36
const lk = ease(cue(spec.leaveCue   ?? 2, 0.15, 0.6));
const rk = ease(cue(spec.returnCue  ?? 3, 0.15, 0.6));
// :54
const my = lerp(lerp(center(ci), center(0), ease(lk)), center(ci), ease(rk));
```

`leaveCue = returnCue = 2` 이고 lead·span 도 같으므로 **`lk` 와 `rk` 는 항상 같은 값**이다.
`a = ease(lk) = ease(rk)` 로 두고 풀면

```
my = c + (z − c)(a − a²)      c = center(2) = 174 (60 칸),  z = center(0) = 70 (100 칸)
```

`a − a²` 의 최댓값은 a = 0.5 에서 **0.25** 다. 실측 대입 결과:

```
표식 최고점 my = 148.00  (자막 시작 +1.28s)
이동 거리 = 26.0px / 전체 104px = 25.0%
100 칸 hot = 0.000        ← 배고픔(100) 칸은 한 번도 켜지지 않는다
창 끝 my = 174            ← 정확히 출발점
```

즉 표식은 60 칸에서 **반 칸(26px)만 들썩였다가 제자리로 돌아온다.** 100 까지 올라가지도,
그 칸을 켜지도 않는다. 덤으로 `이탈과 복귀의 자취`(:137-154)도 `upK`·`downK` 가 같은 값이라
**올라간 점선과 내려온 점선이 동시에 같은 속도로 자란다** — 순서가 없다.

- `reads` 는 이렇게 적혀 있다: *"오른쪽 레일의 표식이 **60에서 100으로 튀어 올랐다가 다시
  60으로 내려온다**"* → 일어나지 않는다.
- 나레이션 자막 2가 *"일하다 배고프면 밥 먹고, 알아서 명령으로 돌아와요."* 라고 **그 사건을
  이름으로 부르는데 화면에 그 사건이 없다.** 말과 그림이 어긋난다.
- 이 샷은 이 편의 논지("명령 전용 상태머신을 안 만들어도 중단·복귀가 공짜로 성립한다")를
  그림으로 증명하는 자리다. 증명이 빠졌다.

**처방(둘 중 하나).**
① `rung60.js` 에서 두 값을 시간으로 가른다 — 같은 cue 를 쓰되 `lk` 를 앞쪽 창
(`cue(2, 0.15, 0.3)`), `rk` 를 뒤쪽 창으로(예: `ease(clamp((cue(2,0.15,0.75) − 0.45)/0.55))`)
잡아 올라갔다가 내려오게 만든다. 문턱 값은 반드시 다시 풀어서 `notes` 에 적을 것.
② 자막 2를 1차본처럼 두 줄로 되돌리고 `leaveCue=2 · returnCue=3` 으로 되돌린다.
길이가 늘지만 이 편에서 가장 값나가는 3초다.

어느 쪽이든 **S8 의 `sfx` 는 손댈 필요가 없다**(`at: 0`, 자막 0 은 무변경).

### C-5. rules.1 — 콜드 오픈 세 줄이 전부 "-었어요"로 닫힌다

문장 단위로 세면 중간에 "했죠"가 끼어 2연속이라 규칙 위반은 아니다. 그러나 **자막 줄이

"돌아갔어요 / 사라지더라고요 / 굳었어요 / 관람이었죠"로 섞여 있었는데 재구성에서 좁아졌다.

### C-6. 효과음 돌려막기 — 대조 대상에 `ep00i` 가 빠졌다

`why` 들이 `ep03s` 만 대조하고 `ep00i`(특별편)를 안 봤다. 실측 대조:

| 이 편 | 가장 가까운 앞 회차 | 간격 |
|---|---|---|
| S11 tick `dur 0.04 · 1750Hz` | **ep00i S9 tick `dur 0.04 · 2100Hz`** | **dur 완전 일치**, freq 약 3반음 |
| S1 thud `dur 0.26 · 132Hz` | **ep00i S8 thud `dur 0.32 · 125Hz`** | dur 0.06 차, freq 약 1반음 |

S11 tick 은 1차 검수 지적을 받고 `dur 0.05 → 0.04` 로 옮긴 자리인데, **옮긴 곳이 ep00i 와
같은 값**이다. 3반음이면 ep03s 사례(150Hz ≈ 1.4반음)보다는 갈렸으므로 즉시 반려는 아니다.
