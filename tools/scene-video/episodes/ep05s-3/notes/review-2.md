## 1. ✅ 반려 사유가 실제로 사라졌다 — 전수 재스캔

`spec` 의 모든 문자열 × 자막 11줄의 `text`·`say` 를 2-gram 으로 다시 훑었다(임계 30%).

| | 1회차 | 지금 |
|---|---|---|
| `S5.spec.meaning` **새 버그가 생길 자리가 구조적으로 차단됐다** | 자막[2] 와 **76%** | **스캔에 안 잡힘 (0건)** |

바뀐 자막은 `scene.json:220-221` 이고 원문에 그대로 있다 —
원문 12번째 문단 *"**단순한 편리함이 아닙니다.** 새 행동을 추가할 때 … 새 버그를 만들 가능성이
**구조적으로 차단됐다는 뜻입니다.**"* 두 문장을 말과 화면이 나눠 가졌다. 지어낸 문장이 아니다.

### 1-a. "자막이 던지고 화면이 답하는가" — 프레임과 시각으로 확인했다

작성팀 판단이 **맞다.** 헤드리스에서 실제 프레임을 떴다(37,500ms):

```
화면 상단   두 번 연속 재현
화면 중앙   [겹친 자국] 에셋 1개, 코드 0줄
화면 하단   ───┤ 차단선 ├───  /  새 버그가 생길 자리가 구조적으로 차단됐다
자막        이게 단순한 / 편리함이 아니에요.
```

같은 문장이 두 번 읽히던 자리가 **질문(말) → 대답(화면)** 으로 갈렸다. 겹치는 글자가 없다.

도착 시각도 맞다. `nk = ease(cue(2, 0.15, 0.6))`, 자막[2] 길이 2.588초 → 창 W = 1.703초.

| 사건 | 자막[2] 시작 기준 |
|---|---|
| 차단선이 그어지기 시작 | **−0.007초** (사실상 동시) |
| `meaning` 글자가 뜨기 시작 (nk>0.3) | **+0.469초** |
| `meaning` 완전 불투명 (nk>0.75) | **+0.997초** |

자막[2]의 발화 구간(0~2.388초) **안에서 전부 끝난다.** 가이드 한도 ±20프레임(0.67초) 안이고,
답이 질문보다 먼저 오지도 않는다. ✅

### 1-b. 앞뒤 자막과 뜻이 이어지는가 — 이어진다. 다만 두 자리가 걸린다 (🟡, 반려 아님)

```
[0] 요리에서 한 번, 집에서 또 한 번.
[1] 이게 두 번 연속 재현된 거예요.
[2] 이게 단순한 편리함이 아니에요.
[3] 다음 편은 주민마다 성격이 달라져요.
```

논리는 산다(사실 → 그게 두 번 → 그게 뜻하는 것). `voice.json` rules.1 도 지킨다
(어미 3연속 없음. `거예요 / 아니에요` 2연속까지).

🟡 **① 「이게」가 두 줄 연속 첫머리에 온다.** 소리 내어 읽으면 걸린다(rules.7).
한 단어면 풀린다 — 예: `[2] 그냥 편해진 게 아니에요.` 또는 `[2] 단순한 편리함이 아니거든요.`
(뒤엣것은 담화 어미까지 섞여 rules.1·3 에도 낫다. 자수가 같아 길이도 안 변한다.)

🟡 **② 소리만 들으면 페이오프가 부정형으로 끝난다.** *"…아니에요"* 뒤에 바로 예고가 온다.
답은 화면에만 있고, 남는 한 줄(훅)도 이제 카드 안 텍스트다.
1회차엔 화면 하단이 `차단선 + meaning + 훅` **세 겹**이라 넷째 줄을 못 얹는다는 게
`scene.json:278` 의 배제 사유였는데, **훅이 카드로 빠져서 지금은 두 겹이다.**
원문에 남은 좋은 재료도 있다 — *"설계의 내구성을 실전에서 두 번 확인한 셈입니다."*
길이도 권장대역 상단까지 4.8초 남는다.
🔴 **이건 선택이지 반려 조건이 아니다.** 지금 그대로 내보내도 결함이 아니다 —
자막·화면이 2.1초 동안 같이 서 있어 읽는 사람은 답을 받는다. 안 고쳐도 통과다.

## 6. 남은 정정 — 1회차 🟡 셋은 하나도 안 고쳐졌다 (재실측해 값을 다시 준다)

### 6-a. `notes.제목_이행`(`scene.json:291`) — 판단은 맞고 근거가 틀렸다

게이트를 손으로 다시 돌렸다(`check.mjs:67-82` 그대로).

```
제목 핵심어 : [기능, 늘었는데, 코드, 0줄이에요]
겹침        : [코드, 0줄이에요]           ← 실행 출력과 일치
```

- 통과는 맞다. **다만 「0줄」이 없어도 통과한다.** ①`코드` 가 자막[0]에서 정확 일치로 잡히고
  ②`say` 의 「영 **줄이에요**」가 `k.includes(h)` 로 제목의 `0줄이에요` 를 문다.
  자막[1]을 「여기도 0줄이고요.」로 바꿔 넣고 다시 돌려도 겹침은 `[코드, 0줄이에요]` 로 같다.
- 그러니 *"활용형만 있으면 이 거친 검사가 못 잡는다"* 는 **사실이 아니다.**
- **판단(맨 어절 「0줄」을 화면에 남긴다)은 그대로 두라.** 시청자에게 이득이다.
  **근거 문장만 고쳐라** — 틀린 근거는 다음 회차가 그대로 베낀다.

### 6-b. `notes.정적_구간_대책`(`scene.json:296`) — 숫자 둘이 틀렸다 (§3 실측)

| 작성팀 주장 | 실측 (10fps 전 구간) |

| 맥동이 `0.0053 ≈ 문턱의 약 6배` | **0.00056~0.00181** (0.7~2.3배). 6배가 아니다 |
| `표식 반경 4.5 → 5.5 로 키웠다`(대책) | **문턱을 못 넘겼다.** 표식만 도는 31.4~33.1초가 0.00023~0.00042 로 계속 문턱 아래 — **이 편의 진짜 정적 구간(1.8초)이 거기다** |

베끼면 안 된다. **표식만으로는 여전히 부족하다.**

### 8-a. 🔴 `scene-writer.md:141` 이 아직 캔버스 훅을 지시한다

### 8-b. 🟡 예고 칩이 완성되고 **0.08초** 뒤 카드에 덮인다 (구조)

*"칩은 예고 자막 시작 +0.3초 안에 완성되게 창을 잡아라"* 로 적는 편이 실효가 있다.
