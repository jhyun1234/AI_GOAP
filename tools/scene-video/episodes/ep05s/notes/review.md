## 🟡 함께 고칠 것 (반려 사유는 아니나 같은 왕복에서 처리할 것)

### C-1. `S4 sprout` 의 `reads` 가 그림보다 세게 말한다 (scene.json:176 · writer.md:185)

```
reads: "… 셋의 위상이 어긋나 있어 세 단계가 늘 동시에 보인다"
writer.md: "어느 t 로 seek 해도 세 단계가 화면에 함께 있다"
```

`sprout.js:38-41,127` 을 그대로 넣고 5.4초 주기를 54,000 등분해 세어 봤다:

| 단계 | 코드상 구간 | 세 위상(간격 1/3) 중 0개인 시간 |
|---|---|---|
| 씨앗 `u < 0.28` | 길이 0.28 (< 0.3333) | **16.0%** (최장 연속 **0.29초**) |
| 자라는 중 `0.28 ≤ u < 0.60` | 길이 0.32 (< 0.3333) | **4.0%** |
| 수확 가능 `0.60 ≤ u < 0.94` | 길이 0.34 (> 0.3333) | **0%** ✅ |

- 작성팀 계산에서 검증되는 것은 **'수확 가능'뿐**이다(0.34 > 1/3). 씨앗·자라는 중은
  구간 길이가 1/3 보다 **짧아서** 원리상 0개인 순간이 생긴다.
- 🟢 **타이밍 위반은 아니다.** 단계 이름은 `stageCue` 에 물린 아래 띠가 붙이고
  (`sprout.js:133-158`), 그 띠는 칸마다 고정 위상 `u = [0.10, 0.44, 0.74]`
  (`sprout.js:151`)로 세 단계를 항상 그려 놓는다. 즉 자막이 부르는 순간 세 단계가 반드시 있다.
- 고칠 것은 **문장**이다("세 단계가 늘 동시에 보인다" → 실제에 맞게). 그림을 유지하고 싶으면
  `sprouted` 문턱을 0.28 → 0.34 로 올리면 씨앗 구간도 1/3 을 넘어 문장이 참이 된다.

### C-2. `notes.coldOpen` 의 "첫 프레임" 서술이 사실과 다르다 (scene.json:528)

> "첫 프레임에 이미 발자국이 겹겹이 난 길이 깔려 있고 주민 표식 셋이 그 위를 왕복하고 있다"

`worn.js:59,99` + `engine.js:240-245` 로 계산: `t=0` 에서 `cue(0,0.15,0.6)` 의 raw 는
`0.15 / (0.15 + 4.976×0.6) = 0.0478` → `pk = ease(0.0478) = 0.0067` → 길 알파 ≈ 0.011(사실상 안 보임).
길이 다 보이는 것은 **+0.6초**, 주민 표식은 `pk > 0.25` 라 **+0.87초**부터다.

🟢 **콜드 오픈 규칙 자체는 통과다** — 제목 카드 없고, 첫 자막과 함께 사건이 시작하며,
승인된 ep04s S1 `standstill` 도 동일하게 `cue(0)` 로 등장한다(`ep04s/kinds/standstill.js:30`).
**문장만 사실에 맞게 고치면 된다.**

### C-3. `thud` 의 dur 이 ep03s 와 같다

작성팀은 직전 편(ep04s 0.26/132Hz)하고만 비교했다. 실제로는 **ep03s S1 `swell` 의 thud 가
dur 0.22**(freq 미지정 = 기본 150Hz)다 — ep05s S2 는 **0.22/176Hz** 로 dur 이 같다.
주파수가 다르고 쓰임(‘무게가 실림’ vs ‘부풀다 무너짐’)도 달라 반려하지 않는다. 다음 회차부터
sfx 대조는 **직전 편만이 아니라 전 회차**로 할 것.
