## 1-B. 🔴 지시가 물은 것 — 「내 실험본과 같은 값인가, 우연히 같은 숫자인가」

**갈라서 답한다. 셋 다 다른 이야기다.**

| | 2차 제출본 | 내 실험본(eprevtmp) | **3차 제출본(현재)** |
|---|---|---|---|
| 통행선 파선 | 없음 | `[8,6]` · `-(t*11)%14` | **`[14,10]` · `-frac(t/1.8)*24`** |
| `cut` 식 | 없음(선이 안 고쳐짐) | `clamp((mk−0.3)/0.4)` | **`clamp(mk*1.8)`** |
| m 평균 36.0~38.8s | 0.000747 (0.93배) | 0.002764 (3.46배) | **0.002211 (2.76배)** |
| m 평균 34.6~38.8s | — | — | **0.002769 (3.46배)** |
| S7 연속 정적 | 15f = 3.0s | (0f) | **0f = 0.0s** |
| check 「최대 정적」 | 3.0s (**S7**) | 1.0s | **1.0s (S10)** |

세 가지를 확정한다.

1. **코드는 내 실험본과 같지 않다.** 파선 규격도 `cut` 식도 다르다. 작성팀은 실험 코드를
   베끼지 않고 조건(①이어져 있을 것 ②자막1에 끊길 것)만 받아 제 방식으로 짰다 —
   2회차 리포트가 *"이 코드를 그대로 쓰라는 뜻은 아니다"* 라고 적은 그대로다.
2. **m 은 같은 값이 아니다.** 같은 창(36.0~38.8s)에서 실험본 0.002764 · 제출본 **0.002211**.
   20% 낮다. 파선 주기가 길고(24px vs 14px) 흐르는 속도가 느려서 프레임당 바뀌는 면적이
   적기 때문이다. 그래도 **임계의 2.76배**이고, 정적 판정은 0프레임이다.
   🔑 우연히 0.002769(= 실험본과 소수 여섯째 자리까지 비슷)가 나오는 창이 하나 있는데
   그건 **34.6~38.8s**(샷 등장 프레임 포함)다. 창이 다르면 숫자도 다르다 — 숫자 하나만
   보고 「같다」고 하면 안 된다.
3. 🔴 **`check.mjs` 가 찍는 「최대 1.0s」는 S7 이 아니라 S10 것이다.** 이건 1차·2차에도
   내내 1.0s 였던 값이고(2차 리포트 §10에 *"이번에도 최장 1.0s 정지"* 로 적어 뒀다),
   **S7 이 1.0s 로 내려온 것이 아니다. S7 은 0.0s 다** — 주장보다 좋다.
   → `notes.검수_2회차_반영` 의 *"최대 정적 1.0s 로 검수 실험본과 같은 값이 나왔다"* 는
   **check 출력 문자열로는 참**이지만, 그 1.0s 의 주인이 S10 이라는 사실은 안 적혀 있다.
   거짓은 아니고 불완전이다. 🟡 정정 대상으로 남긴다(반려 아님).

## 1-C. 🔴 `reads` 가 참인지 — 스틸이 아니라 **픽셀로 확정했다**

- **자막 0 구간(34.8~38.8s): 집 안쪽에 매 프레임 700~1150 픽셀의 선이 있다.**
  → *"마을을 가로지르던"* 은 이제 **참**이다. 2차본은 이 값이 처음부터 끝까지 0 이었다.

  - **42.0s** — 집 테두리 두 곳에서 끊기고 그 자리에 ✕ 둘, 아래에 `standNote`.

### 말과 그림이 같은 순간에 도착하는가 (지시 5의 🔴 규칙)

인덱스만 보지 않고 **문턱이 참이 되는 시각을 자막 기준 초로 환산**했다.

- `mk = ease(cue(1, 0.15, 0.62))`, 창 `W = 0.15 + dur₁×0.62`.
- 끊김 시작 = `mk > 0.02` → `ease⁻¹(0.02) = 0.0827` → 자막1 **+0.15s**.
  실측 픽셀도 39.0s 에 처음 줄기 시작한다(자막1 시작 38.835s → **+0.165s**).
  가이드 한도 ±20프레임 = ±0.67초 **안**이다.
- ✕ 등장 = `xk = clamp((mk−0.3)/0.4) > 0` → `ease⁻¹(0.3) = 0.3618` → 자막1 **+1.18s**. 같은 자막 안.
- 완전 절단 = `cut = clamp(mk*1.8) = 1` → `mk = 0.5556` → 자막1 **+1.82s**. 같은 자막 안.
- 🟢 **`t` 로 도는 조건에 사건이 물려 있지 않다.** 새로 들어온 `frac(t/1.8)` 은 파선 위상뿐이고
  나레이션도 sfx 도 여기에 걸려 있지 않다(ep02s `tripwire` 형 사고 없음).
- 🟢 **다른 cue 에서 파생된 문턱도 없다.** 통행선 블록의 게이트는 `bk`(자막0)와 `mk`(자막1)
  둘뿐이고, 각각 자기 자막의 사건을 그린다(ep00i `runmark` 형 사고 없음).

# 2. ✅ (2회차 반려 2) S7 `sfx.why` 의 숫자 — **다시 세어 맞다**
