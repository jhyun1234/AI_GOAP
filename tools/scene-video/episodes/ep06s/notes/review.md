## 3. B. 말·그림 도착 시각 재검산 (이 환경의 핵심 검수)

### 3.1 t 기반 조건 — 없다

`kinds/*.js` 6개에서 `t` 가 쓰인 자리를 전수로 뽑았다(13곳).

```
anyone.js:56  frac(t/SWEEP)          lockstep.js:66  lineDashOffset -(t*11)%19
anyone.js:99  lineDashOffset         lockstep.js:113 frac(t/CYCLE)
atcopy.js:82  frac(t/SCAN)           noroll.js:106   frac(t/2.4)
atcopy.js:124 frac(t/FLOW + k*0.25)  noroll.js:152   frac(t/1.5 + …)
tilt.js:116/143/163/190              whoto.js:83/140
```

**전부 위치·오프셋·위상에만 쓰이고 `frac(t/N) > x` 형태의 문턱이 한 줄도 없다.**
(ep02s `tripwire` 가 샌 형태 — 이 회차에는 없다.)

유일하게 설명이 필요한 자리는 `atcopy.js:128` 의 `if (fx > NX && mk > 0.05)` 다.
`fx` 는 t 로 흐르지만 이것은 **자리 조건**이고, "배율이 붙었다"는 사실 자체는 `mk`(자막 1의 cue)가
연다. 환산하면 `mk > 0.05` 는 자막 1 시작 **+195ms** 이고, 통로에서 표식 넷 중 2~3개가
항상 NX(140) 오른쪽에 있으므로 실제로 그 시각에 바로 보인다. 문턱이 t 로 미뤄지지 않는다.

### 3.2 다른 cue 에서 파생된 문턱 — 없다

샷마다 문턱이 어느 cue 에서 왔는지 전수 확인했다.

## 4. C. 효과음

### 4.1 배치·절제

3건뿐이고(S3 tick · S4 latch · S5 sweep) 여섯 샷 중 셋은 무음이다. 셋 다 나레이션이 실제로
부르는 사건에 붙어 있고 정적을 메우려고 깐 것이 없다. S1·S2 를 통째로 무음으로 둔 것
("어긋남은 조용하고 개입에서 처음 소리가 난다")은 이 편의 내용과 맞는 설계다.
`why` 는 셋 다 채워져 있고 draw 근거·창 계산·kind 선택 사유까지 적혀 있다.

### 4.2 gain 상한 — 이 회차 옵션으로 직접 쟀다

`synth(kind, {…opts, gain}, rate)` 의 피크로 `0.46 / (peak/gain)` 을 계산했다(순수 JS 라 이
환경에서 돈다). **셋 다 실행 중 `피크 천장에 걸려` 경고가 나오지 않았다.**

| sfx | 옵션 | 이 옵션의 실제 gain 상한 (24k/44.1k/48k) | 쓴 값 | 여유 |
|---|---|---|---|---|
| tick | dur 0.066 · freq 1980 | 0.0667 / 0.0662 / 0.0667 | **0.056** | 16% |
| latch | dur 0.15 · seed 53 | 0.0771 / 0.0734 / 0.0736 | **0.062** | 19% |
| sweep | dur 0.44 · seed 29 | 0.1836 / 0.1765 / 0.1797 | **0.060** | 194% |

작성팀이 `why` 에 적은 "dur 을 기본보다 길게 잡아 여유가 더 있다"도 실측으로 맞다
(tick 기본 옵션 상한 0.0657 → 이 옵션 0.0667, latch 0.0721 → 0.0736).

### 4.3 앞 회차 돌려막기 대조

리포 전체 sfx 42건을 뽑아 대조했다.

- **seed**: 기존 latch seed = 7(기본)·23·37·41·67, sweep seed = 11(기본)·23.
  **53 과 29 는 리포에서 쓰인 적 없는 값이다**(작성팀 주장 확인).
- **dur·freq 쌍**: 기존 tick 은 0.04/2100 · 0.05/1760 · 0.05/1900 · 0.055/1250 · 0.042/1510 ·
  0.07/1080 · 0.048/1380 · 0.09/1050. **0.066/1980 은 겹치지 않는다.**
  latch dur 0.15, sweep dur 0.44 도 기존(0.115~0.19 / 0.58~0.7)과 겹치지 않는다.
- **성격**: sweep 은 이전에 "훑고 내려옴"(ep00i)·"격자 쓸기"(ep02s)·"격자 비우기"(ep03s)·
  "고리 정리"(ep04s-2)로 쓰였다. 이 회차의 "있을 줄 알았던 칸이 접혀 사라짐"은 `sfx.mjs` 가
  sweep 에 부여한 의미("쓸고 지나가거나 지우는 자리") 안이고, 6종뿐인 어휘에서 kind 재사용
  자체는 불가피하다. dur·seed 가 갈려 파형이 다르므로 돌려막기로 보지 않는다.

### 4.4 루틴이 지적한 "S3 tick · S4 latch · S5 sweep 오기" — **오기가 아니다**

확인 결과 `why` 안의 이름은 **샷 배열 인덱스가 아니라 `shot.id` 다.**

```
scene.json:103  "id": "S3"  → sfx[0].kind = "tick"    (배열 인덱스 2)
scene.json:145  "id": "S4"  → sfx[0].kind = "latch"   (배열 인덱스 3)
scene.json:192  "id": "S5"  → sfx[0].kind = "sweep"   (배열 인덱스 4)
```

`why` 의 "S3 tick · S4 latch · S5 sweep" 은 이 id 들과 정확히 일치한다. 1-based 착시도 오기도
아니므로 **정정을 요구하지 않는다.**

## 6. 정정 요구 · 인수인계 (반려 사유 아님)

**① 예고 길이 — 3초 규칙에 붙어 있다.**
`check.mjs` 의 예고 게이트(구두점·공백 포함 26자 ÷ 6.7)로는 **3.88초**이고 warn 한도 4.0초
아래다. 반면 실제 발화에 가까운 산정(구두점·공백 제거 19자 ÷ 6.7)으로는 **2.84초**로
사용자 확정 "3초 안"에 든다. 두 지표가 3초를 사이에 두고 갈린다.
→ **로컬에서 `tts.mjs` 실측 dur 을 보고, 3.0초를 넘으면 한 어절 줄여라**
(예: *"다음 편은 직업이에요. 성격만으론 안 흩어져요."* → *"다음 편은 직업이에요. 성격만으론
안 흩어지더라고요."* 가 아니라 **더 짧은** 쪽으로). 규정상 **반려가 아니라 정정 요구**다.

**② 마지막 샷 — 예고 연출이 아웃트로 카드에 덮일 여유가 4.7프레임뿐이다.**
`engine.js:174` `OUTRO_MS = 2600`, `SHOT_TAIL = 0.35`. 마지막 자막 기준으로
- 카드가 뜨는 시각 = `dur₂ − 2.25s`
- 판 미끄러짐이 끝나는 시각 = `0.16 × dur₂` (`whoto.js:48` span 0.16)
→ 덮이지 않으려면 **`dur₂ > 2.679초`** 여야 한다. 산정치 2.836초라 여유가 **0.157초**뿐이다.
실측 dur 이 2.68초 아래로 나오면 이 편에서 가장 큰 움직임이 카드 뒤에서 끝난다
(정적 검사는 그 구간을 제외하므로 게이트는 통과하지만 연출이 버려진다).
→ 실측 후 `dur₂ ≤ 2.7초`면 `spec` 의 `nextCue` 창(span 0.16)을 0.12 안팎으로 줄여라.

**③ 말투 — 어미 세 줄 연속.**
`voice.json` rules.1 은 "같은 어미 2연속까지, 3연속 금지"다. 앞 세 줄이
**있어요 / 나가요 / 없었어요** 로 해요체 -아/어요 가 세 번 이어진다(각각 다른 활용이라
엄밀히 같은 어미인지는 갈리고, 승인된 ep05s-2 에도 `들어가요 / 자리요 / 있었어요` 선례가 있어
**반려로 세우지 않는다**). 나머지 열 줄은 `거죠 / 고요 / 거든요 / 니까요 / 예요` 로 잘 섞였다.
→ 셋 중 하나만 바꾸면 깨끗해진다(예: S2 첫 줄 *"달라지는 게 없더라고요"*).

**④ 사실 뉘앙스 — "거의"가 자막에서만 빠졌다.**
원문 2절은 *"다섯 명이 **거의** 동시에 배가 고프고, 동시에 쉬고, 동시에 일하러 나갔습니다"* 다.
자막은 *"동시에 배고프고, 동시에 쉬고, 동시에 일하러 나가요"* 로 첫 항의 "거의"가 빠졌고,
`lockstep` 은 다섯 표식을 **완전히 같은 x** 에 둔다.
다만 원문 자신이 1절에서 *"주민들은 전부 똑같은 사람처럼 행동했습니다"* 라고 쓰고 뒤 두 항은
"거의" 없이 "동시에"라고 쓰므로 **원문이 주장한 범위 안이다.** 지어낸 수치가 아니라
반려 사유로 세우지 않는다(`youtube.blurb` 은 "거의"를 살려 두었다). 기록만 남긴다.

**E. 돌려막기.**
- kind 이름 6종(`lockstep anyone atcopy tilt noroll whoto`)이 **리포의 기존 이름 60여 개 중
  어느 것과도 겹치지 않는다**(ep00i~ep05s-3 전수 대조).

  비율이 16~23%** 이고, 그 일치분은 전부 `fit` 헬퍼·`fitCanvas`·`roundRect` 같은 보일러플레이트다.
- 색: 하드코딩 색상 0건, `tone('ink'/'accent'/'sub'/'track')` 과 `GLOW` 만 쓰고 `depthGrad` 미사용.
- 제목: 직전 ep05s-3 「코드는 0줄이에요」와 ep04s-1 「명령했는데 주민이 거절했어요」를
  둘 다 피했다. 명령 거부는 훅이 아니라 S5 의 증거로만 썼다.
- hook 문형도 앞 회차의 'A 는 B 가 아니라 C 였다' · 대구형과 다른 **행위문**이다.

**F. 제목 이행(손 판정).** 1절 게이트 출력대로 핵심어 4개 중 **주민 · 다섯 · 사람처럼** 3개가
첫 두 줄의 `text` 에 원형으로 있다. 제목은 완료형("움직였어요"), 첫 줄은 진행형
("움직이고 있어요") — 낭독이 아니라 이행이다.

**G. 길이.** 자막 **13줄 · 6샷**. 브리프 §3 이 예상한 10~14줄 대역 안이다.
