## 4. `split 0.55` · `payCue span 0.06` — 엔진 코드를 열어 직접 검산

🔴 **분모 논쟁부터 코드로 끝냈다.** `engine.js:163` 이 `dur = durOf(...) + (l.pauseAfter ?? 0)` 이고
`engine.js:169` 가 `rel = ls.map(l => ({ t: …, dur: l.dur / 1000 }))` 다. `cue()`(engine.js:292)의
`l` 은 `s.rel[i]` 이므로 **`l.dur` 은 `rel`(= wav + pauseAfter)이 맞다.** 작성팀·검수 판단 정확.

`timed.json` 실측 wav: S1 3449·3401 / S2 **4064** / S3 3357·3054 / S4 3718·2651.

**ⓐ S2 `split` 0.55** — `gnaw.js:81-84` 확인(`cue(0,0.15,0.85)`, `rk=c0/split`, `gk=(c0−split)/(1−split)`)
- `rel` = 4064 + 250 = 4.314s → `W = 0.15 + 4.314×0.85 = 3.8169s`
- 경계는 **`dur` 4.064s** 로 잰다(pause 는 말 뒤 침묵). spoken 21자, 「존재」 앞이 10자
  (방금2+만든2+부탁2+시스템의4) → `10/21 × 4.064 = 1.9352s`
- `c0 = (1.9352 + 0.15) / 3.8169 = **0.5463** → 0.55` ✅ 자진 정정이 옳다.
  (분모를 `dur` 로 잘못 잡으면 0.58 이 나온다 — 값이 실제로 갈리는 자리다.)

**ⓑ S3 `sweep` delayMs 1240** — `rollback.js:83` `roll = ease(clamp((d0−0.35)/0.45))`
- `rel` = 3357+130 = 3.487s → `W = 2.9396s`. smoothstep 역산 `3x²−2x³ = 0.18` → x ≈ 0.2707
  → `d0 = 0.4718` → `0.4718 × 2.9396 − 0.15 = **1.237s**`. 설정 1,240 과 **3ms(0.09프레임)** 차 ✅

**ⓒ S3 `latch` delayMs 2030** — `rollback.js:85` `run = ease(clamp((r1−0.24)/0.54))` = 1 ⟺ r1 = 0.78
- `rel` = 3054+250 = 3.304s → `W = 2.7932s` → `0.78 × 2.7932 − 0.15 = **2.029s**`. 설정과 1ms 차 ✅
- 그 프레임이 실제로 사건인지도 코드로 확인: `rollback.js:209` `fill = ease(clamp((run−0.86)/0.14))`

- **음성·그림·카드 삼자 일치**(ADR-V25-10) — 스틸 `31.5s.png` 에서 목수 고리와 주민 점 사이
  흰 캘리퍼가 안 변하고 `REWARD` 캡슐이 흐려진다. **음성이 말하는 것과 그림이 보이는 것이 같다**
  (ep10s-2 델타에서 사용자가 못박은 규칙).
  ⚠️ ep11s 재제작본이 별건 반려 중이나 그 사유는 **11→12-1 예고**이고, 이 편의 예고가 기대는 것은
  ep11s 의 **사건**(원문에 고정)이라 영향받지 않는다.

### 승인을 막지 않는 지적 6건

1. 🔴 **`ep10s-2` 의 `youtube.title` 이 내 승인 뒤에 도치형으로 바뀌었는데 보고되지 않았다.**
   `목수한테 시킨 재료 검사를 지웠더니 2번째 부탁은 코드 0줄이었어요` →
   `AI가 알아서 할 수 있을까요? 목수한테 시킨 재료 검사를 전부 지워봤을 때요.`
   **내가 `check.mjs ep10s-2` 를 다시 돌려 확인했고 여전히 통과한다**(제목 이행 겹침 3개).
   🔴 다만 **제목 후킹 축이 「수치(2·0)」에서 「정보·질문형」으로 바뀌었다** — 내 ep10s-2 판정문의
   해당 기록은 이제 stale 이고, `upload.txt` 도 새 제목으로 다시 뽑아야 한다.
   🔑 **승인 뒤 제목·`youtube` 를 고치면 마스터에게 알릴 것.** 형제 카드에 그대로 실려 나간다.
2. 🟡 **`outro.source` 문자열이 형제와 다르다** — 이 편만 `M8 관계·소유·부탁` 이고
   ep10s-1·-2 는 `M8 관계 · 소유 · 부탁` 이다. 카드에 실제로 렌더된다(`36.5s.png`).
   형제 셋을 잇는 **바로 그 문자열**이라 맞춰 두는 편이 좋다(게이트는 안 본다).
3. 🟡 **아웃트로가 7.7초로 정본 표(ADR-V25-8)의 「약 5~6초」를 넘는다.** `TEASER_MAX` 를 5.0 으로
   연 것의 산술적 귀결이라 회차 잘못이 아니다 — **표의 숫자를 갱신할 자리**다.
4. 🟡 **카드 훅이 이 편의 「남는 한 줄」이 아니라 막 전환 문구를 진다**
   (`만드는 이야기는 여기까지, 다음은 잃는 이야기다`). 3막→4막 경계라 정당한 선택이고,
   이 편의 남는 한 줄은 S4 자막이 지고 있다. **관찰만 적는다.**
5. 🟡 **정적 구간 최대 1.6초**(ep10s-2 는 0.2초). 게이트 3초 아래라 통과지만 이 구조에서 가장 큰 값이다.
6. 🔴 **빌드 산출물이 뒤처져 있다** — `video.mp4`·`ep10s-3.en.srt`·`upload.txt`(17:5x) vs
   `timed.json`·`full.wav`(18:32). **승인의 전제 = 재렌더**(검수 R-2).

스틸이 없어 `reads` 를 실물로 볼 수 없었다). **대본은 한 글자도 안 고쳤고 합성 `timed.json` 도 없다.**
