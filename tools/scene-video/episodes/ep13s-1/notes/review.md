## 🔴 반려 ① 「봄」 — 원문에 0회. 그리고 그 근거로 적힌 인용문이 **실재하지 않는다**

**원문에 통째로 없는 것은 이 한 문장뿐**이었다(나머지 불일치 9건은 `/` 로 이어 붙인 목록·

- 더 무거운 것은 **근거의 위조**다. 검수·마스터 두 층은 `source` 의 인용을 신뢰해 통과시킨다.
  이 회차의 다른 자리에서는 작성팀이 **원문에 값이 없다는 이유로 마을 규모 선을 안 그렸고**
  (`notes.화면 문자열`) 감지 반경 가운데 셋의 라벨도 뺐다 — 같은 잣대가 여기서만 풀렸다.

**닫는 법(비용 0 · `spec` 한 칸)** — 셋 중 하나.
1. `seasonTo` 를 원문 어휘로 바꾼다: `"겨울 끝"`(원문 「겨울이 끝났고」).
2. `seasonTo` 를 지운다 — `quietwinter.js:101` 이 `if (spec.seasonTo && …)` 라 없으면 안 그린다.
   시간 띠가 끝까지 차는 것만으로 「겨울이 지나갔다」는 읽힌다.
3. 원문에 「봄」이 실재하는 다른 근거를 제시한다(내가 못 찾은 것이면 줄 번호와 함께).
**어느 쪽이든 `source`·`notes` 의 인용문을 같이 고칠 것.** 자막·TTS·`delayMs` 는 안 움직인다.

## 🔴 반려 ② S3 `latch` 의 `seed 157` 이 **`lf02 S5` 와 같다** — 파형이 사실상 동일

작성팀 `sfx.why`(S3)의 단언:
> 「작성 시점에 전수를 다시 세니 쓰인 seed 는 **16건**이었다 — … 139(lf01 넷) · **179(lf02)**.
>  **157 은 그 목록에 없다.**」

**전수를 다시 훑은 결과 이 열거가 틀렸다.** `lf02` 의 latch 는 넷이고 seed 는 **157·163·167·179** 다.
그리고 `lf02` 자신의 `why` 가 그 넷을 그대로 적어 두고 있다:

```
$ node -e "(episodes/**/scene.json 의 shot.sfx 전수)"
lf02 S5  latch dur=0.16  seed=157 gain=0.062 delay=560
lf02 S11 latch dur=0.19  seed=163 …
lf02 S18 latch dur=0.14  seed=167 …
lf02 S19 latch dur=0.2   seed=179 …
ep13s-1 S3 latch dur=0.135 seed=157 gain=0.06 delay=2070      ← 충돌
```
```
lf02 S5 why: "…이 회차의 latch 넷은 157·163·167·179 이고 리포에서 쓰인 적이 없는 값이다…"
```

### 재는 방법과 실측 (같은 쌍이 검수/마스터에서 갈렸던 전례 때문에 절차를 적어 둔다)

- `synth(kind, opts, 44100)` 을 **씬의 실제 인자로** 호출해 Float32Array 를 얻는다.
- **절대 표본 정렬**로 상관을 낸다 — 짧은 쪽 길이만큼 앞에서부터 그대로 맞춘다.
  🔴 정규화 위치로 리샘플하면 같은 seed 쌍이 −0.02 로 나와 검출이 안 된다.
- `KIT.latch`(`sfx.mjs:73-84`)는 몸통이 **340/680Hz 고정**이고 개성은 `rng(o.seed ?? 7)` 하나에서만
  나온다. 클릭 전이는 `r() * exp(-260·t)` 라 **`dur` 과 무관하게 seed 만으로 결정된다** —
  즉 `dur` 을 0.16 → 0.135 로 바꿔도 앞 15ms 는 표본 단위로 같다.

| 쌍 | 전체 겹침 구간 상관 | 클릭 전이(앞 15ms=662표본) | 앞 662표본 최대 절대차 |
|---|---|---|---|
| **ep13s-1 S3 ↔ lf02 S5 (둘 다 seed 157)** | **0.9963** | **0.9982** | **0.0143** |
| ep13s-1 S3 ↔ ep10s-3 (seed 103) | 0.7095 | 0.6963 | 0.4838 |
| ep13s-1 S3 ↔ ep13s-2 S3 (seed 191) | 0.7444 | 0.7325 | 0.3547 |
| ep13s-1 S3 ↔ lf02 S11 (seed 163) | 0.7506 | 0.7419 | 0.4830 |
| (기준선) 서로 다른 seed 쌍 10개 | 0.71~0.78 | 0.70~0.76 | 0.34~0.48 |

**0.9963 은 기준선 대역(0.71~0.78) 밖의 유일한 값**이고, 앞 15ms 최대 절대차가 0.0143(다른 쌍은 0.34~0.48)
이라 **귀로 구별할 수 없다.**

**성격까지 겹친다** — 인자 복사의 방증이다.
- `lf02 S5 why`: 「게이트 386 칸이 마지막으로 **걸려 잠기는** 자리」
- `ep13s-1 S3 why`: 「무덤이 **그 자리에 걸려 앉는** 순간 … 유일하게 되돌릴 수 없게 된 것」

**닫는 법(비용 0)** — `seed` 를 전수에 없는 값으로 바꾼다. 현재 쓰인 값 전수:
`7(기본) · 11(sweep 기본) · 23 · 29 · 37 · 41 · 43 · 53 · 61 · 67 · 71 · 79 · 83 · 89 · 97 ·
101 · 103 · 113 · 127 · 131 · 137 · 139 · 149 · 151 · 157 · 163 · 167 · 173 · 179 · 191`.
`seed` 는 파형 길이를 안 바꾸므로 **`delayMs`·자막·TTS 가 전부 그대로**다.
🔑 `tick` 쪽은 문제 없다 — `(dur 0.038 · freq 560)` 은 전수에 없고 가장 가까운 후보들과의
상관이 −0.09 ~ −0.25 다(파형 대조로 확인).

### 어디가 어긋나는지 (내가 좁혀 둔 것)

- 어긋나는 프레임: **20,967ms ~ 25,200ms** — 전부 **S3(`chase`)** 안이다(S3 = 20,943~28,148ms).
  첫 프레임 f629 + 그 뒤 `f % 3 == 0` 프레임들.
- 세 패스 중 **전진·역방향은 서로 일치하고, 3칸 건너뛰기 패스만 다르다.**
- 어긋나는 것은 **캔버스 픽셀**이고 DOM(자막·transform)은 일치한다.
- f720(24,000ms)에서 픽셀을 직접 떠서 행별로 세면 **어긋난 2,653px 이 전부 세 자리에만 있다**
  (캔버스 배율 2.7557 로 환산한 코드 y):

```
코드y≈82:  451px      코드y≈85:  455px     ← chase.js SPLIT_Y = 84
코드y≈124: 417px      코드y≈127: 442px     ← chase.js TOP_RULE = 126
코드y≈274: 431px      코드y≈277: 437px     ← chase.js BOT_RULE = 276
```

- 값의 차이는 `(255,255,255,a)` 의 **a 가 21 ↔ 19** — `tone('track')`(흰 0.12, a≈31)로 그린
  **`dashRule()` 세 줄의 안티에일리어싱**이다. 다른 요소는 한 픽셀도 안 어긋난다.

즉 `chase.js:48-55` 의 `dashRule`(`setLineDash([7,7])` + `lineDashOffset = -(t*speed)%14`)이
**같은 `t` 에 대해 그리는 순서에 따라 다르게 래스터화된다.** `chase.js` 만 이 회차에서
`dashRule` 을 **세 번**(speed 9 / 12 / −10) 부르고, 다른 넷은 두 번씩 부른다.

### 왜 그냥 못 넘기나

`notes.그림 설계 — 클립·복제·폰트` 가 이렇게 단언한다:
> 「`Math.random()` · `Date.now()` · 이전 프레임 기억 · CSS 전환이 다섯 파일 어디에도 없다.
>  … **같은 `t` 면 같은 그림이다.**」

**실측이 이 문장을 반증했다.** 결정성은 이 프로젝트의 1번 규약이고(`check.mjs:692` 주석)
mp4 추출의 전제다. 지금 판본은 「전진 렌더면 자기 일관성은 있다」 수준이지 규약을 만족하지 못한다.

**요구** — 원인을 찾아 닫고, 30fps 에서 0 이 되는 것을 보여 달라. 시도해 볼 순서 제안:
1. `dashRule` 의 `lineDashOffset` 을 **양수 유한 구간으로 정규화**한다
   (`((-(t*speed)) % 14 + 14) % 14` — 지금은 음수 mod 라 값이 −14~0 을 오간다).
2. 그래도 남으면 세 줄의 `speed` 중 `9`(SPLIT_Y)를 다른 값으로 바꿔 재현 여부를 가른다.
3. 그래도 남으면 `dashRule` 대신 세그먼트를 직접 그린다(`setLineDash` 미사용).
🔑 **자막·`delayMs`·TTS 는 안 건드린다.** 확인 명령은 `node check.mjs ep13s-1 --fps 30`.

## 🟡 정정 요구

### 1. `delayMs` 두 값을 실측으로 다시 풀었다 — 갱신 요망 (둘 다 허용선 안)

실측 `timed.json`(`rel = dur + pauseAfter`) 기준. 창 `W = lead + rel × span`,
진행도 p 인 시각 = `자막시작 + p×W − lead`(`engine/engine.js:396`).

| 자리 | 문턱 | 실측 `rel` | `W` | 정확한 `delayMs` | 현재 값 | 오차 |
|---|---|---|---|---|---|---|
| S2 `tick` (at 0) | `emptyland.js:100` `walk=ease(c/0.74)` → **c=0.74** | 4,052+250 = **4.302s** | 0.15+4.302×0.85 = 3.8067 | **2,667** | 2,790 | **+123ms (3.7프레임)** |
| S3 `latch` (at 1) | `chase.js:218` `seat=ease((c1−0.72)/0.16)` → **c1=0.72** | 3,585+250 = **3.835s** | 0.15+3.835×0.75 = 3.0263 | **2,029** | 2,070 | **+41ms (1.2프레임)** |

작성팀이 쓴 산정 `rel`(4.489 / 3.911)이 실측(4.302 / 3.835)보다 각각 4.3% · 2.0% 길었다.
둘 다 판정선 ±20프레임(667ms) 안이라 **반려 사유는 아니다.** 다만 작성팀이
「실측이 나오면 반드시 다시 풀 것」이라고 두 곳에 못 박아 뒀으므로 그 약속을 여기서 닫는다.

### 4. 그림 대조표에 **롱폼 `lf01` 행이 없다** (도형 판정 자체는 통과)

`writer.md` §4 의 대조는 `ep12s-1/nextpeek` 한 줄뿐이고, 형제 둘은 「작성 시점에 없었다」로,
롱폼은 아예 언급이 없다. 그런데 **`lf01` 이 이 사건을 이미 그렸다**:

| `lf01` kind | 무엇을 그렸나 | `ep13s-1` 의 같은 소재 |
|---|---|---|
| `threshold.js` | `FLEE THRESHOLD` + **12 · 10 · 8** 을 둥근 사각 상자 셋 + 연결선으로 | `chase.js` 임계값 행 |
| `gravemark.js` | 무덤 = **원** + `GRAVE` + 이름표 자리 + 퍼지는 흔적 링 | `firstgrave.js`·`chase.js` 표석 |
| `nearest.js` | 밭 사각 + 사람 여섯 + 도착 지점에서 **퍼지는 거리 링** | `emptyland.js` 감지 반경 원 |

**내가 실물로 대조한 판정: 통과.** 도형이 갈린다 —
`threshold` 는 상자+연결선이고 `chase` 는 숫자+직접 그린 화살표(지나간 수는 흐려진다) /
`gravemark` 는 원이고 이 편은 세로 표석+받침+가로 홈 /
`nearest` 의 링은 **늑대에서 퍼지는 거리 규칙**이고 `emptyland` 의 원은 **사람마다 다른 감지 반경**(정지)이다.
형제 둘의 `kinds/` 도 파일명 교차 확인 결과 겹치는 것은 구조 역할명(`intro`·`nextpeek`)뿐이고
`nextpeek` 셋은 도형이 전부 다르다(격자+한도선 / 시계 호 되감기 / 창고 칸 분산).

→ 고칠 것은 **그림이 아니라 대조표**다. 다음부터 표에 형제 편 행과 롱폼 행을 넣을 것.

### 5. 영어 자막 S2 — 「도망」이 사라졌다

`text` 「근데 늑대는 정한 자리로만 가고, **주민은 도망치거든요.**」
→ `en` 「But a wolf only walks to the spot it picked. **Villagers don't stay there.**」

두 문장으로 가른 구성과 시제(현재형 = 지금도 도는 규칙)는 좋다. 다만 `don't stay there` 는
**이 편의 핵심어(flee)를 지운다** — 영어 제목이 스스로 `I never planned for fleeing` 이라 쓰고,
`en.blurb` 도 `villagers flee the moment they detect a wolf` 라 쓴다. 자막만 약하다.
제안: `Villagers flee the moment they spot one.` (2줄 상한 안, 사실 추가 없음)

### 브리프를 뒤집은 판단 (코디네이터 지시 ③) — **옳다**

브리프가 이 편의 ③남는 한 줄로 배정한 것은 「늑대를 만드는 시간보다 물게 만드는 시간이 더 길었다」였고,
작성팀이 그 자리를 직전 편의 약속(무덤)에 줬다. **이 판단을 지지한다.**

1. **약속은 되돌릴 수 없다.** `ep12s-3` 은 이미 업로드돼 시청자가 봤다. 브리프 자체가 §0-B 에서
   「13-1편이 진다 · **훅과 착지 양쪽에서** 이행한다」고 못 박았고, 착지 예시 문장까지 적어 뒀다.
   즉 **브리프 안에서 §0-B(약속)와 「사건 1의 ③」이 서로 경합했고**, 작성팀은 §0-B 를 골랐다.
2. **③의 자격을 안 잃었다.** 「첫 무덤」도 어긋난 상태(부상자 0)가 뒤집힌 뒤에 남는 문장이고,

3. **길이 산수가 맞는다.** 둘 다 넣으면 본문이 6줄이 된다. 현재 본문 5줄에 18.8초이고
