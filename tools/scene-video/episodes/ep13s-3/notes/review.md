### 5-C. 그림 — 뜻을 나르는가 · 회차 안 되받기 · 형제 편 돌려막기

기본 도형 한 문장(**「끝 눈금(사망)을 향해 한 줄 위를 나아가는 표식 하나」**)이
여섯 그림을 관통한다. 스틸로 확인한 결과 `reads` 는 전부 빈말이 아니다.

| 스틸 | 확인한 것 |
|---|---|
| `8.62s` (SH) | 바늘이 되감기고 잔상 두 겹이 쌓였는데 **12시 「사망」 눈금은 안 켜진다.** 눈금(r 93~107)과 고리(r 70) 사이가 실측 23px 떠 있어 "닿았다"로 안 읽힌다 |
| `12.5s` (S1) | 위 강조색 「간호→하루」 2/3, 아래 흰 「방치→하루 반」 끝까지, 그 차이에 「반나절」 브래킷. **길이가 곧 수치**라 세 수가 서로를 설명한다 |
| `14.67s` (S2 자막0) | 「간호」 칩이 표식 곁에 앉고 채움은 62% |
| `17.4s` (S2 자막1) | 통행인이 표식 밑을 지나간 직후 **되감기 화살표 + 「되감기」 + 「0.1초」**, 표식은 처음으로 돌아가 있다 |
| `21.26s` (S3) | **14.67s 와 딱 한 가지만 다르다** — 되감기 대신 「멈춤」 막대. 「한 줄만 고쳤다」가 그림으로 읽힌다 |
| `24.86s` (S4) | 채움이 「하루 반」에 처음 닿고 표식이 꺼진 자리에 무덤. 무덤 바닥 y735 ↔ 끝 눈금 위 y755 = **19px 공백, 혼합 픽셀 0** |
| `26.36s` (S4) | 「마을의 마지막 날 / 아무도 남지 않았다」 카드. 수가 한 개도 없다 |
| `30.34·30.74s` (SO) | 공용 창고 → 개인 칸 넷. 강조색 칸 바닥 ↔ 흰 주민 원 위 **가시적 공백** |
| `33.6s` | 아웃트로 카드 — 훅 2줄 · 「M10 야생 위협과 방랑자」·3편 중 3편 · 형제 3줄(13-3 강조) · 「다음 편 · 14편 · 마을 한복판의 공용 창고를 지웁니다」 |

**겹침 감사 — 두 축으로 봤다.**
- 강조색↔흰: `24.86s` 의 무덤/끝 눈금 접점을 픽셀로 직접 훑었다(1080×1920 raw RGB).
  강조 마지막 행 y=735 · 흰 첫 행 y=755. 그 사이 X 로 잡힌 픽셀은 전부 `(0,29,15)`·`(0,38,20)`
  = **강조색 후광의 감쇠**이지 흰↔강조 혼합이 아니다.
- 흰↔흰(`ep12s-1` nextpeek 반려 계열): `nextpeek` 의 흰 요소는 「공용 창고」 상자(y 86~148)와
  주민 원 넷(y 203~225)뿐이고 **위상으로도 갈려 있다**(연결선 알파 0 = u 0.30, 개인 칸 시작 = u 0.36).
  「개인 소유」(강조, baseline 254)와 주민 원(바닥 225) 사이 15px. 스틸 두 장에서 뭉갬 없음. ✅

**회차 안 되받기** — S2 되감김 → S3 붙들림 → S4 도달. 셋이 같은 x(홈의 62%)에서 다른 결말을
맞으므로 「뒤집기」 조건을 만족한다. 훅(원)과 S2(가로 홈)가 둘 다 되감는 것은 작성팀이
스스로 신고한 자리인데, **도형(원 vs 가로)·배우 유무(없음 vs 간호 칩+통행인)·맡은 말
(증상 vs 원인)** 셋이 갈려 있어 통과로 본다. 원문이 「죽음의 시계」라고 직접 이름 붙였으므로
훅을 원으로 만 것도 지어낸 은유가 아니다.

**⚠️ 형제 편 돌려막기 — 무덤 표석 (마스터 판단 참고, 내 판정은 통과)**

`ep13s-1/kinds/firstgrave.js` 도 강조색 표석을 세운다. 두 스틸을 나란히 봤다:

| | ep13s-1 `firstgrave`(훅) | ep13s-3 `lastday`(S4) |
|---|---|---|
| 도형 | **받침 + 가로 홈이 있는 비석 실루엣**(T 자), 폭 18 | 받침·홈 없는 **둥근 머리 슬래브**, 폭 24 |
| 무대 | 마을 띠 안, 흰 사람 표식 5개 사이 | 가로 진행 홈의 **끝 눈금 자리** |
| 역할 | **그 편의 페이오프 그 자체** | 도달→표식 소멸→카드로 가는 **한 박자** |
| 라벨 | 「처음 생긴 무덤」 | 「무덤」 |
| 자막 | 훅이 「무덤」을 직접 부른다 | **자막이 한 번도 안 부른다**(`excluded[1]` 이 명시) |

공유되는 것은 **장치가 아니라 요소 하나**(표석)이고, 원문이 두 자리 모두에서 무덤을 직접
말한다("죽은 자리에는 무덤이 하나 남습니다"). `excluded[1]` 이 13-1 의 몫임을 인정하고
**그림에만 남기는** 처리를 이미 했다. → **반려하지 않는다.**
단 작성팀 대조표에 형제 편 행이 없으므로 §6-11 로 정정 요구한다.

**형제 편 kind 이름 전수**: 13-1 `firstgrave·quietwinter·emptyland·chase` /
13-2 `twoends·written·notch·overrun` / 13-3 `deathclock·twotracks·graze·hold·lastday`
→ **이름 겹침 0**(`intro`·`nextpeek` 은 4단 구조가 정한 역할 이름). 13-2 `overrun`(이산 칸 나열 +
한도 선)과 13-3 의 빗금 채움 막대는 스틸로 대조했고 다른 그림이다.

### 5-D. ⚠️ 인트로 브랜딩의 영문 (트랙 층위 · 이 편 반려 사유 아님)

`engine/intro-brand.js:22` `const LINES = ['$ claude code', '> build my village', 'placing...'];`
`$ claude code` 는 실제 CLI 명령(ⓐ 인용/ⓒ 고유 기술명)이지만 `> build my village` ·
`placing...` 은 **리포에 실재하지 않는 의사 터미널 문구**다. 개정 ADR-V-10 의 잣대
(「한국어로 옮기면 뜻이 상하나?」)를 그대로 대면 상하지 않는다.
다만 ADR-V25-11 이 **인트로 그림을 시리즈 공용으로 못 박았고** 13-1·13-2 도 같은 파일을
재수출하므로, 이 편만 반려하는 것은 잣대를 회차마다 달리 쓰는 것이 된다.
**사용자·마스터가 트랙 단위로 한 번 정할 자리**로 올린다.

### 5-E. 아웃트로 카드가 페이오프를 먹었는가 — 산수로 풀었다

`OUTRO_MS = 3000`(`engine/engine.js:219`, 2,600 아님). 카드 시각 = 35,133 − 3,000 = **32,133ms**.
SO 샷 시작 32,344… 아니라 **28,344ms** 이므로 카드는 **SO 안 3,789ms 지점**에서 뜬다.

- SO 자막 0(예고) 구간 = 0 ~ 3,972ms → **카드는 예고 자막이 끝나기 183ms 전에 뜬다.**
- SO 자막 1(소개, rel 2,467ms < 2.65초) → **소개 줄 전체가 카드 뒤에 있다.**
  🔑 그런데 `nextpeek` 은 **cue 1 에 아무것도 안 걸었다**(파일 머리 주석 41~42행이 그 이유를 명시).
  즉 카드가 덮는 구간에 그려지는 페이오프가 **없다.**
- 미리보기 완성 시각: `pk = ease(cue(0, 0.15, 0.30))`, W = 0.15 + 3.972×0.30 = **1.342초**
  → 자막 시작 +1,192ms 에 pk = 1. 카드까지 **2,597ms = 0.5초 루프 5.2회**가 온전히 보인다.
  스틸 `32.1s.png`(카드 33ms 전)에 미리보기가 그대로 있다. ✅
- 🔑 **이 편의 페이오프(끝 눈금 도달 → 무덤 → 마지막 날 카드)는 S4 에 있고 S4 는 마지막 샷이 아니다.**
  `ep08s-3` 반려 형태(마지막 샷에 페이오프 + 짧은 마지막 자막)를 구조적으로 피했다. ✅
  여유 = S4 종료(27,994ms) → 카드(32,133ms) = **4.1초**.

### 5-F. 말과 그림이 같은 순간에 도착하는가 — `t` 로 도는 값까지 풀었다

`kinds/*.js` 를 열어 **자막 인덱스가 아니라 조건이 참이 되는 시각**을 초로 환산했다.

| kind | `t` 로 도는 것 | 사건을 지는가 | 판정 |
|---|---|---|---|
| `deathclock` | `frac(t/1.5)` 바늘·`floor(t/1.5)` 잔상 | **진다**(되감기) | 훅 자막 한 줄이 4.51초를 통째로 덮고, 되감기는 t=1.02·2.52·4.02초에 **반복**된다. 특정 낱말에 물릴 사건이 아니라 문장 전체의 삽화 → 통과 |
| `graze` | ⚠️ `frac(since(1)/1.7)` — **`t` 가 아니다** | 진다(되감기) | §5-G 에서 초로 환산 |
| `hold`·`lastday`·`twotracks` | 점선 흐름·빗금·글로우만 | 안 진다 | 통과 |
| `nextpeek` | `frac(t/0.5)` 루프 | 안 진다(장식+정적 방지). 등장은 `cue(0)` | 통과 |

**「문턱이 없으니 안전」이라는 사유는 쓰지 않았다 — 넷 다 직접 풀었다.**

### 5-G. 효과음 — 두 축을 따로 검산했다

이 회차는 **소리 두 개**(S2 `sweep` · S4 `thud`), 일곱 샷 중 다섯이 무음.
본문 19.2초에 2개 = 초당 0.104. 기준(23초에 1~2개 · 4단 구조에서 2~3개) 안이다. ✅
S3(멈춤)에 소리를 안 단 것은 작성팀 설명대로 「아무 일도 안 일어나게 만든 것」의 표현이고,
정적을 장식으로 메우지 않았다. ✅

**① 그림 축**

- **S2 `sweep` delayMs 810 — 확정값이 맞다.** `graze.js` 의 지움은
  `wipeB = ease(clamp((q − 0.56)/0.09))`, `q = frac(since(1)/1.7)` 이고 `since(i)` 는
  `ts − rel[i].t`(`engine.js:403`)라 **`delayMs` 와 원점이 같다.**
  지움 구간 q 0.56~0.65 = `since(1)` **0.952~1.105초**, 한가운데 **1.0285초**.
  `KIT.sweep` 은 `lp × sin(πk)`(`sfx.mjs`)라 에너지 정점이 한복판 →
  정점 = 810 + 440/2 = **1,030ms**. **오차 1.5ms.** ✅ 자막 길이가 바뀌어도 안 움직인다.
- 🟡 **S4 `thud` delayMs 1,400 은 아직 어림값이다.** `lastday.js` 의 접촉은
  `runK = ease(clamp((c0 − 0.24)/0.38))` 가 1 이 되는 **c0 = 0.62**.
  실측 rel(S4 자막0) = 2,555 + 130 = **2.685초** → 창 W = 0.15 + 2.685×0.86 = **2.4591초**
  → 접촉 시각 = 0.62×2.4591 − 0.15 = **1,375ms**.
  현재 값 1,400ms 는 **25ms(0.75프레임) 늦다** — 가이드 한도(±20프레임 = 667ms) 안이라
  **반려도 재렌더 강제도 아니지만**, 작성팀이 `why` 에 적어 둔 재계산식
  `(0.62 × (0.15 + rel × 0.86)) − 150` 이 **실행되지 않았다**(반복 결함 ⑮ 계열) → §6-6.
  `KIT.thud` 는 어택 2ms·감쇠 지수 6 이라 에너지 정점이 시작에 있으므로 「시작 = 접촉」 배치가 옳다.

**② 말 축** — 줄별 wav 를 20ms 창 RMS 로 훑었다(선행 무음이 있어 「자막 시작 ≠ 말 시작」).

```
04-0wk11iy.wav (S2 자막1)  길이 2.721  말 0.420~2.180  최대RMS 0.1561
06-0121jeq.wav (S4 자막0)  길이 2.555  말 0.360~2.000  최대RMS 0.1156
```
- S2 sweep 정점 1.030초 = 말 시작 뒤 0.61초 ≈ 「**0.1초만**」을 발음하는 자리.
  그림도 같은 순간에 되감기므로 소리·그림·말이 한 사건(스침→되감김)을 가리킨다. 그 순간 RMS 는
  중간대(`+`)라 마스킹 문제 없음. 두 번째 되감기(2.73초)는 말이 끝난 뒤라 소리를 안 붙인 것이 맞다.
- S4 thud 1.400초 = 말 시작 뒤 1.04초. 낱말 「죽어요」는 1.65~2.00초라 **0.25초 앞선다** —
  한도 안이고, 「죽음이 닿는 그림」과 동시라 배치가 옳다.
  🔑 그 시각의 단기 RMS 가 골짜기(`-`)라 **마스킹이 가장 적은 자리**에 앉았다.

**③ 돌려막기 — `synth()` 를 실호출해 파형 상관을 쟀다** (파라미터 표로는 못 잰다)

재는 법(리포트에 명시하라는 지시대로): `sfx.mjs` 의 `synth(kind, opt, 44100)` 를 씬의 실제

🔴 **코디네이터가 지목한 seed 191 쌍을 반드시 쟀다**:
`ep13s-3 sweep(0.44, seed 191)` vs `ep13s-2 latch(0.17, seed 191)` → **r = 0.0020.**
같은 `rng(191)` 씨앗을 쓰지만 `latch` 는 잡음을 `exp(-260t)` 로 15ms 만에 죽이고 340/680Hz
몸통이 지배하는 반면 `sweep` 은 잡음을 0.44초 내내 저역통과시킨다 — **구조가 달라 겹치지 않는다.**


dur 0.36 은 기존 최댓값 0.34 보다 길고 freq 108 은 기존 최솟값 112 보다 낮다 —
**리포에서 가장 길고 가장 낮은 thud** 라는 작성팀 주장은 참이다.
