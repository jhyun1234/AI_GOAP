### ⚠️ 검수가 통과시킨 S2[1] 「되감겨요」 — 그 판단이 옳은지 봤다

검수 사유는 *"원문 자신이 조건절 안에서 쓴 현재형과 **같은 형태**"* 였다.
**결론은 옳고 사유는 부정확하다.** 원문의 현재형은 「-니까요」가 **앞 문장의 「그렇게 만들면」을
물려받아** 서 있고, 자막의 현재형은 **① 바로 앞 줄 S2[0] 의 「되돌리려 했어요」(의도 프레임)와
② 그 문장 안의 「-스쳐**도**」(양보 조건절)** 두 겹이 진다. 형태가 같은 게 아니라 **조건을 지는
방식이 각각 있는 것**이고, 그래서 통과다. 판정 근거:

- **완료형이 아니다.** 「되감겨요」는 현재형이고, 완료형은 「되감겼어요」다. 규칙이 금지한 것은 후자다.
- **뒤집힘이 한 줄 뒤에 온다.** S3 「그래서 되감지 말고 멈추기만 했어요」가 즉시 무효화한다.
  귀로 듣는 순서(훅 미수형 → 의도 → 결과 → 그래서 안 그랬다)에서 「출시된 빌드가 되감았다」는
  독해가 **성립할 자리가 없다.**
- 🟡 남는 위험 하나는 적어 둔다: **S2[1] 만 잘라서 보면** 현재 사실로 읽힌다. 다만 제목·훅이
  둘 다 미수형이라 자른 조각이 혼자 돌아다닐 경로가 없다. **반려 사유 아님.**

🔑 기획 브리프의 제목 후보는 완료형(「되감아 버렸거든요」, `planner.md:359`)이었다.
**작성팀이 그것을 거부하고 미수형으로 바꾼 판단은 옳다.**

## 5. 아웃트로 카드가 페이오프를 먹는가 — **다시 풀었다**

엔진 상수 실사: `SHOT_TAIL = 0.35`(engine.js:16) · `OUTRO_MS = 3000`(engine.js:219) ·
cue 창 = `[t − lead, t + **dur** × span]`(engine.js:399) 이고 그 `dur` 은
**`말하는 시간 + pauseAfter`**(engine.js:199·205) — 즉 **분모는 `rel` 이다.** 확인 완료.

`timed.json` 에서 손으로:

| 샷 | 자막 합 | +꼬리 | 시작 |
|---|---|---|---|
| S0 | 4,249 | 4,599 | 0 |
| SH | 4,514 | 4,864 | 4,599 |
| S1 | 3,601 | 3,951 | 9,463 |
| S2 | 5,817 | 6,167 | 13,414 |
| S3 | 2,861 | 3,211 | 19,581 |
| S4 | 5,202 | 5,552 | 22,792 |
| SO | 6,439 | 6,789 | 28,344 |

**TOTAL 35,133ms** · 카드 = 35,133 − 3,000 = **32,133ms** = SO 시작 +3,789ms.

- SO 자막0(예고, rel 3,972) → 카드는 예고가 끝나기 **183ms 전**에 뜬다.
- SO 자막1(소개, rel 2,467) → **소개 줄 전체가 카드 뒤**다.
  🔑 그런데 `nextpeek` 은 **cue 1 에 아무것도 안 걸었다**(파일 41~42행 주석이 이유를 명시,
  코드에도 `cue(spec.peekCue ?? 0, …)` **한 줄뿐**). 카드가 덮는 구간에 그려지는 것이 **없다.**
- 마스터 여유식 `(1−span)×rel + 0.35 − 3.0` 은 **적용할 대상이 없다** — 마지막 줄에 걸린 cue 가 0개다.
  대신 실제로 잃는 그림이 있는지로 풀었다: 미리보기 완성 = `0.15 + 3.972×0.30` = **1.342초**
  → 자막 시작 +1,192ms 에 완성, 카드까지 **2,597ms**(0.5초 루프 5.2회) 온전히 보인다.
  **스틸 `32.05s.png`(카드 83ms 전)에 미리보기가 살아 있다.** ✅
- 🔑 **페이오프(끝 눈금 도달 → 무덤 → 마지막 날 카드)는 S4 에 있고 S4 는 마지막 샷이 아니다.**
  S4 종료 28,344ms → 카드 32,133ms = **3.79초 여유**. `ep08s-3` 반려 형태를 구조로 피했다.
  **피날레인데 착지가 카드 뒤에 있을 위험이 0 인 배치다.**

## 6. 🔴 렌더 전 이행 조건

### 6-A. 어미 `-어요` 7연속을 굽는다 (재TTS 발생 · **내 판단**)

자막 10줄의 종결어미를 기계로 뽑았다:
`입니다` / **뻔했어요 · 나아요 · 했어요 · 되감겨요 · 했어요 · 죽어요 · 생겼어요** / `지웁니다` / `만나요`
→ **SH~S4 가 7연속**이다.

- `voice.json` `rules.1_어미를_섞는다` 는 **「같은 어미 2연속까지, 3연속 금지」**로 명문화돼 있다.
  7 은 규칙의 **2.3배**이고, 승인돼 나간 회차 최댓값(`ep10s-3` 의 5)을 **2 나 넘긴다.**
- 🔴 이 규칙은 게이트가 없어 한 번도 집행된 적이 없다 — 그래서 **단독 반려 사유로 쓰지 않는다.**
  다만 나는 `ep12s-3` 판정에서 **이 항목을 파이프라인 문제로 이미 승격**시켰다.

## 7. 한국어 라벨 첫 회차 — **내가 다시 셌다** (개정 `ADR-V-10`)

## 8. 효과음 — `synth()` 를 직접 돌려 파형을 쟀다

리포 전수를 코드로 다시 걷었다: **thud 20건(이 편 포함) · sweep 15건**.


  이고 **여섯 소리 사이의 상관이 전부 |r| < 0.007** 이다. 같은 seed 191 을 써도 `latch` 는
  잡음을 15ms 에 죽이고 `sweep` 은 0.44초 내내 저역통과시킨다 — 구조가 다르다.
- **thud 0.873 을 반려하지 않는 근거**: 전수 190쌍을 다시 재니 **이미 발행된 회차끼리 7쌍이
  이 값보다 높다**(최댓값 `lf01(0.16/150)–lf02(0.17/150)` **0.9904**). 0.873 은 **8위**다.
  🔴 **승인돼 나간 일곱 쌍에 안 댄 잣대를 이 편에만 댈 수는 없다.**
  (다만 이건 「이 편이 깨끗하다」가 아니라 「**리포의 `thud` 기본값 관행이 느슨하다**」는 신호다 —
