# ep15s-3 대본 3D 재작성 — 원문에서 다시 썼다

앞 편들: [`ep15s-1`](../../ep15s-1/notes/3d-rewrite.md) · [`ep15s-2`](../../ep15s-2/notes/3d-rewrite.md)
🔴 **2D 판 대본·화면은 참고하지 않았다**(2026-08-13 지시 · runbook §3-0).
정본은 개발일지 원문(`2026-08-02-unity-goap-m12-trait-vector.html` 「서비스 직업이 외딴 곳에
살아 부탁이 영구 단절되던 결함」 절)이다.

## 이 편은 넷을 고쳤다

### ① 구조 — 구 구조에서 신 구조로

`[인트로][훅]` → `[사건][정체성]`. 훅에서 「오늘 개발 일지 내용은,」(~2.3초)을 걷어낸다.
형제 1·2 가 이미 신 구조라 5부작 안에서 구조가 갈려 있었다.

### ② 원문에 있는데 2D 판이 버린 것 셋 — 되살렸다

| 무엇 | 원문 | 왜 |
|---|---|---|
| **세 시스템이 겹쳤다** | 「떠돌이 성격의 목수가 38타일 밖에 집을 짓습니다. 저번 편에서 마을을 탈중심 구조로 바꿔놨으니 주민들은 각자 자기 집 근처에서만 생활합니다」 | 목수가 멀어진 것만으로는 「왜 아무도 못 만나나」가 안 선다 |
| **반경을 왜 안 늘렸나** | 「부탁 연출이 근접을 전제로… 양쪽이 하던 일을 멈추고 서로를 마주본 채 8초간 말풍선을 주고받습니다」 | 「멀리서도 되게 하면 되잖아」에 답이 있어야 해결이 해결로 읽힌다 |
| **성격은 안 죽였다** | 「떠돌이 목수는 성격 편향 0.95 에 직업 −0.75 가 더해져 최종 0.20 — 기지에서 8타일… 정주형 목수는 여전히 최근접이라 성격 차이는 살아 있습니다」 | 이 5부작의 주제가 성격이다. 성격을 지우고 고쳤다면 그건 이 시리즈의 해결이 아니다 |

### ③ 없던 전제 하나

「부탁」이 무엇인지 한 번도 안 나온다. **집이 없는 주민이 목수에게 지어 달라고 부탁한다** —
이게 없으면 「6타일 안에서 마주쳐야 걸린다」가 무슨 말인지 모른다.

### ④ 「또 만나요」는 뺐다

게이트 「아웃트로 소개 있음」은 낱말 `개발일지|다음 편에서` 를 보므로 예고를
**「다음 편에서는」**으로 연다(줄을 안 늘린다).

## 대본 (8 → 12 줄 · 샷 일곱)

| 샷 | 몫 | 자막 |
|---|---|---|
| SH | 증상 | 목수가 이사 가자 아무도 집을 못 얻었어요. |
| SH | | 성격이 목수를 마을 밖으로 내보냈거든요. |
| S0 | 브랜딩 | Claude Code로만 만드는, 스스로 생각하고 행동하는 AI 마을 개발일지 |
| S1 | **전제** | 집이 없는 주민은 목수한테 지어 달라고 부탁해요. |
| S1 | | 그 부탁은 6타일 안에서 마주쳐야 걸리고요. |
| S2 | **원인** | 떠돌이 성격인 목수는 38타일 밖에 집을 지었어요. |

| S3 | 피해 | 집을 못 얻은 주민은 굶어 죽었어요. |
| S4 | 안 한 것 | 반경을 늘리면, 맵 반대편끼리 허공에 대고 말해요. |
| S4 | **해결** | 그래서 판정이 아니라 자리를 고쳤어요. 목수 집을 8타일 안으로. |
| S4 | | 그래도 정주형 목수는 더 가까워서, 성격 차이는 살아 있고요. |
| SO | 예고 | 다음 편에서는, 집 주변이 모닥불로 뒤덮여요. |

🔴 수치는 셋뿐이다: **6 · 38 · 8 타일**. 원문의 0.95·−0.75·0.20 은 안 올린다(설계값이라
30초 안에 못 세운다). 자막은 아라비아 숫자, `say` 는 「육」·「삼십팔」·「팔」.

## 무엇이 화면에 보이나 — **거리가 곧 사건이다**

🔴 2D 도형을 안 옮긴다. 이 편은 3D 가 2D 보다 유리한 편이다 — **거리가 진짜**다.
🔑 수치는 계기 막대로 띄운다(2026-08-13 지시). 다만 이 편의 수는 **거리**라 범주색이 아니라
**계기 시안**을 쓴다 — 몸·일·위협 어느 것도 아니고 「재는 것」이기 때문이다.
그 막대에는 **문턱 표시**가 있다: 6타일 자리. 채움이 그 선을 넘는 순간 부탁이 끊긴다.

| 샷 | 그림(사건) |
|---|---|
| SH | 집 없는 주민이 목수를 찾아 마을을 가로지른다. 목수 자리는 **비어 있다** |
| S1 | 주민이 목수 앞까지 걸어가 손을 뻗는다 → 목수가 따라와 집을 짓는다(`hammer`). 거리 막대는 문턱 **아래** |
| S2 | 목수가 마을을 등지고 걸어 나간다. 거리 막대가 차오르다 **문턱을 넘고**, 그 순간 프레임 밖으로 사라진다 |
| S3 | 마을. 그 주민이 목수 쪽으로 걷다가 **멈춰 선다.** 그러다 그 자리에 주저앉는다 |
| S4 | 목수가 마을 안쪽으로 되돌아와 자리를 잡는다. 막대가 문턱 아래로 내려오고, 집이 선다 |
| SO | 집 주변에 모닥불이 하나둘 늘기 시작한다 — 다음 편의 무대 |

🔑 S3 의 「걷다가 멈춰 선다」가 이 편의 결함이다. 거절당한 게 아니라 **닿지를 못한다** —
그래서 아무 일도 안 일어나는 그림이 맞다.
