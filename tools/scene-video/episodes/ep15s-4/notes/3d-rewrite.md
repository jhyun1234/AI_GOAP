# ep15s-4 대본 3D 재작성 — 무엇을 왜 이렇게 썼나

앞 편들의 판단 기록: [`ep15s-1`](../../ep15s-1/notes/3d-rewrite.md) · [`ep15s-3`](../../ep15s-3/notes/3d-rewrite.md)

🔴 **이 문서는 2026-08-13 에 통째로 다시 썼다.** 앞 판은 「2D 대본 8줄 → 11줄」이라는
**diff 로** 적혀 있었다 — 줄 세트도 샷 몫도 2D 것을 바닥에 깔고 세 줄을 얹은 것이었다.
사용자 지시는 그게 아니다: **2D 가 만들어 둔 것은 참고하지 않고, 3D 에 맞게 대본과 내용을
재구성한다.** 그래서 `scene.json` 의 `source.note` 가 적어 둔 **사슬 넷**에서 다시 뽑았다.

## 사건 (원문에서 온 것)

① 목수가 집 부탁을 **수락한 상태에서** 자기 모닥불을 짓는다
② 그때 **소유 배정을 건너뛰어** 「내 모닥불 있음」이 안 켜진다
③ 그래서 모닥불 목표가 **다시 발동**하고, 그게 부탁받은 집보다 급하다
④ 원인은 주인을 정하는 판정이 「무엇을 짓는지」를 안 보고 **「누가 바쁜지」만** 본 것

## 3D 라서 새로 되는 것 셋 — 이게 대본을 정했다

1. **모닥불이 실제 소품이다**(`village._fire_pit` + `village.flame`). 하나씩 늘면 정말 덮인다.
   2D 는 이걸 도형 반복으로밖에 못 했다.
2. **되풀이가 몸짓이다** — 다 짓고 **돌아서서 또 짓는다.** 「또」가 사람의 등으로 보인다.
3. 🔑 **지은 개수와 「내 불 있음」을 한 프레임에 나란히** 놓을 수 있다. 불은 느는데 막대는
   바닥이다 — 무한 건축의 원인이 우선순위가 아니라 **셈**이라는 것을 그림 하나가 말한다.
   **2D 판에는 이 자리가 아예 없었다.** ②를 자막으로만 때우던 것이 여기서 그림이 됐다.

## 줄마다 무슨 몸짓 · 어느 크기

| 자막 | 크기 | 몸짓 |
|---|---|---|
| 뒤덮였어요 / 짓고 또 짓거든요 | 넓게 | 불밭이 여섯. 그 사이에서 **또 하나를 짓는다** |
| 부탁을 받아 놨어요 | 중간 | 주민이 손을 뻗고 말한다 → 목수가 **끄덕인다** |
| 자기 모닥불부터 짓죠 | 중간 | **돌아선다.** 주민을 등지고 빈 땅으로 간다 |
| 주인이 안 붙어요 / 없는 걸로 남아요 | 중간 | 불이 다 서는데 옆 막대가 **꼭대기 선 아래 텅** 비어 있다 |
| 돌아서서 또 짓고요 | 중간 | 옮겨 가며 또, 또. **불은 둘에서 넷으로, 막대는 그대로** |
| 급한 일이라 / 시작도 못 해요 | 넓게 → 집터 | 불밭에서 **빈 집터**로 훑는다. 자리만 그려져 있고 주민이 옆에서 기다린다 |
| 누가 바쁜지만 보고 있었어요 | 중간 | 다 지은 불 앞에서 **처음으로 멈춘다** |
| 무엇을 짓는지를 보게 하니까 | 넓게 | 막대가 한 번에 찬다 → 집터로 **뛰어가** 집을 세운다 |
| (예고) | 중간 | 마을이 조용하다. 막대가 넷 다 끝까지 차는데 **아무 일도 안 일어난다** |

🔑 「자기 것으로 안 센다」를 표시나 칸으로 안 그린다 — **행동**이 그 말이다.
🔑 해결도 값이 아니라 **멈춤**이다. 고친 것은 셈 한 줄인데 화면에서는 그가 멈춘다.

## 만들면서 잰 것 / 밟은 함정

- **불 자리를 손으로 안 적었다.** 격자를 깔고 소품 여유(0.95m)를 재서 고른다(`common._fire_spots`).
- **걷는 시간은 거리에서 나온다**(`plan_builds`). 0.85 고정으로 뒀더니 자리 간격이 제각각이라
  도착 전에 망치질이 시작됐다.
- 🔴 **`village._fire_pit` 가 돌·장작을 반환 안 했다** — 집 지붕과 같은 버그다. 부르는 쪽이
  재만 껐고, **아직 짓지도 않은 자리의 돌 테두리 아홉이 처음부터 화면에 있었다.**
  `pit_show()` 를 만들어 통째로 켜고 끈다. ⚠️ **ep15s-3 아웃트로도 같은 버그였고 같이 고쳤다.**
- 🔴 **빈 막대에 강조를 걸지 마라.** 값이 안 바뀌는데 홈이 커졌다 작아져서 **값이 오르내리는
  것처럼** 보였다. 그리고 빈 막대만으로는 초록 막대기라 **꼭대기에 선**을 그어 「여기까지
  차야 하는데」를 보이게 했다.
- 🔴 **빈 땅은 아무 말도 안 한다.** 「시작도 못 했다」를 그리려면 자리가 보여야 한다 —
  `instrument.ring` 으로 집터를 그리고, 집이 다 서면 끈다.
