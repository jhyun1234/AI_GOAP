# ep15s-4 대본 3D 재작성 — 무엇을 왜 바꿨나

앞 편들의 판단 기록: [`ep15s-1`](../../ep15s-1/notes/3d-rewrite.md) · [`ep15s-3`](../../ep15s-3/notes/3d-rewrite.md)

## 이 편은 셋을 고쳤다

### ① 구조 — 신 구조로 (3편과 같은 이유)

`[인트로] [훅]` → `[사건] [정체성]`. 훅에서 「오늘 개발 일지 내용은,」(~2.3초)을 걷어낸다.
5부작 안에서 1·2·3 과 구조를 맞춘다.

### ② 낱말 — 도형 전제 없음

여덟 줄을 훑었는데 도형을 전제하는 문장이 **하나도 없다.** 「뒤덮였어요」·「또 짓고, 또
지어요」는 3D 에서 오히려 더 참이다 — 모닥불은 이 마을에 **실제로 있는 소품**이고
(`village.flame`), 여러 개 세우면 그게 곧 「뒤덮였다」다.

### ③ 전제 — 「주인이 안 붙는다」가 왜 무한 건축이 되나

원문의 사슬은 넷이다: 부탁 수락 → 자기 모닥불 건축 → **소유 배정을 건너뜀** →
「내 모닥불 있음」이 0 → 목표 재발동 → 그게 부탁보다 우선순위가 높아 집은 시작도 못 함.
2D 판은 가운데 둘(0 이 된다 · 그래서 급한 일이 된다)을 말하지 않아 「또 짓는」 이유가 없다.

| 없던 전제 | 새 문장 | 왜 필요한가 |
|---|---|---|
| 주인이 붙어야 **가진 것으로 센다** | 「지은 사람한테 주인이 붙어야 내 불이 생긴 거예요」 | 「주인이 안 붙어요」만으로는 그래서 뭐가 문제인지 모른다 |
| 그래서 **끝나지 않는다** | 「없다고 세니까 또 짓고, 또 지어요」 | 무한 건축의 원인이 우선순위가 아니라 **셈**이라는 것 |
| 왜 집이 밀리나 | 「모닥불이 부탁보다 급한 일이라, 집은 순서가 안 와요」 | 피해(집 못 지음)가 원인과 이어진다 |

## 대본 (8 → 11 줄)

| 샷 | 몫 | 자막 |
|---|---|---|
| SH | 증상 | 집 주변이 모닥불로 뒤덮였어요. |
| S0 | 브랜딩 | Claude Code로만 만드는, 스스로 생각하고 행동하는 AI 마을 개발일지 |
| S1 | 전제 | 목수가 집을 지어 달라는 부탁을 받아 놓고, |
| S1 | | 자기 모닥불부터 짓죠. |
| S2 | **원인** | 지은 사람한테 주인이 붙어야 내 불이 생긴 건데, |
| S2 | | 그게 안 붙어서 없다고 세요. |
| S2 | | 그래서 또 짓고, 또 지어요. |
| S3 | 결과 | 모닥불이 부탁보다 급한 일이라, 집은 시작도 못 하고요. |
| S4 | **해결** | 주인을 정하는 자리가 무엇을 짓는지는 안 보고 누가 바쁜지만 봤어요. |
| S4 | | 그 하나 고치니까 목수가 집을 지어요. |
| SO | 예고 | 다음 편에서는, 숫자는 다 성공인데 볼 게 없었어요. |

🔴 이 편은 **수치가 0개**다(브리프 §6 확인). 새 문장에도 수를 안 넣었다 — 셈이 주제지만
세는 것은 「있다/없다」 하나다.
🔴 「또 만나요」 줄은 뺐다. 예고를 「다음 편에서는」으로 열어 게이트 낱말을 지킨다.

## 무엇이 화면에 보이나 — **불이 하나씩 늘어난다**

🔴 **2D 판 화면은 참고하지 않는다**(2026-08-13 지시). 표시나 칸으로 소유를 그리지 않는다 —
「자기 것으로 안 센다」는 **행동으로만** 보인다: 다 지어 놓고 **돌아서서 또 짓는다.**
이 편은 그래서 3D 로 옮겨 가장 이득을 본다. 모닥불이 실제 소품이라 정말로 뒤덮인다.

| 샷 | 그림(사건) |
|---|---|
| SH | 마을. 집 주변이 모닥불로 빼곡하다. 그 사이에서 목수가 **또 하나를 짓고 있다** |
| S1 | 주민이 목수 앞까지 와 손을 뻗는다(부탁). 목수가 고개를 끄덕이고 **돌아서서 불을 짓는다** |
| S2 | 다 지은 불 앞에서 잠깐 멈췄다가 **옆으로 두 걸음 가서 또 짓는다.** 한 번, 두 번, 세 번 |
| S3 | 집 자리는 빈 땅 그대로다. 부탁한 주민은 그 옆에 서 있다 |
| S4 | 다 지은 불 앞에서 목수가 **처음으로 멈춘다.** 그러고는 빈 땅으로 걸어가 집을 세운다 |

🔑 **되풀이가 이 편의 그림 전부다.** 다만 같은 자리에서 같은 동작을 반복하면 정적 게이트에
걸린다 — **불이 하나씩 늘고 목수가 옆으로 옮겨 가야** 한다. 늘어나는 것이 곧 사건이다.
🔑 S4 의 「처음으로 멈춘다」가 해결이다. 고친 것은 셈 한 줄이지만 화면에서는 **멈춤**이다.

## 안 바꾼 것

- 사건 하나(부탁 수락 중 모닥불 → 소유 미배정 → 무한 건축 → 판정을 「무엇을 짓는지」로).
- `youtube` · 형제 라벨 · `kind` 이름 여섯(packed·intro·sidejob·unowned·noroom·twoasks·nextpeek).
- 15-3 과의 훅 계약: 3편의 목수는 **떠나간 사람**, 이 편의 목수는 **엉뚱한 걸 짓는 사람**.
