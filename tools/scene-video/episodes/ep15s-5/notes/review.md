## 6. 말·소리·영어

### 말투 (`voice.json`)

어미 배열 = 입니다 / 없었어요 / **봤죠 · 달랐죠** / 둘은요 / 없었다 / **있었죠 · 간식뿐이었죠** /

「없었다」는 원문 직접 인용이라 존댓말로 고치면 인용이 깨진다 — 규칙의 예외 조항에 정확히 든다 ✅.
담화표지는 S2[0] 「근데」 하나 — 본문 여섯 줄에 하나면 성기지만 **가장 크게 꺾이는 자리**라 지지한다.

### 효과음 — 그림 축·말 축을 따로 검산

- 배치 **2개 / 본문 20.1초** → 밀도 대역(본문 기준 2~3개) 안 ✅. 여섯 샷 중 넷이 무음.
- `delayMs` 는 `render.mjs:114` 에서 **그 줄의 절대 시작 + delayMs** 이고, 두 사건이 모두
  `since(i)`(= 같은 원점) 위에 있다 → **작성팀의 「실측 불필요」 주장이 맞다.** 검산:

| 샷 | 그림 축 | 소리 | 말 축(wav 실측 선행 무음) |
|---|---|---|---|
| S1 riser | 채움 `since(1)` 0.20→1.38, 한가운데 **0.79** | 포락선 정점 = 595 + 0.195×1000 = **790ms** ✅ | 발화 개시 **0.390** — 소리가 말 안쪽 ✅ |
| S2 drop | 쓰러짐 `since(1)` 0.30→1.20, 눈에 드는 첫 구간 **0.555** | 어택 2ms라 시작을 맞춤 = **555ms** ✅ | 발화 개시 **0.395**, 둘째 줄이 「그냥 죽었어,」로 시작 ✅ (±0.67초 한도 안) |

- gain: riser 0.062 · drop 0.070 — 둘 다 뾰족한 kind(`tick` 0.065 / `latch` 0.071)가 아니고
  기존 drop 대역(0.034~0.076) 안이다. 피크 천장(0.46) 경고는 렌더 로그에서 마스터가 확인.
- 🟡 **형제 대조를 내가 대신 셌다**(작성팀은 폴더가 없어 못 셌고, 그 사실을 정직하게 적었다):

| 편 | 짝 | 성격(무엇을 그리는 소리인가) |
|---|---|---|
| 15-1 | drop + sweep | 끊김 + 쓸어냄 |
| **15-2** | **riser + drop** | **차오름(92→105) → 급락(105→95)** |
| 15-3 | drop + riser | 끊김 → **다가옴** |
| 15-4 | riser + thud | 다가옴/쌓임 + 닿음 |
| **15-5** | **riser + drop** | **차오름(칸이 다 참) → 급락(판정이 뒤집힘)** |

  → 쌍은 5편 중 셋이 `{riser, drop}` 이고, 그중 **15-2 와 15-5 는 순서까지 같고 성격도
  「차오름 → 급락」으로 같다.** 파라미터는 갈라 놓았다(riser 0.68/186→596 vs 0.78/260→900 =
  시작음 10.7반음 차 · drop 0.46/560→104 vs 0.60/300→66). `riser` 의 `dur 0.78` 은 **15-4 와 동일**
  (from/to 는 다름).
  **판정**: 이 편의 사건이 실제로 「차올랐다 떨어진다」이므로 kind 선택 자체는 옳고, 다른 kind 를
  고르라고 하면 소리가 사건과 어긋난다. **반려하지 않는다.** 다만 「같은 kind 를 같은 성격으로
  반복」에 해당하므로 **마스터 판단을 구한다**(정정 ⑤ — 낮추려면 `riser` 의 `dur` 만 15-4·15-2 와
  겹치지 않게 옮기는 것이 가장 싸다. `since()` 원점이라 `delayMs` 재계산 불필요).

| ③ | `recallblank.js:86` | 되받기(사라지는 계단)가 최대 실효 알파 **0.334 · 0.6 이상 0초 · 0.80초에 소멸**. `gone` 을 0.20→0.35 시작 / 0.60→1.20 폭으로 늘려 발화 뒤까지 살릴 것 | kind 파일만 |
| ④ | `notes.한국어 라벨` | 「화면 문자열 전수 열둘」이 전수가 아니다 — **HUD 챕터 칩 6종**(인트로·훅·성공 기준·뒤집힘·진단과 착지·아웃트로)이 빠졌다. 전부 한국어라 판정은 통과, **목록만 틀렸다** | notes |
| ⑤ | `notes.효과음` + 마스터 판단 | 형제 다섯이 다 나왔으니 **예약을 이행해 다시 세라**: `{riser,drop}` 이 3/5 이고 **15-2 와 성격·순서까지 같다**. riser `dur 0.78` 은 15-4 와 동일 | notes(+선택적으로 riser dur) |
| ⑥ | S3[1] `en` | 「The rest: …」 → 「The ones they mostly picked: …」 (원문은 「상위 목표 셋」) | 자막 en 1줄 |
| ⑦ | `notes.낱말` · `notes.길이` · `notes.outro.siblings` | ⓐ「로그」를 **네 번째 칸(「남긴다」)이 아니라 ①풀어쓰기**로 다시 적을 것 ⓑ「길이 — 아직 인용할 실측이 없다」는 **낡았다**(실측 나옴: 총 35.9 · 본문 20.1). `check.mjs` 출력 줄을 그대로 인용해 갈아 끼울 것 ⓒ「`outro.siblings` 는 빈 배열로 냈다」도 **낡았다** — 파일에는 코디네이터가 채운 5줄이 들어 있다. **파일이 자기 `notes` 를 부정하는 상태**(ep13s 선례)를 남기지 말 것 | notes |
