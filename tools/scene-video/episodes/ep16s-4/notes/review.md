## 🔴 2. 반려 사유 (1건)

### R-1. `youtube.blurb` 에 형제 편으로 가는 길이 없다

**증거 — 이 편의 `blurb` 마지막 줄 전문:**

```
(같은 글에서 나온 5편 중 4편)
```

시청자는 「4편」인 것만 알고 **나머지 넷을 어떻게 찾는지는 못 안다.**
`Docs` 정본과 검수 지시서가 요구하는 것은 *"1편 blurb 에 2편으로 가는 길이, 2편 blurb 에 1편으로
가는 길이"* 이고, 이 채널의 고정 형태는 **`(같은 글에서 나온 N편 중 M편 — …는 X-1편, …는 X-2편, …)`** 이다.

**선례:** 같은 사유로 `ep12s-1` 이 반려됐다. 🔴 **`outro.siblings` 카드가 생겼다고 면제된 게 아니다** —
`ep08s`·`ep10s`·`ep12s`·`ep13s`·`ep14s`·`ep15s` 전 회차가 **카드와 blurb 줄을 둘 다** 갖고 있다.
같은 다섯 쌍둥이 안의 **`ep16s-5` 도 이미 갖고 있다**:

```
(같은 글에서 나온 5편 중 5편 — 무덤은 있는데 이름이 없던 이야기는 16-1편, … 죽으면 관계까지
 지워지고 있던 이야기는 16-4편)
```

**영어 쪽에는 있다** — `youtube.en.blurb` 는 `(Part 4 of 5 from the same post.)` 로 같은 수준이지만,
한국어만 형제 지시가 0 이라는 점에서 `ep12s` 트리오와 **정확히 같은 형태의 결함**이다.

## 5. cue·`since` 물림 — `t` 로 도는 값과 파생 문턱까지 풀었다

`kinds/*.js` 다섯을 열어 **조건이 참이 되는 시각을 자막 시작 기준 초로 환산**했다.
`rel dur = wav dur + pauseAfter` · `cue(i,lead,span)` 창 `W = lead + rel×span` · `since(i) = ts − rel[i].t`.

🟢 **이 회차는 사건을 전부 `since()` 위에 세워서 「자막 길이를 바꿨더니 소리가 밀린다」가 원리적으로

### 6-A. 절대 표본 정렬 상관 (리샘플 금지 · 48kHz · gain 0.060 고정)

**`sweep` — 이 편 `{dur 0.68, seed 263}` vs 통제군 19건 · 최댓값 |r| = 0.0202**

```
 -0.0202  lf01/S6 {dur 0.50, seed 149}      0.0094  ep06s/S5 {0.44, 29}
 -0.0184  lf01/S17 {0.55, 151}             -0.0088  ep10s-3/S3 {0.60, 101}
 -0.0136  ep09s-2/S4 {0.47, 79}             0.0073  ep00i/S7 {0.64, 23}
 -0.0111  ep14s-4/S4 {0.56, 239}           -0.0072  ep16s-3/S3 {0.42, 269}   ← 형제
 …
 -0.0052  ep15s-1/S3 {0.66, 257}           -0.0039  ep16s-1/S2 {0.54, 277}   ← 형제
```

**`tick` — 이 편 `{dur 0.064, freq 2760}` vs 통제군 29건 · 최댓값 |r| = 0.1808**

```
 -0.1808  ep10s-1/S2 {0.072, 2320}
 -0.1458  ep11s/S4  {0.044, 2540}
 -0.0998  ep16s-5/S2 {0.092, 2210}   ← 형제
 -0.0775  ep00i/S9  {0.040, 2100}
  (나머지 25건은 전부 |r| < 0.03)
```

🔑 **판정선 0.85 에서 아주 멀다.** 이 편은 통과다.

- 🔴 **통제군 정화 확인**: sweep 은 `seed` 미지정 3건(ep02s·ep03s·ep04s-2·`_archive/eptest-m11`)이
  전부 **기본값 11 로 서로 r = 1.0000** 이지만, **이 편 263 과는 무관**(|r| ≤ 0.0051)이라 상단을
  오염시키지 않았다. 그래도 **「같은 호출(기본값 채운 뒤 인자가 같은 것)」이 통제군에 있다는 사실**은
  적어 둔다 — 다음 회차가 sweep 상단을 근거로 쓸 때 이 넷을 먼저 걸러야 한다.
- 🟢 **`ep16s-1` 의 seed 재시드가 실물로 반영돼 있다** — 현재 `277` 이고 **263 과 충돌하지 않는다**
  (측정 |r| = 0.0039). 코디네이터가 말한 「263 유지가 정본」이 성립한다.

### 6-B. 🔴 「진동 수(freq × dur)」 축은 **판별축이 아니다** — 통과 근거를 바꿔 적는다

코디네이터가 「tick 판정은 표 대조가 아니라 진동 수(freq×dur) 축으로」라고 지시했고
작성팀들이 이번에 그 척도를 세웠다. **재 보니 그 척도는 상관을 설명하지 못한다.**

| 진동 수 | 회차 | 이 편과의 실측 \|r\| |
|---|---|---|
| 148.2 | ep16s-2/S3 (0.095 / **1560**) | 0.0051 |
| 167.0 | ep10s-1/S2 (0.072 / **2320**) ← 진동수 최근접(−5.4%) | **0.1808** |
| **176.6** | **ep16s-4/S2 (0.064 / 2760) — 이 편** | — |
| 203.3 | ep16s-5/S2 (0.092 / **2210**) ← 진동수 최근접(+15%) | 0.0998 |
| 111.8 | ep11s/S4 (0.044 / **2540**) ← **freq** 최근접(Δ220) | 0.1458 |

- 🔴 **진동 수가 가장 가까운 것과의 상관(0.1808)이, 진동 수가 한참 먼(111.8) ep11s 와의
  상관(0.1458)과 사실상 같다.** 반대로 상관 상위 넷은 **전부 freq 2100 이상**이다 —
  줄 세우는 것은 `freq` 이지 `freq×dur` 이 아니다.
- 🔑 원인: **판정 절차가 정규화 리샘플이 아니라 절대 표본 정렬**이라, 실시간 주기를 정하는
  `freq` 가 지배하고 `dur` 은 감쇠 속도만 바꾼다. (같은 결론이 `ep16s-2` 검수에서 이미
  전수 406쌍으로 나왔다 — \|Δ진동수\| vs r 의 상관 **−0.032**.)
- 🟢 **결론은 안 바뀐다 — 이 편은 통과다.** 다만 통과 근거를 다시 쓰면:
  **freq 2760 은 기존 tick 27건 중 어느 것과도 `Δfreq ≥ 220`** 이고(최근접 2540),
  상관 상위 쌍이 나오는 대역(`Δfreq ≤ 40`) 밖이며, **실측 최댓값이 0.1808 로 판정선 0.85 에서 멀다.**
- 🔴 **`sfx.why` 와 다음 회차 지시에서 「진동 수」를 판별축으로 적지 말 것.** tick 의 실효
  판별축은 **`freq` 하나**이고, 최종 정본은 **절대 표본 정렬 상관 실측**이다.

### 6-C. 피크 천장 — 그때 그 인자로 다시 쟀다

```
sweep {dur 0.68, seed 263, gain 0.064} → 피크 0.1609 · 피크/gain 2.51 · 상한 gain 0.1829 → OK (여유 186%)
tick  {dur 0.064, freq 2760, gain 0.060} → 피크 0.4396 · 피크/gain 7.33 · 상한 gain 0.0628 → OK (여유 4.7%)
```

- ✅ 둘 다 안 걸린다. **`synth()` 반환 파형에서 쟀고 `gain` 을 두 번 곱하지 않았다.**
- 🟡 **tick 은 여유가 4.7% 뿐이다**(상한 0.0628 · 현재 0.060). 작성팀이 옛 문서의 「tick 상한 0.065」를
  베끼지 않고 **기본값을 그대로 둔 판단이 정확히 옳았다** — 0.065 였으면 천장에 걸렸다.
  🔴 **다음 회차가 이 편의 0.060 을 「안전한 값」으로 인용하면 안 된다.** 여유는 `freq`·`dur` 마다 다르다.

### 6-D. 배치·밀도·성격

- **2개 / 6샷 중 4샷 무음.** 본문 20.9초에 2개 = **0.096개/초**. 4단 구조에서 「2~3개」로 읽으므로
  ✅ 대역 안. 인트로·아웃트로 무음도 기본대로다.
- **나레이션이 부르는 사건에만 붙었다** — sweep = 「양쪽 다 지워요」(지움 한가운데) ·
  tick = 「사진만 한 장 찍고」(틀 닫힘 완성). 정적을 메운 소리 0개.
- 🟢 **S3 무음이 설계라는 주장을 지지한다.** 이 샷의 지움은 「잘못」이 아니라 「옳음」이고,

  5=tick+latch → **쌍이 겹치는 편 없음.** `why` 는 둘 다 채워져 있다.
