## 0-옛. (완료) 「애니메이션이 상황에 맞게 안 바뀐다」

사용자 판정(2026-08-13, ep15s-3 을 보고): **「애니메이션이 하나도 그 상황에 맞게 바뀌지가 않는데?」**

이게 지금 파이프라인의 **가장 큰 구멍**이고, 다음 세션의 1순위다. 아래는 추측이 아니라
코드를 보고 확인한 사실이다.

### 무엇이 문제인가 (실측)

| 지금 | 그래서 화면이 |
|---|---|
| 샷이 주민마다 **동작 하나를 통째로** 건다(`C.work(arm, job, t)` → `motions.MOTIONS[job](t)`) | 사건이 벌어지는 동안 나머지는 **똑같은 주기를 계속 돈다** |
| 동작 19종이 전부 **주기 루프**이거나 한 번뿐인 것(`reach`·`look_up`)이다 | 「알아차렸다 · 놀랐다 · 포기했다」에 해당하는 몸짓이 **어휘에 없다** |
| **아무도 아무것도 안 본다** — 머리 방향이 동작 안에 박혀 있고 사건 쪽을 겨누지 않는다 | 붉은 덩이가 옆에 와도 시선이 그쪽으로 안 간다 |
| 사건이 나면 바뀌는 것은 **자리와 동작 이름**뿐이다(work→run, walk→reach→hammer) | 「일하다 → 뛴다」는 되는데 「일하다 → **멈칫** → 돌아본다 → 뛴다」가 안 된다 |

**즉 지금 화면은 「루프 + 자리 이동」이지 연기가 아니다.** 대본은 사건을 말하는데 몸은
같은 박자로 돌고 있다. ep15s-2 의 되풀이·달아남처럼 **동작 자체가 사건인 자리**만 살아 있고,
나머지 샷은 배경이 움직이는 정도다.

### 다음 세션이 만들 것 (제안 · 순서대로)

1. **시선 타겟팅** — `motions` 위에 얹는 층. 「그 사람이 무엇을 보고 있는가」를 샷이 정하고
   목·머리 X/Z 를 그쪽으로 돌린다. 🔴 뼈 축은 실측표를 따를 것(위 뼈는 X 양수가 위).
   이거 하나로 「위험이 왔는데 아무도 안 본다」가 사라진다.
2. **반응 동작 셋** — `notice`(멈칫하고 돌아본다) · `slump`(포기하고 주저앉는다) ·
   `point`(가리킨다). 전부 **한 번뿐인 동작**이고 `_snappy` 규약을 따른다.
   🔴 새 동작은 `MOTIONS`·`CYCLE`·어휘 검사 셋을 같이 고쳐야 한다.
3. **샷이 비트마다 동작을 갈아타게** — `motions.sequence`/`blend` 가 이미 있는데 회차
   스크립트가 거의 안 쓴다. 「일한다 → 멈칫 → 본다 → 뛴다」를 비트 시트에 적고 그대로 태운다.
4. **판정 기준을 하나 더** — 자막을 가리고 봐서 **그 사람이 무엇을 느꼈는지**가 보이는가.
   지금 기준(무슨 일이 일어났는지)만으로는 이 구멍이 안 잡혔다.

🔑 **여기서 카메라·구도를 만지지 마라.** 이 프로젝트는 그 함정을 여덟 번 밟았다 —
판정이 나쁘면 **피사체**, 그다음 **동작 곡선**, 그다음 **그 순간 뭘 하는가**를 의심한다.
이번 판정은 명백히 셋째 층이다.

## 2. 밟은 함정 (같은 것을 또 밟지 마라)

| 무엇 | 어떻게 드러났나 |
|---|---|
| 뛰는 각을 손으로 적음 | 궤적 검사가 「소품을 0.39m 뚫는다」로 막았다 → **재서 고른다**(`flee_angles`) |
| 나무꾼을 집·나무 사이에 세움 | **뛰어 나갈 각이 하나도 없었다**(최선 0.04m) → 자리를 옮겼다 |
| 위험이 카메라와 주인공 사이로 옴 | 화면 절반을 덮어 정작 사건을 가렸다 → `behind()` 로 **뒤쪽**에 세운다 |
| 뛰는 시간을 1.7초로 자름 | 주민이 **프레임 안에서 멈춰 굳었다**(사용자가 잡음) → 3.4초 + 멀어지면 렌더에서 뺀다 |
| 계기를 주민에게 묶음 | 사람이 돌면 막대도 돌아 **화면에서 눕는다** → 매 프레임 머리 위에 놓는다 |
| 막대 0.8m × 여섯 | **막대 숲** → 0.42m 로 줄이고 **고르는 순간에만** 켠다 |
| 계기 알베도를 시안 고정값으로 | 노랑·자홍이 시안에 물들어 탁했다 → 알베도를 그 색에서 뽑는다 |
| 아웃트로 카메라가 새 집을 3m 앞에서 겨눔 | 집이 화면을 통째로 덮었다 |
| 모닥불을 `flame` 만 세움 | **허공에 뜬 불꽃** — 모닥불은 돌·장작·불꽃 셋이다(PROPS.md) |

## 4. 2026-08-13 (셋째 세션) — §0 을 ep15s-3 에서 실제로 고쳤다

## 5. ep15s-2 도 같은 방식으로 다시 만들었다 — 그리고 이게 **표준 절차**가 됐다

사용자 지시: 「앞으로 이런 방식으로 진행을 하게끔 해. **딱 맞춰야 한다는 강박은 갖지 말고**,
대본과 내용을 보고 **어느 정도 크기가 필요하겠다 · 어떤 제스처가 필요하겠다**를 분석하고
판단해서 만들어.」 그리고 **ep15s-1 은 이미 업로드했으므로 손대지 않는다.**

### 절차 (§4 의 것을 일반화)
1. `timed.json` 에서 줄별 시작·길이를 뽑는다.
2. 줄마다 **몸짓**과 **크기**를 판단한다. 크기 판단 기준은 「그 줄이 무엇을 보여 줘야 하는가」다 —
   수를 견주는 줄은 가깝게(막대가 안 읽히면 그 줄은 아무 말도 못 한다), 흩어짐·거리는 넓게.
3. 그 대응표를 **샷 독스트링에 그대로 적는다.** 그게 계약이고 다음 판정의 대조표다.
4. 시각은 `C.line_at(SID, i)` 로 읽고, 걷는 시간·쓰러지는 시간은 **거리와 동작 길이에서 역산**한다.
5. 굽고 **프레임을 눈으로 본다.** 이번에도 결함 절반이 게이트가 아니라 접점 시트에서 나왔다.

### ep15s-2 가 얻은 것
- **`common.startle`** — 일한다 → **멈칫하고 돌아본다** → 뛴다. 훅·본문3·본문4 가 다 쓴다.
- 본문2·3 의 죽음이 `huddle`(움츠림)에서 **`collapse`** 로 바뀌었다. 물리는 시각은
  **무너짐이 자막 안에서 끝나도록 역산**한다(`HIT_AT = DUR − COLLAPSE_DUR/RATE − 0.10`).
- 본문4 는 컷 하나로 갈린다 — 「죽은 사람 + 문턱 선이 꺼진다」 → 컷 → 「다시 돌린 마을, 여섯이 다 산다」.
- 아웃트로가 **빈자리를 향해 부르는 몸짓**(`talk`)으로 바뀌었다.

### 계기(막대)에서 새로 배운 것 — 다른 회차도 그대로 해당된다
| 함정 | 어떻게 드러났나 |
|---|---|
| 강조를 **한 막대만** 걸었다 | 그 막대의 홈까지 커져서 **값이 낮은 쪽이 더 길어 보였다**(도망 95 > 배고픔 100). `gauge_place` 가 이제 짝을 통째로 키운다 |
| 문턱 선을 **막대와 같은 색**으로 뒀다 | 채움이 선을 넘는 순간 선이 먹혀 사라졌다 — 그 순간이 사건인데. 이제 계기 시안이고 폭이 2.4배다 |
| 가까운 샷에서 막대를 **머리 위**에 뒀다 | 강조가 걸리면 0.8m 라 꼭대기가 잘렸다. 옆으로 밀고 어깨 높이에 세운다 |
| 주인공이 카메라에 **등을 돌리고** 있었다 | 훅·본문2 내내 뒤통수. 먹는 손도 무너지는 몸도 안 보였다 — 자리 각을 카메라 방위에서 역산한다 |
| 누운 몸을 **정면에서** 잡았다 | 머리가 커서 접힌 몸이 통째로 가려 **흰 공 하나**였다. 90° 돌려 낮게 잡는다 |
| 아웃트로에서 5.1m 를 걷게 했다 | 7.1초짜리 걸음인데 샷이 4.55초 — 영영 도착을 못 하고 화면 모서리에 잘렸다 |

## 6. ep15s-4 — 대본부터 사건에서 다시 뽑았다 (2D diff 가 아니라)

사용자 확인: **「2D 가 만들어 둔 건 절대 참고하지 말고, 3D 애니메이션에 맞게 대본과 내용을
재구성한다.」** ep15s-4 의 기존 3D 초안이 바로 그걸 어기고 있었다 — 「8줄 → 11줄」이라는
**diff** 로 적혀 있어서 줄 세트도 샷 몫도 2D 것을 물려받았고, `kinds/*.js` 여섯은 아직
2D 도형 코드였다.

**다시 쓴 방식** — `scene.json` 의 `source.note` 가 적어 둔 사슬 넷에서 뽑고,
**「3D 라서 새로 되는 것」이 대본을 정하게** 했다:
① 모닥불이 실제 소품이라 정말 늘어나 덮인다 ② 되풀이가 도형 반복이 아니라 **몸짓**이다
③ **지은 개수와 「내 불 있음」을 한 프레임에 나란히** 놓을 수 있다 — 원인이 우선순위가 아니라
**셈**이라는 것을 그림 하나가 말한다(2D 판에는 이 자리가 아예 없었다).

결과: 13줄 · 43.5초 · 게이트 33종 통과. `kinds/*.js` 는 전부 `scene3d.js` 재수출로 바꿨다.

### 이번에 프레임을 보고 잡은 것 — 다른 회차에도 그대로 해당된다

| 무엇 | 어떻게 드러났나 |
|---|---|
| 🔴 `_fire_pit` 이 **돌·장작을 반환 안 했다** | 재만 껐으니 **아직 안 지은 자리의 돌 테두리 아홉**이 처음부터 화면에 있었다. **집 지붕과 같은 버그다** — `village.pit_show()` 신설. ⚠️ **ep15s-3 아웃트로도 같은 버그였고 같이 고쳐 다시 구웠다** |
| 빈 막대에 **강조**를 걸었다 | 홈까지 커져서 **값이 오르내리는 것처럼** 보였다. 값이 안 바뀌는 막대는 강조를 뺀다 |
| 빈 막대만 그렸다 | 그냥 초록 막대기다. **꼭대기에 선**을 그어야 「여기까지 차야 하는데」가 된다 |
| 홈 밝기 기본값(0.06) | 연두처럼 밝은 색은 **빈 막대가 차 있는 것으로** 읽힌다 → `gauge(..., dim=)` 신설 |
| 빈 땅으로 「시작도 못 했다」를 그렸다 | 아무 말도 안 읽힌다 → `instrument.ring` 으로 **집터를 그린다**. 집이 다 서면 끈다 |
| 걷는 시간을 0.85 고정으로 적었다 | 자리 간격이 제각각이라 도착 전에 망치질이 시작됐다 → **거리에서 역산**(`plan_builds`) |

## 7. ep15s-5 — 5부작이 닫혔다

같은 절차(§5). 대본은 `source.note` 의 사건 셋에서 뽑았고, **3D 라서 새로 되는 것 셋**이 정했다:
① 「열다섯 쌍이 다 달랐다」 = 여섯이 실제로 서로 다른 일을 하는 마을(수는 자막이 진다)
② 「그냥 죽었다」 = **아무도 안 돌아보는 죽음**
③ 「로그에만 있었다」 = **쓰러진 몸 위로 떠오르는 막대 넷**(일 2% 만 바닥, 여가·배고픔·간식은 길다)

11줄 · **36.3초** — 이번 넷 중 처음으로 **길이 권장대역(31~38초)에 들어갔다.**

### 이 편이 새로 세운 것
- 🔴 **규약을 일부러 뒤집은 첫 샷**(본문2). 「사건이 나면 남이 반응한다」가 규약인데
  여기서는 **반응이 없는 것**이 사건이다 — `startle`·`watch` 를 쓰면 편의 뜻이 뒤집힌다.
  그래서 `common.all_work()` 에 `watch` 인자를 **일부러 안 만들었다.**
- 🆕 **`village.grave()`** — 낮은 흙더미 + **아무것도 안 적힌 비석.** 글자를 안 새기는 것이
  「이름이 없다」다(다음 편 ep16 의 무대). 🔑 **처음부터 조각 목록을 반환한다** — §6 의 교훈 적용.

### 또 잰 것
| 무엇 | 어떻게 드러났나 |
|---|---|
| 노는 둘의 **각** | 카메라를 정면으로 보게 두면 무너진 몸이 머리 뒤에 가려 **흰 공 하나**가 된다. 두 카메라 양쪽에서 50~70° 어긋나는 각(61°)을 재서 골랐다 |
| 막대를 0.55m 에 뒀다 | 몸에서 떠서 **뒤에 선 사람 것처럼** 보였다 → 0.30m |
| 막대 순서가 좌우 반전 | `cam_right()` 가 주는 것은 **화면 왼쪽**이다. 자막이 먼저 부르는 「일」이 맨 오른쪽에 섰다 → 부호를 뒤집었다 |
| 무덤 하나만 프레임에 | 자막이 「무덤에」라고 복수로 말하는데 하나만 보였다 → 둘 사이를 겨눴다 |
