## 0. 🔴 다음 세션이 먼저 할 것 — 「애니메이션이 상황에 맞게 안 바뀐다」

사용자 판정(2026-08-13, ep15s-3 을 보고): **「애니메이션이 하나도 그 상황에 맞게 바뀌지가 않는데?」**

이게 지금 파이프라인의 **가장 큰 구멍**이고, 다음 세션의 1순위다. 아래는 추측이 아니라
코드를 보고 확인한 사실이다.

### 무엇이 문제인가 (실측)

| 지금 | 그래서 화면이 |
|---|---|
| 샷이 주민마다 **동작 하나를 통째로** 건다(`C.work(arm, job, t)` → `motions.MOTIONS[job](t)`) | 사건이 벌어지는 동안 나머지는 **똑같은 주기를 계속 돈다** |
| 동작 19종이 전부 **주기 루프**이거나 한 번뿐인 것(`reach`·`look_up`)이다 | 「알아차렸다 · 놀랐다 · 포기했다」에 해당하는 몸짓이 **어휘에 없다** |
| **아무도 아무것도 안 본다** — 머리 방향이 동작 안에 박혀 있고 사건 쪽을 겨누지 않는다 | 붉은 덩이가 옆에 와도 시선이 그쪽으로 안 간다 |
| 사건이 나면 바뀌는 것은 **자리와 동작 이름**뿐이다(work→run, walk→reach→hammer) | 「일하다 → 뛴다」는 되는데 「일하다 → **멈칫** → 돌아본다 → 뛴다」가 안 된다 |

**즉 지금 화면은 「루프 + 자리 이동」이지 연기가 아니다.** 대본은 사건을 말하는데 몸은
같은 박자로 돌고 있다. ep15s-2 의 되풀이·달아남처럼 **동작 자체가 사건인 자리**만 살아 있고,
나머지 샷은 배경이 움직이는 정도다.

### 다음 세션이 만들 것 (제안 · 순서대로)

1. **시선 타겟팅** — `motions` 위에 얹는 층. 「그 사람이 무엇을 보고 있는가」를 샷이 정하고
   목·머리 X/Z 를 그쪽으로 돌린다. 🔴 뼈 축은 실측표를 따를 것(위 뼈는 X 양수가 위).
   이거 하나로 「위험이 왔는데 아무도 안 본다」가 사라진다.
2. **반응 동작 셋** — `notice`(멈칫하고 돌아본다) · `slump`(포기하고 주저앉는다) ·
   `point`(가리킨다). 전부 **한 번뿐인 동작**이고 `_snappy` 규약을 따른다.
   🔴 새 동작은 `MOTIONS`·`CYCLE`·어휘 검사 셋을 같이 고쳐야 한다.
3. **샷이 비트마다 동작을 갈아타게** — `motions.sequence`/`blend` 가 이미 있는데 회차
   스크립트가 거의 안 쓴다. 「일한다 → 멈칫 → 본다 → 뛴다」를 비트 시트에 적고 그대로 태운다.
4. **판정 기준을 하나 더** — 자막을 가리고 봐서 **그 사람이 무엇을 느꼈는지**가 보이는가.
   지금 기준(무슨 일이 일어났는지)만으로는 이 구멍이 안 잡혔다.

🔑 **여기서 카메라·구도를 만지지 마라.** 이 프로젝트는 그 함정을 여덟 번 밟았다 —
판정이 나쁘면 **피사체**, 그다음 **동작 곡선**, 그다음 **그 순간 뭘 하는가**를 의심한다.
이번 판정은 명백히 셋째 층이다.

## 1. 이번 세션에 끝낸 것

### 발 고정 (2본 IK) — 인계 §4-1 완료
`motions.py` 하나에서 끝났다. `walk`·`run` 이 **다리 각을 안 적는다** — 발 자리를 정하고
허벅지·정강이를 역산한다(`_gait_plan`·`_foot`·`_legs`·`_leg_ik`).
- 디딘 발 세계 이동 **0.000 m**(앞 판 최대 23.8cm) · 블렌더에서 스킨된 발바닥으로 재도
  붙어 있는 동안 프레임당 0.4mm · 땅 뚫기 −1.8mm.
- **골반 상하가 계산 결과가 됐다**(걷기 3.5cm · 뛰기 2.5cm). 발을 묶으면 다리 길이가 천장이다.
- 발 크기는 **메시를 재서** 넣었다(발목 뒤 2.5 ~ 앞 14.1cm). 뼈 꼬리를 발끝으로 알고 한 판 버렸다.
- 검사 셋: 디딘 발 이동 < 2cm · IK 가 잘리지 않음(무릎 역꺾임 포함) · 골반 가속도 < 0.016.

### 수치 계기 — 「수치가 안 보여서 밋밋하다」의 답
`instrument.gauge`(막대 슬라이더) · `gauge_mark`(문턱 표시) · `gauge_k`(수→비율, 순수 함수).
❌ 원판(다이얼)은 만들었다가 **걷어냈다** — 조각으로 원을 흉내 내면 차이가 안 보인다(판정).

**행동 수치 색표**(`palette.py`, 계기층 확장 · `MEANING` 밖이라 뜻층 예산 안 먹는다):

| 범주 | 색 | 색상각 |
|---|---|---|
| 몸(배고픔·휴식·간식·치료) | `need_body` #F1FF5C | 65° |
| 일(채집·농사·건설·수리) | `need_work` #92FF5C | 100° |
| 위협(도망·방어) | `need_threat` #FF5CE4 | 310° |
| 여가·그 밖 | `instrument` #5CF4FF | 184° |

🔴 **새 색은 셋이 한계다.** 완전 탐색 실측: 넷이면 최소 간격 29.1° 로 문턱(30°) 아래라
여가색과 성격 보라가 경계에서 서로로 잡혀 **뜻층 예산이 잘못 세어진다.** 셋이면 31.9°.
검사(`test_palette`)가 이 간격을 단언한다 — 색을 더 넣고 싶어지면 거기서 막힌다.

**강조는 대본이 정한다** — `stage.shot_lines`(=`timed.json`)에서 줄 시각을 읽어, 그 줄이
부르는 막대를 1.9배로 키웠다 되돌린다. 손으로 시각을 안 적으므로 대본이 바뀌면 따라간다.

## 2. 밟은 함정 (같은 것을 또 밟지 마라)

| 무엇 | 어떻게 드러났나 |
|---|---|
| 뛰는 각을 손으로 적음 | 궤적 검사가 「소품을 0.39m 뚫는다」로 막았다 → **재서 고른다**(`flee_angles`) |
| 나무꾼을 집·나무 사이에 세움 | **뛰어 나갈 각이 하나도 없었다**(최선 0.04m) → 자리를 옮겼다 |
| 위험이 카메라와 주인공 사이로 옴 | 화면 절반을 덮어 정작 사건을 가렸다 → `behind()` 로 **뒤쪽**에 세운다 |
| 뛰는 시간을 1.7초로 자름 | 주민이 **프레임 안에서 멈춰 굳었다**(사용자가 잡음) → 3.4초 + 멀어지면 렌더에서 뺀다 |
| 계기를 주민에게 묶음 | 사람이 돌면 막대도 돌아 **화면에서 눕는다** → 매 프레임 머리 위에 놓는다 |
| 막대 0.8m × 여섯 | **막대 숲** → 0.42m 로 줄이고 **고르는 순간에만** 켠다 |
| 계기 알베도를 시안 고정값으로 | 노랑·자홍이 시안에 물들어 탁했다 → 알베도를 그 색에서 뽑는다 |
| 아웃트로 카메라가 새 집을 3m 앞에서 겨눔 | 집이 화면을 통째로 덮었다 |
| 모닥불을 `flame` 만 세움 | **허공에 뜬 불꽃** — 모닥불은 돌·장작·불꽃 셋이다(PROPS.md) |
