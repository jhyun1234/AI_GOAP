## 3. 확정된 규칙

**그림**
- 형상은 그 물건처럼. 동그라미≠무덤. **비석·사람·모니터**로 그린다.
- 주인공은 화면의 36~71%. 옛 동그라미는 16% 였다(가이드 최소 40% 위반).
- 채운다. 검정 배경의 3px 윤곽선은 무게가 없다.
- 파낸 홈은 **`destination-out`**. `PALETTE.bg`(#0E1117)로 칠하면 경계에서 팔레트 위반 색이 난다.

**사람** — 8두신 정준(Loomis). 바닥 0 · 정수리 1 기준
- 턱 .875 · 어깨 .833 · 가슴 .750 · 허리 .625 · 사타구니 **.500** · 무릎 .250 · 발목 .055
- 너비(머리 높이 배수): 어깨 2.33 · 가슴 1.75 · 허리 1.20 · 골반 1.45 · 머리 0.72
- **관절이 핵심.** 팔 어깨–팔꿈치–손목, 다리 골반–무릎–발목 **두 마디**.
  한 마디 막대는 각도를 줘도 「기울어진 막대」다.
- 얼굴·손가락 금지(`MINIMAL_DESIGN_LANGUAGE:838`). 못 그리는 것은 **구도로 가린다**
  (손목을 키보드 뒤로).

**움직임**
- 깊이는 배율이 아니라 **시차**. 카메라를 z 로 움직여라.
- 사건으로 그린다(상태 나열 금지). anticipation → 스냅 → 오버슛.
- 무한 루프 금지. 정적 3초 게이트는 **사건**이 넘긴다. 카메라가 움직이면 원리적으로 안 걸린다.

**하지 말 것 (전부 실물로 확인하고 되돌림)**
- ❌ 촬영 박자 양자화(`shot.step`) — 렉으로 읽힌다. 손그림 on 2s 는 **매 스텝이 다른 그림**이라 성립한다.
- ❌ 반전 플래시 / 집중선 — 눈이 아프다.
- ❌ 2D 확대로 「가까워짐」 표현 — 「커졌다」로만 읽힌다.
- ❌ 지평선 쪽을 밝게 깐 지면 — 바닥이 아니라 **회색 벽**이 된다.

## 4. refs.mjs — 눈대중을 안 남긴다

```bash
node tools/scene-video/refs.mjs plan <회차>       # ⭐ 이것 하나면 된다
node tools/scene-video/refs.mjs add <url> --ep <회차> --tag walk
```
`plan` 이 하는 일 — **회차마다 자동으로**:
① `shot.motions` 선언과 `kinds/*.js` 가 실제로 쓰는 동작을 **대조**한다(어긋나면 게이트가 멈춘다)
② 그 동작의 레퍼런스가 없으면 `MOTIONS[tag].q` 로 **자동으로 받아** 둔다
③ 우리 회차를 같은 함수로 재서 `notes/refs.md`(사람용)·`notes/refs.json`(게이트용)에 남긴다
`publish.mjs --prepare` 가 렌더 뒤 `check.mjs` 앞에서 이걸 부른다 — 손으로 안 불러도 돈다.
남의 영상은 리포에 안 담는다(`.gitignore refs/*/ref.mp4`).

🔴 `reads` 낱말은 **힌트일 뿐 판정이 아니다.** 우리 대본은 사람 아닌 것도 걷고 앉는 것처럼
쓴다(「동그라미가 내려앉고」·「점선이 흘러 들어가고」). 판정은 **선언**이 진다.

## 5. 새 회차 점검 순서

1. `refs.mjs plan <회차>` — 동작 대조 · 레퍼런스 자동 수급 · 같은 잣대 실측이 한 번에 된다.
2. 렌더 후 **자막·HUD 를 가린 프레임 그리드**를 뽑는다:
   ```bash
   ffmpeg -i build/video.mp4 -vf "drawbox=0:0:1080:420:black:t=fill,\
   drawbox=0:1266:1080:654:black:t=fill,crop=1080:846:0:420,fps=1/1.55,scale=190:-1,tile=8x3" \
   -frames:v 1 nocaption.png
   ```
   **읽히지 않으면 그림이 틀린 것이다.** 카메라·컷·이펙트를 만지지 마라.
   (모든 `scene.json` 의 `reads` 필드가 「라벨을 다 가려도 읽힌다」고 주장해 왔는데
    아무도 검증한 적이 없었다.)
3. `check.mjs` 33종. 확대·반전으로 잉크가 화면 밖에 닿는 샷은 `checks.edge` 로 사유 선언.
