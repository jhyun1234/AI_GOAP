## 2. 🔴 먼저 풀 것 — 「이름」을 3D 로 어떻게 그리나

**이게 이 회차의 급소다.** 이 세계에는 **글자가 없다**(블렌더 쪽에 폰트가 없고, 화면에
글자를 올리는 것은 자막·HUD·아웃트로 카드뿐이다). 그런데 16s 다섯 중 넷이
**이름 · 명부 · 알림 · 기록** — 전부 글자다. 2D 판은 캔버스에 글자를 찍어서 풀었다.
**그 길이 막혔다.**

🔴 **판단을 미루고 대본부터 쓰면 안 된다.** 이름을 못 그리는 채로 쓰면 다섯 편이
전부 「자막은 말하는데 화면은 아무 말도 안 하는」 편이 된다.

### 있는 재료로 풀 수 있는 길 (제안 — 다음 세션이 판단한다)

| 대본이 말하는 것 | 3D 가 지는 방법 |
|---|---|
| **이름** | **그 사람 자체.** 사람은 하는 일 · 든 도구(도끼·곡괭이·망치·물뿌리개) · 선 자리로 이미 구별된다 |
| **「이름이 없다」** | 비석이 **비어 있고**, 무덤 곁에 **아무도 안 선다.** 누구였는지 화면에 단서가 없다 |
| **「이름을 새겼다」** | 무덤 곁에 **그 사람의 표식**이 선다 — 성격 보라(`violet`)가 이미 「성격이 닿은 자리」 색이고, 도구를 비석 옆에 세우면 「이 사람이었다」가 된다 |
| **알림 칸 · 명부** | `instrument.build(cols, rows)` 격자가 **이미 있다.** 「최신 한 건만 남아 일곱이 서로를 지운다」 = 칸이 켜졌다 곧바로 꺼지는 것 |
| **「한 명이 다 덮었다」** | 격자 칸이 **한 색으로 다 칠해지는 것** |
| **「사망 +1」** | 막대가 한 칸 오르는 것. 🔴 수(일곱 · Day 45 · +1)는 **자막이 진다** |
| **「관계가 지워졌다」** | `instrument.thread`(두 점을 잇는 실)가 **끊기는 것.** 양방향이면 실이 둘 |

🆕 **새 소품이 필요하면**: 무덤은 이미 있다(`village.grave` — 흙더미 + 빈 비석, 조각 목록 반환).
그 밖의 것은 `render_prop_look.py` 로 **주민 옆에 세워** 판정한다(축척이 늘 문제였다).

## 3. 절차 (회차 하나당)

```bash
# 0) 읽는다: 이 문서 → Docs/3D_대본_문법.md → blender3d/README.md · PROPS.md
# 1) 기획 — 사건을 **동사로** 넘긴다 (scene-planner)
# 2) 작성 — scene.json + 자막 줄 ↔ 「몸짓·크기」 표 (scene-writer)
# 3) kinds/*.js 여섯을 scene3d 재수출 한 줄로
cp episodes/ep15s-5/kinds/intro.js episodes/ep16s-1/kinds/<각 kind>.js
# 4) 목소리 → timed.json (몸짓 시각의 정본)
node tts.mjs ep16s-1
# 5) 3D 샷 — blender3d/ep16s-1/{common.py, render_hook.py, render_body*.py, render_outro.py}
# 6) 굽는다 (회차당 벽시계 4~5분)
python blender3d/bake.py --ep ep16s-1
# 7) 🔴 프레임을 **눈으로 본다** (PIL 로 접점 시트 3~5장) — 결함 절반이 여기서 나온다
# 8) 게이트 → 렌더
node check.mjs ep16s-1 && node render.mjs ep16s-1
```

회차는 `spec.frames` 를 `/3d/_intro/frames` 로 겨누기만 한다 — 다시 굽지 마라.

## 7. 먼저 막을 구멍 — 이번 5부작에서 **실제로 밟은** 것들

| 함정 | 어떻게 드러났나 |
|---|---|
| 소품 함수가 **조각 하나만 반환** | `hide_render` 로 끄면 나머지가 남는다. 집 지붕·모닥불 돌 테두리로 **두 번** 밟았다. 새 소품은 조각 목록을 반환하거나 `*_show()` 를 같이 만든다 |
| **빈 막대에 강조** | 홈까지 커져서 **값이 오르내리는 것처럼** 보인다. 값이 안 변하는 막대는 강조를 안 건다 |
| **문턱 선이 막대와 같은 색** | 채움이 그 선을 넘는 순간 먹혀 사라진다 — 봐야 할 그 순간에 안 보인다 |
| **빈 땅으로 「없다」를 그림** | 아무 말도 안 읽힌다. `ring` 으로 자리를 그리거나 사람이 기다리게 한다 |
| **누운 몸을 정면에서** | 머리가 커서 접힌 몸이 가려 **흰 공 하나**가 된다. 90° 돌려 낮게 잡는다 |
| **걷는 시간을 고정값으로** | 자리 간격이 제각각이라 도착 전에 망치질이 시작된다. **거리에서 역산**한다 |
| **`cam_right()` 를 화면 오른쪽으로 착각** | 막대 순서가 좌우로 뒤집힌다 — 자막이 먼저 부르는 값이 맨 오른쪽에 선다 |
| **`arm.rotation_euler` 를 읽어 보간** | 앞 프레임 값이 누적돼 **결정성 게이트가 죽는다.** 원래 각에서 다시 계산한다 |
| **뛰어 나갈 각을 눈대중으로** | 마을이 빽빽해서 통로가 사실상 하나다. 소품 반지름을 넣고 방위 360개를 훑어서 고른다 |
| **넓히면 빈 땅이 커진다** | 바닥(200)·마을 바깥(`outskirts`)·카메라 높이를 **같이** 넓혀야 한다 |

## 8. 판정 기준 — 굽고 나서 이걸로 본다

1. **자막을 가리고 봐도 무슨 일이 일어났는지** 보이는가
2. **자막을 가리고 봐도 그 사람이 무엇을 느꼈는지** 보이는가
3. **처음 보는 사람이 자막까지 보고 이해**가 되는가 ← 최종 목표
4. 줄마다 정한 몸짓이 **그 말을 할 때** 나오는가 (독스트링 표와 화면 대조)
