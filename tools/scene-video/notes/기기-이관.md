# 다른 노트북에서 이어서 작업하기

이 리포는 **git 이 「만드는 데 필요한 것」만 담고 「만들어진 것」은 안 담는다**(`.gitignore` 맨 위).
그래서 기기를 옮길 때 손으로 챙길 것이 넷 있고, 3.5 GB 짜리 산출물은 **다시 구우면 된다.**

🔴 **한 번에 한 기기만 `exp/palette4` 를 만진다.** 옮기기 전에 반드시 push, 시작하기 전에
반드시 pull. 이 브랜치는 워크트리 하나가 통째로 쓰는 자리라 갈라지면 합치기가 아프다.

## 5. 클로드 코드 세션 메모리

**계정이 같아도 메모리는 기기별 로컬 파일이다.** 안 옮기면 새 기기의 클로드는 이
프로젝트에 대해 아무것도 모르는 상태로 시작한다.

그래서 리포에 **`.claude/session-memory/`** 로 사본을 넣어 뒀다 — git 이 옮겨 준다.
새 기기에서 한 번만 제자리로 복사하면 된다:

```bash
mkdir -p ~/.claude/projects/D--AI-GOAP-videos/memory
cp .claude/session-memory/*.md ~/.claude/projects/D--AI-GOAP-videos/memory/
```

🔴 **폴더 이름은 「그 세션의 작업 폴더 경로」에서 나온다.** 지금은 `D:\AI_GOAP-videos`
→ `D--AI-GOAP-videos` 다. 새 기기에서 다른 경로로 열면 폴더 이름이 달라지므로,
클로드를 한 번 켜서 만들어진 폴더 이름을 보고 거기에 넣어라.

🔑 사본은 **한 방향으로만 관리한다** — 새 기기에서 메모리가 바뀌면 다시
`.claude/session-memory/` 로 복사해서 커밋한다. 두 기기가 각자 고치면 갈라진다.

세션 기록(대화 로그) 자체는 안 옮겨진다. 그래서 이 파이프라인은 **인계 문서를**
`notes/` 에 남기는 것을 규칙으로 두고 있다 — 새 기기의 첫 세션은
`notes/2026-08-13-세션-인계-2.md` 부터 읽으면 된다.
